# 内容与学时规划：八章64学时

八章共64学时，第05章为“寻优的旅程：非线性方程与数值优化”。保留现有趣味章名，以知识主题作副标题。每章4节，每节2学时；讲解、推导、实验和讨论均安排在这四节内，不另算章节或学时。按逐章列出的四节执行，不再同时采用“5—6节”的另一种计数。

各章细化到三级条目的内容结构见[教材详细目录](教材详细目录.md)。

## 范围和学时口径

第05章聚焦4个核心概念，其余各章聚焦3个核心概念；其他方法用于应用、比较或概念联系。每节的2学时同时包含必要讲解和小规模实践；长期训练、完整架构复现和选读不作为课堂最低要求。学时长度按学校规定，不直接等同于60分钟。

64学时是八章内容预算。若集中在12周，平均约5.33学时/周；若每周4学时，需要16周。若另设4周专门期中/期末审阅，应由教师明确审阅是否另计学时，或从章节预算中调剂；不能同时把64学时内容、额外审阅和每周4—5学时视为已配平。这里不预填评价材料或固定周次。

## 学生如何使用

1. 从下方进入自己的章节，按章节README和写作教程复制模板、改成本章组名前缀，再填写正文与实验；两者节号相同。A1、A2各自独立完成全章四节，不预先分小节。
2. 先填写概念、条件与运行前预测，再补代码、运行并解释真实输出。原有起步代码只覆盖部分内容。
3. 完善按四节对应的习题与解答，A/B/C在各自小组的报告副本内记录本章工作；对话仍分别记录。
4. 两份完整初稿分别核对、保存和提交，B/C提供验证与批判证据；本章六个ABC小组讨论各部分采用版本后，由D/E整合成章。每个ABC小组参与3个不同章节，分别承担A/B/C，角色轮换规则不变。

## 第05章 寻优的旅程：非线性方程与数值优化

**核心问题：** 迭代怎样从“产生一个新数”变成有依据地“接近根或极小值”？

**核心概念：** 非线性迭代、下降方向与步长、Newton型方法、非线性最小二乘。

| 节 | 内容 | 学时 |
| --- | --- | --- |
| 5.1 | 非线性方程：从夹逼到迭代 | 2 |
| 5.2 | 下降方向：往哪里走，走多远 | 2 |
| 5.3 | Newton与拟Newton：把曲率用起来 | 2 |
| 5.4 | 非线性最小二乘：从残差到参数 | 2 |

**参考：**《数值分析》第7章与《数值优化方法》第2、3、5章。原书方法较多，采用“求根→方向与步长→曲率→残差拟合”的教学顺序；Newton联系贯穿本章。

**必做深度：** 标量Newton、Armijo回溯、小型GN/LM拟合实验；BFGS说明更新结构并小规模对照。**选读：** Aitken/Steffensen、抛物线法、多项式求根、完整方程组实现、DFP/BB、Dogleg、大剩余量修正和长篇收敛证明。

**起步代码：** 四段NumPy演示分别展示Newton、一次回溯、二次模型Newton一步和指数拟合的GN/固定阻尼一步。固定阻尼一步不等于完整自适应LM，学生须补停止条件、参数更新、失败案例和实际结果。

**分工与进度：** 本章沿用第五章分组，由E1—E3共同统筹，按后四章的截止日期完成内容框架、初稿和两次修订。

填写入口：[正文](../教材/第05章-寻优的旅程/模板/模板-A组-正文.md)、[Notebook](../教材/第05章-寻优的旅程/模板/模板-A组-实验.ipynb)、[本章说明](../教材/第05章-寻优的旅程/README.md)。
