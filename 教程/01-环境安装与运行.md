# 01 环境安装与运行

推荐使用 **Python 3.12 + venv + CPU**。先安装Git和Python 3.12；下面的命令在终端运行，不能放入Notebook普通Python单元。不要直接使用系统默认的3.14来安装本仓库的固定依赖。

## Windows PowerShell

```powershell
git clone https://github.com/prince19992516/-2026.git course-2026
cd course-2026
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r 环境/requirements.txt
.\.venv\Scripts\python.exe -m ipykernel install --sys-prefix --name python3 --display-name "Python 3 (course-2026)"
.\.venv\Scripts\python.exe -m jupyterlab
```

不需要修改PowerShell执行策略。上面用完整的虚拟环境Python路径，也适用于激活脚本被禁用的电脑。后续教程中的 `python` 在此模式下替换为 `.\.venv\Scripts\python.exe`。

## macOS / Linux

```bash
git clone https://github.com/prince19992516/-2026.git course-2026
cd course-2026
python3.12 -m venv .venv
source .venv/bin/activate
python -m pip install -r 环境/requirements.txt
python -m ipykernel install --sys-prefix --name python3 --display-name "Python 3 (course-2026)"
python -m jupyterlab
```

## 第一次打开Notebook

1. 保留启动Jupyter的终端，浏览器打开其本地地址。
2. 打开 `教材/第01章-误差/实验.ipynb`，选择 `Python 3 (course-2026)` 内核。
3. 选择“Kernel → Restart Kernel and Run All Cells”，检查输出和断言。
4. Markdown单元写中文、公式与解释；Code单元写Python。`Shift+Enter` 运行当前单元。
5. 保存文件。终端中使用下列命令复核；执行结果另存，不覆盖源码Notebook。

```bash
python -m pip check
python 脚本/检查笔记本.py 教材/第01章-误差
```

## Conda替代方案

已使用Conda的同学可以替代venv；不要同时混用两套环境。先进入环境目录，确保pip相对路径一致。

```bash
cd 环境
conda env create -f environment.yml
conda activate scientific-computing-2026
cd ..
python -m ipykernel install --sys-prefix --name python3 --display-name "Python 3 (course-2026)"
python -m jupyterlab
```

## Docker替代方案

在仓库根目录运行；Windows建议使用Docker Desktop的Linux容器。镜像包含构建时的文件快照，本地改动后需重新构建；若要保存容器内编辑内容，请使用宿主目录挂载。

```bash
docker build -f 环境/Dockerfile -t course-2026 .
docker run --rm -p 127.0.0.1:8888:8888 -v "${PWD}:/course" course-2026
```

从终端复制带token的localhost链接。该挂载命令适用于PowerShell及常见POSIX shell。

## 可选深度学习环境

八章起步实验无需GPU、API密钥或网络数据。学生开始PINN/FNO扩展时，再在独立环境安装 `环境/requirements-ai.txt`；该文件提供待具体实验验证的版本起点，**不属于默认CI验证范围**。先安装主环境，再运行：

```bash
python -m pip install -r 环境/requirements-ai.txt
python -m pip check
```

GPU安装需按设备与驱动采用PyTorch/JAX官方方案，并在报告记录实际版本；不要假设本文件自动匹配所有CUDA设备。训练扩展应另提供小规模CPU测试或单独工作流，不能靠跳过单元让CI变绿。

## 依赖与常见问题

- `py -3.12` 找不到：先安装Python 3.12，或使用已安装的Conda方案。
- `ModuleNotFoundError`：检查Notebook内核与安装环境是否一致，可在单元中执行 `import sys; print(sys.executable)`。
- `No such kernel`：用当前环境Python重新执行ipykernel注册命令，关闭并重新打开Jupyter。
- `AssertionError`：查看假设、预期和输入；不要直接删除断言或扩大容差。
- 中文路径显示乱码：命令仍应使用实际中文路径；PowerShell可设置 `$env:PYTHONUTF8="1"` 后重试。
- 端口占用：运行 `python -m jupyterlab --port=8890`。

主依赖固定直接版本以保持课程接口稳定；间接依赖仍可能随安装日期变化。正式验收时保存 `python -m pip freeze`、Python版本和操作系统作为环境证据。教材工具链明确固定为Jupyter Book **1.x**，请勿单独升级到2.x后沿用旧配置。
