# 教程阅读顺序

第一次使用，从01开始。完成安装后，再学习Notebook写作和GitHub提交。

1. [01 环境安装与首次运行](01-环境安装与运行.md)：从没有装软件的电脑开始，安装Python和Git，亲手创建.venv、安装库，之后再启动JupyterLab。
2. [02 Notebook教材写作](02-Notebook教材写作.md)：写文字、公式和代码，亲自运行、核对结果、保存。
3. [03 GitHub协作与提交](03-GitHub协作与提交.md)：建立分支、提交修改、请求助教审阅。

以下按任务需要阅读：

- [05 生成与查看教材](05-生成与查看教材.md)
- [06 补装Python库与记录依赖](06-补装Python库与记录依赖.md)
- [07 B角色在干净环境复现](07-B组如何在干净环境复现.md)
- [08 目录与gitkeep说明](08-目录与gitkeep说明.md)

需要生成整本网页教材时，看[生成与查看教材](05-生成与查看教材.md)，直接使用根目录课程助手。
