# 模板使用说明

A/B/C是每章的工作角色，实际学生小组用G01、G02等编号。每组至少参与3个不同章节，分别承担过A、B、C角色；同一章的三个角色由不同小组承担。报告填写实际小组编号和本次角色；每章只交本次角色对应的报告。

八章目录已放置相应模板，不必重复创建。新增实验时复制[实验模板](A组-实验模板.ipynb)，重命名并改标题；新增教材页面还要更新 `教材/_toc.yml`。

## 开场风格：科学问题的小故事

每章从一幅插图或两至三格漫画开始，推荐顺序是：**有趣的画面 → 先猜一个结果 → 给出数学定义与推导 → 亲手运行实验 → 回答开场问题**。用具体的疑问吸引读者，再用证据回答，避免只放一张装饰图。

八章已经配有不同的导入图和问题，可在此基础上改写：

| 章节 | 开场情境 | 接回的科学问题 |
| --- | --- | --- |
| 误差的代价 | 两个大数一减，差额怎么没了？ | 浮点表示、抵消与稳定计算 |
| 逼近的智慧 | 用直边拼出弯曲的面积 | 梯形求积、步长与误差阶 |
| 离散的世界 | 连续的曲线变成一串节点 | 差分、边界条件与网格误差 |
| 矩阵的解剖 | 一个方向为何格外脆弱？ | 奇异值、条件数与扰动放大 |
| 频域的魔法 | 不同波形留下同一串脚印 | 离散采样、混叠与频谱 |
| 学习的力量 | 方程答对了，边界呢？ | PDE约束、残差与真解误差 |
| 信任的边界 | 地图画到这里，路还通吗？ | 训练范围、外推与独立验证 |
| 加速的秘诀 | 把一叠快照装进小背包 | 降阶、截断误差与计算成本 |

### 怎样把插图放进自己的章节

1. 八章现有的正文和Notebook已引用本章 `ABC共用-图片/A-章节导入.svg`，直接打开即可看到。
2. 需要新建页面时，复制[章节模板](A组-章节模板.md)或[实验模板](A组-实验模板.ipynb)到章节目录，同时复制[导入插图模板](A组-导入插图模板.svg)到该章的 `ABC共用-图片/`，命名为 `A-章节导入.svg`。如果已有同名图，使用新的、有含义的名字，避免覆盖。
3. 将复制后的正文或Notebook开头图片路径从 `A组-导入插图模板.svg` 改为 `ABC共用-图片/A-章节导入.svg`，或刚才选定的实际文件名。正文和Notebook位于章节目录时使用这一相对路径。
4. SVG是可缩放的矢量图片。可用SVG绘图工具编辑；只改文字时，也可以在JupyterLab文件列表中右键选择“Open With → Editor”，修改文字后保存，不熟悉时先复制一份。也可换成自己画的PNG漫画或照片，并同步修改引用路径。
5. 在Markdown单元写好图片说明，按Shift+Enter预览，确认文字、公式和图意都清楚，再保存。手机截图式的小字不适合教材。

### 趣味表达怎样保留科学性

开场可以有角色和对话；定义、假设、推导和结果要准确。文字说明必须让不看图的人也能理解问题。概念图明确写“示意”，真实实验图注明参数、坐标、单位及来源。不要把角色的猜测写成结论，也不要把比喻当证明。

A角色负责图文一致、来源说明及可检验的问题；B角色独立核对问题的预期和实验结论；C角色检查比喻是否隐藏条件、图片是否容易误导。相关发现写进各自已有报告即可。

图片如由AI辅助生成，记录提示词、工具、日期及人工修改，填入本章对应角色的AI对话记录。现有九幅SVG为仓库初始化助手绘制的概念示意，仍需学生结合最终正文复核与完善。
