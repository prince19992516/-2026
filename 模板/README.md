# 模板命名与使用说明

## 先分清模板、组稿和整合稿

| 文件类型 | 例子 | 谁来编辑 |
| --- | --- | --- |
| 原始模板 | `模板-A组-正文.md`、`模板-B组-验证报告.md` | 保留原件，供各组复制 |
| 小组成果 | `A1组-正文.md`、`B2组-验证报告.md` | 对应小组填写自己的副本 |
| 教材整合稿 | `整合-正文.md`、`整合-实验.ipynb`、`整合-习题.md` | 整合组汇总已确认内容 |

“模板”统一放在文件名最前面，方便识别。A/B/C是本章角色；G编号是固定的实际学生小组。每章同一角色有两组，原分组表从左到右分别叫第1组、第2组。**不能自己挑1或2**，应查[章节分工表](../协作管理/章节分工表.md)。同一A1组称呼在不同章节可能对应不同G组；需要跨章引用时，同时写章号和G编号。

例如G22在第01章叫A2组，在第02章叫B2组，在第03章叫C2组；不是永久叫A2。公开只填组别，不写姓名或GitHub账号。D1—D3、E1—E3沿用原名；第09章的组别待安排。

## 在JupyterLab里复制并改名：第一次照着做

1. 完成[环境安装](../教程/01-环境安装与运行.md)，按[Git提交教程](../教程/03-GitHub协作与提交.md)创建自己的任务分支，再启动JupyterLab。
2. 在左侧双击“教材”，进入分配给自己的章节，先读该章README里的组名表。
3. 找到本次角色的模板。例如第01章G22负责A，需要 `模板-A组-正文.md`。**右键模板 → Duplicate（创建副本/复制）**；界面不显示Duplicate时，用文件菜单的复制、粘贴。确认原件还在、同目录多了一份副本。
4. 右键新副本 → Rename（重命名）。把整个名字改为 `A2组-正文.md`，按Enter。保留 `.md`；Notebook保留 `.ipynb`。不要只改页面里的标题，不要把文件变成 `.md.txt`。
5. 按同样方法复制本角色需要的其他文件。A组6份、B组5份、C组5份，具体清单见章节README；本次只复制自己的角色。已有本组副本时直接继续编辑，不再复制一套覆盖旧记录。
6. 打开副本填写。Markdown用右键 **Open With → Editor**；Notebook直接双击。将文件内标题和基本信息改为本章组名、实际G编号与任务范围。
7. **同步副本里的链接。** 例如 `A2组-正文.md` 中 `[实验](模板-A组-实验.ipynb)` 要改为 `[实验](A2组-实验.ipynb)`。报告中的AI对话链接也改为本组文件。Notebook里的Markdown单元同样检查。不要全仓库替换，避免修改别组文件或原模板。
8. 引用其他组时，写实际目标：B2若复现第01章A1和A2，分别写两份实验文件路径和各自完整commit；不要把所有A链接都改成A2。只审一部分就明确范围。
9. 图片放本章 `ABC共用-图片/`，自己新增的图叫 `A2组-章节导入.png` 等。共用的已有导入图可以继续引用，不必每组复制。正文与Notebook均位于章目录，图片相对路径示例为 `ABC共用-图片/A2组-章节导入.png`。
10. 保存，Notebook按 **Kernel → Restart Kernel and Run All Cells** 运行并核对输出，再保存。按Git教程提交本组副本及必要图片；不要把模板运行后的偶然变化当作本组成果提交。

## 同一章的两组怎样合作

A1、A2先约定小节与实验范围，分别维护自己的文件，保留另一部分为“由另一组负责”；不要求每组重复写完整章。B1/B2、C1/C2分别保留独立证据，报告写清审阅的A/B组与版本。AI对话也分开为 `A1组-AI对话记录.md`、`A2组-AI对话记录.md` 等，不再往一个共享角色报告里追加两组内容。

整合组汇总为一份完整教材，保留来源与组别，不能直接覆盖一组的文件来冒充合并。若其他分支上已有人使用旧的 `A组-正文.md` 等名字，先保留其修改，再协调迁移到正确小组副本；不要以新模板覆盖已有工作。

## 漫画开场与科学性

前八章已有SVG导入图；第09章提供“机器人下山”的三格分镜供绘制。开场按“情境与猜想→定义与条件→推导→实际运行→回答开场问题”展开。示意图标明示意，实测图给出坐标、参数和数据来源；比喻不替代证明。AI生成图记录工具、提示词、日期、人工修改及来源。

通用模板中的 `模板-A组-导入插图.svg` 仅在本目录有效。复制正文/Notebook到章目录时，改成章内现有图片路径，或把图复制到本章图片目录并改成组名。不要留下指向模板目录中不存在文件的链接。

## 什么会显示在整本教材里

当前 `教材/_toc.yml` 使用九章模板展示结构。学生组稿创建后不会自动加入网页目录。整合完成后由整合组切换到 `整合-*` 三份文件，步骤见[04生成教程](../教程/04-生成与查看教材.md)。报告、AI对话和参考解答继续在仓库中保留，不必全部列进教材目录。
