## 运行方式

打开根目录Notebook，选择已安装的 **Python 3 (course-2026)** 内核，其注册名是`python3`，工作目录设为本文件夹，运行全部单元。本机使用课程虚拟环境，不使用其他conda解释器。

在本文件夹的终端中也可运行：

```bash
python 配套代码/experiments.py
python 配套代码/generate_figures.py
```

第一条生成网格结果、随机抽样结果、参数分组CSV及JSON；第二条读取参数分组并生成全部配图。区间比较和手选解析温度CSV由Notebook生成。移动时需整体保留子目录，重跑只更新本包，不写入旧版。

环境：Python 3.12.7、NumPy 1.26.4、pandas 2.2.3；制图使用Matplotlib与Pillow。CPU即可，无需GPU或深度学习框架。绘图使用Windows微软雅黑；其他系统重画时需更换为可用中文字体路径，阅读现成PNG不需要这些工具。

正文数表按显示位数舍入，参考解答10位小数可用绝对差不超过1e-8核对；该容差只检查复现一致性，不是可接受模型误差。
