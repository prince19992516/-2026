## ABC轮换与D/E整合

**22个小组分为16个ABC组、3个D组、3个E组。** ABC组各参与3个不同章节，分别承担A、B、C，每章每个角色各两组。D1—D3（G2、G5、G7）共同整合第01—04章；E1—E3（G10、G11、G16）共同整合第05—08章，D/E不兼任ABC。各章组别及整合任务见[章节分工表](协作管理/章节分工表.md)。

| 本章角色 | 主要工作 | 对应报告 |
| --- | --- | --- |
| A：编写 | AI辅助写初稿、代码、例题和习题；人工核验公式与引用、运行代码、补充自己的解释 | A组-编写报告.md |
| B：验证 | 先独立推导与建立预期，再用另一AI辅助，在新环境亲自复现并记录差异 | B组-验证报告.md |
| C：批判 | AI辅助寻找漏洞和反例，人工核验关键步骤、实际运行反例、记录AI陷阱 | C组-批判报告.md及C组-AI陷阱.md |

A修订后，B/C针对修改内容复测，助教根据报告与证据验收。B/C报告注明所审内容的完整commit；ABC小组按当次角色交对应报告，AI对话分别保存在本章的`A组-AI对话记录.md`、`B组-AI对话记录.md`、`C组-AI对话记录.md`。AI输出、程序能运行、网页能生成，都不能单独证明数学结论正确。

**当前是可填写的教材框架。** 每章4节、每节2学时，8章共64学时；各章正文与Notebook已细化到讲解、推导、实验和结果解释，学生直接填写即可。八个起步实验保留，完整教学内容与B/C证据仍待完成。

每章从一幅贴合主题的三格插图开始，按“情境与猜想 → 数学推导 → 代码实验 → 回答开场问题”展开。图片是概念示意，科学结论仍需推导与实际输出支撑；改写步骤见[模板使用说明](模板/README.md)。

## 安装完成后的日常使用

没有安装过的同学先完整阅读第1份教程。安装完成后，在课程根目录的PowerShell运行：

```powershell
.\course.cmd lab
```

浏览器打开后，在Notebook中写作，选择 **Kernel → Restart Kernel and Run All Cells**，亲自核对输出并按 **Ctrl+S** 保存。启动Jupyter的终端要保持打开；提交作业或生成教材时，再开一个终端进入同一课程目录。

需要整本HTML教材时，按[生成教程](教程/04-生成与查看教材.md)执行build，再执行preview。日常写作只需运行并保存Notebook。

开始写作前，先核对[章节分组](协作管理/章节分工表.md)与[截止日期](协作管理/进度安排.md)。引用与内容授权的注意事项见[写作教程](教程/02-Notebook教材写作.md#习题与来源)。
