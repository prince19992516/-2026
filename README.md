## ABC轮换与D/E整合

**22个小组分为16个ABC组、3个D组、3个E组。** ABC组各参与3个不同章节，分别承担A、B、C，每章每个角色各两组。D1—D3（G2、G5、G7）共同整合第01—04章；E1—E3（G10、G11、G16）共同整合第05—08章，D/E不兼任ABC。各章组别及整合任务见[章节分工表](协作管理/章节分工表.md)。

| 本章角色 | 主要工作 | 对应报告 |
| --- | --- | --- |
| A：编写 | A1、A2各自独立完成全章初稿、代码、例题和习题；人工核验公式与引用、运行代码、补充自己的解释 | 例如 A1组-编写报告.md，A2组另存自己的报告 |
| B：验证 | 先独立推导与建立预期，再用另一AI辅助，在新环境亲自复现并记录差异 | 例如 B1组-验证报告.md，B2组另存自己的报告 |
| C：批判 | AI辅助寻找漏洞和反例，人工核验关键步骤、实际运行反例、记录AI陷阱 | 例如 C1组-批判报告.md及C1组-AI陷阱.md，C2组另存 |

**A1、A2各自独立完成本章四节的完整版本**，包括正文、实验Notebook、习题与解答、编写报告和AI对话记录；不能预先分成两半，也不能把另一组的工作算作本组完成。两份初稿完成并经过B/C验证后，本章A1、A2、B1、B2、C1、C2共同讨论每部分采用哪组版本，必要时综合改写，再由D/E按讨论结论整合成一章。

A修订后，B/C针对修改内容复测，助教根据报告与证据验收。B/C报告注明所审内容的完整commit；ABC小组按当次角色交对应报告，AI对话按具体组别分开，例如本章的 `A1组-AI对话记录.md`、`A2组-AI对话记录.md`、`B2组-AI对话记录.md`。AI输出、程序能运行、网页能生成，都不能单独证明数学结论正确。

**当前是可填写的教材框架。** 每章4节、每节2学时，八章共64学时；各章正文与Notebook已细化到讲解、推导、实验和结果解释，学生先从本章 `模板/` 复制到 `工作/`，改为带本章组名的副本，再填写。第05章提供四段起步演示，其余七章保留各自的起步实验，完整教学内容与B/C证据仍待完成。

第05章提供待绘制的三格漫画分镜，其余七章已有三格插图，按“情境与猜想 → 数学推导 → 代码实验 → 回答开场问题”展开。图片是概念示意，科学结论仍需推导与实际输出支撑；改写步骤见[模板使用说明](教程/02-Notebook教材写作.md#模板复制与命名)。

```text
教材/           全书配置与8章；各章分为模板/与工作/
教程/           从安装环境开始的操作教程
协作管理/       公开组别、截止日期、角色规则与章节安排
阶段性评价/     期中/、期末/（仅保留空目录占位）
.github/        GitHub任务、问题和提交说明模板
course.cmd      Windows课程助手入口
course.py       课程助手：启动JupyterLab、生成和预览教材
```

每章都按下面的方式摆放，首次下载时 `工作/` 还没有小组成果：

```text
教材/第01章-误差的代价/
├── README.md          本章说明、角色分工与文件清单
├── 模板/              本章所有原始模板，供各组复制
│   ├── 模板-A组-正文.md
│   ├── 模板-A组-实验.ipynb
│   ├── ……             其余A/B/C模板
│   └── 图片/          模板自带插图或绘图说明
└── 工作/              在这里填写A1组、B2组等副本与整合稿
    ├── .gitkeep       空目录占位，不用打开、填写或运行
    └── 图片/
        └── .gitkeep   在这里放实际使用的图片
```

`工作/图片/` 最初为空；要沿用模板插图，先把它从本章 `模板/图片/` **复制**到 `工作/图片/`。所有章节采用相同结构，操作详见[模板使用说明](教程/02-Notebook教材写作.md#模板复制与命名)。

## 安装完成后的日常使用

没有安装过的同学先完整阅读第1份教程。安装完成后，在课程根目录的PowerShell运行：

```powershell
.\course.cmd lab
```

浏览器打开后，在Notebook中写作，选择 **Kernel → Restart Kernel and Run All Cells**，亲自核对输出并按 **Ctrl+S** 保存。启动Jupyter的终端要保持打开；提交作业或生成教材时，再开一个终端进入同一课程目录。

需要整本HTML教材时，按[生成教程](教程/04-生成与查看教材.md)执行build，再执行preview。日常写作只需运行并保存Notebook。

开始写作前，先核对[章节分组](协作管理/章节分工表.md)与[截止日期](协作管理/进度安排.md)。引用与内容授权的注意事项见[写作教程](教程/02-Notebook教材写作.md#习题与来源)。
