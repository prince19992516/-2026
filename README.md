## 角色轮换和每章交付

**A/B/C是工作角色。每个实际学生小组至少参与3个不同章节，分别承担过A、B、C。** 同一章的三个角色由不同小组承担。实际小组用G01、G02等编号，在章节分工表记录任务及完成证据。

| 本章角色 | 主要工作 | 对应报告 |
| --- | --- | --- |
| A：编写 | AI辅助写初稿、代码、例题和习题；人工核验公式与引用、运行代码、补充自己的解释 | A组-编写报告.md |
| B：验证 | 先独立推导与建立预期，再用另一AI辅助，在新环境亲自复现并记录差异 | B组-验证报告.md |
| C：批判 | AI辅助寻找漏洞和反例，人工核验关键步骤、实际运行反例、记录AI陷阱 | C组-批判报告.md及C组-AI陷阱.md |

A修订后，B/C针对修改内容复测，助教根据报告与证据验收。B/C报告注明所审内容的完整commit；每个实际小组按当次角色交对应报告。AI输出、程序能运行、网页能生成，都不能单独证明数学结论正确。

**当前是教材起步框架。** 8章有可运行的起步实验，正文、B/C验证Notebook及角色报告仍需要学生补充。

## 安装完成后的日常使用

没有安装过的同学先完整阅读第1份教程。安装完成后，在课程根目录的PowerShell运行：

```powershell
.\course.cmd lab
```

浏览器打开后，在Notebook中写作，选择 **Kernel → Restart Kernel and Run All Cells**，亲自核对输出并按 **Ctrl+S** 保存。启动Jupyter的终端要保持打开；提交作业或生成教材时，再开一个终端进入同一课程目录。

需要整本HTML教材时，按[生成教程](教程/05-生成与查看教材.md)执行build，再执行preview。日常写作只需运行并保存Notebook。

教学团队填写实际小组编号、章节任务、日期、参考教材和评分规则，并确认[内容授权说明](版权与引用说明.md)。
