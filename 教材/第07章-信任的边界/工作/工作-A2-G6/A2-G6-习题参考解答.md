# 7.1 开放式习题参考思路与评价要点

开放任务没有唯一数值答案。以下为可行方向，不是学生已经完成的实验；新增任务的结果须由实际运行产生。

## 任务1
应核查：目标连续、区域为单位立方体、激活连续sigmoidal、允许宽度和参数随精度改变、一致误差的量词。定理只保证存在，不直接给出训练和泛化保证。ReLU不属于该版本。评价重点是逐项核查与准确改写，而非批评AI的数量。

## 任务2
一种构造：对不同训练输入x_i，令q(x)=∏(x−x_i)，取g₂=g₁+Cq。训练点上q为零，其他位置通常不为零。可取X在[0,1]均匀、真实标签Y=g₁(X)、平方损失，此时g₁风险为零，g₂风险为C²∫q²。换真实标签规律可能改变优劣，因此结论依赖任务设定。数值积分或Monte Carlo结果须标为近似。

## 任务3
固定模型真实错误率为p，独立同分布测试下测试错误率均值为p、方差p(1−p)/m。可用配套种子固定模型p=0.124，但更换训练种子后应重新计算。一般预期测试集越大波动越小，不要求每批或有限重复均值单调改善。评价重点：固定模型、独立抽样和不混淆期望与观测值。

## 任务4
可分别在训练集和验证集选取候选模型，再用独立审计集评价。建议使用相同候选类和数据预算并重复抽样。审计误差仍只是风险估计；阈值游戏亦可直接计算真实风险。选择机制可能偏好偶然成绩好的模型，但有限样本不保证每次都出现可见偏差。不能先看审计结果再修改方案而仍称其为未使用测试数据。

## 任务5
理论半径为sqrt[ln(2M/δ)/(2n)]。固定其他因素，n增加使半径下降，M增加或δ减小使半径上升。实测量必须是全类最大绝对差距，不能只用所选模型的差距替代。零次超界不证明失败概率零。若预先比较K个设置并要求整体失败概率≤δ，可各分配δ/K并用联合界；这不是声称试验恰有δ比例失败。

## 任务6
清晰反例：Y为等概率0/1的单次随机标签，候选模型恒预测0；将同一观测复制n次。真实风险1/2，经验误差始终为0或1，绝对差恒为1/2；若把复制次数代入n，界右侧随n下降，将导致失效。例子中损失有界、类有限、边际分布相同，缺少的是独立性。无界损失案例则须区分“不能套Hoeffding”与“已构造违反该公式的反例”。

## 建议评价标准
问题与假设清楚20%；方法及代码可复现30%；图表与结果解释30%；局限、来源与AI核查记录20%。数学分析任务不强求代码；未用AI不扣分，AI参与必须如实说明。可接受负结果和与预测不同的结果，不接受虚构输出。

# 7.2 参考解答

> 对应[习题题面](A2组-7.2-习题.md)，仅7.2节。数值来自助手实际执行，仍需小组独立核对。

## 1. 按生成规则判断，而不是按成绩猜

- A是ID。训练和测试都按 $U[-1,1]$ 产生输入，答案都由同一正弦函数给出；新点不等于新分布。
- B是OOD。输入分布从 $U[-1,1]$ 变为 $U[2,3]$，尽管答案公式没有变。
- C也是OOD。输入范围不变，但左右半区的概率由各50%变成25%和75%。

测试误差小不能反推ID，误差大也不能反推OOD。ID/OOD描述生成分布的关系，误差描述模型在具体数据上的表现，是两个问题。

## 2. 抽样实验与网格实验

实验一采用种子7201、NumPy default_rng（PCG64）；预先固定三次多项式。依次独立抽取41个训练点、1000个ID点和1000个OOD点。前两组输入来自 $U[-1,1]$，最后一组来自 $U[2,3]$，答案均为 $\sin x$。

| 用途 | RMSE（10位小数） | 点集最大绝对误差（10位小数） |
| --- | ---: | ---: |
| 训练 | 0.0002893635 | 0.0006967878 |
| ID测试 | 0.0003192053 | 0.0011693338 |
| OOD测试 | 0.7391980874 | 1.4136176255 |

完整精度见[抽样结果](数据/sampled_results.csv)。实验一中的ID表现较好，不能因此保证目标OOD表现；一次随机抽样的有限结果也不是总体误差保证。

实验二使用固定网格训练与评价，是另一个重新拟合的三次多项式。其训练、区间内新点、区间外新点的RMSE依次为0.0003411224、0.0003120702、0.7273004622。它保留老师的确定性起步实验，用于观察区间变化，不能把这些固定点当作实验一的独立随机抽样样本。

实验三保持实验二的网格不变，三次、五次、八次模型的区间外RMSE分别为0.7273004622、0.1365271873、0.0149322009。当前无噪声函数中提高次数改善了外推，不代表更高次总是更好。

实验四固定实验二的三次模型，每个区间取101个等距点，得到：

原始结果见[网格实验CSV](数据/experiment_results.csv)与[区间比较CSV](数据/interval_results.csv)。相同环境与设置复跑时，可用绝对差不超过 $10^{-8}$ 核对本解答中的10位小数值。这是复现检查容差，不是模型可接受误差，也不是连续区间严格误差界；正文表格按各自显示位数舍入。

## 3. 留点测试不能代替留工况测试

第一处问题是扩大了评价对象。只在 $\nu=0.10$ 的解中随机留点，检查的是这一工况下新位置、时刻的预测，没有检验 $\nu=0.50$。这种划分不必一概判错，但只能支持相应的用途。

第二处问题是测试集参与了选模型。即使优化器没有用测试标签拟合，人工按测试分数选优也使用了测试信息，后续不能把同一成绩当作未参与选择的最终评价。

可行方案：训练、验证、ID测试的参数分别独立从 $U[0.05,0.10]$ 抽取，OOD参数独立从 $U[0.20,0.50]$ 抽取。每个参数对应的完整解只进入一个集合，各组坐标网格、初值与边界条件规则相同。训练拟合参数、验证选择设置，定稿后分别报告ID和OOD测试；若继续按测试结果调整，需另外准备未参与调整的最终测试工况。

正文按种子7202实际抽出了9个不同参数，完整值见[工况表](数据/heat_split.csv)。ID参数0.0853、0.0997虽高于本次三个训练参数的最大值，仍由同一个 $U[0.05,0.10]$ 产生。这直接说明，不能用有限样本的最小/最大值代替分布判断。

每个工况的51×51网格不是2601种独立材料。当前工况数量只是教学演示；尚未训练温度模型，所以不能填写它的测试误差。

## 选做：相差8的两个答案

仅凭旧区间数据，预测者不能区分两个可能函数，所以同一预测办法在 $x=3$ 给出相同答案 $a$。由三角不等式，

$$
8\leq|a-f_1(3)|+|a-f_2(3)|.
$$

若两个误差都小于4，和就小于8，矛盾。中点预测使两边恰好各差4，不代表两边都准确。

这里不能保证的是对所有与已知观测相符的函数都外推准确，不是否定每个具体函数上的成功。如果明确告知真实公式就是正弦函数，就排除了另一种可能，增加了原来没有的信息。

# 7.3 机器学习与降阶模型 — 习题参考解答

> 对应[习题题面](7.3-习题.md)，仅 7.3 节。数值来自 `7.3-实验.ipynb` 实际执行（固定种子），复现时可用绝对差不超过 $10^{-6}$ 核对；手算部分为推导结果。

## 1. 概念辨析

**题 1（概念配对）。**

| 降阶模型 | 机器学习 | 共同点 |
| --- | --- | --- |
| 截断误差 | 逼近误差 | 用「有限个自由度」去逼近真实对象所引入的误差 |
| 模态取得太少 | 欠拟合 | 表达力不足，连数据本身的结构都没抓住 |
| 追平每一个快照而引入噪声 | 过拟合 | 为了贴合训练样本把噪声也学了进去，损失泛化能力 |
| 投影与重构 | 泛化与推断 | 从已有样本里找规律，再对没见过的情况下判断 |
| 离线阶段 / 在线阶段 | 训练 / 推理 | 「贵一次、便宜很多次」的分工：先离线学习结构，再反复便宜使用 |

**题 2（判断题）。**

- (a) **对**。PCA 逐个挑选方差最大、且与已选方向正交的方向，即数据「最散开」的方向。
- (b) **错**。瓶颈越窄，被迫概括得越狠，**信息损失越大**（可压缩的冗余有限时，更窄的门只会丢掉结构）。
- (c) **错**。万能逼近定理只保证「存在」一个足够大、连续激活的网络能以任意精度逼近连续函数，它**不**给出训练算法、有限样本误差或泛化保证。
- (d) **对**。这是流形假设的标准表述，正文 7.3.1 的「弹珠沿弯线排列」就是它的写照。
- (e) **错**。过拟合是「训练误差很小、测试（泛化）误差很大」的**差距**；只看测试误差一个数无法判断，必须与训练误差对比，也需知道数据来自何种分布。

## 2. 手算

**题 3（PCA 手算）。**

1. 均值 $\mu = \left(\frac{1+2+3}{3},\ \frac{2+4+6}{3}\right) = (2,4)$；中心化后为 $(-1,-2),\ (0,0),\ (1,2)$。
2. 中心化数据矩阵 $X = \begin{bmatrix}-1&-2\\0&0\\1&2\end{bmatrix}$，故
   $$
   X^{\mathsf T}X=\begin{bmatrix}2&4\\4&8\end{bmatrix},\qquad
   C=\frac13\begin{bmatrix}2&4\\4&8\end{bmatrix}
   =\begin{bmatrix}2/3&4/3\\4/3&8/3\end{bmatrix}.
   $$
3. 特征值：$\operatorname{tr}C=\tfrac{10}{3}$、$\det C=0$，故 $\lambda_1=\tfrac{10}{3}$，$\lambda_2=0$。
4. 第一主轴是 $\lambda_1$ 对应的单位特征向量：解 $Cv=\lambda_1 v$ 得 $v_2=2v_1$，归一化得 $\phi_1=\tfrac{1}{\sqrt5}(1,2)^{\mathsf T}\approx(0.4472,0.8944)^{\mathsf T}$。
5. 方差比例 $=\dfrac{\lambda_1}{\lambda_1+\lambda_2}=\dfrac{10/3}{10/3}=100\%$。（三点严格共线，第二主成分为零。）

**题 4（能量与截断误差）。** 能量 $\sigma^2 = 100,16,4,1,0.25$，总和 $121.25$。

| $k$ | 能量占比 $\eta_k$ | 相对重构误差 $\epsilon_k=\sqrt{1-\eta_k}$ |
| ---: | ---: | ---: |
| 1 | $100/121.25=82.47\%$ | $\sqrt{21.25/121.25}=0.4186$ |
| 2 | $116/121.25=95.67\%$ | $\sqrt{5.25/121.25}=0.2081$ |
| 3 | $120/121.25=98.97\%$ | $\sqrt{1.25/121.25}=0.1015$ |

注意能量占比（方差）与重构误差（范数）是**平方关系**：能量丢掉 17.53% 对应范数误差 41.86%。

**题 5（投影与重构误差）。** 由正交性，
$$
\hat x = (x\cdot u_1)u_1 + (x\cdot u_2)u_2 = 1\cdot(1,0,0)+2\cdot(0,1,0)=(1,2,0).
$$
残差 $x-\hat x=(0,0,3)^{\mathsf T}$，$\|x-\hat x\|=3$。第三维是被该 2 维子空间「截断」掉的部分。

## 3. 实验

**题 6（PCA：弯线需要几个线性方向）。**

运行实验一（种子 7301，200 个点，3 维螺旋线加噪声 0.05）得到：

| 量 | 数值 |
| --- | --- |
| 奇异值 | 26.9608, 10.0957, 6.0084 |
| 能量占比 | 0.8404, 0.1178, 0.0417 |
| 累计能量 | 0.8404, 0.9583, 1.0000 |
| 重构误差 $k=1,2,3$ | 0.3995, 0.2043, 0.0000 |

螺旋线虽然是「1 个参数 $t$」决定的曲线，但它**不落在任何一条直线上**，而是一条弯曲的 1 维流形。线性 PCA 只能给出**直线子空间**，第一主轴只沿「最散开」的 $x$ 方向，解释 84% 能量；要贴住弯曲的部分，必须用更多（乃至全部）线性方向。这对应正文 7.3.2「**当直线不够用**」——需要把「直线子空间」放宽成「弯曲的流形」（自编码器）。

**题 7（POD 与截断误差）。**

运行实验二（种子 7302，$120\times60$ 快照矩阵，$u=\sin(\pi x)\cos(\pi t)+0.4\sin(3\pi x)\cos(3\pi t)$）得到：

| 量 | 数值 |
| --- | --- |
| 奇异值（前 3） | 42.6039, 17.0289, 0.0017 |
| 累计能量（前 3） | 0.8622, 1.0000, 1.0000 |
| 重构误差 $k=1,2,3$ | 0.3712, $1.77\times10^{-4}$, $1.73\times10^{-4}$ |

这族解**精确只含 2 个空间模态**（$\sin\pi x$ 与 $\sin 3\pi x$），所以 2 个 POD 模态就把重构误差压到 $10^{-4}$ 量级（残余来自那 $10^{-4}$ 的数值噪声），第 3 个模态已无物理意义。对应正文的分工：**离线阶段**把昂贵仿真得到的快照做 SVD、固定下少数模态；**在线阶段**只需解少数权重，即「贵一次、便宜很多次」。

**题 8（过拟合）。**

运行实验三（种子 7303，12 个训练点 + 噪声 0.15，$10^3$ 个测试点）得到（节选）：

| 次数 | 训练 MSE | 测试 MSE |
| ---: | ---: | ---: |
| 1 | 0.257653 | 0.222036 |
| 3 | 0.014769 | 0.014003 |
| 5 | 0.007422 | 0.010822 |
| 6 | 0.007396 | **0.010767** |
| 8 | 0.006822 | 0.013550 |
| 9 | 0.006332 | 1.211789 |
| 11 | 0.000000 | 6931.415374 |
| 15 | 0.000000 | 34082.323157 |

测试误差最小的次数是 **6**。

1. 训练误差随次数**单调不增**（最终归零）：更高次多项式包含更低次的模型，拟合能力更强，在训练点上能贴得更近。
2. 测试误差**先降后升**：低次时欠拟合（模型太简单），随后逼近真实规律、误差下降；超过某个次数后开始「死记硬背」训练噪声，出现**过拟合**。
3. 次数≥11 时，12 个训练点几乎被精确插值（训练误差≈0），多项式在训练点之间剧烈振荡，测试误差爆炸。这正是正文「会总结 vs 死记硬背」的数值写照。

**题 9（窄门 ≈ 主轴）。**

运行实验四（种子 7304，$300\times10$ 数据，线性自编码器梯度下降 4000 步）得到：

| 瓶颈宽 $k$ | PCA 误差 | 自编码器误差 |
| ---: | ---: | ---: |
| 1 | 0.864313 | 0.864327 |
| 2 | 0.709347 | 0.709348 |
| 3 | 0.587932 | 0.587932 |
| 5 | 0.370030 | 0.370034 |
| 8 | 0.109689 | 0.109733 |

对每个 $k$，自编码器误差都**不低于**（且几乎等于）PCA 误差。原因是 **Eckart–Young 定理**：rank-$k$ 的最优线性重构就是截断 SVD（即 PCA）。线性自编码器在线性映射族里逼近的正是这个最优解，所以它学到的瓶颈子空间就是 PCA 子空间——「窄门」与「主轴」在做同一件事，只是一个是数据驱动的参数更新、一个是代数的最优解。

## 4. 综合

**题 10（同一枚硬币）。**

- **降阶模型（POD）**：先做若干次完整仿真，把若干时刻的温度场作为「快照」堆成矩阵，做 SVD 挑出少数「基本形态」（如整体升温、左热右冷、中间鼓起）作为模态 $\phi_1,\dots,\phi_k$；往后任一时刻的场近似写成 $\sum_i a_i\phi_i$，只需解少数权重 $a_i$。低维结构**显式地**写成这几个模态的组合。
- **机器学习**：把「当前温度场 → 下一时刻温度场」的成对数据喂给网络，反复训练让网络自己学出这个映射，不被告知任何物理规律。低维结构**隐式地**藏在网络内部的参数（权重）里。

两者殊途同归：决定这场温度演化的其实只是极少数自由度，一个把它写成模态，一个把它藏进网络——这就是「同一枚硬币的两面」。数值分析里丈量「近似有多好」的误差界，也因此能原样搬到机器学习上。
