# 7.1 开放式习题与实践任务

以下任务允许不同方案和不同结果，不以复现某组漂亮数字作为目标。建议完成任务1、2，再从3—6任选两题。代码、参数、随机种子与实际输出应随报告提交；未运行的部分标明未运行。使用AI时保留关键提示、原回答和自己的核查，不以AI输出代替证据。

## 任务1：给“万能”二字写一份使用说明（AI辨析）
请让AI用150字解释通用逼近定理，再请它回答：“固定10个神经元够不够？有限样本训练后一定有效吗？能否直接换成ReLU？”也可自行拟造一段明显标注为假设的回答供辨析。

将回答拆成可核查的判断，对照正文及Cybenko定理条件，找出准确、含糊或过强之处。最后为初学者改写一份不超过250字的说明。AI未犯错时如实记录，不强行寻找错误。

提交：关键对话节选、至少三个判断的核查表、来源位置、改写稿。重点说明哪些是定理结论，哪些需要其他假设。

## 任务2：两位画家，同一张练习纸（编程与反例）
自行选择至少4个不同训练输入，构造两个在这些点上预测完全相同、在其他位置明显不同的函数。画出两条函数与训练点，再自行指定任务分布、真实标签规律和损失，比较它们的训练误差及总体表现。

可以让AI建议构造方法，但须解释为什么训练点上相同。允许解析计算总体风险，或用独立大样本估计；后者必须称作估计值。

提交：构造思路、可运行代码、一张图、分布与损失说明，以及“仅凭训练数据能否判定谁更好”的讨论。

## 任务3：一场测验能代表真实水平吗（模拟探究）
用配套阈值游戏训练一次并固定模型。自行选择至少三种测试集大小，各独立抽取至少100批测试数据，比较测试误差的分布。提出运行前预测，再检查结果是否支持预测。

提交：误差分布图或箱线图、均值与标准差、与解析风险的比较。说明“无偏”与“单次准确”为什么不同；不得在更换测试集时悄悄重新训练。

## 任务4：让测试集帮忙选模型，会发生什么（可选挑战）
设计一个公平对照：一组在训练数据上选模型，另一组借助有限验证样本选模型；两组均用额外的、从未参与选择的独立数据作最终评价。可改变候选模型数量或验证集大小，研究用于选择的成绩与最终成绩之间的差距。

提交：数据使用流程图、至少两种设置的重复试验结果、局限分析。此处用于选择的数据应称验证集；如果历史上把它称作测试集，也须说明其实际用途。未观察到明显乐观偏差也应如实解释。

## 任务5：理论护栏有多宽（编程与可视化）
保留有限候选类、独立同分布和0—1损失条件，自行改变样本量、候选数或置信参数中的一个因素，其余保持固定。比较理论半径与全部候选模型中的最大绝对训练—风险差距，至少运行三种预设设置。

提交：参数表、重复试验图、各设置超界次数及重复次数。讨论候选集合为何必须事先确定，为什么不能把神经元数代入M。若同时声称多种设置全部满足高概率保证，须解释多重比较问题，或明确仅逐设置解释。

## 任务6：主动破坏一个假设（开放探究）
在“重复同一个样本冒充独立数据”“改变评价分布”“使用无界平方损失”中任选一个。先写出原界所需条件，再设计能清楚展示条件变化的案例，可用数学分析或代码模拟。

提交：改变前后对照、真实运行结果或推理，以及该案例究竟否定了什么。不能仅因一次结果看似符合原界，就断言条件可以删除；也不能因原界不能直接使用，就断言不存在其他泛化理论。

本节把降阶模型（ROM）与机器学习（ML）并置，说明它们是「同一枚硬币的两面」，核心数学工具是 PCA/POD（奇异值分解）、截断误差与过拟合。习题分四部分：概念辨析、手算、实验、综合。建议先做 1、3、4、6，再完成其余。

## 1. 概念辨析

**题 1（概念配对）。** 下表左右两列是降阶模型与机器学习中含义对应的术语。请逐一配对，并用一句话写出每一对的共同点。

| 降阶模型 | 机器学习 |
| --- | --- |
| 截断误差 | 逼近误差 |
| 模态取得太少 | 过拟合 |
| 追平每一个快照而引入噪声 | 泛化与推断 |
| 投影与重构 | 欠拟合 |
| 离线阶段 / 在线阶段 | 训练 / 推理 |

**题 2（判断题）。** 判断下列说法的对错，并各用一句话说明理由：

- (a) PCA/POD 挑出的主轴是数据「最散开」的方向。
- (b) 自编码器的瓶颈越窄，信息损失一定越小。
- (c) 万能逼近定理保证：用有限样本训练出来的神经网络一定对新数据泛化良好。
- (d) 流形假设说的是：现实世界看似高维的数据，往往蜷缩在一个低维流形上。
- (e) 一个模型测试误差很小，足以说明它没有过拟合。

## 2. 手算

**题 3（PCA 手算）。** 平面上三个数据点为 $P_1=(1,2)$、$P_2=(2,4)$、$P_3=(3,6)$。求：

1. 均值向量 $\mu$ 与中心化后的数据；
2. 协方差矩阵 $C=\frac1n\sum_i \tilde x_i \tilde x_i^{\mathsf T}$（用 $n$ 归一）；
3. $C$ 的特征值；
4. 第一主轴（最大特征值对应的单位特征向量）；
5. 只保留第一个主成分时，能解释的方差比例是多少？

**题 4（能量与截断误差）。** 某数据矩阵去均值后做 SVD，得到奇异值 $\sigma_1=10,\ \sigma_2=4,\ \sigma_3=2,\ \sigma_4=1,\ \sigma_5=0.5$。分别对 $k=1,2,3$ 计算：

1. 保留前 $k$ 个模态的**能量占比** $\eta_k=\dfrac{\sum_{i\le k}\sigma_i^2}{\sum_i \sigma_i^2}$；
2. 对应的**相对重构误差** $\epsilon_k=\sqrt{1-\eta_k}$（即 Frobenius 范数意义下被舍弃部分的占比）。

**题 5（投影与重构误差）。** 向量 $x=(1,2,3)^{\mathsf T}$，子空间由标准正交基 $u_1=(1,0,0)^{\mathsf T}$、$u_2=(0,1,0)^{\mathsf T}$ 张成。求 $x$ 在该子空间上的正交投影 $\hat x$、重构误差向量 $x-\hat x$，以及 $\|x-\hat x\|$。
