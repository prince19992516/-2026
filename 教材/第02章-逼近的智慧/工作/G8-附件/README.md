## 运行

从上一级“工作”目录打开 A1组-实验.ipynb。它将自动从 G8-附件 导入程序，结果与图片也写入本附件目录。

安装依赖后，从工作目录运行：

```text
python -m pip install -r G8-附件/requirements.txt
python G8-附件/G8-运行Notebook.py A1组-实验.ipynb
```

本次采用现有 Python 环境执行全部单元，未另建干净环境安装本次依赖；实际版本见环境版本.json。
