# 第二章符号与约定

所有变量与计算量均无量纲。这里的表用于查阅，首次使用时仍在正文说明。

| 符号 | 含义与约定 |
| --- | --- |
| $`[a,b]`$ | 实闭区间，$`a<b`$；统一变量 $`t=(2x-a-b)/(b-a)`$ 映至 $`[-1,1]`$ |
| $`C^r[a,b]`$ | 至 $`r`$ 阶导数连续；端点导数按从内部连续延拓理解 |
| $`\Vert x\Vert _p`$、$`\Vert g\Vert _{p,[a,b]}`$ | 向量与函数的 $`p`$-范数，完整定义见附录 A.1–A.2；$`\Vert \cdot\Vert _\infty`$ 即最大绝对值 |
| $`\varepsilon`$ | 双精度机器 epsilon，$`\varepsilon\approx2.22\times10^{-16}`$；见附录 A.4 |
| $`\mathcal P_n`$ | 次数不超过 $`n`$ 的实多项式，允许 $`n=0`$ |
| $`n,x_j,p_n`$ | 插值次数上限、$`n+1`$ 个互异节点（$`j=0,\ldots,n`$）、插值多项式 |
| $`\ell_j,\omega_{n+1},w_j`$ | Lagrange基函数、首一节点多项式、重心权重；与网络中的 $`w_j`$ 依所在节区分 |
| $`T_k(x)`$ | Chebyshev多项式；零点族与含端点极值点族明确分开 |
| $`m,d,A,c,y`$ | 拟合样本数、次数、$`m\times(d+1)`$设计矩阵、$`(d+1)`$维系数、$`m`$维数据；$`r=Ac-y`$ |
| $`\Vert v\Vert _2,\kappa_2(A)`$ | 欧氏范数、满列秩矩阵的 2 范数条件数；定义见附录 A.5，正文 2.2 只引用结论 |
| $`\Vert g\Vert _{\infty,[a,b]}`$ | 连续函数在整个闭区间的最大绝对值；有限网格最大值仅为采样量 |
| $`N,h,T_N`$ | 积分小区间数、$`h=(b-a)/N`$、复合梯形值；$`T_N`$无自变量时表示求积值 |
| $`I-T_N`$ | 带符号的积分误差；对 $`x^2`$ 为负 |
| $`S`$、代数精度 | 单区间 Simpson 求积值 $`\frac h3[f(u)+4f(m)+f(v)]`$；代数精度指对次数不超过 $`k`$ 的多项式精确的最大 $`k`$ |
| $`\langle\cdot,\cdot\rangle_w`$、$`\{\phi_k\}`$ | 加权内积与正交函数系，定义见附录 B；正文只在 2.1 扩展框中提及 Legendre、Chebyshev |
| $`\delta`$ | 正文的差分步长；实验代码及习题也使用变量名 $`h`$，由上下文区分积分步长 |
| $`\dot v,\bar v`$ | 前向切向量、反向输出敏感性；重复使用同一节点须累加贡献 |
| $`q,\theta,u_\theta`$ | 隐层宽度、$`3q+1`$维参数、标量网络；参数按 $`(a,w,b,c)`$ 排列 |
| $`u_\theta',u_\theta''`$ | 保持参数不变的输入一阶、二阶导数 |
| $`\nabla_\theta u_\theta`$ | 保持输入不变的参数梯度；不能代替输入导数 |
| $`N_r,\xi_i,r_\theta`$ | 方程配点数、内部配点、$`-u_\theta''-\pi^2\sin(\pi x)`$；正文和习题同此符号 |
| $`\lambda_r,\lambda_b`$ | PINN残差项和边界项的正权重 |
