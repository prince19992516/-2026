## 2. §2.1 插值与 Runge 现象

### 2.1 题设与假设

目标函数取龙格函数

```math
f(x)=\frac{1}{1+25x^2},\qquad x\in[-1,1].
```

A1使用插值多项式 $p_n$，次数为 $n$，节点数为 $n+1$；A2使用节点数 $n$，多项式次数至多 $n-1$。两者都要求节点互异，误差评价网格独立于插值节点。

### 2.2 独立推导

对 $n+1$ 个互异节点 $x_0,\ldots,x_n$，Lagrange 插值余项为

```math
f(x)-p_n(x)=\frac{f^{(n+1)}(\xi)}{(n+1)!}\omega(x),\qquad
\omega(x)=\prod_{j=0}^{n}(x-x_j),
```

其中 $\xi$ 介于 $x$ 与节点区间之间。节点上 $\omega(x_i)=0$，所以节点误差为零；这不能说明区间内部误差小。

在 $[-1,1]$ 上，首一多项式的最小最大模由 $2^{-n}T_{n+1}$ 达到：

```math
\min_{\text{首一 }q,\ \deg q=n+1}\|q\|_\infty=2^{-n},
\qquad \omega=2^{-n}T_{n+1}\ \text{时取等}.
```

取 $T_{n+1}$ 的零点

```math
x_j=\cos\frac{(2j+1)\pi}{2n+2},\qquad j=0,\ldots,n,
```

得到误差界

```math
\|f-p_n\|_\infty\le
\frac{\|f^{(n+1)}\|_\infty}{2^n(n+1)!}.
```

这个界是充分条件。对龙格函数，高阶导数增长很快，不能由 $2^{-n}$ 单独推出收敛速度，也不能由“界很大”直接宣布发散；发散要用具体节点族与具体函数验证。

## 3. §2.2 最小二乘与 Chebyshev 逼近

### 3.1 独立推导

设设计矩阵 $A\in\mathbb R^{m\times(d+1)}$，目标

```math
J(c)=\|Ac-y\|_2^2.
```

展开并对 $c$ 求梯度：

```math
J(c)=c^{\mathsf T}A^{\mathsf T}Ac-2c^{\mathsf T}A^{\mathsf T}y+y^{\mathsf T}y,
\qquad
\nabla J(c)=2A^{\mathsf T}(Ac-y).
```

最优解满足正规方程

```math
A^{\mathsf T}Ac=A^{\mathsf T}y.
```

若 $A$ 列满秩，$A^{\mathsf T}A$ 正定，解唯一；若列不满秩，所有解给出相同的拟合值 $Ac$，但系数不唯一。几何上，最优残差与 $A$ 的列空间正交。

若两组基 $\phi$ 与 $\psi$ 张成同一空间，则存在可逆矩阵 $B$ 使 $A_\psi=A_\phi B$，两个最小化问题等价，最优多项式相同。换基只改变坐标与数值条件。

对2-范数条件数，

```math
\kappa_2(A^{\mathsf T}A)=\kappa_2(A)^2.
```

因此显式形成正规方程会把条件数平方；实际计算应优先用QR/SVD或专用最小二乘求解器。

最后，用Chebyshev多项式作**最小二乘基**，与极小极大（一致）逼近是两个目标：前者最小化 $\ell_2$ 残差，后者最小化 $\ell_\infty$ 误差。两者解一般不同，不能因为用了Chebyshev基就称为“最佳一致逼近”。

## 4. §2.3 数值积分与自动微分

### 4.1 复合梯形

设 $f\in C^2[a,b]$，$h=(b-a)/N$。在每段 $[x_k,x_{k+1}]$ 上，梯形公式是分段线性插值的精确积分。余项积分给出

```math
I-T_N=-\frac{(b-a)h^2}{12}f''(\xi),\qquad \xi\in(a,b).
```

对 $f=x^2$、$[0,1]$，$f''=2$，于是

```math
I=\frac13,\qquad T_N=\frac13+\frac{1}{6N^2}.
```

因此 $T_4=11/32=0.34375$、$T_8=43/128=0.3359375$，绝对误差分别为 $1/96$ 与 $1/384$，比值恰为4。这是二次函数的代数事实，不是所有 $C^2$ 函数的逐次恒等。

### 4.2 Simpson公式

设区间 $[u,v]$，全宽 $H=v-u$，中点 $m=(u+v)/2$。对二次插值积分，得到

```math
\int_u^v f(x)\,dx\approx
\frac{H}{6}\bigl[f(u)+4f(m)+f(v)\bigr].
```

若令半宽 $h=H/2$，则 $m=u+h$，公式写成

```math
\int_u^v f(x)\,dx\approx
\frac{h}{3}\bigl[f(u)+4f(u+h)+f(v)\bigr].
```

A1正文写的是

```math
\int_u^v f\approx\frac{h}{6}\bigl[f(u)+4f(u+h)+f(v)\bigr].
```

它把“全宽系数 $H/6$”与“半宽节点 $u+h$”混在一起：

- 若 $h=H/2$ 使 $u+h$ 为中点，系数应为 $h/3$，原式给正确值的一半；
- 若 $h=H$ 使系数 $h/6$ 正确，节点应为 $u+H/2$，原式的 $u+h=v$ 重复了端点。

用 $f=x^2$、$[0,1]$ 核验（真值 $1/3$）：

| 写法 | 数值 |
| --- | ---: |
| $H/6$，中点 $u+H/2$ | 0.333333333333333 |
| $(H/2)/6$，节点 $u+H/2$ | 0.166666666666667 |
| $H/6$，节点 $u+H$（A1原式） | 0.833333333333333 |

A1题解3.2写的是 $h=(v-u)/2$、系数 $h/3$，本身正确；正文扩展框与自己的题解矛盾。**C002成立**，B1的 `B-2.3-01` 结论正确。

### 4.3 中心差分

由Taylor展开，

```math
F(x+h)=F(x)+hF'(x)+\frac{h^2}{2}F''(x)+\frac{h^3}{6}F'''(x)+O(h^4),
```

```math
F(x-h)=F(x)-hF'(x)+\frac{h^2}{2}F''(x)-\frac{h^3}{6}F'''(x)+O(h^4).
```

相减除以 $2h$：

```math
D_h^0F(x)=\frac{F(x+h)-F(x-h)}{2h}
=F'(x)+\frac{h^2}{6}F'''(x)+O(h^4).
```

所以

```math
D_h^0F-F'=+\frac{h^2}{6}F''',\qquad
F'-D_h^0=-\frac{h^2}{6}F'''.
```

A1正文式(2.4.2)写的是后者，正确；A1题解4.2写成 $D_h^0F-F'=-\frac{h^2}{6}F'''$，把负号抄反了。**C003成立**，B1的 `B1-丙-02` 结论正确。

对 $F(x)=\sin(x^2)+e^x$、$x=0.7$：

```math
F'(0.7)=3.2490187095246466,
```

```math
D_{0.1}^0F=\frac{F(0.8)-F(0.6)}{0.2}=3.2417166809463027,
```

```math
D_{0.1}^0F-F'(0.7)=-7.302028578344\times10^{-3}.
```

A1表中写 `3.2563`，而 `3.2563 = F'(0.7)+|D-F'| = 3.2563207381`，说明不是随机笔误，而是把修正项的符号写反。**C001成立**，B1的 `B1-丙-01` 结论正确。

## 5. §2.4 神经网络逼近与PINN求导

### 5.1 独立推导

单隐层tanh网络

```math
u_\theta(x)=c+\sum_{j=1}^{q}a_j\tanh(w_jx+b_j).
```

记 $z_j=w_jx+b_j$、$t_j=\tanh z_j$、$s_j=1-t_j^2$，则

```math
u_\theta'(x)=\sum_j a_jw_js_j,\qquad
u_\theta''(x)=-2\sum_j a_jw_j^2t_js_j.
```

参数导数：

```math
\frac{\partial u}{\partial c}=1,\quad
\frac{\partial u}{\partial a_j}=t_j,\quad
\frac{\partial u}{\partial w_j}=a_js_jx,\quad
\frac{\partial u}{\partial b_j}=a_js_j.
```

均方损失

```math
L_{\rm data}=\frac1m\sum_i(u_\theta(x_i)-y_i)^2
```

的梯度为

```math
\nabla_\theta L_{\rm data}
=\frac{2}{m}\sum_i(u_\theta(x_i)-y_i)\nabla_\theta u_\theta(x_i).
```

这与输入导数 $\partial_xu_\theta$ 的求导对象不同：前者是参数梯度，后者是场量的空间导数，不能把 `loss.backward()` 的结果直接当作物理导数。

ReLU是分段仿射函数：段内二阶导数为0，折点处经典二阶导数不存在。框架在折点返回的0是约定，不是数学结论；强形式二阶PDE的残差需要 $C^2$ 激活（如tanh），或改用弱形式。

高频反例：

```math
v_k(x)=\sin(\pi x)+\frac1k\sin(kx).
```

在 $x=0$ 处一阶导数差为1；在 $x=\pi/(2k)$ 处二阶导数差为 $k$；而函数值误差只有 $1/k$。所以函数值一致逼近不能推出导数逼近。

### 5.2 数值核验

用一个随机tanh网络（$q=5$，种子2026）核对：

| 量 | 解析值 | 中心差分/独立传播 | 差异 |
| --- | ---: | ---: | ---: |
| $u'(0.37)$ | -0.980878309902 | -0.980878309909 | 6.60e-12 |
| $u''(0.37)$ | 0.083766772635 | 0.083766327208 | 4.45e-7 |
| 参数梯度 | — | — | 6.47e-11 |

二阶中心差分的误差来自差分截断，不是解析公式错误；缩小步长或改用高阶差分可进一步降低。参数导数表与有限差分一致到 `6.47e-11`，说明链式法则与参数导数表正确。

ReLU在 $x=-0.5,0,0.5$ 处：值 `0,0,0.5`；中心差分 `0,0.5,1`。折点 $x=0$ 的中心差分给 `0.5`，而PyTorch的约定返回 `0`；两者都不是“经典导数存在”的证据。A2正文对此的说明正确。

高频反例重算：$k=10,100,1000$ 时函数误差 `1e-1,1e-2,1e-3`，一阶误差恒为 `1`，二阶误差 `10,100,1000`，与解析结论一致。

A2的两隐藏层结构 $1-32-32-1$ 参数数为

```math
(1\cdot32+32)+(32\cdot32+32)+(32\cdot1+1)=1153,
```

与A2正文一致。Poisson问题 $u_*=\sin(\pi x)$ 的残差 $-u_*''-\pi^2\sin(\pi x)$ 在2001点网格上最大值为 `0.0`，解析解代入正确。
