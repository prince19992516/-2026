# 第02章 逼近的智慧：课后习题

本习题为教材编写稿，五道题依次对应正文 2.1—2.5 节。所有变量无量纲。建议先完成手算，再运行实验。配套程序为 [ch2_numerics.py](G8-附件/ch2_numerics.py)，参考解答见[习题参考解答](A1组-习题参考解答.md)。下面的辨析语句均为教学构造。

## 题1：插值精确性与区间误差（对应 2.1）

设 $`\mathcal P_n`$ 是次数不超过 $`n`$ 的实多项式空间，$`f(x)=1/(1+25x^2)`$，$`x\in[-1,1]`$。

1. 对节点 $`-1,0,1`$，写出三个Lagrange基函数，并求数据 $`q(x)=2x^2-x+3`$ 的插值多项式。为什么任意 $`\mathcal P_2`$ 中的多项式都被这三个节点精确恢复？用 $`-0.73,0.23,0.89`$ 三个非节点检验你的实现。
2. 对一般互异节点 $`x_0,\ldots,x_n`$，说明Lagrange基函数的节点性质如何给出插值存在性和唯一性。若 $`f\in C^{n+1}[-1,1]`$，写出插值余项及其上界，并指出其中随 $`n`$ 改变的两种量。该上界是否自动随 $`n`$ 减小？
3. 取 $`n=8,16,32`$，分别使用 $`x_j=-1+2j/n`$ 和Chebyshev零点 $`x_j=\cos((2j+1)\pi/(2n+2))`$，$`j=0,\ldots,n`$。用同一6001点独立网格 $`z_\ell=-1+2(\ell+0.371)/6001`$，$`\ell=0,\ldots,6000`$，计算 $`\max_\ell\vert p_n(z_\ell)-f(z_\ell)\vert `$，列出六组结果并画误差曲线。可用NumPy及附带的重心插值实现；须说明它计算的仍是同一Lagrange插值多项式。另报节点最大误差及节点命中处理方式。
4. 辨析：“节点误差为零，所以增加节点一定提高整个区间及区间外的精度。”解释第3问的证据能说明什么、不能说明什么；Chebyshev零点是否包括区间端点？

## 题2：相同多项式空间与不同误差目标（对应 2.2）

1. 用常数 $`c`$ 拟合 $`x^2`$。先对样本 $`\{-1,0,1\}`$ 最小化 $`\sum_{x\in\{-1,0,1\}}(c-x^2)^2`$，再在连续区间 $`[-1,1]`$ 最小化 $`\max_{x\in[-1,1]}\vert c-x^2\vert `$。分别求唯一最优常数和目标函数最小值，解释两者不同的原因。
2. 对41个样本 $`x_i=-1+2(i-1)/40`$，$`i=1,\ldots,41`$，取 $`y_i=e^{x_i}+\eta_i`$。噪声由 `np.random.default_rng(2026).normal(0.,.015,41)` 一次生成后共用。固定次数 $`d=12`$，分别以 $`1,x,\ldots,x^{12}`$ 和 $`T_0(x),\ldots,T_{12}(x)`$ 建立设计矩阵。写出尺寸、最小二乘目标及正规方程；说明满列秩条件为何成立，以及两种基在精确算术下得到同一最优多项式的理由。无需实现QR或SVD分解。
3. 用 `numpy.linalg.lstsq` 求两种基下的系数，在共用独立网格 $`z_\ell=-1+2(\ell+0.371)/2001`$，$`\ell=0,\ldots,2000`$，分别报告训练残差 $`\Vert Ac-y\Vert _2`$、相对无噪目标 $`e^x`$ 的网格最大误差及两条预测曲线的最大差异。选做：用 `numpy.linalg.cond(A)` 报告矩阵的2范数条件数，作为数值敏感性的指标；本题不要求推导该例程内部算法。
4. 辨析：“Chebyshev基的条件数更小，因此它在同一数据和次数下定义了另一个、更优的最小二乘问题，并自动给出连续最优一致逼近。”指出错误；若同时改变次数，是否还能把效果全部归因于换基？为什么训练残差更小也不能保证无噪目标误差更小？

## 题3：插值积分——误差从余项里积出来（对应 2.3）

1. 对 $`I=\int_0^1x^2\,dx`$，手算复合梯形值 $`T_4,T_8`$，并推导一般 $`N\ge1`$ 时的 $`I-T_N`$。验证加密一倍后的绝对误差比为4，并与 $`\vert I-T_N\vert \le (b-a)h^2\Vert f''\Vert _\infty/12`$ 对照。说明这条误差公式是如何由插值余项积分得到的，几何因子 $`\int\omega`$ 等于什么。
2. 在 $`[u,v]`$ 上令 $`h=(v-u)/2`$，用二次插值（端点与中点三点）推导 Simpson 公式 $`S=\frac{h}{3}[f(u)+4f(u+h)+f(v)]`$ 在单区间上的形式，并验证它对三次多项式精确、对四次多项式不精确。由此说明它的代数精度是几，误差阶为何是 $`O(h^4)`$。选做：用复合 Simpson 重算第1问的积分，比较 $`N=4`$ 时它与 $`T_4`$ 的误差。
3. 设 $`f(x)=\sqrt x`$、$`[0,1]`$。证明仅第一段就给出 $`I-T_N\ge h^{3/2}/6`$，因而 $`\lvert I-T_N\rvert\le Ch^2`$ 不可能对与 $`N`$ 无关的 $`C`$ 成立。由此预测 $`N`$ 加倍时误差比的极限值，并解释它为什么不是 $`0.25`$。
4. 辨析：“积分误差比是 $`0.25`$，所以任何连续函数的梯形误差都按四分之一缩小。”指出错误所在：问题出在阶、出在常数，还是出在对齐方式？再说明为什么“梯形公式对一次函数精确”不能推出“对光滑函数误差很小”。

## 题4：插值微分——截断、舍入与自动微分（对应 2.4）

1. 令 $`F(x)=\sin(x^2)+e^x`$。画出节点 $`v_0=x,v_1=v_0v_0,v_2=\sin v_1,v_3=e^{v_0},v_4=v_2+v_3`$ 的计算图，写出每个节点的前向值与切向导数，初值 $`\dot v_0=1`$。另从 $`\bar v_4=1`$ 写出反向伴随量；说明 $`v_0`$ 从两条分支得到的贡献为什么要相加。
2. 用一次插值导出前向差分、用二次插值导出中心差分，并写出各自的截断误差主项。说明为什么前向是一阶、中心是二阶，以及"差分公式 = 插值多项式的导数"这句话在这里的具体含义。
3. 在 $`x=0.7`$ 运行前向和反向自动微分，与解析导数比较。对 $`h=10^{-1-j/4}`$，$`j=0,\ldots,60`$，同时计算前向差分和中心差分，画绝对误差随步长变化的双对数图，报告误差最小点及最小步长处的结果。可用附带的教学 `Dual`、`Graph`、`Jet2` 类；说明这三个类是链式法则的实现，不含差分近似。
4. 辨析：“自动微分就是令差分步长非常小；AD 结果接近解析导数，就证明了积分实验也准确。”指出两处错误，区分截断误差、舍入误差，以及"对已给计算过程求导"的浮点误差；并说明为什么前向与中心差分的最优步长相差约 $`\varepsilon^{-1/6}`$ 倍。

## 题5：网络的输入导数、参数导数与光滑性（对应 2.5）

令 $`u_\theta(x)=c+\sum_{j=1}^q a_j\tanh(w_jx+b_j)`$，$`x\in[-1,1]`$，所有参数为实数，$`\theta=(a,w,b,c)\in\mathbb R^{3q+1}`$。

1. 记 $`t_j=\tanh(w_jx+b_j)`$，推导 $`u_\theta'(x),u_\theta''(x)`$ 及对 $`a_j,w_j,b_j,c`$ 的偏导。对训练点 $`x_i`$、数据 $`y_i`$ 和均方损失 $`L(\theta)=m^{-1}\sum_i(u_\theta(x_i)-y_i)^2`$，写出参数梯度。用 $`q=1,(a,w,b,c)=(2,3,0,1),x=0,y=0`$ 手算 $`u,u',u''`$ 及该单点损失的参数梯度。
2. 读取本章保存的网络参数或复现实验：目标 $`f(x)=\sin(\pi x)`$，81个等距训练点，$`q=12`$，其余初始化与迭代设置以 `train_network` 为准。用 $`z_\ell=-1+2(\ell+0.371)/2001`$ 的2001点独立网格评估函数值、一阶和二阶导数误差，解析参考分别为 $`f,f'=\pi\cos(\pi x),f''=-\pi^2\sin(\pi x)`$。分别报告训练均方损失与这三个网格最大误差。以第1问公式和教学 `Jet2` 的输出相互核查；不得只报训练损失。
3. 取 $`g_k(x)=\sin(kx)/k^2`$，$`k=2,3,\ldots`$。证明 $`\Vert g_k\Vert _\infty\to0`$、$`\Vert g_k'\Vert _\infty\to0`$，但 $`\Vert g_k''\Vert _\infty\not\to0`$，范数均指 $`[-1,1]`$ 上的连续一致范数。代入 $`k=100`$ 给出三个精确范数。它否定了什么推断？是否说明每个实际训练网络都必然有大导数误差？
4. 对 $`\rho(x)=\max(0,x)`$，讨论一阶与二阶经典导数及 $`x=0`$ 的情形。再讨论由有限多个ReLU单元组成的上述单隐层结构，为什么不适合直接表示有非零连续二阶导数的经典解。借助形式残差 $`r_\theta(x)=-u_\theta''(x)-\pi^2\sin(\pi x)`$，解释为什么求残差先需要输入导数，而训练损失需要参数导数；值拟合实验是否已求解带边界条件的微分方程？
