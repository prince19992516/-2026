# B1组-丙-复现说明（环境与重建）

本说明用于在**本机**重建丙的验证环境。可运行的课程副本与 venv **不随提交包提供**，以免占用体积；本组实测环境如下，按需重建即可。

## 环境

- **A1**：Python 3.12.10；NumPy 2.0.1；Matplotlib 3.9.1.post1；nbformat 5.10.4；nbclient 0.10.0；ipykernel 6.29.5；`pip check` 无冲突。完整依赖见 `证据-丙-pip冻结-A1.txt`。
- **A2**：Python 3.12.10；NumPy 2.5.4；Matplotlib 3.11.2；PyTorch 2.14.1+cpu；nbformat 5.11.1；nbclient 0.11.0；ipykernel 7.4.0；`pip check` 无冲突。完整依赖见 `证据-丙-pip冻结-A2.txt`。

说明：A2 `requirements-G21.txt` 在 Python 3.12 下可原样安装；最初在 Python 3.10 的 `pip index` 只看到 numpy 2.2.6，属 `Requires-Python` 过滤误判，已撤销。

## 重建步骤（PowerShell）

1. 取受审仓库第 02 章的 `工作/` 目录作为课程副本（工作目录）。
2. 建两个 venv 并安装依赖：

```powershell
py -3.12 -m venv venv-A1
.\venv-A1\Scripts\python.exe -m pip install -r <课程副本>\G8-附件\requirements.txt

py -3.12 -m venv venv-A2
.\venv-A2\Scripts\python.exe -m pip install -r <课程副本>\G21-附件\requirements-G21.txt
```

3. 注册内核并执行 Notebook（A1 内核 `ch2-course`，A2 内核 `python3`）：

```powershell
$env:JUPYTER_PATH="<...>\venv-A1\share\jupyter"
& "<...>\venv-A1\Scripts\python.exe" -m jupyter nbconvert `
  --to notebook --execute --inplace --ExecutePreprocessor.timeout=1800 "A1组-实验.ipynb"
# A2 把 venv-A1 换成 venv-A2、A1组-实验.ipynb 换成 A2组-实验.ipynb
```
