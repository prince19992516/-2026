| 字段 | 内容 |

| 条目编号 | `CH04-G4-T001`（对应 `C01`） |
| 来源 | **真实 AI 线索**：本轮会话「读全规则与 B1 材料」阶段，AI 在整理候选漏洞时给出的线索 |
| 模型、日期与对话位置 | WorkBuddy（腾讯混元 Hy），2026-11-16；本轮会话前段「候选漏洞清单」；原始提示词见[AI对话记录](C1组-AI对话记录.md) 轮 1 |
| 原主张（线索原文要义） | 「$\kappa(C)=\lambda_{\max}/\lambda_{\min}$ 只比较最大与最小尺度，无法说明有几个方向重要；因此『谱快速衰减（大 $\kappa$）是 PCA 奏效的前提』整句应删」 |
| 隐含假设 | 把「$\kappa$ 不能判断有效秩」直接等同于「$\kappa$ 与 PCA 奏效无关」，未区分**必要条件**与**充分条件** |
| 最小反例与独立依据 | 独立推导 (D9)：$E_r\le\frac{r\kappa}{d-r+r\kappa}$。B1 的例子 $d=1001,\kappa=100,E_1=9.090909\%$ **恰好取等**，即「$\kappa$ 不够大 ⇒ 能量注定不集中」，与原句的必要前提一致；真正驳充分性的反例是 $C=\mathrm{diag}(10^6\mathbf1_{1000},1)$（$\kappa=10^6$、$E_1=0.1000\%$、到 99.9% 需 1000 个方向） |
| 预期、实测和容差 | 预期 $E_1=100/1100=9.090909\%$，实测 $9.090909\%$（比值 $1.0000000000$，容差 $10^{-12}$）；反例 A 预期 $E_1\approx0.1\%$，实测 $0.1000\%$（单元 1） |
| 影响与修正建议 | 影响 B1 修正清单 `G18-05` 与 D3 L2171；若整句删除会丢掉可定量保留的结论。建议按[批判报告](C1组-批判报告.md) §4 拆成「删前半句 + 补必要条件不等式与充分性反例」 |
| 判断 | **线索成立，推论不成立**（$\kappa$ 确不能判有效秩；但「大 $\kappa$ 是必要前提」在 (D9) 下成立）。B1 的反例方向打反了 |
| 复测版本与结论 | 本组单元 1 已实跑；修复后的教材文本尚未产生（见 `C15`，条件不足），需 A/D3 改稿后由 B/C 复测 |
