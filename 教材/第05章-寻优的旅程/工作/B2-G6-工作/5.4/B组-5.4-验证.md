## 四、关键数值独立复算

以下代码可独立复算两道指数模型例题的步长：

```python
import numpy as np

t = np.array([0.0, 1.0, 2.0])
y = np.array([1.0, 2.5, 6.0])
a, b = 1.0, 0.5
E = np.exp(b * t)
r = y - a * E
J = np.column_stack([-E, -a * t * E])
H = J.T @ J
g = J.T @ r

d_gn = np.linalg.solve(H, -g)
d_lm = np.linalg.solve(H + 0.1 * np.eye(2), -g)
print("J.T @ J =\n", H)
print("J.T @ r =", g)
print("GN step =", d_gn, "new x =", np.array([a, b]) + d_gn)
print("LM step =", d_lm, "new x =", np.array([a, b]) + d_lm)
```

## 五、理论与 API 核验

| 核验项 | 预期/依据 | 结论 |
| --- | --- | --- |
| \(\nabla F=J^\top r\) | 对可微残差目标由链式法则直接成立，不要求 \(J\) 列满秩 | 正文定义中的列满秩前提应移至唯一性/正定性说明 |
| 最小值存在性 | 目标有下界不等于下确界可达 | “有下界则解总存在”不成立 |
| GN 收敛阶 | 不能只凭 \(r(x^*)\ne 0\) 推出 \(S(x^*)\ne 0\) 或一概断言线性收敛 | 需补充局部条件并弱化绝对化结论 |
| 条件数 | 满列秩时 \(\kappa_2(J^\top J)=\kappa_2(J)^2\) | “GN 对条件数不敏感”不准确 |
| SciPy `least_squares` | 未传 `method` 时默认 `trf` | 正文“内部用 LM”注释错误；应改注释或显式指定 `method='lm'` |
