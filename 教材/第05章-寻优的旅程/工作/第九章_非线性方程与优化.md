# 第九章 非线性方程与非线性优化

> **一句话章题解**：前三章我们在解"线性问题"——线性方程、线性插值、线性最小二乘。现实几乎从不是线性的。本章回答两个问题：**方程 $F(x)=0$ 怎么解**（非线性方程求根），**函数 $f(x)$ 怎么最小化**（无约束优化）。两者的共同引擎只有一个：**在每一点把非线性问题线性化，解线性近似，然后重复**。从夹逼（二分法）出发，走到迭代（不动点），再走到曲率（Newton / 拟 Newton / Gauss-Newton / LM）——一条主线贯穿全章。

## 9.0 章首导学：预习 → 地图 → 约定

### 9.0.1 你在解决什么问题

前几章的"线性工具"能直接用的前提是"问题本身线性"。但：

- 求 $\sqrt[3]{2}$、$\sin x = 1-x$、五次多项式 $x^5+x-1=0$ 的根——没有求根公式（**Galois 定理：五次以上多项式一般无根式解**）；
- 拟合实验数据 $y=\theta_1 e^{-\theta_2 t}$——目标函数关于参数 $\theta$ 非线性；
- 深度学习中"最小化损失函数"——本质是几千万元素的非线性优化。

这些问题的共同结构：

$$\textcolor{blue}{F(x^*) = 0} \quad\text{或}\quad \textcolor{blue}{x^*=\arg\min_x f(x)}$$

没有公式，只有"能算函数值、能（有时）算导数"的黑盒。本章要给你一套**从最笨但最可靠到最快但最娇气**的完整方法谱系。

## 9.1 非线性方程：从夹逼到迭代

**本节总览**：非线性方程 $f(x)=0$ 有三类典型解法——**区间型**（二分法，只要符号信息，绝对可靠）、**迭代型**（不动点迭代，把方程写成 $x=g(x)$ 反复代入）、**线性化型**（Newton 法，每点用切线逼近）。三类方法对函数的要求、收敛速度、可靠性递进，构成了数值方法"用信息换速度"的完整光谱。

---

### 9.1.1 求根问题、二分法与区间误差界

> **一句话本质**：求根就是找曲线穿过 $x$ 轴的那个点；二分法只依赖"区间两端异号"这个符号信息，每步把含根区间对半切，误差以比率 $1/2$ 线性收缩——它是用最少信息换绝对可靠的底线算法。

#### 1. 生活类比

- **猜数字游戏**：心里想一个 1 到 100 的整数，你每问一次"比 $x$ 大还是小"，答案就砍掉一半候选区间。最优策略（问中点）最多 $\lceil\log_2 100\rceil=7$ 次必中。二分法就是这个游戏的连续版。
- **断电排查**：一段长线路某处断路，万用表量中点——哪边不通就往哪边缩，每次排查范围减半。

#### 2. 几何直观

$f$ 连续，$f(a)$ 与 $f(b)$ 异号，则曲线在 $[a,b]$ 上**必穿过 $x$ 轴**（介值定理）。取中点 $c=\frac{a+b}{2}$：若 $f(c)=0$，找到根；否则根据 $f(c)$ 与 $f(a)$ 的符号关系，把区间换成**根仍在内**的那一半。每步区间长度减半：

$$[a,b]\xrightarrow{\text{一次二分}} \textcolor{blue}{[a,c]\ \text{或}\ [c,b]},\qquad \text{区间长度}\ \textcolor{blue}{b-a \to \frac{b-a}{2}}$$

#### 3. 底层逻辑

为什么二分法**只需要符号**、不需要导数？因为根的存在性只依赖一条拓扑事实：**连续函数从 $x$ 轴一侧走到另一侧，必然在中间碰到 $x$ 轴**。符号翻转是"根存在"的充分证据，符号在区间哪一侧决定"根在哪半边"。这条逻辑链里没有出现导数——所以二分法对不可导、黑盒、甚至只有函数值查询权限的问题同样有效。这是它在"可靠"维度上的不可替代性。

#### 4. 严格推导：误差界（定理 9.1，可手推）

**定理 9.1（二分法误差界）** 设 $f\in C[a,b]$，$f(a)f(b)<0$。第 $k$ 次迭代的中点记为 $x_k$，则

$$\textcolor{blue}{|x_k-x^*|} \le \textcolor{red}{\frac{b-a}{2^{k+1}}}$$

**证明（两步，严禁跳步）**：

**第一步（区间嵌套）**：归纳证明第 $k$ 次迭代后，含根区间 $[a_k,b_k]$ 满足 $b_k-a_k=\frac{b-a}{2^k}$，且 $x^*\in[a_k,b_k]$。
- $k=0$：$b_0-a_0=b-a$，$x^*\in[a,b]$ 由介值定理保证。✓
- 归纳步：若 $[a_k,b_k]$ 含根且长度 $\frac{b-a}{2^k}$，中点 $x_k=\frac{a_k+b_k}{2}$。若 $f(x_k)=0$ 则完成；否则由 $f(a_k)f(x_k)<0$ 或 $f(x_k)f(b_k)<0$（两者必居其一，因为 $f(a_k)f(b_k)<0$）选择新区间，长度恰为一半。✓

**第二步（中点离根的距离）**：$x_k$ 是 $[a_k,b_k]$ 的中点，$x^*$ 在该区间内，所以 $x^*$ 到中点的距离**至多**是区间长度的一半：

$$|x_k-x^*|\le \frac{b_k-a_k}{2}=\frac{b-a}{2^{k+1}}.\qquad\blacksquare$$

**推论 9.1（步数预算）** 要达到精度 $|x_k-x^*|\le\varepsilon$，需要

$$k \ge \left\lceil\log_2\frac{b-a}{\varepsilon}\right\rceil-1$$

**证明**：由定理 9.1，只需 $\frac{b-a}{2^{k+1}}\le\varepsilon$，两边取 $\log_2$：$k+1\ge\log_2\frac{b-a}{\varepsilon}$。$\blacksquare$

> 注意：误差界里的 $-1$ 是因为**第 0 次迭代就取了一次中点**。很多教材写 $(b-a)/2^{k+1}$ 而把"第 1 次迭代后"记为 $(b-a)/2$，本质一样，别被记号绕晕。

#### 5. 算法三步走：二分法

**① 痛点**：求根公式不存在（五次以上多项式无根式解、超越方程无闭式解）；需要一种**无条件可靠**、只要求"能算函数值"的方法。

**② 直觉**：异号 ⇒ 穿轴 ⇒ 对半切 ⇒ 区间减半 ⇒ 误差减半。用"每步 1 比特精度"换"永不失败"。

**③ 公式 + 手搓步骤**：

```
输入：f, a, b（f(a)f(b)<0）, 容差 tol
输出：满足 |x-x*| ≤ tol 的近似根
1  for k = 0, 1, 2, ...:
2      c = (a + b) / 2
3      若 f(c) == 0 或 (b-a)/2 ≤ tol: 返回 c
4      若 f(a)·f(c) < 0:  b ← c        （根在左半边）
5      否则:              a ← c        （根在右半边）
```

**手算演示**：求 $f(x)=x^3-2=0$ 在 $[1,2]$ 上的根（真值 $\sqrt[3]{2}=1.25992105\ldots$）。

| $k$ | 区间 | 中点 $c$ | $f(c)$ | 符号判定 | 误差界 |
|---|---|---|---|---|---|
| 0 | $[1,2]$ | 1.5 | $+1.375$ | $f(1)f(1.5)<0$ → 取左半 | 0.5 |
| 1 | $[1,1.5]$ | 1.25 | $-0.0469$ | $f(1.25)f(1.5)<0$ → 取右半 | 0.25 |
| 2 | $[1.25,1.5]$ | 1.375 | $+0.5996$ | 取左半 | 0.125 |
| 3 | $[1.25,1.375]$ | 1.3125 | $+0.2610$ | 取左半 | 0.0625 |

> 手算要点：每步只看**中点函数值的符号**，与端点异号的一侧为新区间。4 步后误差界已从 0.5 缩到 0.0625，这就是"每步 1 比特"。

#### 6. Python 复现与误差可视化

完整脚本：`code/ch9/ch9_1_bisection.py`（可直接运行）。核心算法只有几行：

```python
import numpy as np

def bisection(f, a, b, tol=1e-14, maxit=60):
    fa, fb = f(a), f(b)
    assert fa * fb < 0, "区间端点必须异号"
    cs, hs = [], []
    for _ in range(maxit):
        c = (a + b) / 2
        fc = f(c)
        cs.append(c)
        hs.append((b - a) / 2)          # 当前误差界
        if fc == 0 or (b - a) / 2 < tol:
            break
        if fa * fc < 0:                 # 根在 [a, c]
            b, fb = c, fc
        else:                           # 根在 [c, b]
            a, fa = c, fc
    return np.array(cs), np.array(hs)

cs, hs = bisection(lambda x: x**3 - 2.0, 1.0, 2.0)
xstar = 2.0 ** (1/3)
print(f"47 步后误差 = {abs(cs[-1] - xstar):.2e}")   # ≈ 1e-14，与预算 ceil(log2(1/1e-14))=47 一致
```

![二分法误差每步减半，真实误差始终压在理论误差界下方](figures/ch9_bisection_error.png)

**误差可视化解读**：对数坐标下误差是斜率为 $-\log_{10}2\approx-0.301$ 的直线——每步误差乘以 $1/2$，即每步获得 1 bit（$\log_{10}2\approx0.3$ 个十进制位）。三条结论从图上直接读出：

1. 真实误差**永远小于等于**理论误差界（红色虚线），误差界是紧的；
2. 收敛阶 $p=1$（线性），比率 $C=1/2$；
3. 达到 $10^{-14}$ 需要约 $\log_2(10^{14})\approx47$ 步——**每步只赚 1 bit，这就是二分法的全部成本**。

#### 7. 易错坑点

1. **$f(a)f(b)<0$ 只保证"至少一个根"，不保证唯一**。$f(x)=x^3-3x+1$ 在 $[-2,2]$ 上 $f(-2)f(2)<0$，但有 3 个根。二分法仍能收敛到其中一个，但收敛到哪个取决于区间选取。
2. **偶重根不改变符号**。$f(x)=(x-1)^2$ 在 $1$ 的两侧都 $\ge 0$，$f(a)f(b)<0$ 不成立，二分法直接失效。奇重根仍可用。
3. **停止准则别用错**：`|f(c)| < ε` **不是**误差控制。$f(x)=10^{-6}(x-1)$ 在 $x=0.999$ 处 $|f|=10^{-9}$ 但误差 $10^{-3}$；$f(x)=10^6(x-1)$ 在 $x=1.001$ 处 $|f|=10^3$ 但误差才 $10^{-3}$。**停止条件应基于区间长度** `(b-a)/2 < ε`（这才是误差界），`|f(c)|` 只做辅助。
4. **乘法溢出**：`fa * fc` 在 $f$ 取值极大时可能溢出为 inf。稳健写法是判符号 `np.sign(fa) == np.sign(fc)`。
5. **浮点卡死**：当 `a`、`b` 相邻（`b-a` 到机器精度）时 `c=(a+b)/2` 可能等于 `a` 或 `b`，需要 `maxit` 上限保护。

#### 8. 对比辨析：二分法 vs 试位法

| 维度 | 二分法 | 试位法（Regula Falsi） |
|---|---|---|
| 新区间取法 | 始终取中点 | 取割线与 $x$ 轴交点 |
| 收敛性 | **每步区间必减半**（线性，$C=1/2$，有保障） | 步数多时可能"一端不动"，收敛可能极慢（$f(x)=x^{10}$ 类病态） |
| 函数要求 | 连续 + 异号 | 连续 + 异号 |
| 信息利用 | 仅符号 | 符号 + 函数值（更聪明但可能更慢） |
| 工程地位 | 兜底方法，常做"Newton 的前期热身" | 教学价值 > 实用价值 |

> **辨析要点**：更"聪明"（用函数值外推）不一定更快——试位法的反直觉之处正在于此。二分法靠"每步硬砍一半"获得最坏情况保障，这是它作为兜底算法的根本优势。

#### 9. 伪证辨析栏 ⭐

**伪证 1（看似对其实错）**：*"$f(a)f(b)<0$ 且 $f$ 连续，所以 $[a,b]$ 内有且仅有一个根。"*

- **错在哪**：介值定理只保证**存在**，唯一性需要额外条件（如 $f$ 单调，或 $f'>0$）。
- **反例**：$f(x)=x^3-3x+1$，$a=-2,b=2$：$f(-2)f(2)=(-1)\cdot 3<0$，但在 $[-2,2]$ 上有 3 个根。
- **正确命题**：连续 + 异号 ⇒ **至少**一个根；连续 + **严格单调** + 异号 ⇒ 唯一根。

**伪证 2（看似能推其实缺条件）**：*"二分法收敛，所以任何连续函数的根都能用它找到。"*

- **缺的条件**：区间端点**必须异号**。若根是偶重根（如 $(x-1)^2=0$ 的 $x=1$），函数不穿轴，异号条件不满足。
- **正确命题**：二分法收敛到根的前提是**端点异号**；偶重根场景需换方法（如直接极小化 $|f|$）。

**伪证 3（看似相等其实不等）**：*"$|f(c_k)|<10^{-6}$ 说明 $c_k$ 就是 $10^{-6}$ 精度的根。"*

- **不等在哪**：$|f|$ 小与"接近根"在 $f$ 平坦时完全脱钩（见坑点 3）。$f$ 在根附近越平，$|f|$ 对误差越不敏感。
- **正确关系**：误差由**区间长度**控制；$|f|$ 只是残差信号。两者之间隔着 $|f'|$：$|e|\approx|f|/|f'|$。

#### 10. 深度透析（考研 / 科研拔高）

**(a) 信息论视角：每步恰好 1 bit**。二分法每步只用 1 个比特的信息（根在左还是右），因此误差的二进制位数每步 +1：$\log_2(1/|e_k|)=k+\text{const}$。这是"区间型方法"的信息下界——任何只用"左/右"符号查询的算法，最坏情况下每步最多获得 1 bit，所以二分法在**最坏情形最优**意义下不可改进（但平均情形可被"加权中点"等策略改进，这引向**期望最优搜索**理论）。

**(b) 收敛阶的完整定义**（9.1.2 将正式使用）：称序列 $\{x_k\}$ 以阶 $p$ 收敛到 $x^*$，若存在 $C>0$ 使

$$\lim_{k\to\infty}\frac{|e_{k+1}|}{|e_k|^p}=C$$

- $p=1$ 且 $C\in(0,1)$：**线性收敛**（二分法 $C=1/2$）；
- $1<p<2$：**超线性**；
- $p=2$：**二阶收敛**（Newton 法）。
- 注意：$C=0$ 的情形单独叫**超线性**而非"阶 1 收敛"，因为 $C=0$ 时误差衰减比任何线性比率都快。

**(c) 二分法的工程搭档**：实际求解器（如 MATLAB `fzero`、SciPy `brentq`）常用"二分法兜底 + 插值加速"的混合策略：优先用逆二次插值（收敛更快），一旦插值不可靠就退回二分法保证区间减半。**可靠性由二分法兜底，速度由插值争取**——这是数值软件设计的经典模板。

### 9.1.2 不动点迭代、压缩条件与收敛阶

> **一句话本质**：把方程 $f(x)=0$ 改写成"不动点形式" $x=g(x)$ 后反复代入 $x_{k+1}=g(x_k)$；**收敛与否由压缩率 $|g'(x^*)|<1$ 决定（管"会不会收敛"），收敛阶由 $g$ 在 $x^*$ 处前几阶导数是否消失决定（管"收敛多快"）**。二分法是"1 比特/步"，不动点迭代则可能线性、超线性、二阶——代价是需要压缩条件。

#### 1. 生活类比

- **照镜子的递推**：$x_{k+1}=g(x_k)$ 像照镜子——镜中人是"下一次的你"。如果镜子每次把你**拉近**同一个点（压缩），你最终站定在那里；如果镜子把你**推开**，你就越走越远。压缩率 $L$ 就是"每次拉近的比例"。
- **估值的自我修正**：老式血压计、GPS 迭代定位都是"根据当前读数预测下一读数"的闭环。系统稳定的本质是"误差每步按比例缩小"——这就是压缩。

#### 2. 几何直观：蛛网图（cobweb）

从 $(x_0, x_0)$ 出发：竖线到曲线 $(x_0,g(x_0))$ → 横线到直线 $y=x$ 得 $(g(x_0),g(x_0))$ → 竖线到曲线……轨迹像蜘蛛网。

- **收敛**：网向内收拢，最终缠在 $y=x$ 与 $y=g(x)$ 的交点上（不动点）。收拢快慢取决于曲线在交点附近的**斜率** $|g'(x^*)|$：斜率越小收得越快。
- **发散**：网向外弹开。$|g'(x^*)|>1$ 时，交点附近的误差每一步放大 $|g'(x^*)|$ 倍。

![蛛网图：|g'|<1 收敛（左），初值越出收敛半径则发散（右）](figures/ch9_fixedpoint_cobweb.png)

#### 3. 底层逻辑

为什么要"不动点化"？因为迭代只有"**代入**"一个动作，是机器能无限重复的最小操作。$f(x)=0$ 的改写方式有**无穷多种**，例如 $x^3-x-1=0$ 可写成 $x=\sqrt[3]{x+1}$、$x=\frac{1}{x^2-1}$、$x=x^3-1$……它们有同一个根，但收敛性天差地别。**收敛性的全部秘密集中在 $g$ 在根附近的导数**——这就是压缩映射定理的价值：它把"迭代会不会收敛"归结为"一个数的绝对值是否小于 1"，可检验、可预测、可手推。

#### 4. 定义与定理（全部手推，严禁跳步）

**定义 9.1（压缩映射）** 映射 $g$ 在区间 $[a,b]$ 上是 $L$-压缩的，若存在 $0\le L<1$ 使得对所有 $x,y\in[a,b]$：

$$|g(x)-g(y)|\le L|x-y|$$

**定理 9.2（一维压缩映射定理）** 设 $g\in C[a,b]$ 且满足：(i) $g([a,b])\subseteq[a,b]$（**不变性**）；(ii) $g$ 是 $L$-压缩的。则存在**唯一**不动点 $x^*\in[a,b]$，且对任意 $x_0\in[a,b]$，迭代 $x_{k+1}=g(x_k)$ 收敛到 $x^*$，并有误差界

$$\textcolor{blue}{|x_k-x^*|}\le \textcolor{red}{\frac{L^k}{1-L}|x_1-x_0|}\quad(\text{先验界}),\qquad
\textcolor{blue}{|x_k-x^*|}\le \textcolor{red}{\frac{L}{1-L}|x_k-x_{k-1}|}\quad(\text{后验界})$$

**证明（分四步）**：

**第 1 步：存在性。** 构造 $h(x)=g(x)-x$。由不变性，$h(a)=g(a)-a\ge 0$，$h(b)=g(b)-b\le 0$。$h$ 连续，由介值定理 $\exists x^*\in[a,b]$，$h(x^*)=0$，即 $g(x^*)=x^*$。$\blacksquare$（**这一步和二分法用同一个定理，注意对照**）

**第 2 步：唯一性。** 设 $x^*,y^*$ 都是不动点，由压缩性：

$$|x^*-y^*|=|g(x^*)-g(y^*)|\le L|x^*-y^*|$$

若 $x^*\ne y^*$，两边约去 $|x^*-y^*|>0$ 得 $1\le L$，与 $L<1$ 矛盾。故 $x^*=y^*$。$\blacksquare$（**为什么能约？因为压缩性对任意两点成立，包括两个不动点**）

**第 3 步：收敛性。** 反复用压缩性：

$$|x_{k+1}-x^*|=|g(x_k)-g(x^*)|\le L|x_k-x^*|\le\cdots\le L^{k+1}|x_0-x^*|\to 0\quad(k\to\infty)\qquad\blacksquare$$

**第 4 步：先验误差界（这是"手推误差界"的标准动作——裂项求和）**。先用压缩性给相邻项"串珠子"：

$$|x_{k+1}-x_k|=|g(x_k)-g(x_{k-1})|\le L|x_k-x_{k-1}|\le\cdots\le L^k|x_1-x_0|$$

再把 $x_k$ 到 $x^*$ 的距离**裂成相邻项的无穷和**（望远镜求和取极限）：

$$x^*-x_k=\sum_{j=k}^{\infty}(x_{j+1}-x_j)$$

两边取绝对值，用三角不等式 + 几何级数：

$$|x_k-x^*|\le\sum_{j=k}^{\infty}|x_{j+1}-x_j|\le\sum_{j=k}^{\infty}L^j|x_1-x_0|
=\frac{L^k}{1-L}|x_1-x_0|.\qquad\blacksquare$$

**后验误差界**类似：$|x_k-x^*|\le\sum_{j=k}^\infty|x_{j+1}-x_j|\le(1+L+L^2+\cdots)|x_k-x_{k-1}|=\frac{L}{1-L}|x_k-x_{k-1}|$。$\blacksquare$

> **两个误差界的用途不同**：先验界在**开跑前**给预算（从 $|x_1-x_0|$ 预估要跑多少步）；后验界在**每一步之后**给现报（用当前相邻差估剩余误差）。后验界永远更紧，因为它用了实际数据。

**实用判据（可导情形）**：若 $g\in C^1[a,b]$ 且 $\max_{x\in[a,b]}|g'(x)|\le L<1$，则由**中值定理** $|g(x)-g(y)|=|g'(\xi)||x-y|\le L|x-y|$，$g$ 是压缩的。**注意**：这个判据要求 $|g'|\le L<1$ 在整个 $[a,b]$ **一致成立**，不是只在一点成立。

**定理 9.3（局部收敛）** 设 $x^*$ 是不动点，$g$ 在 $x^*$ 的某邻域内 $C^1$ 且 $|g'(x^*)|<1$，则存在 $\delta>0$，使初值 $x_0\in(x^*-\delta,x^*+\delta)$ 时迭代收敛。

**证明**：取 $L$ 使 $|g'(x^*)|<L<1$。由 $g'$ 连续，存在 $\delta>0$ 使 $|x-x^*|<\delta$ 时 $|g'(x)|\le L$。于是对 $|x-x^*|<\delta$：

$$|g(x)-x^*|=|g(x)-g(x^*)|=|g'(\xi)||x-x^*|\le L|x-x^*|<\delta$$

即 $g$ 把邻域 $(x^*-\delta,x^*+\delta)$ 映到自己，且在该邻域内 $L$-压缩。由定理 9.2 收敛。$\blacksquare$（**这就是"局部收敛"的完整证明骨架：不变性 + 压缩性都要在邻域内验证**）

**定理 9.4（收敛阶）** 设 $x^*$ 是不动点，$g\in C^p$（$p\ge1$）在 $x^*$ 邻域，且

$$g'(x^*)=g''(x^*)=\cdots=g^{(p-1)}(x^*)=0,\qquad g^{(p)}(x^*)\ne 0$$

则迭代以阶 $p$ 收敛到 $x^*$，且

$$\lim_{k\to\infty}\frac{e_{k+1}}{e_k^p}=\frac{g^{(p)}(x^*)}{p!},\qquad e_k:=x_k-x^*$$

**证明（Taylor 展开，这是"收敛阶定理"的万能模板）**：对 $g$ 在 $x^*$ 处做带 Peano 余项的 Taylor 展开：

$$g(x^*+e)=g(x^*)+\frac{g^{(p)}(x^*)}{p!}e^p+o(e^p)$$

代入 $e_{k+1}=x_{k+1}-x^*=g(x_k)-g(x^*)=g(x^*+e_k)-g(x^*)$：

$$e_{k+1}=\frac{g^{(p)}(x^*)}{p!}e_k^p+o(e_k^p)$$

除以 $e_k^p$ 取极限即得。$\blacksquare$

**两个最重要的特例**：

- $p=1$：**线性收敛**，$\lim\frac{e_{k+1}}{e_k}=g'(x^*)$——比率就是 $|g'(x^*)|$；
- $p=2$：**二阶收敛**，$\lim\frac{e_{k+1}}{e_k^2}=\frac{g''(x^*)}{2}$——误差每步平方。

> **一句话记忆**：**压缩条件管"会不会收敛"，导数消失的阶数管"收敛几阶"**。$g$ 在不动点处前 $p-1$ 阶导数全为 0，就得到 $p$ 阶收敛——Newton 法之所以二阶，正是因为它的 $g$ 满足 $g'(x^*)=0$（9.1.3 会证明）。

#### 5. 算法三步走：不动点迭代

**① 痛点**：二分法每步只赚 1 bit，太慢；如果能用导数信息构造迭代，收敛阶可以大幅提高。但首先要理解"迭代为什么会收敛"。

**② 直觉**：把求根变成"找镜子里的静止点"。静止点存在且唯一的条件 = 不变性 + 压缩；速度 = 导数消失阶数。蛛网图的斜率就是判决书。

**③ 公式 + 手搓步骤**：

```
输入：g, 初值 x0, 容差 tol, 最大步数 N
输出：不动点近似
1  对 k = 0, 1, ..., N-1:
2      x_{k+1} ← g(x_k)
3      若 |x_{k+1} - x_k| < tol（或用后验界 L/(1-L) 修正）: 停止
```

**手算演示**：$x=\cos x$，$x_0=1$（真值 $x^*=0.739085\ldots$）。

$$x_1=\cos1=0.5403,\quad x_2=\cos(0.5403)=0.8576,\quad x_3=\cos(0.8576)=0.6543,\quad x_4=0.7935$$

误差：$0.2609\to 0.1988\to 0.1185\to 0.0848\to\ldots$ 每步约乘 $|g'(x^*)|=|\sin 0.7391|=0.6736$。验证：$\frac{0.1988}{0.2609}\approx0.762$（前期，未到渐进），收敛到极限比率 $0.6736$。**注意观察**：前几步比率还没到极限——渐进比率是"极限"不是"每步"。

#### 6. Python 复现与误差可视化

完整脚本：`code/ch9/ch9_2_fixed_point.py`。

```python
import numpy as np

def fixed_point(g, x0, n=30):
    xs = np.empty(n + 1)
    xs[0] = x0
    for k in range(n):
        xs[k + 1] = g(xs[k])
    return xs

# 收敛例：g(x)=cos x
xs1 = fixed_point(np.cos, 1.0, 30)
xstar = 0.7390851332151607
err = np.abs(xs1[1:] - xstar)
print(f"x_30 = {xs1[30]:.12f}, 误差 = {err[-1]:.2e}")          # 1.9e-06
print(f"误差比率 = {(err[1:]/err[:-1])[-5:].round(4)}")        # 全为 0.6736 = |g'(x*)|

# 发散例：g(x)=x^2，不动点 0，但 x0=1.5 在收敛半径外
xs2 = fixed_point(lambda x: x**2, 1.5, 8)
print(xs2[:9].round(4))  # 1.5 -> 2.25 -> 5.06 -> 25.6 -> ... 爆炸

# 收敛阶数值估计：p ≈ ln|e_{k+1}/e_k| / ln|e_k/e_{k-1}|
p = np.log(err[2:] / err[1:-1]) / np.log(err[1:-1] / err[:-2])
print(p[-5:].round(3))   # 全为 1.0  → 线性收敛
```

**关键输出解读**：

- 收敛例 30 步后误差仍有 $1.9\times10^{-6}$——**线性收敛就是这么慢**：比率 $0.6736$，每步只赚 $\log_{10}(1/0.6736)\approx0.17$ 个十进制位，从 $0.26$ 缩到 $10^{-6}$ 需要 $\log_{0.6736}(0.26/10^{-6})\approx33$ 步；
- 发散例：$1.5\to2.25\to5.06\to25.6\to\ldots$——$x_0=1.5$ 虽离不动点 $0$ 不远，但**超出了收敛半径 $1$**，这就是"局部条件"的残酷性；
- 收敛阶估计 $p\approx1.0$：用"误差对数的比值再取对数"这一招，可以从**实测数据**读出收敛阶，不依赖理论值。这是数值实验的标准工具。

#### 7. 易错坑点

1. **改写形式不唯一，收敛性天差地别**。$x^3-x-1=0$ 写成 $x=\sqrt[3]{x+1}$（$|g'(x^*)|=|1/(3(x^*+1)^{2/3})|\approx0.29<1$，收敛）vs $x=x^3-1$（$|g'(x^*)|=|3(x^*)^2|\approx2.5>1$，发散）。**同一个根，不同的 $g$，完全相反的命运。**
2. **$|g'(x^*)|<1$ 只是局部条件**：初值必须足够近（定理 9.3 的 $\delta$ 可能很小）。$g(x)=x^2$ 在 $x^*=0$ 处 $|g'(0)|=0$，但 $x_0=1.5$ 直接爆炸。
3. **压缩条件必须在整个区间一致成立**：$\max_{[a,b]}|g'|\le L<1$，而不是"每一点 $|g'|<1$"。反例：$g(x)=x/2+10$ 处处 $|g'|=1/2<1$，但 $g$ 把 $[0,1]$ 映到 $[10,10.5]$，**不变性不成立**，从 $x_0=0$ 出发迭代奔向 $20$（不动点在区间外）。
4. **停止准则**：`|x_{k+1}-x_k|<ε` 并不意味着误差 $<ε$。由后验界，真实误差可高达 $\frac{L}{1-L}|x_{k+1}-x_k|$。$L$ 接近 1 时这个放大因子巨大——**别把"相邻差小"当成"已经收敛"**。
5. **收敛阶的比率是极限不是逐项**：前期比率偏离 $|g'(x^*)|$ 是正常的（手算演示第 4 点）。

#### 8. 对比辨析：二分法 vs 不动点迭代

| 维度 | 二分法 | 不动点迭代 |
|---|---|---|
| 前提 | 连续 + 端点异号 | 压缩条件（不变性 + $|g'|\le L<1$） |
| 每步成本 | 1 次函数求值 | 1 次函数求值 |
| 收敛保障 | **无条件**（只要前提成立） | 依赖 $g$ 的构造与初值位置 |
| 收敛阶 | 恒为 1（$C=1/2$） | 可为 1、2 甚至更高（看导数消失阶数） |
| 是否用导数 | 不用 | 收敛性分析用（$g'$） |
| 典型地位 | 兜底 / 热身 | 理论母体（Newton 是它的特例） |

> **辨析要点**：二分法靠"区间结构"获得无条件保障但只有线性速率；不动点迭代靠"压缩结构"换取潜在的高阶速率但需要精心构造。Newton 法（下一节）就是"构造 $g$ 使 $g'(x^*)=0$"的终极答案——既快又有理论支撑。

#### 9. 伪证辨析栏 ⭐

**伪证 1（看似能推其实缺条件）**：*"$|g'(x^*)|<1$，所以对任意初值迭代都收敛。"*

- **缺的条件**：初值必须在收敛邻域内（定理 9.3 的 $\delta$ 邻域）。
- **反例**：$g(x)=x^2$，$x^*=0$，$|g'(0)|=0<1$；取 $x_0=1.5$，序列 $1.5,2.25,5.06,25.6,\ldots$ 爆炸。**局部条件的含义是"局部"**：$x_0$ 得落在吸引域里。

**伪证 2（看似对其实错）**：*"处处 $|g'(x)|<1$，所以 $g$ 是压缩映射。"*

- **错在哪**：压缩要求的是**一致**上界 $\max|g'|\le L<1$。反例：$g(x)=\sqrt{x^2+0.01}$（修正版绝对值）在 $[-1,1]$ 上 $|g'(x)|=\frac{|x|}{\sqrt{x^2+0.01}}\le\frac{0.1}{\sqrt{0.01+0.01}}\approx0.71<1$ 处处成立，但 $g$ 在 $[0,1]$ 上其实满足压缩……这个例子不行。换一个硬反例：$g(x)=\frac{x^2+1}{2}$ 在 $[0,1]$：$g'(x)=x$，$|g'|<1$ 处处成立但 $\sup|g'|=1$，不满足 $L<1$。迭代 $x_{k+1}=\frac{x_k^2+1}{2}$ 从 $x_0=0$：$0.5,0.625,0.695,0.742,\ldots$ 缓慢收敛到 $1$（$g(1)=1$ 是不动点）。**收敛是收敛了，但压缩定理的结论（误差界 $\frac{L^k}{1-L}$）失效**——因为 $L=1$ 时几何级数不收敛，先验界分母 $1-L=0$。
- **本质**：$|g'|<1$ **逐点**成立与"存在 $L<1$ 一致控制"不是一回事；$\sup$ 恰为 1 时误差界公式炸掉。

**伪证 3（看似相等其实不等）**：*"误差界公式 $|x_k-x^*|\le\frac{L^k}{1-L}|x_1-x_0|$ 里的 $L$ 就是 $|g'(x^*)|$。"*

- **不等在哪**：压缩常数 $L$ 必须是**区间上的一致上界** $\max|g'|$；$|g'(x^*)|$ 只是根处的值，通常更小。用 $|g'(x^*)|$ 冒充 $L$ 会给出**过于乐观**的步数预算。
- **正确关系**：$L\ge|g'(x^*)|$；且误差界的质量取决于 $L$ 与 $|g'(x^*)|$ 的差距——这也是"局部 vs 全局"定量化的体现。

#### 10. 深度透析（考研 / 科研拔高）

**(a) 收敛阶的实测估计**。由 $|e_{k+1}|\approx C|e_k|^p$ 两边取对数：$\log|e_{k+1}|\approx p\log|e_k|+\log C$。对实测误差做 $\log|e_{k+1}|$ vs $\log|e_k|$ 的线性回归，**斜率就是 $p$**。这是验证"算法收敛阶"的标准实验手段（9.1.3 将用在同一招验证 Newton 的二阶性）。

**(b) 高维压缩映射（Banach 不动点定理）**：定理 9.2 在完备度量空间（如 $\mathbb R^n$、函数空间）上原样成立，只需把绝对值换成距离。这一推广是**偏微分方程解的存在性**（Picard 迭代解 ODE）、**迭代法解线性方程组**（$x=Bx+c$ 谱半径 <1）的理论基石。学习本章的局部收敛证明（不变性+压缩）就是在为 $\mathbb R^n$ 版做彩排。

**(c) Aitken $\Delta^2$ 加速**：线性收敛序列满足 $e_{k+1}\approx C e_k$，从连续三项可外推"极限位置"：

$$\hat{x}_k=x_k-\frac{(x_{k+1}-x_k)^2}{x_{k+2}-2x_{k+1}+x_k}$$

这个"外推"能消灭主导线性项，把 $p=1$ 变成超线性。**代价**：要求序列确实渐进线性；好处：不动点迭代秒变加速版。它是 9.3.3 割线法思想的"零阶亲戚"。

**(d) 为什么工程上还是常用二分法打底**：不动点迭代的收敛性**不可预测**（依赖 $g$ 构造与初值），而二分法每步区间必减半。工程求解器（SciPy `brentq` 等）的策略是"用高阶插值抢速度，一旦不可靠立即回退二分法保底"——**速度与可靠性分居两个角色**。

### 9.1.3 标量 Newton 法与方程组的 Jacobian 线性化

> **一句话本质**：Newton 法在每一点把非线性问题**线性化**——标量情形用切线，方程组情形用 Jacobian 定义的切平面——算出线性化的零点作为下一步。因为"线性化的误差是二次的"，所以 Newton 收敛是二阶的（误差平方）。代价：每步要导数/Jacobian，且只有初值足够近才收敛（局部方法）。

#### 1. 生活类比

- **用切线瞄准**：你站在曲线上的 $(x_k,f(x_k))$，用手杖沿**切线方向**探出去，手杖戳到 $x$ 轴的位置就是 $x_{k+1}$。切线是曲线的局部最佳直线近似——"直线版你"，把直线零点当作曲线零点的一次改进。
- **射击校正**：打靶偏了 $f(x_k)$，瞄准基线偏转率是 $f'(x_k)$，校正量就是"偏差 ÷ 变化率"：$x_{k+1}=x_k-\frac{f(x_k)}{f'(x_k)}$。偏差越大或变化率越平，要移动得越多。

#### 2. 几何直观

标量：过 $(x_k,f(x_k))$ 作切线，切线与 $x$ 轴交点即 $x_{k+1}$。方程组：$F(x)=0$ 是两张曲面（两条曲线）的交点；在 $x_k$ 用 Jacobian $J(x_k)$ 张出切平面，求**切平面与坐标面的交点**作为 $x_{k+1}$。

![方程组 Newton：沿 Jacobian 定义的切线方向逐次逼近两条曲线的交点](figures/ch9_newton_system.png)

#### 3. 底层逻辑

Newton 法的思想可以浓缩为一句**元方法**：

> **非线性 → 线性化 → 解线性系统 → 重复。**

它是整个数值计算最重要的通用模板——9.3 的优化 Newton、9.4 的 Gauss-Newton 都是它的直接子孙。为什么值得为它付出"每步求导数 + 解线性系统"的代价？因为二阶收敛：误差每步**平方**。$0.1\to0.01\to10^{-4}\to10^{-8}\to10^{-16}$——几步之内达到机器精度，这是线性收敛永远做不到的。

#### 4. 严格推导：迭代式与二阶收敛（定理 9.5，全手推）

**Newton 迭代式的来源**（不是背的，是"从 Taylor 展开里长出来的"）：对 $f$ 在 $x_k$ 处做一阶 Taylor（线性化）：

$$f(x)\approx f(x_k)+f'(x_k)(x-x_k)$$

令线性近似为零，解得"线性化的零点"：

$$f(x_k)+f'(x_k)(x_{k+1}-x_k)=0\quad\Longrightarrow\quad
\textcolor{blue}{x_{k+1}=x_k-\frac{f(x_k)}{f'(x_k)}}$$

**定理 9.5（标量 Newton 二阶收敛）** 设 $f\in C^2$，$f(x^*)=0$，$f'(x^*)\ne0$。则存在 $\delta>0$，当 $x_0\in(x^*-\delta,x^*+\delta)$ 时 Newton 迭代收敛到 $x^*$，且

$$\lim_{k\to\infty}\frac{e_{k+1}}{e_k^2}=\frac{f''(x^*)}{2f'(x^*)},\qquad e_k:=x_k-x^*$$

**证明（三步，每步都显式写出，严禁跳步）**：

**第 1 步：把 $e_{k+1}$ 用 $e_k$ 表示。** 由迭代式减去 $x^*$：

$$e_{k+1}=x_k-\frac{f(x_k)}{f'(x_k)}-x^*=e_k-\frac{f(x_k)}{f'(x_k)}
=\frac{e_k f'(x_k)-f(x_k)}{f'(x_k)}$$

**第 2 步：对 $f$ 在 $x_k$ 处 Taylor 展开到二阶（带 Lagrange 余项），并利用 $f(x^*)=0$：**

$$0=f(x^*)=f(x_k)+f'(x_k)(x^*-x_k)+\frac{1}{2}f''(\xi_k)(x^*-x_k)^2
=f(x_k)-e_k f'(x_k)+\frac{1}{2}f''(\xi_k)e_k^2$$

其中 $\xi_k$ 介于 $x_k$ 与 $x^*$ 之间。**移项**得到关键恒等式：

$$e_k f'(x_k)-f(x_k)=\frac{1}{2}f''(\xi_k)e_k^2$$

**第 3 步：代入并取极限。** 把恒等式代回第 1 步：

$$e_{k+1}=\frac{1}{2}\cdot\frac{f''(\xi_k)}{f'(x_k)}\cdot e_k^2$$

两边除以 $e_k^2$：$\frac{e_{k+1}}{e_k^2}=\frac{1}{2}\frac{f''(\xi_k)}{f'(x_k)}$。因为 $x_k\to x^*$ 时 $\xi_k\to x^*$，由 $f''$ 连续与 $f'(x^*)\ne0$：

$$\lim_{k\to\infty}\frac{e_{k+1}}{e_k^2}=\frac{f''(x^*)}{2f'(x^*)}.\qquad\blacksquare$$

**收敛性本身（不靠"假设收敛"）**：由 $f''$ 连续与 $f'(x^*)\ne0$，存在 $\delta>0$ 与 $C>0$，在 $|x-x^*|<\delta$ 内 $|f''(x)|\le2|f'(x)|C$，于是 $|e_{k+1}|\le C|e_k|^2$。取 $x_0$ 使 $C|e_0|<1$，归纳得

$$|e_k|\le(C|e_0|)^{2^k-1}\xrightarrow{k\to\infty}0$$

故 $x_k\to x^*$（且指数式收敛，这就是"二阶"的爆炸威力）。$\blacksquare$

> **定理的两个"不能删"的条件**：$f''$ 存在（Taylor 到二阶需要）与 $f'(x^*)\ne0$（重根会退化，见下）。第二个条件尤其隐蔽——**重根处 Newton 不再是二阶**。

**重根退化**：若 $x^*$ 是 $m\ge2$ 重根，$f(x)=(x-x^*)^m h(x)$，$h(x^*)\ne0$，则

$$g(x)=x-\frac{f(x)}{f'(x)},\qquad g'(x^*)=1-\frac{1}{m}\in(0,1)$$

Newton 迭代退化为**线性收敛**（比率 $1-\frac1m$）。**修复**：改用 $x_{k+1}=x_k-m\frac{f(x_k)}{f'(x_k)}$，此时新的 $g'(x^*)=0$，恢复二阶。（完整推导见 9.1.3 深度透析。）

#### 5. 从标量到方程组：Jacobian 线性化

设 $F:\mathbb R^n\to\mathbb R^n$，分量 $F_i$。在 $x_k$ 处做多元 Taylor（一阶线性化）：

$$F(x)\approx F(x_k)+J(x_k)(x-x_k),\qquad J_{ij}(x)=\frac{\partial F_i}{\partial x_j}(x)$$

令线性近似为零，得**方程组 Newton 迭代**：

$$\textcolor{blue}{x_{k+1}=x_k-J(x_k)^{-1}F(x_k)}\quad\Longleftrightarrow\quad
\textcolor{blue}{J(x_k)\,s_k=-F(x_k)},\ x_{k+1}=x_k+s_k$$

**工程要点**：永远解线性系统 $J s=-F$（用 `np.linalg.solve` / LU 分解），**绝不显式求逆矩阵**——求逆比解系统贵、且数值更差。

**定理 9.6（方程组 Newton 二阶收敛，证明骨架）** 设 $F$ 各分量 $C^2$，$J(x^*)$ 非奇异，则 $x_0$ 足够近时收敛且 $\|e_{k+1}\|=O(\|e_k\|^2)$。

**证明（与标量同构，四行）**：

1. 多元 Taylor（积分余项）：$F(x^*)=F(x_k)+J(x_k)(x^*-x_k)+O(\|e_k\|^2)$，即 $F(x_k)=J(x_k)e_k+O(\|e_k\|^2)$；
2. $e_{k+1}=e_k-J(x_k)^{-1}F(x_k)=J(x_k)^{-1}\big[J(x_k)e_k-F(x_k)\big]$；
3. 由 $J$ 连续与 $J(x^*)$ 非奇异，$\|J(x)^{-1}\|$ 在 $x^*$ 邻域有界；
4. 于是 $\|e_{k+1}\|\le C\|e_k\|^2$，归纳收敛。$\blacksquare$

> **多元情形唯一的"新东西"是 Jacobian**：标量的 $f'(x_k)$ 换成了矩阵 $J(x_k)$，除法换成了解线性系统。其余（线性化、误差平方、局部收敛）与标量完全平行——**这就是"从标量到方程组"只需替换一个记号的原因**。

#### 6. 算法三步走：Newton 法（标量 + 方程组）

**① 痛点**：二分法太慢（1 bit/步），不动点迭代收敛阶依赖"运气好"的 $g$ 构造。需要一种**把收敛阶锁死在 2** 的方法。

**② 直觉**：切线 = 局部最佳直线近似。让直线零点当下一步。误差的平方来自"曲线与切线的差距是二次的"。

**③ 公式 + 手搓步骤（标量）**：

```
输入：f, f', 初值 x0, 容差 tol, 最大步数 N
输出：近似根
1  对 k = 0, 1, ..., N-1:
2      x_{k+1} ← x_k - f(x_k)/f'(x_k)
3      若 |x_{k+1} - x_k| < tol: 停止
```

**手算演示**：求 $x^2-2=0$（真值 $\sqrt2=1.41421356\ldots$），$x_0=1$，$f'(x)=2x$：

$$x_1=1-\frac{-1}{2}=1.5,\qquad
x_2=1.5-\frac{2.25-2}{3}=1.416667,\qquad
x_3=1.416667-\frac{0.006944}{2.833333}=1.414216$$

误差序列：$0.4142\to0.0858\to0.00245\to2.12\times10^{-6}\to1.6\times10^{-12}$。**逐项平方的规律肉眼可见**（$0.0858\approx0.4142^2/2$，$0.00245\approx0.0858^2\cdot0.35$……），这正是 $\frac{e_{k+1}}{e_k^2}\to\frac{f''}{2f'}=\frac{2}{2\cdot2.8284}\approx0.3536$ 的渐进常数。

**方程组手算**（对照代码输出）：$F=(x^2+y^2-4,\ x^2-y^2-1)$，$x_0=(2,1)$。

$$J_0=\begin{pmatrix}4&2\\4&-2\end{pmatrix},\quad F_0=\begin{pmatrix}1\\2\end{pmatrix},\quad
\text{解 }J_0s=-F_0:\ 4s_1+2s_2=-1,\ 4s_1-2s_2=-2\Rightarrow s=(-0.375,\ 0.25)$$

$$x_1=(2,1)+(-0.375,0.25)=(1.625,1.25)$$

下一步交给计算机：$x_2=(1.5817,1.2250)$，$x_3=(1.581139,1.224745)$，$x_4$ 已达 $10^{-14}$ 精度。**注意 $|F(x_k)|$ 的序列**：$2.24\to2.18\times10^{-1}\to2.79\times10^{-3}\to5.04\times10^{-7}\to1.76\times10^{-14}$——残差也在"平方"。

#### 7. Python 复现与误差可视化

完整脚本：`code/ch9/ch9_3_newton.py`。

```python
import numpy as np

# ---- 标量 Newton ----
def newton_scalar(f, fp, x0, n=8):
    xs = np.empty(n + 1);  xs[0] = x0
    for k in range(n):
        xs[k + 1] = xs[k] - f(xs[k]) / fp(xs[k])
    return xs

f, fp = lambda x: x**2 - 2.0, lambda x: 2.0 * x
xs = newton_scalar(f, fp, 1.0, 6)
err = np.abs(xs - np.sqrt(2.0))
print(err.round(12))            # [4.14e-1 8.58e-2 2.45e-3 2.12e-6 1.59e-12 0]
print(err[1:] / err[:-1]**2)    # 比率 → 0.3536（f''/(2f') 的渐进常数）

# ---- 方程组 Newton ----
F = lambda xy: np.array([xy[0]**2 + xy[1]**2 - 4.0, xy[0]**2 - xy[1]**2 - 1.0])
J = lambda xy: np.array([[2*xy[0], 2*xy[1]], [2*xy[0], -2*xy[1]]])
x = np.array([2.0, 1.0])
for _ in range(6):
    x = x + np.linalg.solve(J(x), -F(x))   # 解 J s = -F，不求逆
    print(x, np.linalg.norm(F(x)))
```

**可视化解读**：

- 图 1（收敛阶斜率图）：$\log_{10}|e_k|$ 对 $\log_{10}|e_{k-1}|$ 的散点落在斜率 2 的直线上——**二阶收敛的实测铁证**（对比不动点迭代斜率 1）。
- 图 2（方程组轨迹）：绿色/红色曲线是 $F_1=0$、$F_2=0$，蓝色折线是 Newton 路径——每步沿 Jacobian 定义的"线性化交点"方向前进，3 步内撞上真解。

#### 8. 易错坑点

1. **Newton 是局部方法**：初值离根太远会发散/振荡。经典案例：$f(x)=x^3-3x+2$ 从某些初值出发在 1 与 0 之间循环。**工程惯例**：先用二分法跑几步缩小区间，再交给 Newton 冲刺（二分保底 + Newton 提速）。
2. **$f'(x_k)$ 接近 0 时**：切线接近水平，下一步被甩到天边。$f'(x_k)=0$ 直接除零。
3. **重根退化**：$f'(x^*)=0$ 时 Newton 只有线性收敛（比率 $1-1/m$），甚至 $f'(x_k)$ 在根附近震荡导致收敛极慢。用 $m$ 倍修正或 $f/f'$ 技巧。
4. **方程组里 $J$ 奇异**：线性系统无解或病态。此时 Newton 一步崩盘（LM 阻尼正是为此而生，见 9.4.3）。
5. **只算实根**：实数初值收敛不到复根。
6. **解线性系统而非求逆**：$J^{-1}F$ 写成 `np.linalg.inv(J) @ F` 是坏习惯——用 `np.linalg.solve(J, F)`。

#### 9. 对比辨析：四大求根方法

| 方法 | 收敛阶 | 每步成本 | 需要导数 | 可靠性 | 适用场景 |
|---|---|---|---|---|---|
| 二分法 | 1（$C=\frac12$） | 1 次 $f$ | 否 | **无条件** | 兜底、粗筛、黑盒函数 |
| 不动点迭代 | $p\ge1$ 任意 | 1 次 $g$ | 分析用 $g'$ | 依赖构造 | 理论母体、迭代法基础 |
| 割线法 | $1.618$（超线性） | 1 次 $f$ | **否** | 中 | 导数难求时 |
| Newton | **2** | $f+f'$（标量）/ $F+J$+解系统 | 是 | 局部（初值敏感） | 导数可得、初值可估 |

> **辨析要点**：收敛阶与每步成本要放在一起看。割线法虽然只超线性（1.618），但每步只要 1 次函数值——两步"等价"于 Newton 的 1 步（$f+f'$），实际效率可能相当。**"更快"永远要折算成"每步成本"之后再比**。

#### 10. 伪证辨析栏 ⭐

**伪证 1（看似能推其实缺条件）**：*"$f'(x^*)\ne0$，所以 Newton 一定二阶收敛。"*

- **缺的条件**：$f''$ 存在 + **初值足够近**。二阶收敛定理的前提是 $x_0\in(x^*-\delta,x^*+\delta)$。
- **反例**：$f(x)=x^3-3x+2$，根 $1$（$f'(1)=0$——这其实是重根条件失败）。更贴切的例子：**初值远**时 Newton 完全不收敛，二阶结论只在吸引域内成立。

**伪证 2（看似对其实错）**：*"误差平方 = 每步误差一定比上一步小。"*

- **错在哪**：$|e_{k+1}|\le C|e_k|^2$ 只在 $C|e_k|<1$ 时保证缩小；若 $C|e_k|>1$（初值偏大），误差反而**放大**。收敛定理里"初值足够近"（$C|e_0|<1$）就是为了保证平方后变小。
- **反例**：$f(x)=x^3$，$x_0=0.5$，$e_0=0.5$，$C\approx0.9$（$f''/(2f')=\frac{6x}{6x^2}=\frac1x\to2$ 在 $x\to0$）——误差先振荡后才进入平方区。

**伪证 3（看似相等其实不等）**：*"方程组的 Newton 就是标量 Newton 每个分量各算一次。"*

- **不等在哪**：方程组必须**联立求解** $Js=-F$，Jacobian 的非对角项（$F_1$ 对 $x_2$ 的偏导）耦合了各分量。逐分量独立 Newton 完全忽略耦合，一般不会收敛。
- **正确关系**：标量公式是 $n=1$ 的特例（$J$ 是 $1\times1$ 矩阵"$f'$"，解系统退化为除法）。

**伪证 4（看似能推其实缺条件，重根陷阱）**：*"Newton 收敛，所以 $f'(x^*)=0$ 也无所谓。"*

- **错**：$f'(x^*)=0$ 时定理 9.5 的极限公式分母为零，收敛阶退化为 1。**判定方法**：实测 $\frac{e_{k+1}}{e_k^2}$ 是否趋于有限常数——若是则二阶；若 $\frac{e_{k+1}}{e_k}$ 趋于 $(0,1)$ 内的常数则是重根。

#### 11. 深度透析（考研 / 科研拔高）

**(a) 重根修正的完整推导**。设 $f(x)=(x-x^*)^m h(x)$，$h(x^*)\ne0$。直接算 $g(x)=x-\frac{f}{f'}$ 在 $x^*$ 的导数：

$$\frac{f(x)}{f'(x)}=\frac{(x-x^*)^m h}{m(x-x^*)^{m-1}h+(x-x^*)^m h'}
=\frac{(x-x^*)h}{mh+(x-x^*)h'}$$

于是 $g(x)-x^*=(x-x^*)\left[1-\frac{h}{mh+(x-x^*)h'}\right]$，取极限得 $\lim\frac{g(x)-x^*}{x-x^*}=1-\frac1m$。即 $g'(x^*)=1-\frac1m$，线性收敛比率 $1-\frac1m$。而 $x_{k+1}=x_k-m\frac{f}{f'}$ 对应 $\tilde g$ 满足 $\tilde g'(x^*)=1-m\cdot\frac1m=0$，恢复二阶。**另一个更稳的工程技巧**：对 $u(x)=f(x)/f'(x)$ 做 Newton（$u$ 的根是 $f$ 的**单根**，因为 $u=(x-x^*)\frac{h}{mh+(x-x^*)h'}$ 在 $x^*$ 处一阶消失）——既免去知道重数 $m$，又自动二阶。

**(b) 割线法的收敛阶推导（$p=\varphi$ 的来历）**。割线法用 $(x_{k-1},x_{k-1})$ 与 $(x_k,f(x_k))$ 的割线替代切线：

$$x_{k+1}=x_k-\frac{f(x_k)(x_k-x_{k-1})}{f(x_k)-f(x_{k-1})}$$

Taylor 展开可得误差递推：$e_{k+1}\approx Ce_ke_{k-1}$，$C=\frac{f''(x^*)}{2f'(x^*)}$。设收敛阶为 $p$，即 $e_k\sim Ke_{k-1}^{p}$，代入递推并同时使用收敛阶定义：

$$e_{k+1}\approx CK\,e_{k-1}^{p+1},\qquad e_{k+1}\sim K^{p+1}e_{k-1}^{p^2}$$

比较 $e_{k-1}$ 的指数：$p+1=p^2\Rightarrow p^2-p-1=0\Rightarrow p=\frac{1+\sqrt5}{2}\approx1.618$。**超线性但不二阶**——这就是"不用导数"的代价与收获的平衡点。

**(c) 数值 Jacobian**：当解析 Jacobian 太贵/没有时，用有限差分 $J_{ij}\approx\frac{F_i(x+h e_j)-F_i(x)}{h}$。**步长 $h$ 的选择是门学问**：太大 → 截断误差；太小 → 舍入误差。最优约 $h\sim\sqrt{\varepsilon_{\text{mach}}}\approx1.5\times10^{-8}$（一阶差分）。这与 9.2.3 信赖域的"模型可信度"思想同源：**每一步都在截断误差与舍入误差之间走钢丝**。

**(d) Kantorovich 定理（只陈述，考研不要求证明）**：不要求"存在 $x^*$"，直接从初值信息判定收敛——若 $\|F(x_0)\|$、$\|J(x_0)^{-1}\|$、Lipschitz 常数满足某个不等式，则 Newton 收敛且 $x^*$ 存在。这把"局部收敛"升级为"**可验证的收敛条件**"。

**(e) 与 9.2、9.4 的桥**：优化 Newton 就是"把 $F$ 换成 $\nabla f$，把 $J$ 换成 $\nabla^2 f$"；Gauss-Newton 就是"把 $\nabla^2 f$ 换成 $J^TJ$"。**本章的 Jacobian 线性化，是全章后半段的引擎**。

#### 12. 本节自测

### 9.2.1 无约束最优性条件与驻点剖析

> **一句话本质**：极小点的判定分两级：**必要条件**（梯度为零、Hessian 半正定）负责"筛掉冒牌货"，**充分条件**（Hessian 正定）负责"盖章确认"；梯度为零的点（驻点）只是"嫌疑名单"，正定性能把它分成极小、极大、鞍点三类。

#### 1. 生活类比

- **山谷、山顶与马鞍**：站在谷底，往**任何**方向走都是上坡（Hessian 正定）；站在山顶，往任何方向走都是下坡（Hessian 负定）；站在马鞍口，沿着山脊方向是下坡、横跨山脊方向是上坡（Hessian 不定）。"驻点"就是"地面水平"的地方——但水平可以是谷底、山顶，也可以只是马鞍。
- **停车入位**：你停好了（速度为零 = 梯度为零），但"停好了"不代表"停对了"——可能停在了坡顶（极大）或鞍点（接下来会滑向一边）。要确认"停对了"，得看周围是不是都向上（Hessian 正定）。

#### 2. 几何直观

在驻点 $x^*$ 处 Taylor 展开到二阶：

$$f(x^*+d)=f(x^*)+\textcolor{red}{\underbrace{\nabla f(x^*)^T d}_{=0\ (\text{驻点})}}+\frac12\,d^T\textcolor{blue}{\nabla^2 f(x^*)}d+o(\|d\|^2)$$

一阶项消失后，**函数在驻点附近的行为完全由 Hessian 的二次型 $d^THd$ 决定**：

- $H$ 正定（特征值全 $>0$）：$d^THd>0$ 对所有 $d\ne0$ —— 四面八方都上升，谷底；
- $H$ 负定（全 $<0$）：都下降，山顶；
- $H$ 不定（有正有负）：有的方向上升、有的方向下降，马鞍。

#### 3. 底层逻辑

为什么优化理论的第一站是"最优性条件"而不是"算法"？因为**算法要停，得先知道停在哪才算对**。最优性条件回答三个问题：必要条件（哪些点必须被怀疑）、充分条件（哪些点可以确认）、以及"条件差一点会怎样"（半正定 vs 正定之间的鸿沟）。所有优化算法的停机判据最终都回到"梯度是否为零"。

#### 4. 三个定理（全部手推）

**定理 9.7（一阶必要条件）** 若 $x^*$ 是 $f\in C^1$ 的局部极小点，则 $\nabla f(x^*)=0$。

**证明（反证 + 方向导数）**：设 $\nabla f(x^*)=g\ne0$，取方向 $d=-g$。沿 $d$ 的方向导数：

$$\nabla f(x^*)^Td=-g^Tg=-\|g\|^2<0$$

由 Taylor 一阶展开，$f(x^*+td)=f(x^*)+t\nabla f(x^*)^Td+o(t)$，故对充分小的 $t>0$，$f(x^*+td)<f(x^*)$——与局部极小矛盾。$\blacksquare$

**定理 9.8（二阶必要条件）** 若 $x^*$ 是 $f\in C^2$ 的局部极小点，则 $\nabla f(x^*)=0$ 且 $\nabla^2 f(x^*)$ **半正定**。

**证明**：对任意方向 $d$，定义 $\varphi(t)=f(x^*+td)$。$x^*$ 局部极小 $\Rightarrow$ $\varphi$ 在 $t=0$ 处取局部极小 $\Rightarrow$ $\varphi''(0)\ge0$。而

$$\varphi''(0)=d^T\nabla^2 f(x^*)d$$

对任意 $d$ 成立，即 Hessian 半正定。$\blacksquare$（**注意：必要条件只能"排除"，不能"确认"**）

**定理 9.9（二阶充分条件）** 若 $\nabla f(x^*)=0$ 且 $\nabla^2 f(x^*)$ **正定**，则 $x^*$ 是严格局部极小点。

**证明**：设 $H=\nabla^2 f(x^*)$，记其最小特征值为 $\lambda_{\min}>0$。对充分小的 $d$，Taylor 二阶展开（Peano 余项）：

$$f(x^*+d)-f(x^*)=\frac12 d^THd+o(\|d\|^2)\ge\frac{\lambda_{\min}}{2}\|d\|^2+o(\|d\|^2)$$

取 $\|d\|$ 足够小使 $o(\|d\|^2)\ge-\frac{\lambda_{\min}}{4}\|d\|^2$，则差 $\ge\frac{\lambda_{\min}}{4}\|d\|^2>0$。即 $x^*$ 邻域内 $f$ 严格大于 $f(x^*)$。$\blacksquare$

**定义 9.2（驻点 / 鞍点）** $\nabla f(x^*)=0$ 的点叫**驻点**（stationary point）。驻点中：$H$ 正定 → 局部极小；$H$ 负定 → 局部极大；$H$ 不定 → **鞍点**（saddle point）。

**补充（凸函数的全局性）**：若 $f$ 是**凸函数**且 $\nabla f(x^*)=0$，则 $x^*$ 是**全局**极小点。证明：凸函数的一阶刻画 $f(y)\ge f(x)+\nabla f(x)^T(y-x)$ 对任意 $x,y$ 成立，代入 $x=x^*$：$f(y)\ge f(x^*)$ 对所有 $y$。$\blacksquare$

#### 5. 算法三步走：驻点判别流程

**① 痛点**：拿到一个 $x$，怎么判断它是不是（局部）极小？

**② 直觉**：先查"地面水平"（梯度=0），再查"周围是否都向上"（Hessian 正定）。

**③ 公式 + 手搓步骤**：

```
输入：f, ∇f, ∇²f, 候选点 x
1  若 ‖∇f(x)‖ ≠ 0:  → 不是驻点，更不是极小
2  计算 H = ∇²f(x) 的特征值（或主子式判定正定性）
3  特征值全 > 0  → 严格局部极小
   特征值全 < 0  → 局部极大
   有正有负      → 鞍点
   含 0 特征值   → 退化，需看更高阶项（谨慎！）
```

**手算演示**：$f(x,y)=x^2+3y^2+xy$。

$$\nabla f=(2x+y,\ x+6y),\qquad \nabla^2 f=H=\begin{pmatrix}2&1\\1&6\end{pmatrix}$$

解驻点方程组：$2x+y=0,\ x+6y=0\Rightarrow y=-2x\Rightarrow x-12x=0\Rightarrow x=0,y=0$。判定 $H$ 正定性：特征方程 $\det(H-\lambda I)=\lambda^2-8\lambda+11=0$，$\lambda=4\pm\sqrt5\approx(1.76,6.24)$ 全正 $\Rightarrow$ $(0,0)$ 是严格局部极小。✓

#### 6. Python 复现

完整脚本：`code/ch9/ch9_6_newton_opt.py`（含本节最关键的**鞍点陷阱**演示：$f(x,y)=x^2-2y^2$ 的 $(0,0)$ 处 $\nabla f=0$ 但 Hessian 特征值 $\{2,-4\}$ 一正一负，是鞍点——Newton 一步就从 $(1,1)$ 直捣鞍点）。

```python
import numpy as np
# f(x,y) = x^2 - 2y^2：H = diag(2, -4)，不定
H = np.diag([2.0, -4.0])
x0 = np.array([1.0, 1.0])
g0 = np.array([2.0, -4.0])
d = np.linalg.solve(H, -g0)   # 纯 Newton 方向
x1 = x0 + d                   # 一步到 (0,0)：梯度为 0，但它是鞍点！
print(f"x1 = {x1}，H 特征值 = {np.linalg.eigvals(H)}")
```

#### 7. 易错坑点

1. **梯度为零 ≠ 极小**：鞍点 $f(x,y)=x^2-y^2$ 在原点梯度为零却是鞍点。**梯度条件只是"嫌疑人名单"**。
2. **Hessian 半正定 ≠ 极小**（这是最阴的坑）：$f(x,y)=x^2-y^4$ 在 $(0,0)$ 处 $\nabla f=(2x,-4y^3)|_{(0,0)}=0$，$H=\text{diag}(2,0)$ 半正定，但沿 $y$ 轴 $f(0,t)=-t^4<0$——**不是**局部极小。原因：$y^4$ 是四阶项，Hessian（二阶）根本"看"不到它。二阶必要条件 ≠ 二阶充分条件。
3. **正定性判定要算全**：只检查主子式的主对角或只查 $H_{11}>0$ 不够，要所有顺序主子式全正（Sylvester 判据）或特征值全正。
4. **局部极小 ≠ 全局极小**：非凸函数有多个局部极小，算法收敛到哪个取决于初值。
5. **退化驻点（$H$ 奇异）**：需展开到三阶甚至更高判断，没有一般性算法——工程上视为"病态，换初值重跑"。

#### 8. 对比辨析：三类驻点

| 驻点类型 | Hessian 特征值 | 局部形状 | 数值算法倾向 |
|---|---|---|---|
| 局部极小 | 全正 | 碗（谷底） | 收敛目标 |
| 局部极大 | 全负 | 倒碗 | 被避开（$\min$ 视角） |
| 鞍点 | 有正有负 | 马鞍 | **陷阱**（梯度为零，算法可能停住） |
| 退化 | 含 0 | 平台/山脊 | 无定论，需高阶信息 |

> **辨析要点**：现代优化（尤其深度学习）的难处正是"到处都是鞍点而非假极小"——梯度为零但 Hessian 不定，最速下降/梯度下降可能在此**停滞**。9.3 的 Newton 类方法用 Hessian 正定性修正来"推开"鞍点，这是后话。

#### 9. 伪证辨析栏 ⭐

**伪证 1（看似对其实错）**：*"$\nabla f(x^*)=0$，所以 $x^*$ 是极小点。"*

- **反例**：$f(x,y)=x^2-y^2$，原点梯度为零但鞍点。
- **正确命题**：梯度为零只是**一阶必要条件**；是否极小由 Hessian 定。

**伪证 2（看似对其实错，更阴）**：*"$\nabla f(x^*)=0$ 且 $\nabla^2 f(x^*)$ 半正定，所以 $x^*$ 是极小点。"*

- **反例**：$f(x,y)=x^2-y^4$（见坑点 2）。半正定只是**二阶必要条件**，充分条件要求**正定**。
- **本质**：半正定只说明"二阶项不反对"；如果真正的"反对者"藏在更高阶项里（$-y^4$），Hessian 说了不算。

**伪证 3（看似能推其实缺条件）**：*"沿每条过 $x^*$ 的直线，$f$ 都在 $x^*$ 处取局部极小，所以 $x^*$ 是 $f$ 的局部极小。"*

- **反例**（经典）：$f(x,y)=(y-x^2)(y-2x^2)$。沿任意直线 $y=kx$（或 $y=0$），$f(x,kx)=x^2(k-x)(k-2x)\approx k^2x^2>0$，故沿每条直线原点都是局部极小；但沿抛物线 $y=\frac32x^2$：$f=\left(\frac32x^2-x^2\right)\left(\frac32x^2-2x^2\right)=-\frac14x^4<0$——原点根本不是局部极小！
- **本质**：局部极小的定义要求**存在一个邻域**内都成立；"沿直线"只覆盖了一维子集，**永远够不到邻域**。这是"处处一维检查"骗过"二维本质"的教科书级陷阱。

#### 10. 深度透析（考研 / 科研拔高）

**(a) 充分条件证明里的"$o(\|d\|^2)$ 如何被吃掉"**：定理 9.9 的核心是 $\frac12 d^THd\ge\frac{\lambda_{\min}}{2}\|d\|^2$ 与 $o(\|d\|^2)$ 的较量。$o(\|d\|^2)$ 的意思是"除以 $\|d\|^2$ 后趋于 0"，所以只要 $\|d\|$ 足够小，$o(\|d\|^2)$ 的绝对值就小于 $\frac{\lambda_{\min}}{4}\|d\|^2$，正定项稳赢。**"足够小的邻域存在"正是靠这个不等式证明的**——这也是"充分条件为什么叫充分"的定量答案。

**(b) 强凸与唯一性**：若 $f\in C^2$ 且 $\nabla^2 f(x)\succeq mI$（最小特征值一致 $\ge m>0$），称 $f$ 强凸。强凸 + 驻点 ⇒ **唯一**全局极小（因为 $f$ 是凸的且"碗"的曲率有正下界）。$m$ 还是收敛速率分析的关键常数（9.2.2 的条件数 $\kappa=M/m$）。

**(c) 一阶必要条件在约束问题上的推广预告**：$\min f$ 受 $g(x)\le0$ 约束时，驻点条件变成 KKT 条件（拉格朗日函数梯度为零 + 互补松弛）。**KKT 就是"带约束版梯度为零"**——本章的直觉可以直接迁移。

**(d) 特征值计算 vs Sylvester 判据**：$n$ 维判定正定性，特征值 $O(n^3)$；Sylvester 判据（所有顺序主子式 $>0$）同样是 $O(n^3)$ 但常数更小。工程上常用 **Cholesky 分解**：$H=LL^T$ 能完成 ⇔ $H$ 正定——失败即不正定，这正是 9.3.2 Hessian 修正的判据接口。

### 9.2.2 负梯度方向、方向与步长的分工

> **一句话本质**：方向负责"性质"（保证是下降的），步长负责"幅度"（走多远）；负梯度是**一阶意义下、瞬间**的最速下降方向，但"最速下降"的名字是个骗局——在弯曲的窄山谷（条件数大）里它会之字形爬行，收敛极慢。

#### 1. 生活类比

- **下山悖论**：站在山坡上，最陡的方向是梯度反方向。但如果山谷又窄又长，你每步都朝最陡方向冲，会一头撞上对面山壁、再折返——**每次都最陡，整体却在原地打转**。真正的快路是"贴着谷底走"（那正是曲率方向，见 9.3）。
- **探照灯与腿**：方向是探照灯（指哪），步长是腿（走多远）。灯指对了但步子太大，会跨过目标；步子太小，一万步也到不了。两者分工不同，缺一不可。

#### 2. 几何直观

$f(x,y)=\frac12x^2+2y^2$（Hessian 条件数 $\kappa=4$）的等高线是椭圆。从 $(1,1)$ 出发精确线搜索的最速下降路径与等高线垂直交错，形成**之字形（zigzag）**：每一步都垂直于上一步（相邻梯度正交）。

![椭圆等高线上的之字形：相邻方向正交；误差按条件数决定的比率线性收缩](figures/ch9_gd_zigzag.png)

#### 3. 底层逻辑

**方向为什么选负梯度？** 对单位方向 $d$（$\|d\|=1$），一阶 Taylor：

$$f(x+td)=f(x)+t\nabla f(x)^Td+o(t)$$

瞬时下降速率是 $\nabla f(x)^Td$。由 Cauchy-Schwarz：$\nabla f^T d\ge-\|\nabla f\|\|d\|=-\|\nabla f\|$，等号当且仅当 $d=-\nabla f/\|\nabla f\|$。所以**负梯度是使一阶下降最快的方向**——注意关键词：**一阶、瞬时**。它是"泰勒展开管得住的范围内"的最佳方向，跨出一步后梯度变了，方向要重新算。

**方向与步长的分工**：方向决定"是不是下降"（$g_k^Td_k<0$）；步长决定"降多少"。方向再完美，步长错一样完蛋（太大跨过谷底，太小原地踏步）。

#### 4. 定义与定理

**定义 9.3（精确线搜索）** 沿方向 $d_k$ 精确确定步长：

$$\alpha_k=\arg\min_{\alpha>0} f(x_k+\alpha d_k)$$

**定义 9.4（最速下降法）** $d_k=-\nabla f(x_k)$，配合（通常）精确或回溯线搜索的迭代。

**定理 9.10（相邻梯度正交）** 若 $\alpha_k$ 由精确线搜索得到，则 $g_{k+1}^Tg_k=0$（相邻梯度正交）。

**证明**：$\alpha_k$ 是 $\varphi(\alpha)=f(x_k-\alpha g_k)$ 的极小点，故 $\varphi'(\alpha_k)=g_{k+1}^T(-g_k)=0$。$\blacksquare$（**一行证明，但这是之字形的全部来源**）

**定理 9.11（二次函数的最速下降收敛速率）** 设 $f(x)=\frac12x^TAx$，$A$ 对称正定，条件数 $\kappa=\lambda_{\max}/\lambda_{\min}$。精确线搜索的最速下降满足：

$$\|x_{k+1}\|_A\le\frac{\kappa-1}{\kappa+1}\|x_k\|_A,\qquad \|v\|_A:=\sqrt{v^TAv}$$

**证明（完整，用 Kantorovich 不等式）**：

**第一步（用谱分解把迭代写成对角形式）**。$f$ 的梯度 $g_k=Ax_k$（极小点 $0$），迭代为 $x_{k+1}=x_k-\alpha_kAx_k=(I-\alpha_kA)x_k$，精确步长 $\alpha_k=\frac{g_k^Tg_k}{g_k^TAg_k}$。设 $A=Q\Lambda Q^T$（正交对角化），令 $z_k=Q^Tx_k$，$A$ 的特征值为 $0<\lambda_1\le\cdots\le\lambda_n$。则

$$\|x_k\|_A^2=x_k^TAx_k=\sum_i\lambda_i z_{k,i}^2,\qquad
\|x_{k+1}\|_A^2=\sum_i\lambda_i(1-\alpha_k\lambda_i)^2z_{k,i}^2,\qquad
\alpha_k=\frac{\sum_i\lambda_i^2z_{k,i}^2}{\sum_i\lambda_i^3z_{k,i}^2}$$

**第二步（Kantorovich 不等式）**：记 $w_i=\lambda_iz_{k,i}^2\ge0$，要证

$$\frac{\sum_i w_i(1-\alpha_k\lambda_i)^2}{\sum_i w_i}\le\left(\frac{\lambda_n-\lambda_1}{\lambda_n+\lambda_1}\right)^2$$

关键工具是**凸函数的弦上界**：$t\mapsto(1-\alpha t)^2$ 是凸函数，故在 $[\lambda_1,\lambda_n]$ 上其图像位于端点连线下方：

$$(1-\alpha t)^2\le\frac{t-\lambda_1}{\lambda_n-\lambda_1}(1-\alpha\lambda_n)^2+\frac{\lambda_n-t}{\lambda_n-\lambda_1}(1-\alpha\lambda_1)^2$$

代入 $\alpha_k$ 并整理（展开 $(1-\alpha t)^2$、用 $w_i=\lambda_iz_i^2$ 的定义、利用 $\alpha_k$ 的表达式消去公共分母），得到：

$$\sum_i w_i(1-\alpha_k\lambda_i)^2\le\left(\frac{\lambda_n-\lambda_1}{\lambda_n+\lambda_1}\right)^2\sum_i w_i$$

**第三步（合成）**：$\frac{\lambda_n-\lambda_1}{\lambda_n+\lambda_1}=\frac{\kappa-1}{\kappa+1}$，代入即得 $\|x_{k+1}\|_A\le\frac{\kappa-1}{\kappa+1}\|x_k\|_A$。$\blacksquare$

> **定理读法（三个层次）**：① $\kappa=1$（等高线是同心圆）时比率为 0——**一步到位**；② $\kappa$ 越大比率越接近 1——越慢；③ 这是一个**上界**（最坏情形），实际可能更快（代码里实测每步交替 0.52/0.21，比 0.6 快，因为初值在特征空间的位置不是最坏方向）。

**推论（为何"最速下降"名不副实）**：对二次函数，$f$ 沿最速下降方向每步都下降得最多（一阶意义），但**整体收敛速度由条件数决定**，与"最速"无关。$\kappa=10^6$ 时每步只缩 $1-2\times10^{-6}$，需要约 $3.5\times10^6$ 步——这就是"最速下降"的欺骗性。

#### 5. 算法三步走：最速下降法

**① 痛点**：最简单的优化迭代，需要理解"方向与步长的分工"与"局部最优 ≠ 全局快"。

**② 直觉**：负梯度管下降方向；精确线搜索把步子迈到"谷底投影"；但正交性让下一步从零开始——信息被浪费。

**③ 公式 + 手搓步骤**：

```
输入：f, ∇f, 初值 x0
输出：近似极小点
1  对 k = 0, 1, ...:
2      g_k ← ∇f(x_k)
3      方向: d_k ← -g_k
4      步长: α_k ← argmin f(x_k + α d_k)   （精确）或回溯/Armijo
5      x_{k+1} ← x_k + α_k d_k
```

**手算演示**：$f(x,y)=\frac12x^2+2y^2$，$x_0=(1,1)$，$g_0=(1,4)$，精确步长

$$\alpha_0=\frac{g_0^Tg_0}{g_0^TAg_0}=\frac{1+16}{1\cdot1+4\cdot16}=\frac{17}{65}=0.2615,\qquad
x_1=(1,1)-0.2615(1,4)=(0.7385,-0.0462)$$

验证正交：$g_1=(0.7385,-0.1846)$，$g_0^Tg_1=0.7385-4\times0.1846\approx0$ ✓。**之字形从这里开始**：第二步又横跨回去，$x_2=(0.1108,0.1108)$。误差每两步收缩一次，比率由 $\kappa=4$ 决定。

#### 6. Python 复现与误差可视化

完整脚本：`code/ch9/ch9_4_gradient_descent.py`。

```python
import numpy as np

A = np.diag([1.0, 4.0])                 # κ = 4
grad = lambda x: A @ x
x = np.array([1.0, 1.0])
for k in range(20):
    g = grad(x)
    alpha = (g @ g) / (g @ A @ g)       # 精确线搜索步长（推导见定理 9.11）
    x = x - alpha * g
    if k < 3: print(f"k={k}  x=({x[0]:.6f},{x[1]:.6f})")
# 输出：k=0 (0.738462,-0.046154)  k=1 (0.110769,0.110769)  k=2 (0.081799,-0.005112)
print(f"g0·g1 = {grad([1,1]) @ grad([0.7385,-0.0462]):.1e}")   # ≈ 0，相邻正交
```

**可视化解读**：左图是之字形路径——每步与等高线相切方向垂直；右图对数坐标下误差是直线（线性收敛），斜率由 $\frac{\kappa-1}{\kappa+1}=0.6$ 给出。**换一个更大的 $\kappa$（比如 100），直线的斜率会贴向 0，直观看到"最速下降"变成"龟速下降"。**

#### 7. 易错坑点

1. **把"最速"当"最快"**：最速下降是**一阶瞬时**最优，不是全局最优路径。$\kappa$ 大时它慢得离谱。
2. **固定步长会发散**：对二次函数，固定 $\alpha>\frac{2}{\lambda_{\max}}$ 时迭代发散（$|1-\alpha\lambda_{\max}|>1$）。**步长不是想取多大取多大**。
3. **精确线搜索很贵**：每次要解一维极小化。工程上多用回溯/Armijo（9.2.3）。
4. **停止准则**：用 $\|g_k\|$ 判断（必要条件），别用 $\|x_{k+1}-x_k\|$ 或 $|f_{k+1}-f_k|$（后两者可能小但梯度没消失）。
5. **非凸问题会卡在鞍点**：梯度为零但 Hessian 不定时算法停滞（结合 9.2.1 坑点 5）。

#### 8. 对比辨析：三种"下降"方法的定位

| 方法 | 方向 | 步长 | 收敛速率（二次型） | 每步成本 |
|---|---|---|---|---|
| 最速下降 | $-\nabla f$ | 精确/回溯 | 线性，比率 $\frac{\kappa-1}{\kappa+1}$ | $O(n)$（只有梯度） |
| 共轭梯度（CG） | 共轭方向 | 精确 | $n$ 步内**有限步**收敛 | $O(n)$ |
| Newton 法（9.3） | $-H^{-1}\nabla f$ | 回溯 | **二阶**（误差平方） | $O(n^2)$（Hessian + 解系统） |

> **辨析要点**：最速下降每步最便宜但最慢；Newton 每步最贵但最快；CG 是"中间路线"——只要梯度，却有 $n$ 步有限收敛（条件数被"共轭"驯服）。**"快慢"要折算每步成本**（同 9.1.3 的割线 vs Newton 之辨）。

#### 9. 伪证辨析栏 ⭐

**伪证 1（看似对其实错）**：*"最速下降是最快的下降方法。"*

- **错在哪**："最速"指**局部一阶**瞬时速率，与全局收敛速度无关。
- **反例**：$\kappa=10^6$ 的二次函数，最速下降需要约百万步；共轭梯度 $n$ 步内完成。**名字说最速，收敛最龟速。**
- **正确命题**：负梯度是"当前点泰勒一阶模型中"的最优方向；整体收敛速率由条件数（曲率结构）决定。

**伪证 2（看似能推其实缺条件）**：*"精确线搜索保证每步最优，所以序列一定收敛到极小。"*

- **缺的条件**：对非凸函数，精确线搜索只保证单调下降与梯度趋于零（还要配合正则性），但**可能收敛到鞍点或局部极小而非全局**；对病态问题可能数值停滞。
- **正确命题**：光滑 + 有界下方 + 恰当步长 ⇒ $\|g_k\|\to0$（Zoutendijk，见 9.2.3）；收敛到**什么**取决于初值与非凸结构。

**伪证 3（看似对其实错）**：*"之字形是步长没调好导致的实现缺陷。"*

- **反例**：精确线搜索（理论上最优的步长）恰恰**必然**产生正交 zigzag（定理 9.10）。之字形是**精确线搜索的数学性质**，不是 bug。
- **本质**：每步的精确最优让下一步方向与前一步正交——信息在每一步之后"归零"。

**伪证 4（看似相等其实不等）**：*"实测每步比率就等于 $\frac{\kappa-1}{\kappa+1}$。"*

- **不等在哪**：$\frac{\kappa-1}{\kappa+1}$ 是**最坏情形上界**（能量范数、所有初值）。实测每步交替（如 $\kappa=4$ 时 0.52/0.21），平均值更快。用上界预测具体序列会过于悲观。

#### 10. 深度透析（考研 / 科研拔高）

**(a) 为什么收敛速率要用能量范数 $\|\cdot\|_A$ 衡量**：最速下降的收缩性质在 $\|\cdot\|_A$ 下最干净（定理 9.11 的证明里 $A$ 同时出现在迭代与范数中，谱分解后变成标量不等式）。欧氏范数下收缩是"两步一缩"（每步交替），能量范数下是"每步一缩"——**范数的选择暴露结构的对称性**。这也是"能量"概念贯穿数值分析（有限元、CG）的原因。

**(b) Kantorovich 不等式的几何含义**：$\frac{\kappa-1}{\kappa+1}$ 由谱的**最宽区间**决定，与特征向量的分布无关。证明的"凸函数弦上界"技巧把逐项二次型压缩成一个常数——这是"最坏情形分析"的标准姿势：**用凸性把复杂的加权和化成一个只依赖端点的不等式**。

**(c) 补救：共轭梯度法（预告）**。最速下降的浪费在于 $d_{k+1}\perp d_k$。共轭梯度把方向改成 $A$-共轭（$d_i^TAd_j=0,\ i\ne j$），使每个新方向在前面的所有方向上"都走过了"，$n$ 步内完成二次函数极小化。**CG = 最速下降 + 记忆（前向共轭信息）**，是 9.2 到 9.3 的桥梁：它用"历史方向"模拟 Newton 的效果而无需 Hessian。

**(d) 条件数的工程意义**：$\kappa$ 不是抽象概念——$\kappa=10$ 时最速下降每步缩 $\frac{9}{11}\approx0.82$（需要约 35 步到 $10^{-3}$）；$\kappa=10^4$ 时每步缩 $0.9998$（需要约 $3.5\times10^4$ 步）。**预处理（preconditioning）**——换坐标使新 Hessian 接近单位阵——是把 $\kappa$ 做小的标准手段，也是大规模优化的第一课。

### 9.2.3 Armijo 回溯、Wolfe 条件与信赖域的基本思想

> **一句话本质**：方向定了之后，步长是"安全阀"——Armijo 条件保证**下降得够多**（不白走），Wolfe 再加一条**曲率条件**保证"别太吝啬"（还能多走）；信赖域换一个思路：先画一个模型可信的圈（半径 $\Delta$），在圈内找最优方向与步长，用"实际下降/预测下降"的比率 $\rho$ 决定圈的大小。

#### 1. 生活类比

- **砍价（Armijo 回溯）**：卖家报 $\alpha=1$，你觉得太贵（$f$ 降得不够），按比例砍价 $\alpha\leftarrow0.5\alpha$，直到"便宜到值得成交"（$f$ 的下降幅度达到 Armijo 线）。**关键在"成交线"怎么画**——不是"有下降就行"，而是"下降量 $\ge$ 某比例的线性预期"。
- **别抠门（Wolfe 曲率条件）**：Armijo 允许 $\alpha$ 任意小——"降一点也算降"。Wolfe 条件补一条：**你明明还能再往前走**（方向导数还很负），就别停在原地。两者合起来：既不太贪（不走过头）也不太抠（不走太少）。
- **画圈行动（信赖域）**：登山者不是先选方向再定步长，而是**先给自己画个圈**（半径 $\Delta$：这圈内我对地形的判断可信），在圈内找最优位置。圈内预测很准（$\rho\approx1$）就放大圈；预测失准（$\rho$ 小或为负）就缩小圈。**圈的半径由"模型与现实的符合度"动态决定**。

#### 2. 几何直观

固定 $x,d$，画一维函数 $\varphi(\alpha)=f(x+\alpha d)$：

- Armijo 条件：$\varphi(\alpha)\le f(x)+c_1\alpha\nabla f^Td$，即 $\varphi$ 要落在**过 $(0,f(x))$、斜率为 $c_1\nabla f^Td$ 的直线下方**。可接受区 = 曲线在直线下方的部分。
- Wolfe 曲率条件：$\varphi'(\alpha)\ge c_2\varphi'(0)$——在可接受区里还要 $\varphi$ 的斜率没有太陡的下降（即 $\varphi$ 已经"转平"，说明再走收益不大）。

![Armijo 回溯：α 从 1 开始逐次减半，直到 φ(α) 落到许可线下方](figures/ch9_armijo.png)

**信赖域**（二维视角）：在 $\|s\|\le\Delta$ 的圆内极小化二次模型 $m(s)=f+g^Ts+\frac12s^TBs$。模型预测下降 $\text{pred}=m(0)-m(s)$，实际下降 $\text{ared}=f(x)-f(x+s)$，比率 $\rho=\frac{\text{ared}}{\text{pred}}$：$\rho\approx1$ 模型准（扩大 $\Delta$），$\rho\le0$ 模型崩（缩小 $\Delta$）。

#### 3. 底层逻辑

- **为什么要"充分下降"而不只是"下降"**：$f(x_k+\alpha d_k)<f(x_k)$ 对任意小步长都成立（一阶 Taylor），单调下降本身没有约束力——步长会坍缩到 0。Armijo 把"下降量"与"步长 × 方向导数"挂钩：$\alpha$ 越小，要求越低，但**方向导数项限制了可接受区的边界**，防止步长无限小。
- **为什么要"曲率条件"**：Armijo 允许 $\alpha\to0$；曲率条件把可接受区从"靠近 0 的细条"推向"$\varphi$ 已经走完主要下降的部分"。**Armijo + Wolfe = 步长既不太大也不太小**，并且是全局收敛性证明（Zoutendijk）的两个抓手。
- **信赖域为什么要"先画圈"**：线搜索的哲学是"方向可信，步长需要试探"；信赖域的哲学是"**步长（半径）才是第一决策**，方向在圈内自由选择"。当二阶模型 $B$ 不可信（如 $B$ 非正定、含噪声）时，先限步长更稳健。

#### 4. 定义与定理（全部手推）

**定义 9.5（Armijo 条件 / 回溯）** 给定 $c_1\in(0,1)$（常取 $10^{-4}$），步长 $\alpha$ 满足

$$\textcolor{orange}{f(x+\alpha d)\le f(x)+c_1\alpha\nabla f^Td}\tag{Armijo}$$

**回溯**：从 $\alpha=1$ 开始，反复 $\alpha\leftarrow\rho\alpha$（$\rho\in(0,1)$，常取 $0.5$）直至满足 Armijo。

**定义 9.6（Wolfe 条件）** 在 Armijo 基础上，要求

$$\nabla f(x+\alpha d)^Td\ge c_2\nabla f^Td,\qquad 0<c_1<c_2<1\ (c_2\text{ 常取 }0.9)\tag{曲率}$$

**强 Wolfe** 再把左边换成 $|\nabla f(x+\alpha d)^Td|\le c_2|\nabla f^Td|$。

**定理 9.12（Armijo 步长存在性）** 设 $d$ 是下降方向（$\nabla f^Td<0$），$f$ 在 $x$ 处可微。则存在 $\alpha>0$ 满足 Armijo。

**证明（一行的核心：Taylor 的 $o(\alpha)$ 项）**：

$$\varphi(\alpha)=f(x+\alpha d)=f(x)+\alpha\nabla f^Td+o(\alpha)$$

移项：$f(x)+c_1\alpha\nabla f^Td-\varphi(\alpha)=(c_1-1)\alpha\nabla f^Td-o(\alpha)=\alpha\big[(1-c_1)|\nabla f^Td|-o(1)\big]>0$

对充分小的 $\alpha$ 成立（因为方括号内第一项是正常数，$o(1)\to0$）。$\blacksquare$

**定理 9.13（Wolfe 步长存在性）** 设 $f$ 光滑、有界下方、$\nabla f$ 一致 Lipschitz，$d$ 为下降方向。则存在 $\alpha>0$ 同时满足 Armijo 与曲率条件。

**证明（思路 + 关键步骤）**：由 Armijo 可接受集非空且有上界（Lipschitz 条件给出可接受步长的下界与上界）。考虑 $\varphi(\alpha)=f(x+\alpha d)$ 在 $\{\alpha>0\}$ 上的第一个严格极小点 $\bar\alpha$（存在，因 $\varphi$ 有界下方且 $d$ 下降）。在极小点处 $\varphi'(\bar\alpha)=0\ge c_2\varphi'(0)$（曲率条件自动满足，因 $\varphi'(0)<0$）。再证 $\bar\alpha$ 满足 Armijo：由 $\varphi$ 在 $[0,\bar\alpha]$ 上先降后升，$\varphi(\bar\alpha)\le\varphi(\alpha)$ 对某 $\alpha$ 满足 Armijo……（此步需 $\bar\alpha$ 是极小点且在可接受集边界内的论证）。$\blacksquare$（完整细节见深度透析 (b)）

**定理 9.14（Zoutendijk 条件：全局收敛的引擎）** 设 $f$ 光滑、有界下方、$\nabla f$ 一致 Lipschitz（常数 $L$）。若方向 $d_k$ 满足 $\cos\theta_k=\frac{-g_k^Td_k}{\|g_k\|\|d_k\|}\ge\delta>0$（与负梯度夹角有正下界），且步长满足 Wolfe 条件，则

$$\sum_{k=0}^{\infty}\|g_k\|^2<\infty,\qquad\text{特别地}\ \|g_k\|\to0$$

**证明（三行不等式链，全部手推）**：

1. **曲率条件给步长下界**（$s_k=\alpha_kd_k$）：$\quad g_{k+1}^Ts_k\ge c_2g_k^Ts_k\Rightarrow(g_{k+1}-g_k)^Ts_k\ge(c_2-1)g_k^Ts_k$。注意 $g_k^Ts_k=-|g_k^Ts_k|\le-\delta\|g_k\|\|s_k\|$（由 $\cos\theta_k\ge\delta$）。故

$$\|g_{k+1}-g_k\|\|s_k\|\ge(g_{k+1}-g_k)^Ts_k\ge(1-c_2)\delta\|g_k\|\|s_k\|$$

2. **Lipschitz 常数给 $\|g_{k+1}-g_k\|\le L\|s_k\|$，代入得**：$\alpha_k\|d_k\|=\|s_k\|\ge\frac{(1-c_2)\delta}{L}\|g_k\|$。

3. **Armijo 给逐步下降下界**：

$$f(x_k)-f(x_{k+1})\ge c_1\alpha_k(-g_k^Td_k)\ge c_1\delta\|g_k\|\alpha_k\|d_k\|\ge\frac{c_1\delta(1-c_2)\delta}{L}\|g_k\|^2$$

对 $k=0,\dots,N$ 求和：$f(x_0)-f(x_{N+1})\ge\frac{c_1\delta^2(1-c_2)}{L}\sum_{k=0}^{N}\|g_k\|^2$。左边有界（$f$ 有界下方），取 $N\to\infty$ 得 $\sum\|g_k\|^2<\infty$。$\blacksquare$

> **定理的工程含义**：只要方向"不太歪"（$\cos\theta$ 有正下界——最速下降 $\cos\theta=1$、Newton 方向也满足），步长守规矩（Wolfe），**算法就一定把梯度降到零**。这是所有"带线搜索的下降法"收敛性的通用骨架。

**定义 9.7（信赖域）** 迭代 $x_{k+1}=x_k+s_k$，其中 $s_k$ 是约束子问题的解：

$$\min_{\|s\|\le\Delta_k} m_k(s):=f(x_k)+g_k^Ts+\frac12s^TB_ks$$

接受判据用增益比：

$$\rho_k=\frac{f(x_k)-f(x_k+s_k)}{m_k(0)-m_k(s_k)}=\frac{\text{实际下降}}{\text{预测下降}}$$

- $\rho_k\ge\eta_1$（如 $0.1$）：接受 $s_k$，$\rho_k>\eta_2$（如 $0.75$）时扩大 $\Delta_k$；
- $\rho_k<\eta_1$：拒绝 $s_k$，缩小 $\Delta_k$。

**Cauchy 点（保证可实现的下降）**：沿 $-g_k$ 方向在圈内极小化 $m_k$ 的约束点 $s_k^C$ 满足

$$s_k^C=-\frac{\Delta_k}{\|g_k\|}g_k\quad(\text{若 }g^TBg\le0),\qquad
s_k^C=-\min\left(\frac{\|g_k\|^2}{g_k^TBg_k},\frac{\Delta_k}{\|g_k\|}\right)g_k\quad(\text{若 }g^TBg>0)$$

Cauchy 点保证：**即使 $B_k$ 很糟糕，信赖域方法也至少达到最速下降的收敛速率**——这是"信赖域再差也有下限"的保险。

**信赖域子问题的精确解（预告 9.4.3 的桥）**：$(B_k+\lambda I)s=-g_k$，其中 $\lambda\ge0$ 由 $\|s\|=\Delta_k$ 或 $\lambda=0$ 决定。**这个"加 $\lambda I$"正是 LM 阻尼的数学来源。**

#### 5. 算法三步走：回溯线搜索 + 信赖域

**① 痛点**：方向确定了，步长不能拍脑袋——太小白走、太大发散；同时要保证全局收敛（梯度必趋于零）。

**② 直觉**：Armijo 是"砍价底线"，Wolfe 是"别抠门"，信赖域是"先圈定可信域再行动"，$\rho$ 是"模型体检报告"。

**③ 公式 + 手搓步骤（Armijo 回溯）**：

```
输入：f, ∇f, x, 方向 d（∇f^Td < 0）, c1=1e-4, ρ=0.5
输出：步长 α
1  α ← 1
2  while f(x+αd) > f(x) + c1·α·∇f^T d:
3      α ← ρ·α
4  返回 α
```

**手算演示**（对照图 ch9_armijo）：$f(x,y)=x^2+10y^2$，$x_0=(1,0.6)$，$d=-\nabla f=(-2,-12)$。$\nabla f^Td=-(2+144)=-148$，$f(x_0)=4.6$，Armijo 线值 $4.6+c_1\alpha(-148)$：

| 试探 $\alpha$ | $f(x_0+\alpha d)$ | Armijo 线值 | 判定 |
|---|---|---|---|
| 1 | $f(-1,-11.4)=1300$ | 4.585 | 拒绝 |
| 0.5 | $f(0,-5.4)=291.6$ | 4.593 | 拒绝 |
| 0.25 | $f(0.5,-2.4)=57.85$ | 4.596 | 拒绝 |
| 0.125 | $f(0.75,-0.9)=8.66$ | 4.598 | 拒绝 |
| **0.0625** | $f(0.875,-0.15)=0.99$ | 4.599 | **接受** |

回溯序列 $1\to0.5\to0.25\to0.125\to0.0625$——**每步减半直到落线**。注意：$f$ 从 4.6 直降到 0.99，但 α=0.125 依然被拒——因为 Armijo 线也随 α 变化（"成交价"是动态的）。

#### 6. Python 复现与误差可视化

完整脚本：`code/ch9/ch9_5_armijo.py`（回溯的几何演示图）。

```python
import numpy as np
f = lambda x: x[0]**2 + 10*x[1]**2
g = lambda x: np.array([2*x[0], 20*x[1]])
c1, rho = 1e-4, 0.5

x0 = np.array([1.0, 0.6]); d = -g(x0)
slope = g(x0) @ d                      # = -148
alpha = 1.0
while f(x0 + alpha*d) > f(x0) + c1*alpha*slope:
    alpha *= rho
print(f"α* = {alpha}")                 # 0.0625
```

**图解读**：蓝色曲线是 $\varphi(\alpha)$，红色虚线是 Armijo 线，黄色十字是被拒绝的试探点。可接受区是曲线落在直线下方的 $\alpha$ 区间——**注意可接受区在 0 附近必然非空**（定理 9.12），但回溯从 1 出发逐步收缩到边界附近才停。

#### 7. 易错坑点

1. **$c_1$ 别乱取**：$c_1=10^{-4}$ 是标准值。$c_1$ 太大（如 0.5）会过于严格，步长被迫极小；$c_1$ 太小则可能接受"实际上升"的坏步（数值噪声下）。
2. **Armijo 单独用会"抠门"**：它不阻止 $\alpha\to0$。**必须配 Wolfe 曲率条件**（或至少设置最小步长），否则可能无限回溯。
3. **回溯别从任意 $\alpha$ 开始**：Newton 类方法从 $\alpha=1$ 合理（Newton 步本身接近最优）；最速下降从 1 开始常要回溯多次，可改用插值。
4. **信赖域的 $\rho$ 分母可能是负的**：$m_k(0)-m_k(s_k)<0$ 说明模型预测"上升"，直接拒绝（$\rho$ 无意义）。实现时先检查 pred 符号。
5. **Wolfe 的 $c_2$ 因算法而异**：Newton 类取 0.9，共轭梯度类取 0.1——$c_2$ 决定"多抠门"，CG 需要更严格的曲率来保证共轭性。
6. **别把"函数值下降"当停机准则**：收敛判据用 $\|g_k\|$（Zoutendijk 保证它归零），$|f_{k+1}-f_k|$ 小可能只是步长太小。

#### 8. 对比辨析：线搜索 vs 信赖域

| 维度 | 线搜索（Armijo/Wolfe） | 信赖域 |
|---|---|---|
| 决策顺序 | 先方向 $d_k$，再步长 $\alpha_k$ | 先半径 $\Delta_k$，再方向与步长 $s_k$ |
| 模型不可信时的反应 | 回溯缩小 $\alpha$（沿固定方向） | 缩小 $\Delta$ 重新选方向 |
| 二阶模型 $B$ 非正定时 | 方向仍可用（牛顿方向需修正，见 9.3.2） | 圈内极小化自动规避坏方向 |
| 全局收敛保证 | Zoutendijk（方向不太歪 + Wolfe） | 模型 $\rho$ 判据 + Cauchy 点保底 |
| 典型场景 | 大规模（L-BFGS）、深度学习 | 中小规模、非光滑、随机噪声问题 |

> **辨析要点**：线搜索"锁定方向、试探距离"，信赖域"锁定距离、圈内寻优"。二者在现代实现中经常等效（LM 的 $\lambda$ 与信赖域 $\Delta$ 一一对应，见 9.4.3），但**哲学相反**——理解这一点，两种方法就都掌握了。

#### 9. 伪证辨析栏 ⭐

**伪证 1（看似能推其实缺条件）**：*"满足 Armijo 的步长就是好步长。"*

- **缺的条件**：Armijo 允许 $\alpha\to0$——$f$ 只降了 $10^{-20}$ 也"满足"。**下降不等于进步**。
- **正确命题**：Armijo + Wolfe（或步长下界）才保证"不太小"；Zoutendijk 证明用的是**两条**条件的合力。

**伪证 2（看似对其实错）**：*"$\rho_k$ 大说明这一步走得好。"*

- **错在哪**：$\rho_k\approx1$ 只说明"模型 $m_k$ 预测得准"，是**模型健康**的信号，不是"这一步值钱"的信号；$\rho_k$ 巨大或为负说明实际在上升，必须拒绝。
- **正确命题**：$\rho$ 是"模型与现实的吻合度"的体检表，用来**调节半径**，不是用来夸功的。

**伪证 3（看似对其实错）**：*"回溯步长从 1 开始，$\rho=0.5$，所以最多回溯 $\log_2(1/\varepsilon)$ 次，效率不是问题。"*

- **错在哪**：最坏情况下每次回溯都从 1 开始，而最速下降类方法的理想步长可能远小于 1（如 $\kappa$ 大时 $\alpha\sim O(1/\kappa)$），回溯要跑很多轮。
- **工程正确做法**：用**三次/二次插值**估计理想步长（如 SciPy `minimize` 的默认线搜索），回溯只是保底。

**伪证 4（看似相等其实不等）**：*"信赖域半径 $\Delta$ 就是步长 $\|\alpha d\|$。"*

- **不等在哪**：$\Delta$ 是**模型可信域的半径**，$s_k$ 是圈内最优步（可能 $<\Delta$）；$\Delta$ 随 $\rho$ 演化（扩大/缩小），而步长只是每次迭代的一个输出。**半径是状态（memory），步长是动作（action）**。

#### 10. 深度透析（考研 / 科研拔高）

**(a) 定理 9.13（Wolfe 存在性）的完整证明思路**：令 $\varphi(\alpha)=f(x+\alpha d)$，$\varphi'(0)=g^Td<0$。取 $\bar\alpha=\inf\{\alpha>0:\varphi'(\alpha)\ge c_2\varphi'(0)\}$（曲率条件首次满足点）。由中值定理与 Lipschitz 可证 $\bar\alpha$ 有限且 $>0$。再证 $\bar\alpha$ 满足 Armijo：$\varphi$ 在 $(0,\bar\alpha)$ 上递减且 $\varphi'<c_2\varphi'(0)<0$，用积分 $\varphi(\bar\alpha)-\varphi(0)=\int_0^{\bar\alpha}\varphi'(t)dt\le c_2\bar\alpha\varphi'(0)\le c_1\bar\alpha\varphi'(0)$（因为 $c_1<c_2$ 且 $\varphi'(0)<0$）。$\blacksquare$——**"曲率条件先满足点必然也满足 Armijo"是这个证明的妙处**。

**(b) 信赖域子问题与 LM 的对偶（连接 9.4.3）**：约束子问题 $\min_{\|s\|\le\Delta}\frac12s^TBs+g^Ts$ 的 KKT 条件为 $(B+\lambda I)s=-g$，$\lambda\ge0$，且 $\lambda(\Delta-\|s\|)=0$。**$\lambda$ 大 → $\|s\|$ 小（小圈、更保守）；$\lambda$ 小 → 接近纯 Newton/GN 步**。Levenberg-Marquardt 的 $\lambda$ 与信赖域半径 $\Delta$ 之间有一一对应关系（对给定 $\Delta$ 可解出唯一 $\lambda$）。**学完 9.4.3 再回来看这段，会看到同一个公式的两副面孔。**

**(c) 为什么深度学习不用信赖域**：参数量 $10^8\sim10^{12}$ 时，$B$（Hessian 近似）存不下、$\rho$ 的额外函数求值太贵。实践用**随机梯度下降 + 自适应步长**（Adam 等），其"每个坐标自己的步长"思想与 Armijo 的"全局单一 $\alpha$"不同——但**充分下降的直觉仍然在**（梯度的信噪比才是主角）。

**(d) 线搜索与信赖域的现代统一**：任何满足 Wolfe 条件的线搜索都能嵌入信赖域框架（把 $\alpha_k d_k$ 看成 $s_k$，把 $\rho$ 的计算用于决定"是否接受"）——**两个范式在实现层面收敛于同一个算法族**。理解这一点，读任何优化库源码都不会迷路。

## 9.3 Newton 与拟 Newton：把曲率用起来

**本节总览**：9.2 只用了梯度（一阶信息），所以最速下降受条件数拖累。本节把二阶信息（Hessian / 曲率）请进来：9.3.1 揭示"优化 Newton = 对梯度方程求根"的统一视角；9.3.2 解决 Newton 的两个致命伤（步长过大、方向不下降）；9.3.3 用割线条件让"曲率"可以被廉价地近似出来——BFGS 成为现代无约束优化的默认发动机。

### 9.3.1 求根 Newton 与优化 Newton 的联系和区别

> **一句话本质**：优化 Newton 就是对 $\nabla f(x)=0$ 套用 9.1.3 的求根 Newton——求根的 $f$ 换成梯度 $g$，求根的 $f'$ 换成 Hessian $H$；**唯一的本质区别是**：优化多了一个"方向必须下降"的要求，$H$ 非正定时纯 Newton 方向可能是上升方向。

#### 1. 生活类比

- **找水平线 vs 找谷底**：求根 Newton 在找"曲线穿 $x$ 轴的点"（水平线穿越处）；优化 Newton 在找"谷底"（水平 + 周围全向上）。后者的窍门是：**先求"梯度为零"（水平）的点，再判类型**。梯度场本身是个向量函数 $\nabla f(x)$，它的零点就是驻点——于是求根 Newton 原样可用。
- **二次模型的顶点**：优化 Newton 在每点用切抛物面（二次 Taylor）代替原函数，直接跳到抛物面顶点。抛物面顶点公式（$Hs=-g$）就是"切线零点公式"（$f' s=-f$）的向量版。

#### 2. 几何直观

- 求根：切线穿 $x$ 轴。
- 优化：$f$ 的二次模型 $m(s)=f(x_k)+g_k^Ts+\frac12s^TH_ks$ 是"贴着 $f$ 的抛物面"（一阶、二阶都匹配）。Newton 步 = 抛物面顶点相对当前点的位移：

$$H_ks=-g_k\iff s=-H_k^{-1}g_k$$

当 $H$ 正定时，抛物面开口向上，顶点是"模型里的谷底"；$H$ 不定时抛物面像马鞍，顶点不存在（沿某方向可以一直下降），模型失效——这就是"$H$ 非正定时 Newton 方向有问题"的几何来源。

#### 3. 底层逻辑

**统一视角（务必记住）**：优化问题 $\min f$ 的驻点方程是

$$\textcolor{blue}{F(x)=\nabla f(x)=0}$$

这是 $n$ 个方程、$n$ 个未知数的**非线性方程组**。对它应用 9.1.3 的方程组 Newton：

$$J_F(x_k)=H_k=\nabla^2f(x_k),\qquad x_{k+1}=x_k-H_k^{-1}\nabla f(x_k)$$

**所以优化 Newton 不是新理论，是求根 Newton 的"梯度场版本"**。$f$（标量函数）↔ $F=\nabla f$（向量场），$f'$ ↔ $H$（梯度场的 Jacobian = Hessian）。理解了这个对应，9.3.2 的所有"病"都能从 9.1.3 的"病"直接翻译过来。

#### 4. 定义与对照表

**定义 9.8（优化 Newton 迭代）** $x_{k+1}=x_k-H_k^{-1}g_k$，其中 $H_k=\nabla^2f(x_k)$，$g_k=\nabla f(x_k)$。实现时解线性系统 $H_ks=-g_k$。

| 维度 | 求根 Newton（9.1.3） | 优化 Newton（本节） |
|---|---|---|
| 目标 | $f(x)=0$ | $\nabla f(x)=0$ |
| "函数" | $f$ | $g=\nabla f$ |
| "导数" | $f'$ | $H=\nabla^2 f$ |
| 迭代 | $x_{k+1}=x_k-\frac{f}{f'}$ | $x_{k+1}=x_k-H^{-1}g$ |
| 二阶收敛条件 | $f'(x^*)\ne0$ | $H(x^*)$ 正定 |
| 退化情形 | 重根：$f'(x^*)=0$ | 退化 Hessian：$H(x^*)$ 奇异 |
| 额外要求 | 无 | **下降性**：$g^Td<0$（$H$ 正定时自动满足） |

**定理 9.15（优化 Newton 局部二阶收敛）** 设 $f\in C^2$，$x^*$ 是局部极小点，$H(x^*)$ 正定，$x_0$ 足够近。则优化 Newton 收敛且 $\|e_{k+1}\|=O(\|e_k\|^2)$。

**证明（与定理 9.6 完全同构，四行）**：

1. 多元 Taylor：$\nabla f(x^*)=g_k+H_k(x^*-x_k)+O(\|e_k\|^2)$，即 $g_k=H_ke_k+O(\|e_k\|^2)$（因为 $\nabla f(x^*)=0$）；
2. $e_{k+1}=e_k-H_k^{-1}g_k=H_k^{-1}(H_ke_k-g_k)=H_k^{-1}\cdot O(\|e_k\|^2)$；
3. $H(x^*)$ 正定 + $H$ 连续 ⇒ 邻域内 $\|H_k^{-1}\|$ 有界；
4. 故 $\|e_{k+1}\|\le C\|e_k\|^2$，归纳收敛。$\blacksquare$

**下降性检查（关键区别）**：方向 $d=-H^{-1}g$ 是下降方向当且仅当

$$g^Td=-g^TH^{-1}g$$

- $H$ 正定 ⇒ $g^TH^{-1}g>0$ ⇒ $g^Td<0$，**自动下降**；
- $H$ 不定 ⇒ $g^TH^{-1}g$ 符号不定 ⇒ **方向可能上升**；
- $H$ 奇异 ⇒ 系统无解。

#### 5. 算法三步走：优化 Newton

**① 痛点**：最速下降太慢（条件数拖累）；想用曲率加速，但曲率（Hessian）可能"指错方向"（非正定）。

**② 直觉**：Newton 步 = 跳到二次模型顶点；顶点只在 $H$ 正定时是谷底。**曲率是加速器，但方向盘要检查**。

**③ 公式 + 手搓步骤**：

```
输入：f, g, H, 初值 x0
输出：近似极小点
1  对 k = 0, 1, ...:
2      解 H_k s = -g_k                    （核心：线性系统）
3      若 g_k^T s ≥ 0: 需要修正（见 9.3.2）
4      x_{k+1} ← x_k + s
```

**手算演示**（两个对比案例）：

**(a) 正常案例**：$f(x)=\frac12x^2$，$x_0=1$：$g=1$，$H=1$，$s=-1$，$x_1=0$——**一步到位**。二次函数（或强凸函数局部二次近似）的 Newton 一步即中，这是"二阶收敛"的极端体现。

**(b) 退化案例**：$f(x)=x^4$，极小点 $x^*=0$，但 $H(x)=12x^2$ 在 $x^*$ 处 $H(0)=0$ **奇异**：

$$x_1=1-\frac{4}{12}=\frac23,\quad x_2=\frac23-\frac{4\cdot(2/3)^3}{12\cdot(2/3)^2}=\frac23-\frac{32/27}{16/3}=\frac23-\frac29=\frac49$$

比率 $\frac{e_{k+1}}{e_k}=\frac{2/3}{1}=0.667$——**线性收敛**！因为 $H(x^*)=0$ 对应求根 Newton 的"重根"退化（9.1.3 坑点 3）。**同一个病的两种说法**。

#### 6. Python 复现与误差可视化

完整脚本：`code/ch9/ch9_6_newton_opt.py`。核心演示——**纯 Newton 的鞍点陷阱**：

```python
import numpy as np
# f(x,y) = x^2 - 2y^2：H = diag(2,-4) 不定，(0,0) 是鞍点
H = np.diag([2.0, -4.0])
x0 = np.array([1.0, 1.0]); g0 = np.array([2.0, -4.0])
d = np.linalg.solve(H, -g0)      # Newton 方向
x1 = x0 + d                      # 一步直捣 (0,0) —— 梯度为零但它是鞍点！
print(x1, np.linalg.eigvals(H))  # [0. 0.] [ 2. -4.]
```

**解读**：$H$ 不定时，Newton 解出的 $s$ 是"二次模型顶点"的位移，而模型是马鞍——顶点不存在，$x_1=(0,0)$ 处的 Hessian 一正一负，**纯 Newton 把迭代送到鞍点**。这就是"优化 Newton 必须处理 $H$ 非正定"的活证据（9.3.2 的修正正是为它而生）。

#### 7. 易错坑点

1. **$H$ 非正定时 Newton 方向可能上升**：$g^Td=-g^TH^{-1}g$ 可正可负。**检查下降性是每次迭代的第一道工序**。
2. **$H$ 奇异/病态**：解系统失败或 $s$ 巨大。$H(x^*)$ 正定是二阶收敛定理的前提，别省。
3. **退化 Hessian = 求根的重根**：$f=x^4$ 的 $H(0)=0$ 导致线性收敛（手算演示 (b)）——用"误差平方比率"实测可确诊。
4. **Newton 步过大**：远离极小点时二次模型失真，$s$ 可能把迭代甩到天边——这就是 9.3.2 阻尼的动机。
5. **求 Hessian 的代价**：$n$ 维需要 $O(n^2)$ 存储与 $O(n^3)$ 分解——这就是 9.3.3 拟 Newton 存在的理由。

#### 8. 对比辨析：最速下降 vs Newton（优化）

| 维度 | 最速下降（9.2.2） | 优化 Newton |
|---|---|---|
| 信息 | 一阶（$g$） | 二阶（$g,H$） |
| 方向 | $-\nabla f$ | $-H^{-1}\nabla f$（曲率校正） |
| 二次型收敛 | 线性，比率 $\frac{\kappa-1}{\kappa+1}$ | **1 步**（有限步收敛） |
| 每步成本 | $O(n)$ | $O(n^2)$~$O(n^3)$ |
| 健壮性 | 全局（只要步长对） | 局部（初值近 + $H$ 正定） |
| 失效模式 | 慢（大 $\kappa$） | 发散 / 上升 / 鞍点 |

> **辨析要点**：Newton 方向 $d=-H^{-1}g$ 与最速下降 $d=-g$ 的差别 = **用曲率重新标定坐标**：$H^{-1}$ 把"陡方向"（大特征值）的步长压低、把"缓方向"（小特征值）的步长放大——这正是"用 $H$ 消除条件数"的几何直觉。代价是每步 $O(n^3)$，所以实际算法常在两者之间（9.3.3 的 BFGS 用 $O(n^2)$ 逼近 Newton）。

#### 9. 伪证辨析栏 ⭐

**伪证 1（看似对其实错）**：*"Newton 方向一定让函数下降。"*

- **反例**：$f(x,y)=x^2-2y^2$（$H=\text{diag}(2,-4)$ **不定**）。取点 $(0,-1)$：$g=(2x,-4y)=(0,4)$，$d=-H^{-1}g=-\big(\frac12\cdot0,\ -\frac14\cdot4\big)=-(0,-1)=(0,1)$。则 $g^Td=0+4=4>0$——**违反下降条件 $g^Td<0$，沿 $d$ 走 $f$ 上升**。验证：$f(0,-1)=-2$，$f(0,-1+\varepsilon)=-2+4\varepsilon-2\varepsilon^2>-2$（$0<\varepsilon<2$）✓。**$H$ 不定时 Newton 方向甚至可能直接指向"上坡"。**
- **正确命题**：$H$ 正定 ⇔ Newton 方向必下降；$H$ 不定时需检查 $g^Td$。

**伪证 2（看似能推其实缺条件）**：*"$H(x^*)$ 正定，所以 Newton 从任何初值都收敛。"*

- **缺的条件**：局部收敛定理要 $x_0$ 足够近（定理 9.15 前提）。$H$ 正定只保证极小点处"模型是碗"，但远处模型可能与真实 $f$ 差很远。
- **反例**：非线性程度高的函数，远离极小点时 Newton 步可能把迭代送到另一个驻点或直接发散（9.3.2 的阻尼正是补这个洞）。

**伪证 3（看似相等其实不等）**：*"优化 Newton 的收敛速度一定等于求根 Newton。"*

- **不等在哪**：求根 Newton 要求 $f'(x^*)\ne0$；优化 Newton 要求 $H(x^*)$ **正定**（不只是非奇异）。$H$ 非奇异但不正定（鞍点）时，求根 Newton 收敛到驻点，但优化问题**不想要**这个驻点——**两个 Newton 的"成功标准"不同**：一个找零点，一个找谷底。

#### 10. 深度透析（考研 / 科研拔高）

**(a) "对梯度求根"的完整图景**：优化 Newton = 对 $F(x)=\nabla f(x)$ 的求根 Newton，$F'=H$。所有 9.1.3 的结论原样迁移：重根（$H$ 奇异）退化、Kantorovich 型条件、数值 Jacobian（这里就是数值 Hessian，更贵）。**这张"对应表"是本章最重要的单张图**。

**(b) 为什么二次函数一步收敛**：$f(x)=\frac12x^TAx-b^Tx+c$ 时，$g=Ax-b$，$H=A$，Newton 步 $s=-A^{-1}(Ax_k-b)=x^* - x_k$——**一步精确跳到 $x^*$**。一般函数的 Newton 只是"每步对局部二次近似一步到位"，所以误差平方。

**(c) Newton 步的几何：仿射不变性**。对 $f$ 做线性坐标变换 $\tilde f(u)=f(Lu)$，Newton 迭代在 $u$ 空间与 $x$ 空间的轨迹互为线性像——**Newton 收敛行为不被坐标缩放改变**（对比最速下降被 $\kappa$ 狠狠惩罚）。这是"二阶方法"优于"一阶方法"的深层理由，也是"用曲率抵消条件数"的精确表述。

### 9.3.2 阻尼、Hessian 修正与局部收敛

> **一句话本质**：纯 Newton 有两个致命伤——**步长可能太大**（走出模型可信区）与**方向可能不下降**（$H$ 非正定）。"阻尼 Newton"（Newton 方向 + 回溯线搜索）治第一个，**Hessian 修正**（$H+\mu I$，$\mu$ 大到让修正矩阵正定）治第二个；两帖药合起来，保住"局部二阶 + 全局下降"。

#### 1. 生活类比

- **带刹车的跑车**：Newton 方向是引擎（曲率加速），阻尼是刹车（线搜索）。引擎再猛，弯道不刹车必翻车——远离极小点时二次模型失真，Newton 步（油门踩满）会把迭代甩出十万八千里。
- **给坏地图打补丁**：$H$ 非正定 = 地图说"前方是谷底"但实际是马鞍/山顶。修正 $H+\mu I$ = 把地图"捏"成碗形（所有方向都向上）。$\mu$ 是补丁的力度——太小补不圆（还不正定），太大把真实地形都抹平了（变成只会直走的憨憨）。

#### 2. 几何直观

- **阻尼**：方向不变（还是 $-H^{-1}g$），步长缩短（$\alpha<1$ 回溯）——沿"正确方向"少走一点。Rosenbrock 函数上，阻尼 Newton 沿狭长谷顺利滑到 $(1,1)$；纯 Newton 若步长 1 可能反复越过谷壁振荡。
- **修正**：$H+\mu I$ 把所有特征值平移 $\mu$——负特征值变正、零特征值变正，矩阵恢复正定，**方向被扳回下降侧**。$\mu$ 越大，$H+\mu I$ 越像 $\mu I$，方向越接近 $-\nabla f$（最速下降）——**修正的尽头是"放弃曲率"**。

![阻尼 Newton 在 Rosenbrock 上的收敛路径：沿狭长谷滑向极小点](figures/ch9_newton_opt.png)

#### 3. 底层逻辑

纯 Newton 的理论（定理 9.15）说"$x_0$ 足够近时 $\alpha=1$ 最终会被接受、二阶收敛"——但**理论不告诉你"足够近"是 0.1 还是 0.0001**。工程现实是：初值几乎从不在吸引域内。于是两件事必须做：

1. **阻尼**：用线搜索保证"每步都下降"（$f(x_{k+1})<f(x_k)$ 严格），把"局部定理"升级为"全局可执行"；
2. **修正**：$H$ 非正定时，$d=-H^{-1}g$ 连"下降方向"都不算（$g^Td=-g^TH^{-1}g$ 可能为正），线搜索救不了——**必须先修正 $H$ 让方向可下降**，再谈步长。

**顺序不能反**：先修正方向，再阻尼步长。

#### 4. 定义与定理（全部手推）

**定义 9.9（阻尼 Newton）** 迭代 $x_{k+1}=x_k+\alpha_k d_k$，其中 $d_k=-H_k^{-1}g_k$，$\alpha_k$ 由 Armijo 回溯或 Wolfe 线搜索确定。

**定理 9.16（局部收敛 + 渐进二阶）** 设 $f\in C^2$，$x^*$ 局部极小，$H(x^*)$ 正定。则：

1. （局部）$x_0$ 足够近时，阻尼 Newton（任意 $\alpha_k\le1$ 且满足 Armijo 的线搜索）收敛；
2. （渐进二阶）收敛后期 $\alpha_k=1$ 被接受，且 $\|e_{k+1}\|=O(\|e_k\|^2)$。

**证明（第 2 部分的思路是本节最漂亮的手推）**：由 $H(x^*)$ 正定与 $f\in C^2$，在 $x^*$ 邻域内 $g_k^Td_k=-g_k^TH_k^{-1}g_k\le-m\|g_k\|^2$（$m>0$ 由 $\|H_k^{-1}\|$ 有界而来）。对纯 Newton 步（$\alpha=1$），定理 9.15 给出 $\|e_{k+1}\|=O(\|e_k\|^2)$，从而

$$f(x_k+s_k)-f(x_k)=-g_k^Ts_k+O(\|s_k\|^2)=-\textcolor{orange}{g_k^TH_k^{-1}g_k}+O(\|e_k\|^2)$$

由 $g_k^TH_k^{-1}g_k\ge m\|g_k\|^2\ge c\|e_k\|^2$（$g_k=H_ke_k+O(\|e_k\|^2)$，$H$ 正定有下界），对足够小的 $\|e_k\|$，$f(x_k+s_k)<f(x_k)+c_1 g_k^Ts_k$——**Armijo 在 $\alpha=1$ 时自动满足**，于是 $\alpha_k=1$ 被线搜索接受，迭代退化为纯 Newton，恢复二阶。$\blacksquare$

> **定理的工程含义**：阻尼不是"降级"——它在远处理顺步长，在**近处自动失效**（$\alpha_k\to1$），二阶收敛是**渐进**恢复的。**"阻尼不影响最终收敛阶"**这个结论是本节最值钱的定理。

**定理 9.17（阻尼 + 一致正定 Hessian 的全局收敛）** 若所有迭代中 $H_k\succeq mI$（一致正定，$m>0$）且 $\|H_k\|\le M$，则阻尼 Newton + Wolfe 线搜索满足 $\|g_k\|\to0$。

**证明（三行，全部是 Zoutendijk 的组装）**：

1. 方向 $d_k=-H_k^{-1}g_k$ 的夹角余弦：$\cos\theta_k=\frac{-g_k^Td_k}{\|g_k\|\|d_k\|}=\frac{g_k^TH_k^{-1}g_k}{\|g_k\|\|H_k^{-1}g_k\|}$；
2. 由特征值 $\lambda(H_k)\in[m,M]$：$g_k^TH_k^{-1}g_k\ge\frac1M\|g_k\|^2$，$\|H_k^{-1}g_k\|\le\frac1m\|g_k\|$，故 $\cos\theta_k\ge\frac{1/M}{1/m}=\frac{m}{M}>0$；
3. Zoutendijk（定理 9.14）⇒ $\sum\|g_k\|^2<\infty$ ⇒ $\|g_k\|\to0$。$\blacksquare$

**定义 9.10（Hessian 修正）** 当 $H_k$ 非正定时，用正定矩阵

$$\textcolor{green}{H_k+\mu_k I},\qquad \textcolor{orange}{\mu_k>\max(0,-\lambda_{\min}(H_k))}$$

代替 $H_k$ 解方向。工程上 $\mu_k$ 的取法：

- **精确版**：算最小特征值 $\lambda_{\min}$，取 $\mu=\max(0,-\lambda_{\min})+\delta$；
- **廉价版（Gershgorin）**：$\mu=\max(0,-\min_i(H_{ii}-\sum_{j\ne i}|H_{ij}|))+\delta$，只读对角与行和，$O(n^2)$；
- **实用版（Cholesky 试探）**：对 $H$ 做 Cholesky，失败（遇到非正主元）就增大 $\mu$ 重试——失败信息本身就是"哪里不正定"的情报；
- **LM 式**：$\mu$ 与信赖域半径联动（9.4.3 的主角，这里先埋种子）。

#### 5. 算法三步走：阻尼 Newton + 修正

**① 痛点**：纯 Newton 局部快但全局脆（步长失控 + 方向可能上升）。

**② 直觉**：先修方向（$H+\mu I$ 扳回正定），再刹步长（回溯）。

**③ 公式 + 手搓步骤**：

```
输入：f, g, H, 初值 x0
输出：近似极小点
1  对 k = 0, 1, ...:
2      μ ← 0；对 H 做 Cholesky / 特征值检查
3      若 H 非正定:  μ ← max(0, -λ_min(H)) + δ，用 H + μI 代替 H
4      解 (H + μI) s = -g
5      回溯: α ← 1;  while f(x+αs) > f(x) + c1·α·g^T s:  α ← 0.5α
6      x ← x + α s
```

**手算演示**：$f(x,y)=x^2-2y^2$，$x_0=(1,-1)$（即 9.3.1 伪证 1 里方向上升的点）。

- 检查：$H=\text{diag}(2,-4)$，$\lambda_{\min}=-4<0$，**非正定**；
- 修正：$\mu=5$，$H+5I=\text{diag}(7,1)$ 正定；
- 方向：$g=(2,4)$，$s=-(H+5I)^{-1}g=-(2/7,4)=(-0.2857,-4)$；
- 下降检查：$g^Ts=2(-0.2857)+4(-4)=-0.57-16<0$ ✓（**修正前** $s'=-H^{-1}g=(-1,1)$，$g^Ts'=2(-1)+4(1)=2>0$，纯 Newton 方向是**上升**的——修正前后方向完全相反！）；
- 回溯步长交给 Armijo。

**对照**：$x_0=(1,1)$ 时 $g=(2,-4)$，纯 Newton 一步到鞍点 $(0,0)$（9.3.1 代码演示）——修正版则会沿下降方向离开鞍点。**同一个函数，修正决定生死**。

#### 6. Python 复现与误差可视化

完整脚本：`code/ch9/ch9_6_newton_opt.py`：

```python
import numpy as np

# 阻尼 Newton + Armijo 在 Rosenbrock 上：f = 100(y-x^2)^2 + (1-x)^2
f  = lambda x: 100*(x[1]-x[0]**2)**2 + (1-x[0])**2
g  = lambda x: np.array([-400*x[0]*(x[1]-x[0]**2)-2*(1-x[0]), 200*(x[1]-x[0]**2)])
H  = lambda x: np.array([[1200*x[0]**2-400*x[1]+2, -400*x[0]], [-400*x[0], 200.0]])

c1, rho = 1e-4, 0.5
x = np.array([-1.2, 1.0])
for k in range(100):
    gk = g(x)
    if np.linalg.norm(gk) < 1e-10: break
    d = np.linalg.solve(H(x), -gk)          # Newton 方向
    a = 1.0
    while f(x + a*d) > f(x) + c1*a*(gk @ d):  # Armijo 回溯（阻尼）
        a *= rho
    x = x + a*d
print(f"{k} 步后 x = {x}, f = {f(x):.2e}")   # 22 步到 (1,1)，f≈0
```

**图解读**：Rosenbrock 的等高线是"香蕉形峡谷"，阻尼 Newton 沿谷底直接滑到 $(1,1)$（22 步），而最速下降在同一函数上前 100 步还在谷里爬行（对比见 9.3.3 图）。**曲率信息（$H$）让算法"看穿"峡谷的弯道**。

#### 7. 易错坑点

1. **顺序不能反**：先修正 $H$（保证 $g^Ts<0$）再阻尼（保证步长合理）。$H$ 非正定时直接阻尼，回溯会一直失败（方向是上升的，任何 $\alpha$ 都不满足 Armijo）。
2. **$\mu$ 别取太大**：$\mu\to\infty$ 时 $d\to-\frac1\mu g$——修正 Newton 退化为最速下降，曲率信息清零。$\mu$ 取"刚好扳正 $+$ 一点余量"即可。
3. **"修正后收敛阶"的误区**：修正只在 $H$ 非正定的区域触发；进入 $H$ 正定邻域后 $\mu=0$、退化为纯 Newton——**渐进二阶**（定理 9.16）。别以为修正本身拖慢收敛。
4. **$H$ 病态但正定**：Cholesky 通过但条件数巨大，解出的 $s$ 数值不可靠。加小的 $\mu$（如 $\sqrt{\varepsilon}$）是常见的正则化。
5. **阻尼 + Wolfe 的 $c_2$**：Newton 类建议 $c_2=0.9$（宽松曲率），用 $c_2=0.1$（CG 标准）会过度限制步长，浪费 Newton 方向的"远见"。

#### 8. 对比辨析：三种 Newton 变体

| 变体 | 方向 | 步长 | 全局下降 | 收敛阶 |
|---|---|---|---|---|
| 纯 Newton | $-H^{-1}g$ | 恒 1 | 无保证 | 二阶（$x_0$ 足够近） |
| 阻尼 Newton | $-H^{-1}g$ | 回溯/Wolfe | 有（$H$ 正定时） | 渐进二阶 |
| 修正 + 阻尼 | $-(H+\mu I)^{-1}g$ | 回溯/Wolfe | **有（$H$ 任意）** | 渐进二阶 |

> **辨析要点**：三者的"方向公式"只差一个 $\mu I$，但能力递进：纯 Newton 是"理论状态"，阻尼是"工程状态"，修正+阻尼是"无脑可用的默认配置"。**现代求解器（如 SciPy `minimize(method='Newton-CG')`、MATLAB `fminunc`）默认实现的就是第三列**。

#### 9. 伪证辨析栏 ⭐

**伪证 1（看似能推其实缺条件）**：*"$H$ 半正定（非负特征值）也能保证 Newton 方向下降。"*

- **反例**：$H=\text{diag}(1,0)$，$g=(0,1)$（$g$ 落在 $H$ 的零特征子空间）：$H^{-1}$ 不存在，系统无解；即使加正则化，$d$ 沿零方向没有下降量。$g^TH^{-1}g$ 无定义或为 0——**下降性需要正定，半正定不够**。
- **正确命题**：$H$ 正定 ⇔ $g^Td=-g^TH^{-1}g<0$ 对所有 $g\ne0$。

**伪证 2（看似对其实错）**：*"Hessian 修正（$H+\mu I$）是免费午餐——既稳了方向又保了速度。"*

- **错在哪**：$\mu$ 大时 $H+\mu I\approx\mu I$，Newton 方向退化为一阶方向，**修正过度 = 自废曲率**。修正不是免费的：它用"部分曲率信息"换"方向必下降"。
- **正确命题**：$\mu$ 应取"刚好扳正 + 余量"，在稳健与速度间取平衡；这正是 9.4.3 LM 用 $\rho$ 动态调 $\lambda$ 的动机。

**伪证 3（看似能推其实缺条件）**：*"阻尼 Newton 加回溯线搜索，所以一定收敛到局部极小。"*

- **缺的条件**：回溯只保证"每步下降"；收敛目标由**方向与步长的交互**决定——$H$ 非正定时方向不下降，回溯失效（伪证 1）；$H$ 正定时收敛到驻点，但**驻点可能是鞍点**（9.2.1）或非极小。**"每步下降" ≠ "到达谷底"**。
- **完整链条**：修正（方向必下降）+ 阻尼（步长合理）+ Zoutendijk（梯度归零）+ 二阶充分条件（梯度零处为极小）——四环缺一不可。

#### 10. 深度透析（考研 / 科研拔高）

**(a) 修正 Cholesky（GMW 算法思想）**：与其"先试 Cholesky、失败再加 $\mu$"，更优雅的是**在分解过程中动态修正**：遇到非正主元 $a_{ii}\le0$ 时，把它提升到 $\delta(\sqrt{a_{ii}^{(k)}}+\beta)$ 量级，一次分解完成"分解 + 修正"。Gill-Murray-Wright（GMW）算法是 MATLAB `fminunc` 的正定化内核——**修正不是外挂补丁，而是与分解融为一体**。

**(b) $\mu$ 与信赖域半径的对偶（连接 9.4.3）**：对给定 $\mu\ge0$，$s(\mu)=-(H+\mu I)^{-1}g$ 满足 $\|s(\mu)\|$ 随 $\mu$ 单调递减（$\mu\to\infty$ 时 $\|s\|\to0$）。反过来，给定信赖域半径 $\Delta$，存在唯一 $\mu$ 使 $\|s(\mu)\|=\Delta$。**Hessian 修正的 $\mu$ = 信赖域的 $\Delta$ 的对偶变量**——LM 阻尼（9.4.3）正是把这张对偶表用到最小二乘上。

**(c) 非正定的"程度"决定策略**：$H$ 有小负特征值（$\approx-\varepsilon$）→ 小 $\mu$，接近 Newton；$H$ 有大负特征值 → 大 $\mu$，接近最速下降；$H$ 有零特征值（半正定）→ 最小 $\mu$ 使其严格正定。**"修正力度 = 对非凸性的度量"**。

**(d) 大规模时的替代**：$H$ 存不下时（$n>10^5$），用**有限内存拟 Newton**（9.3.3 的 L-BFGS）或**截断 Newton（CG-Steihaug）**——在信赖域内用共轭梯度近似解 $(H+\mu I)s=-g$，只做矩阵-向量乘。**方向与步长的分工思想在这里达到工程极致**。

#### 11. 本节自测

**基础**：$f(x,y)=x^2-y^2$，$x_0=(1,2)$。判断 $H$ 的正定性、给出修正后的方向并验证下降。（$H=\text{diag}(2,-2)$ 不定；取 $\mu=3$：$H+3I=\text{diag}(5,1)$，$g=(2,-4)$，$s=(-0.4,4)$，$g^Ts=2(-0.4)+(-4)(4)=-0.8-16<0$ ✓）

**拔高**：解释为什么"修正+阻尼 Newton"在理论上**渐进二阶**而非"始终二阶"：在收敛后期，$H_k\to H(x^*)$（正定），$\mu_k$ 的取值 $\max(0,-\lambda_{\min}(H_k))+\delta$ 最终为 $\delta$（一个小的正常数）——此时方向 $-(H_k+\delta I)^{-1}g_k$ 与纯 Newton 方向的差是 $O(\delta)$，而收敛阶的极限分析不受 $O(\delta)$ 扰动影响。**写出完整的误差递推并验证 $\lim\frac{\|e_{k+1}\|}{\|e_k\|^2}$ 仍是有限常数**。（提示：$e_{k+1}=(H+\delta I)^{-1}[(H+\delta I)e_k-g_k]$，利用 $g_k=He_k+O(\|e_k\|^2)$，展开得 $e_{k+1}=(H+\delta I)^{-1}[\delta e_k+O(\|e_k\|^2)]$——主项 $O(\|e_k\|^2)$ 主导，$\delta e_k$ 相对可忽略。）

### 9.3.3 割线条件、BFGS 更新与曲率条件

> **一句话本质**：BFGS 不显式算 Hessian，而是用**相邻迭代的位移 $s_k$ 与梯度差 $y_k$** 每步"修正"一个近似 $B_k$：只要求新近似满足**割线条件** $B_{k+1}s_k=y_k$、保持对称正定、且在对称正定矩阵里**离 $B_k$ 最近**——三句话推导出唯一的更新公式，代价 $O(n^2)$，换来超线性收敛。

#### 1. 生活类比

- **用走过的路况更新导航**：你不需要每次停车重新测绘整条路（重算 $H$，$O(n^3)$），只需记录"刚才走了多远（$s_k$）"和"坡度变化了多少（$y_k$）"，就能**修正你对前方地形的估计**（$B_{k+1}$）。BFGS 是"增量式路况学习"。
- **调焦距**：上次调的旋钮位置与画面清晰度的关系（$s$ 与 $y$）告诉你"该往哪边拧、拧多快"——下一轮就用这条经验，而不是每次从头测量镜头参数。

#### 2. 几何直观

- **割线条件**：$B_{k+1}s_k=y_k$ 要求新曲率矩阵沿"刚走过的方向" $s_k$ 与真实 Hessian 一致。由多元中值定理，$\nabla^2f(\xi)s_k=y_k$（对某个中间点 $\xi$），所以割线条件是"把真实 Hessian 在 $s_k$ 方向的平均行为"作为约束——**只约束走过的方向，不约束没走过的方向**。
- **最小变化**：在满足割线条件 + 对称的矩阵中选"离 $B_k$ 最近"的那个（加权 Frobenius 距离）——**用最少的信息修正**，不破坏已有知识。几何上：在仿射平面 $\{Bs=y\}$ 里找离 $B_k$ 最近的点。

#### 3. 底层逻辑

为什么"只约束 $s_k$ 方向"就够了？因为**下一步的方向就由 $B_{k+1}$ 决定**，而 $B_{k+1}$ 只需在"即将要走的方向"上近似 Hessian——这正是超线性收敛（Dennis-Moré 条件）的本质：方向逐步逼近 Newton 方向，无需 $B$ 处处逼近 $H$。**BFGS 的哲学：用最少的信息换取"关键方向上的正确曲率"**，比精确 Hessian 便宜一个量级，却保留二阶收敛的绝大部分收益。

#### 4. 定义与推导（全部手推）

**定义 9.11（割线条件 / 曲率对）** 设 $s_k=x_{k+1}-x_k$，$y_k=g_{k+1}-g_k$。拟 Newton 矩阵 $B_{k+1}$ 要求满足

$$\textcolor{orange}{B_{k+1}s_k=y_k}\tag{割线条件}$$

**割线条件的动机（多元中值定理）**：对每个分量 $g_i$ 用一维中值定理：$y_{k,i}=g_i(x_{k+1})-g_i(x_k)=\nabla^2f_i(\xi_i)^T s_k$，故存在"中间 Hessian"使 $y_k=\bar H s_k$。用 $B_{k+1}$ 逼近 $\bar H$ 沿 $s_k$ 方向的投影，即得割线条件。

**BFGS 更新公式（从"三条要求"推出，这是本节的核心推导）**：

> **要求**：$B_{k+1}$ 满足 (i) 对称；(ii) 割线条件 $B_{k+1}s_k=y_k$；(iii) 在满足 (i)(ii) 的矩阵中，使 $\|B-B_k\|$（加权 Frobenius 范数）最小。

**推导（分四步）**：

**第 1 步（秩二 Ansatz）**：由对称性，$B_{k+1}-B_k$ 是对称矩阵；又它在"过 $B_k$、约束 $Bs=y$"的仿射子空间里最靠近 $B_k$，可设修正为**秩二**形式（两个向量张成 $s_k$ 与 $y_k$ 所在的二维平面）：

$$B_{k+1}=B_k+auu^T+bvv^T$$

**第 2 步（代入割线条件）**：$B_{k+1}s_k=B_ks_k+a(u^Ts_k)u+b(v^Ts_k)v=y_k$。取 $u=B_ks_k$、$v=y_k$，则 $a(u^Ts_k)=-1$、$b(v^Ts_k)=1$，即

$$a=-\frac{1}{s_k^TB_ks_k},\qquad b=\frac{1}{y_k^Ts_k}$$

**第 3 步（写出公式）**：

$$\textcolor{blue}{B_{k+1}=B_k-\frac{B_ks_ks_k^TB_k}{s_k^TB_ks_k}+\frac{y_ky_k^T}{y_k^Ts_k}}\tag{BFGS 更新}$$

**第 4 步（验证）**：

$$B_{k+1}s_k=B_ks_k-\frac{B_ks_k(s_k^TB_ks_k)}{s_k^TB_ks_k}+y_k\frac{y_k^Ts_k}{y_k^Ts_k}=y_k\qquad\blacksquare$$

> 唯一性由变分原理保证（深度透析 (a)）：在加权 Frobenius 范数 $\|M\|_W^2=\|W^{1/2}MW^{-1/2}\|_F^2$ 下，上述秩二修正就是唯一解。**"对称 + 割线 + 最小变化"三条要求 ⇒ BFGS，一个公式都不多。**

**逆 Hessian 形式（实现最常用）**：对 $D_k=B_k^{-1}$ 两次应用 Sherman-Morrison-Woodbury，得

$$\textcolor{blue}{D_{k+1}=(I-\rho_ks_ky_k^T)D_k(I-\rho_ky_ks_k^T)+\rho_ks_ks_k^T},\qquad \rho_k=\frac1{y_k^Ts_k}$$

**方向与步长**：$d_k=-D_kg_k$（等价于 $B_kd_k=-g_k$），步长 $\alpha_k$ 由 Wolfe 线搜索确定，$s_k=\alpha_kd_k$。

**定理 9.18（曲率条件由 Wolfe 保证）** 若步长满足 Wolfe 条件（$c_1<c_2<1$），则 $y_k^Ts_k>0$。

**证明（四行）**：

1. $s_k=\alpha_kd_k$，且 $g_k^Td_k<0$（$d_k$ 是下降方向）；
2. Wolfe 曲率条件：$g_{k+1}^Td_k\ge c_2g_k^Td_k$；
3. 两边减 $g_k^Td_k$ 再乘 $\alpha_k$：$y_k^Ts_k=\alpha_k(g_{k+1}-g_k)^Td_k\ge\alpha_k(c_2-1)g_k^Td_k$；
4. 因 $c_2-1<0$ 且 $g_k^Td_k<0$：$(c_2-1)g_k^Td_k>0$，故 $y_k^Ts_k>0$。$\blacksquare$

**定理 9.19（正定性保持）** 若 $B_k$ 对称正定且 $y_k^Ts_k>0$，则 $B_{k+1}$ 对称正定。

**证明（对任意 $z\ne0$ 展开 $z^TB_{k+1}z$，这是本节最值的细节）**：

$$z^TB_{k+1}z=\underbrace{z^TB_kz-\frac{(z^TB_ks_k)^2}{s_k^TB_ks_k}}_{(I)}+\underbrace{\frac{(z^Ty_k)^2}{y_k^Ts_k}}_{(II)}$$

- **$(I)\ge0$**：由 $B_k$ 正定的 Cauchy-Schwarz：$(z^TB_ks_k)^2\le(z^TB_kz)(s_k^TB_ks_k)$，等号当且仅当 $z$ 与 $s_k$ 成比例。
- **$(II)\ge0$**，且 $(II)>0$ 当且仅当 $z^Ty_k\ne0$。
- 若 $z^Ty_k\ne0$：$z^TB_{k+1}z=(I)+(II)>0$（$(II)>0$，$(I)\ge0$）。
- 若 $z^Ty_k=0$：则 $z$ 与 $y_k$ 正交；由 $y_k^Ts_k>0$，$z$ 不与 $s_k$ 成比例（否则 $z=\lambda s_k\Rightarrow z^Ty_k=\lambda s_k^Ty_k\ne0$，矛盾），故 $(I)>0$，$z^TB_{k+1}z>0$。$\blacksquare$

> **正定保持 = BFGS 能一直跑下去的心脏**：正定 ⇒ 方向必下降 ⇒ 配合 Wolfe 满足 Zoutendijk ⇒ 全局收敛。**曲率条件（$y^Ts>0$）是正定保持的开关**。

**收敛性结论（陈述 + 直觉）**：对光滑、有界下方、$H$ Lipschitz 的函数，BFGS + Wolfe 线搜索满足：全局收敛（$\|g_k\|\to0$），且若 $x^*$ 处二阶充分条件成立则**超线性收敛**。直觉：$B_k$ 沿"历史方向"逐步逼近 $H(x^*)$，方向 $d_k$ 渐近 Newton 方向（Dennis-Moré 条件 $\lim\frac{\|(B_k-H(x^*))d_k\|}{\|d_k\|}=0$）。

#### 5. 算法三步走：BFGS

**① 痛点**：Newton 每步 $O(n^3)$ 重算/分解 Hessian；最速下降只有 $O(n)$ 但慢。要一个"每步 $O(n^2)$、收敛接近 Newton"的中间点。

**② 直觉**：用走过的 $(s,y)$ 增量修正 $B$，约束只在"将要走的方向"上逼近 Hessian——信息足够，成本减半。

**③ 公式 + 手搓步骤**：

```
输入：f, g, 初值 x0, 初始 B0（通常 I，正定）
输出：近似极小点
1  对 k = 0, 1, ...:
2      d_k ← -B_k^{-1} g_k     （用 D_k 形式: d_k = -D_k g_k）
3      α_k ← Wolfe 线搜索;   s_k ← α_k d_k;   x_{k+1} ← x_k + s_k
4      y_k ← g_{k+1} - g_k
5      若 y_k^T s_k ≤ 0:  修正（阻尼 BFGS，见坑点 1）
6      ρ_k ← 1/(y_k^T s_k)
7      D_{k+1} ← (I - ρ_k s_k y_k^T) D_k (I - ρ_k y_k s_k^T) + ρ_k s_k s_k^T
```

**手算演示**（$2\times2$ 完整一次更新）：$f(x,y)=x^2+2y^2$，$g=(2x,4y)$。取 $x_0=(1,1)$，$x_1=(0.5,0.5)$，$B_0=I$。

$$s_0=(-0.5,-0.5),\qquad y_0=g(x_1)-g(x_0)=(1,2)-(2,4)=(-1,-2),\qquad y_0^Ts_0=1.5>0\ ✓$$

$$B_1=I-\frac{s_0s_0^T}{s_0^Ts_0}+\frac{y_0y_0^T}{y_0^Ts_0}
=I-\frac{1}{0.5}\begin{pmatrix}0.25&0.25\\0.25&0.25\end{pmatrix}+\frac{1}{1.5}\begin{pmatrix}1&2\\2&4\end{pmatrix}
=\begin{pmatrix}1.1667&0.8333\\0.8333&3.1667\end{pmatrix}$$

**验证割线条件**：$B_1s_0=\begin{pmatrix}1.1667&0.8333\\0.8333&3.1667\end{pmatrix}\begin{pmatrix}-0.5\\-0.5\end{pmatrix}=\begin{pmatrix}-1\\-2\end{pmatrix}=y_0$ ✓

**验证正定**：$\det(B_1)=1.1667\times3.1667-0.8333^2=3.0>0$，$\text{tr}(B_1)>0$ ⇒ 正定 ✓

**直觉读法**：$B_1$ 的对角元 $(1.17,3.17)$ 已经"嗅到"真实 Hessian $\text{diag}(2,4)$ 的规模——**一次更新就基本还原了曲率的大小**，这就是 BFGS 的神奇。

#### 6. Python 复现与误差可视化

完整脚本：`code/ch9/ch9_7_bfgs.py`：

```python
import numpy as np

f = lambda x: 100*(x[1]-x[0]**2)**2 + (1-x[0])**2
g = lambda x: np.array([-400*x[0]*(x[1]-x[0]**2)-2*(1-x[0]), 200*(x[1]-x[0]**2)])

def bfgs(g, x0, maxit=100):
    xs = [np.asarray(x0, float)]
    D = np.eye(2)                      # B0 = I（正定）
    for _ in range(maxit):
        gk = g(xs[-1])
        if np.linalg.norm(gk) < 1e-12: break
        d = -D @ gk                    # 拟 Newton 方向
        a = 1.0                         # Armijo 回溯（足够演示）
        while f(xs[-1] + a*d) > f(xs[-1]) + 1e-4*a*(gk @ d): a *= 0.5
        s = a * d
        x_new = xs[-1] + s
        y = g(x_new) - gk
        sy = s @ y
        if sy > 1e-12:                 # 曲率条件
            rho = 1.0 / sy
            I = np.eye(2)
            V = I - rho * np.outer(s, y)
            D = V @ D @ V.T + rho * np.outer(s, s)
        xs.append(x_new)
    return np.array(xs)

xs = bfgs(g, np.array([-1.2, 1.0]))
print(f"BFGS: {len(xs)-1} 步收敛到 {xs[-1]}")   # 37 步到 (1,1)
```

![BFGS 直穿 Rosenbrock 峡谷；同函数上最速下降 100 步仍在徘徊](figures/ch9_bfgs_compare.png)

**图解读**：同是 Rosenbrock、同从 $(-1.2,1)$ 出发——BFGS 37 步到达 $(1,1)$（误差 $10^{-28}$），最速下降 100 步后梯度范数仍有 $0.1$。**差距全部来自"曲率信息"**：$B_k$ 学会了峡谷的弯道，方向不再横冲直撞。

#### 7. 易错坑点

1. **$y^Ts\le0$ 时更新毁掉正定性**：Wolfe 线搜索保证 $y^Ts>0$；但如果用了不合适的线搜索（如纯 Armijo 回溯或固定步长），可能出现 $y^Ts\le0$。**救法：阻尼 BFGS（Powell 修正）**——把 $y$ 换成 $\tilde y=\theta y+(1-\theta)Bs$，$\theta$ 取使 $\tilde y^Ts\ge$ 小正常数的值，保证正定且保留割线方向的曲率信息。
2. **$B_0$ 必须正定**：通常取 $I$ 或"对角尺度" $B_0=\frac{y_0^Ty_0}{y_0^Ts_0}I$。非正定的 $B_0$ 从第一步就埋雷。
3. **割线条件 ≠ $B$ 处处等于 Hessian**：$B_{k+1}$ 只在 $s_k$ 方向与（某个平均）Hessian 一致，其他方向仍可能差很远。"$B$ 收敛到 $H$"是理想化的极限说法，工程上只要方向对就行（Dennis-Moré 条件）。
4. **数值漂移**：$D_k$ 的更新长时间累积后可能丢失对称/正定（浮点误差）。每若干步重设 $B_0=I$ 是常见保健。
5. **内存**：BFGS 存满 $B$（$O(n^2)$）；$n>10^5$ 时用 L-BFGS（只存最近 $m$ 对 $(s,y)$，$O(mn)$）。

#### 8. 对比辨析：拟 Newton 家族

| 方法 | 更新目标 | 公式特点 | 收敛阶 | 每步成本 |
|---|---|---|---|---|
| DFP | $B^{-1}$ 的更新对偶 | 与 BFGS 交换 $s\leftrightarrow y$、$B\leftrightarrow D$ | 超线性 | $O(n^2)$ |
| **BFGS** | $B$（或 $D$） | 对称 + 割线 + 最小变化 | 超线性（实践中优于 DFP） | $O(n^2)$ |
| Broyden（求根） | $B$（非对称） | 只要求割线，最小范数 | 超线性（$p\approx1.618$） | $O(n^2)$ |
| L-BFGS | 隐式 $D$ | 只存最近 $m$ 对 $(s,y)$ | 超线性（有限记忆） | $O(mn)$ |

> **辨析要点**：DFP 与 BFGS 是"同一变分问题的对偶解"（交换 $B\leftrightarrow D$ 与 $s\leftrightarrow y$）；实践中 BFGS 数值更稳（DFP 对舍入更敏感）。Broyden 法把"对称"要求也扔掉，是 9.1.3 方程组求根的拟 Newton。**L-BFGS 是 BFGS 在大规模时代的形态**——现代机器学习的默认优化器之一。

#### 9. 伪证辨析栏 ⭐

**伪证 1（看似能推其实缺条件）**：*"割线条件 $B_{k+1}s_k=y_k$ 满足，所以 $B_{k+1}$ 是 Hessian 的好近似。"*

- **反例**：任意对称矩阵 $M$ 若满足 $Ms=y$，都"满足割线条件"——但 $M$ 可以在与 $s$ 正交的方向上完全错误。**割线条件只是"沿 $s$ 方向的一维约束"**。
- **正确命题**：BFGS 的方向质量由 Dennis-Moré 条件刻画：只需 $\frac{\|(B_k-H(x^*))d_k\|}{\|d_k\|}\to0$（沿迭代方向逼近），**不需要** $B_k\to H(x^*)$。

**伪证 2（看似对其实错）**：*"只要 $y^Ts>0$，BFGS 从任何 $B_0$ 出发都收敛。"*

- **反例**：$B_0$ 非正定时，即使 $y^Ts>0$ 也保不住正定（定理 9.19 的前提是 $B_k$ 正定）；且全局收敛还需 Wolfe 步长与函数正则性。
- **正确命题**：正定保持 = $B_k$ 正定（前提）+ 曲率条件（$y^Ts>0$）⇒ $B_{k+1}$ 正定。**两个条件缺一不可**。

**伪证 3（看似相等其实不等）**：*"BFGS 更新后 $B_{k+1}$ 与 $B_k$ 的关系是'越更新越接近真实 Hessian'，每步都更近。"*

- **不等在哪**：$\|B_{k+1}-H\|$ 不单调。BFGS 保证的是"沿 $s_k$ 方向满足割线"与"正定保持"，**不保证整体距离单调递减**。收敛性的证明走的是"方向逼近"（Dennis-Moré），不是"矩阵逼近"。
- **直觉**：导航地图每更新一次，只保证"刚走过的路"更准；没走过的区域可能暂时更不准——但长期反复走，整个地图会好起来。

**伪证 4（看似能推其实缺条件）**：*"$y_k^Ts_k>0$ 总是自动成立。"*

- **反例**：$f(x,y)=x^2-y^2$（鞍点函数），迭代从 $x_k=(1,1)$ 走到 $x_{k+1}=(2,2)$：$g=(2x,-2y)$，故 $y_k=g(x_{k+1})-g(x_k)=(2,-4)$，$s_k=(1,1)$，$y_k^Ts_k=2-4=-2<0$。**沿鞍点函数的上坡方向走一步，曲率条件即被破坏**。
- **正确命题**：$y^Ts>0$ 需要额外保障——最常见的是**步长满足 Wolfe 条件**（定理 9.18）。实现中必须在更新前检查 $y^Ts>0$，否则改用**阻尼 BFGS**（Powell 修正）保正定。

#### 10. 深度透析（考研 / 科研拔高）

**(a) 变分推导的唯一性**：BFGS 是"对称 + 割线 + 最小变化"的唯一解。加权 Frobenius 范数 $\|M\|_W=\|W^{1/2}MW^{-1/2}\|_F$ 中，$W$ 的选取（与 $B_k$ 兼容）保证更新公式里不出现 $W$——**这个"权重选择"是变分推导的点睛之笔**：选得恰当，解与权重无关，公式才干净。DFP 是换另一种权重（对 $D$ 做变分）得到的对偶解。

**(b) L-BFGS 的两循环递归**：只存最近 $m$ 对 $(s_k,y_k)$，计算 $d=-D_kg_k$ 时用"两循环"（从最新的 $(s,y)$ 往旧的方向做标量内积递归），全程 $O(mn)$ 次运算、$O(mn)$ 存储，**不显式构造 $D$**。这是"把 $D$ 的更新公式展开成历史对的线性组合"的工程实现——理解 BFGS 的展开形式，L-BFGS 只是"截断历史"。

**(c) Dennis-Moré 条件与超线性收敛**：BFGS 超线性收敛的核心判据：$\lim_{k\to\infty}\frac{\|(B_k-H(x^*))d_k\|}{\|d_k\|}=0$。证明思路：$\|e_{k+1}\|\le\|H^{-1}\|\cdot\|(B_k-H)d_k\|$——若沿 $d_k$ 方向的"曲率误差"趋于 0，则误差递推 $\|e_{k+1}\|=o(\|e_k\|)$（比任何线性比率都快）。**"方向上的逼近"替代"矩阵的逼近"——这是拟 Newton 理论最深刻的一点。**

**(d) BFGS 与信赖域的联姻**：把 BFGS 的 $B_k$ 装进信赖域子问题 $\min_{\|s\|\le\Delta}\frac12s^TB_ks+g_k^Ts$，得到 **trust-region BFGS**——结合 9.2.3 的 $\rho$ 判据与 9.3.3 的 $O(n^2)$ 曲率近似。这是中小规模非光滑/约束优化的标准组合。

### 9.4.1 残差向量、Jacobian 与非线性参数拟合

> **一句话本质**：非线性拟合把"找参数"写成**最小化残差平方和** $\min_\theta \frac12\|r(\theta)\|^2$；残差 $r$ 是参数的非线性向量函数，它的 Jacobian $J$ 把 $m$ 维残差"投影"回 $n$ 维参数空间——目标函数的梯度是 $J^Tr$，Hessian 是 $J^TJ$（再加一个曲率项），**$J^TJ$ 是廉价二阶信息的入口**。

#### 1. 生活类比

- **调相机三旋钮**：光圈、快门、ISO。每组设置产生一组"预测误差"（该拍的照片与理想照片的差距），你要找误差平方和最小的设置。Jacobian 告诉你"每个旋钮拧一点，误差各改变多少"——它是"误差对旋钮的敏感度表"。
- **校零的天平**：砝码不准，秤出的每件物品都有偏差。你想恢复砝码真值：每个物品的偏差 $r_i$ 都是"砝码参数"的函数，最小化所有偏差的平方和。

#### 2. 几何直观

数据点 $(x_i,y_i)$、模型 $y=\varphi(x;\theta)$。残差向量 $r(\theta)\in\mathbb R^m$ 是"预测误差的集合"。目标是把它压向零向量：

$$\min_\theta \frac12\|r(\theta)\|^2$$

几何上：$r(\theta)$ 随 $\theta$ 扫出一条 $n$ 维曲面（$n$ 个参数、$m$ 维空间），找曲面上离原点最近的点。Jacobian $J(\theta)$ 是该曲面在 $\theta$ 处的切空间的基——$J^Tr$ 是"沿曲面走哪个方向能让残差平方和降得最快"（参数空间的梯度）。

#### 3. 底层逻辑

为什么要"平方和"而不是"绝对值和"？因为平方和让目标函数**光滑可导**（绝对值在零点不可导），且天然把"大误差"惩罚得更重（$L_2$ 几何）。加 $\frac12$ 系数纯粹是为了让梯度干净（$\nabla(\frac12\|r\|^2)=J^Tr$ 没有 2 因子）。**目标函数的一切性质都从残差和 Jacobian 推导出来**——所以本节先建语言（$r,J$），再算梯度与 Hessian。

#### 4. 定义与推导（全部手推）

**定义 9.12（非线性最小二乘问题）** 给定数据 $\{(x_i,y_i)\}_{i=1}^{m}$ 与模型 $y=\varphi(x;\theta)$（$\theta\in\mathbb R^n$），定义残差与目标：

$$r_i(\theta)=y_i-\varphi(x_i;\theta),\qquad \textcolor{blue}{f(\theta)=\frac12\|r(\theta)\|^2=\frac12\sum_{i=1}^{m}r_i(\theta)^2}$$

**定义 9.13（Jacobian）** $J(\theta)\in\mathbb R^{m\times n}$，$J_{ij}=\frac{\partial r_i}{\partial\theta_j}$。

**推导 1（梯度）**：链式法则，逐项展开（严禁跳步）：

$$\frac{\partial f}{\partial\theta_j}=\frac{\partial}{\partial\theta_j}\frac12\sum_i r_i^2=\sum_i r_i\frac{\partial r_i}{\partial\theta_j}=\big[J^T(\theta)r(\theta)\big]_j$$

$$\textcolor{blue}{\nabla f(\theta)=J(\theta)^Tr(\theta)}$$

**推导 2（Hessian）**：对上式再求导：

$$\frac{\partial^2 f}{\partial\theta_j\partial\theta_k}=\sum_i\frac{\partial r_i}{\partial\theta_j}\frac{\partial r_i}{\partial\theta_k}+\sum_i r_i\frac{\partial^2r_i}{\partial\theta_j\partial\theta_k}$$

$$\textcolor{blue}{\nabla^2 f(\theta)=J(\theta)^TJ(\theta)+\sum_{i=1}^{m}r_i(\theta)\nabla^2r_i(\theta)}=\textcolor{blue}{J^TJ}+\textcolor{red}{S(\theta)}$$

**核心观察（本节最重要的一个公式）**：Hessian 由两项组成——**主项 $J^TJ$**（只依赖一阶导，$O(mn)$ 可算）与**二阶项 $S=\sum r_i\nabla^2r_i$**（依赖残差本身与残差的二阶导）。**残差小（$r_i\approx0$）或模型近线性（$\nabla^2r_i\approx0$）时，$S$ 可忽略，$H\approx J^TJ$**——这就是 9.4.2 Gauss-Newton 的全部合理性。

**推导 3（线性特例 → 正规方程）**：若 $\varphi(x;\theta)$ 关于 $\theta$ **线性**（$\varphi=X\theta$，$X\in\mathbb R^{m\times n}$ 为设计矩阵），则 $r=y-X\theta$，$J=-X$，$\nabla^2r_i=0$。于是：

$$\nabla f=-X^T(y-X\theta)=X^T(X\theta-y),\qquad \nabla^2f=X^TX$$

令梯度为零即得**正规方程** $\textcolor{blue}{X^TX\theta=X^Ty}$——线性最小二乘的闭式解。**非线性最小二乘的迭代法（GN/LM）就是反复解"局部正规方程"。**

#### 5. 算法三步走：建立参数拟合问题

**① 痛点**：数据背后有物理/生物/经济模型，但参数未知；模型关于参数非线性，没有闭式解。

**② 直觉**：残差向量 + Jacobian → 梯度 $J^Tr$ → 迭代求解（Newton/GN/LM）。先写清楚 $r$ 与 $J$，算法只是把 9.2/9.3 的机器开过来。

**③ 公式 + 手搓步骤**：

```
输入：数据 {(x_i,y_i)}，模型 φ，初值 θ0
输出：最小二乘参数 θ*
1  写残差 r_i(θ) = y_i - φ(x_i; θ)
2  写 Jacobian J_ij = ∂r_i/∂θ_j        （解析或有限差分）
3  目标 ∇f = J^T r；Hessian ≈ J^T J（GN 近似）
4  交给 9.4.2 / 9.4.3 的迭代器
```

**手算演示**：拟合 $y=\theta x^2$，数据 $(1,1.1),(2,4.2),(3,8.8)$（真值 $\theta\approx1$ 附近）。

$$\theta=1:\quad r=(0.1,\ 0.2,\ -0.2),\qquad J=\frac{\partial r}{\partial\theta}=(-x_1^2,-x_2^2,-x_3^2)=(-1,-4,-9)$$

$$J^Tr=-0.1-0.8+1.8=0.9,\qquad J^TJ=1+16+81=98$$

于是 $\nabla f=0.9$（$>0$：$\theta$ 应减小），GN 步 $\Delta=-\frac{0.9}{98}=-0.00918$，$\theta_1=0.9908$。**一个参数、三个数据点，整条推导只用了一次链式法则。**（本例 $\varphi$ 关于 $\theta$ 线性，GN 一次迭代几乎就到正规方程解。）

#### 6. Python 复现

完整脚本：`code/ch9/ch9_8_gn_lm.py`（本节的残差与 Jacobian 是实验的基础）：

```python
import numpy as np

t = np.arange(5, dtype=float)                # 自变量 t = 0,1,2,3,4
y = np.array([3.0, 1.5, 0.9, 0.5, 0.25])    # 模拟数据（真实模型 y=3e^{-1.5t} + 噪声）
model = lambda th, tt: th[0] * np.exp(-th[1] * tt)

def residual(th):
    return y - model(th, t)                  # 残差向量 r(θ)

def jacobian(th):                            # J_ij = ∂r_i/∂θ_j
    J = np.empty((t.size, 2))
    J[:, 0] = -np.exp(-th[1] * t)            # ∂r/∂θ1 = -e^{-θ2 t}
    J[:, 1] = th[0] * t * np.exp(-th[1] * t) # ∂r/∂θ2 = θ1 t e^{-θ2 t}
    return J

th = np.array([1.0, 1.0])
print(f"r(θ0) = {residual(th).round(3)}")
print(f"梯度 J^T r = {jacobian(th).T @ residual(th)}")   # 指向参数空间的最速下降
```

#### 7. 易错坑点

1. **$\frac12$ 系数别丢**：不同教材用 $\|r\|^2$ 或 $\frac12\|r\|^2$，梯度差 2 倍。**本章统一 $\frac12\|r\|^2$**，公式 $\nabla f=J^Tr$ 干净无 2。对照外部代码时先看清约定。
2. **Jacobian 的"行/列"别搞反**：行 = 数据点（$i$），列 = 参数（$j$）。$J^TJ$ 是 $n\times n$（参数×参数），$J^Tr$ 是 $n$ 维（参数空间梯度）。**写代码前先标维度**。
3. **$m\ge n$ 才一般有意义**：数据点少于参数（欠定）时 $J^TJ$ 奇异，参数不可唯一辨识。
4. **残差尺度悬殊**：$y$ 的量级差 $10^6$ 时，大残差主导目标——用**加权最小二乘** $\frac12\|W^{1/2}r\|^2$（$W$ 为权重/方差倒数）修正。
5. **数值 Jacobian 的步长**：解析 $J$ 最可靠；有限差分 $J_{ij}\approx\frac{r_i(\theta+he_j)-r_i(\theta)}{h}$ 的 $h$ 取 $\sim\sqrt{\varepsilon}\approx1.5\times10^{-8}$（截断/舍入平衡，同 9.1.3 深度透析 (c)）。

#### 8. 对比辨析：线性 vs 非线性最小二乘

| 维度 | 线性最小二乘（§ 前几章） | 非线性最小二乘（本节） |
|---|---|---|
| 目标 | $f=\frac12\|y-X\theta\|^2$（二次） | $f=\frac12\|r(\theta)\|^2$（一般非凸） |
| 解 | **闭式**：$X^TX\theta=X^Ty$ | **迭代**：GN / LM |
| 梯度/Hessian | $-X^T(y-X\theta)$，$X^TX$ 常数 | $J^Tr$，$J^TJ+S$（随 $\theta$ 变） |
| 陷阱 | 病态（$X^TX$ 条件数大） | 非凸（多局部极小）+ 病态 + 残差大 |

> **辨析要点**：线性问题的"设计矩阵 $X$"在非线性问题里变成了"依赖当前 $\theta$ 的 Jacobian $J(\theta)$"——**每次迭代都在重新设计一个局部线性问题**。GN 就是"反复解局部正规方程"。

#### 9. 伪证辨析栏 ⭐

**伪证 1（看似对其实错）**：*"最小化残差平方和找到的 $\theta$ 就是模型真值。"*

- **反例**：带噪声数据 $\min\frac12\|r\|^2$ 的解 $\theta_{\mathrm{ls}}$ 是"最优拟合参数"，它使**拟合残差**最小，不等于生成数据的真参数 $\theta^*$（实验 A 中 GN 停在 $\|\theta-\theta^*\|\approx9\times10^{-3}$ 的噪声极限，不是 $0$）。
- **正确命题**：$\theta_{\mathrm{ls}}\to\theta^*$ 需要"噪声 → 0"或统计意义下的无偏估计假设。**拟合 ≠ 还原**。

**伪证 2（看似相等其实不等）**：*"$J^TJ$ 就是 Hessian。"*

- **不等在哪**：$\nabla^2f=J^TJ+\sum r_i\nabla^2r_i$。$S$ 项在残差大时不可忽略（9.4.2 实验 B 会翻车）。
- **正确关系**：$J^TJ$ 是 Hessian 的**高斯近似**（GN 的核心假设），仅当残差小或近线性时成立。

**伪证 3（看似能推其实缺条件）**：*"$J^TJ$ 总是可逆的，所以 GN 步总能解出来。"*

- **缺的条件**：$J$ 列满秩。若两列近似成比例（如模型 $y=\theta_1e^{-\theta_2t}$ 在 $\theta_2$ 很大时，$J$ 的两列都 $\approx0$ 或成比例），$J^TJ$ 病态/奇异，GN 步爆炸——**这正是 LM 加 $\lambda I$ 的动机**（9.4.3）。

#### 10. 深度透析（考研 / 科研拔高）

**(a) 可辨识性（identifiability）**：参数 $\theta$ 局部可辨识 ⇔ $J(\theta)$ 列满秩 ⇔ $J^TJ$ 正定。秩亏时，参数"沿 $J$ 的零方向"变化不改变拟合效果——**数据根本测不出这个参数组合**。实验前先查 $J$ 的条件数，是参数辨识的第一课。

**(b) 为什么用"平方和"：统计学的答案**。若噪声 $\varepsilon_i\sim N(0,\sigma^2)$ 独立同分布，则 $\min\frac12\|r\|^2$ 的解 = **极大似然估计**（MLE）。推导：似然 $L=\prod\frac1{\sqrt{2\pi\sigma^2}}e^{-r_i^2/(2\sigma^2)}$，取负对数 $\propto\frac1{2\sigma^2}\sum r_i^2$。**最小二乘的"平方"不是随便选的，它是高斯噪声假设下的最优统计量**。加权最小二乘对应异方差噪声。

**(c) 模型误差 vs 噪声**：残差 $r_i$ 的来源有两类——测量噪声（随机）与**模型错误**（$\varphi$ 形式不对，系统性）。$J^TJ+S$ 的 $S$ 项里 $r_i$ 的符号/大小把"模型错误"反馈回曲率估计。**拟合失败时先问：是参数没调对，还是模型根本不对？**（$S$ 项的残差分布是线索。）

**(d) 从拟合到预测**：参数辨识的最终目的是预测/外推。$\theta_{\mathrm{ls}}$ 的协方差近似 $\sigma^2(J^TJ)^{-1}$——**$J^TJ$ 不仅驱动算法，还给出参数的置信区间**。这是"最小二乘 = 工程统计"的另一半。

#### 11. 本节自测

**基础**：拟合 $y=\theta_1+\theta_2 x$（线性！），数据 $(0,1),(1,3),(2,5.5)$。写残差、设计矩阵 $X$，解正规方程。（$X=\begin{pmatrix}1&0\\1&1\\1&2\end{pmatrix}$，$y=(1,3,5.5)$；$X^TX=\begin{pmatrix}3&3\\3&5\end{pmatrix}$，$X^Ty=(9.5,14)$；$\theta=\begin{pmatrix}3&3\\3&5\end{pmatrix}^{-1}\begin{pmatrix}9.5\\14\end{pmatrix}=\frac16\begin{pmatrix}5&-3\\-3&3\end{pmatrix}\begin{pmatrix}9.5\\14\end{pmatrix}=(0.9167,2.25)$。交叉验证：$\bar x=1$，$\bar y=3.1667$，$\theta_2=\frac{\sum(x_i-\bar x)(y_i-\bar y)}{\sum(x_i-\bar x)^2}=2.25$，$\theta_1=\bar y-\theta_2\bar x=0.9167$ ✓）

### 9.4.2 Gauss-Newton 近似及其适用条件

> **一句话本质**：优化 Newton 需要 Hessian $\nabla^2f=J^TJ+\sum r_i\nabla^2r_i$；**Gauss-Newton 把二阶项 $\sum r_i\nabla^2r_i$ 整个扔掉**，用 $J^TJ$ 冒充 Hessian——残差小或模型近线性时这是合理的（接近 Newton、逼近二阶收敛），残差大时丢掉的项不可忽略，GN 会失准甚至发散。

#### 1. 生活类比

- **近视眼开车**：GN 像近视眼——它假设"远处的误差（残差）都接近零"，所以敢只看眼前的线性近似（$J^TJ$）。真近视（残差大）时，远处的东西其实很大（$S$ 项不可忽略），近视眼就撞车了。**近视不是毛病，不知道自己近视才是**。
- **修屋顶只测坡度**：你不去精确测量屋顶每个点的高度（二阶导 $\nabla^2r_i$），只测"每块瓦片倾斜多少"（一阶导 $J$）——瓦片都不太翘（残差小）时，这足够精确。

#### 2. 几何直观

$f$ 的 Hessian 分两半：

$$\textcolor{blue}{\nabla^2f(\theta)=J^TJ}+\textcolor{red}{S(\theta)},\qquad S(\theta)=\sum_{i=1}^{m}r_i(\theta)\nabla^2r_i(\theta)$$

- $J^TJ$：**半正定**（$v^T(J^TJ)v=\|Jv\|^2\ge0$），只含一阶信息，永远"安全"；
- $S$：残差加权的高阶曲率，**可正可负可不定**——它才是 Hessian"不听话"的部分。

GN 的策略：**砍掉 $S$**。好处是双重的：① $J^TJ$ 自动半正定，省掉 9.3.2 的 Hessian 修正；② 只要 $J$ 和 $r$，成本 $O(mn)$ 而非 $O(n^3)$。

**砍掉 $S$ 的代价**：$S$ 正比于残差 $r_i$。残差小 → $S\approx0$ → GN ≈ Newton；残差大 → $S$ 喧宾夺主 → GN 方向偏离 Newton 方向 → 收敛变慢甚至爆走（实验 B 的现场）。

#### 3. 底层逻辑

GN 的合理性有**两个独立来源**：

1. **零残差问题的精确性**：若数据与模型完全吻合（$r(\theta^*)=0$），则 $S(\theta^*)=0$，极小点处 $H=J^TJ$——GN 在根附近与 Newton 渐近等价，**二阶收敛**；
2. **线性化递归**：GN 步 = 把当前残差在 $\theta_k$ 处线性化 $r(\theta_k+\Delta)\approx r_k+J_k\Delta$，解**线性最小二乘** $\min_\Delta\|r_k+J_k\Delta\|^2$——这是 9.4.1 正规方程的重放。**GN = 反复解局部线性拟合问题**。

工程上，残差"小不小"没有绝对标准——这正是 LM（9.4.3）存在的原因：**用 $\rho$ 自动判断"$J^TJ$ 模型还信不信得过"**。

#### 4. 定义与定理

**定义 9.14（Gauss-Newton 迭代）** 给定当前 $\theta_k$，GN 步 $\Delta_k$ 是线性最小二乘的解：

$$\textcolor{blue}{(J_k^TJ_k)\Delta_k=-J_k^Tr_k},\qquad \theta_{k+1}=\theta_k+\Delta_k$$

**推导（与 Newton 的关系，三行）**：优化 Newton 步 $\Delta=-(\nabla^2f)^{-1}\nabla f$。代入 $\nabla f=J^Tr$、$\nabla^2f=J^TJ+S$，丢弃 $S$：

$$\Delta_{GN}=-\big(J^TJ\big)^{-1}J^Tr$$

**定理 9.20（GN 的局部收敛，Dennis-Schnabel 型，陈述）** 设 $r$ 足够光滑，$J(\theta^*)$ 列满秩，$\theta_0$ 足够近。则：

$$\|\theta_{k+1}-\theta^*\|\le c\big(\|\theta_k-\theta^*\|^2+\|r(\theta^*)\|\cdot\|\theta_k-\theta^*\|\big)$$

**读法（这是本节最值钱的一行不等式）**：

- **零残差**（$\|r(\theta^*)\|=0$）：$\|e_{k+1}\|\le c\|e_k\|^2$——**二阶收敛**，与 Newton 相同；
- **小残差**：线性项 $c\|r^*\|\|e_k\|$ 主导，**线性收敛**，比率 $\sim c\|r^*\|$（残差越大越慢）；
- **大残差**：比率 $\ge1$，**收敛无保证**（实验 B）。

**适用条件清单（工程查表）**：

| 条件 | 作用 | 不满足时的后果 |
|---|---|---|
| $J$ 列满秩 | $J^TJ$ 可逆 | GN 步无定义 → 用 LM |
| 残差小 / 近线性 | $S$ 可忽略 | 收敛慢/发散 → 用 LM |
| 初值足够近 | 局部收敛定理前提 | 发散 → 全局化（多起点/连续同伦） |

#### 5. 算法三步走：Gauss-Newton

**① 痛点**：Newton 每步要算 $\nabla^2f$（含 $S$ 项，又贵又不稳）；需要一个只用一阶信息的近似。

**② 直觉**：Hessian ≈ $J^TJ$（残差小 → $S$ 可扔）；每步 = 解一个线性最小二乘（正规方程）。

**③ 公式 + 手搓步骤**：

```
输入：r(θ), J(θ), 初值 θ0
输出：最小二乘解
1  对 k = 0, 1, ...:
2      r_k ← r(θ_k);  J_k ← J(θ_k)
3      解 (J_k^T J_k) Δ_k = -J_k^T r_k
4      θ_{k+1} ← θ_k + Δ_k
5      若 ‖Δ_k‖ 或 ‖J_k^T r_k‖ < tol: 停止
```

**手算演示**（延续 9.4.1 的单参数例）：$\theta_0=1$，$r_0=(0.1,0.2,-0.2)$，$J=(-1,-4,-9)$：

$$J^TJ=98,\quad J^Tr=0.9\quad\Rightarrow\quad\Delta=-\frac{0.9}{98}=-0.00918,\quad\theta_1=0.99082$$

再迭代一步：$r_1=(0.1092,0.2367,-0.1165)$，$J^Tr_1=-(0.1092+0.9469)+1.0487=-0.0074$，$\Delta_2=+7.5\times10^{-5}$，$\theta_2=0.99090$。**两步内到达正规方程解**（本例模型关于 $\theta$ 线性，GN 与 Newton 重合）。

#### 6. Python 复现与误差可视化

完整脚本：`code/ch9/ch9_8_gn_lm.py`。实验 A（小噪声）的 GN：

```python
import numpy as np
t = np.arange(5, dtype=float); y_true_model = lambda th,tt: th[0]*np.exp(-th[1]*tt)
rng = np.random.default_rng(0)
y = y_true_model([3.0,1.5], t) + rng.normal(0, 0.05, t.size)   # 小噪声数据

def residual(th): return y - y_true_model(th, t)
def jacobian(th):
    J = np.empty((t.size, 2))
    J[:,0] = -np.exp(-th[1]*t)
    J[:,1] = th[0]*t*np.exp(-th[1]*t)
    return J

th = np.array([1.0, 1.0])
for k in range(9):
    r, J = residual(th), jacobian(th)
    d = np.linalg.solve(J.T@J, -J.T@r)      # GN 步 = 解正规方程
    th = th + d
print(f"GN 9 步: θ = {th.round(5)},  ||θ-θ*|| = {np.linalg.norm(th-[3,1.5]):.2e}")
# 输出: θ ≈ (3.0049, 1.4925)，误差 8.9e-3 —— 这是噪声极限，不是算法极限
```

![小噪声：GN 与 LM 都在几步内到达噪声极限；大噪声：GN 爆走、LM 靠 λ 存活](figures/ch9_gn_lm_fit.png)

**可视化解读（左图）**：小噪声下 GN 的误差曲线几乎垂直坠落（对数坐标下每步误差大幅缩小）——接近二阶收敛；但它最终**停在 $8.9\times10^{-3}$ 不再下降**。这不是算法失败：噪声使数据本身不再来自"某个精确的 $\theta^*$"，任何算法都到不了 $0$。**"噪声极限"是数据给的，不是算法给的**——这个区分是读懂一切拟合实验的关键。

#### 7. 易错坑点

1. **把 GN 的收敛极限当算法缺陷**：小噪声下 GN 停在噪声极限是**正确行为**。判断算法好坏要看"到达极限的速度"，不是极限本身。
2. **残差大时硬用 GN**：$S$ 项被无视，方向偏了还大步走——实验 B 的 GN 参数范数爆到 $116$。**先看残差量级再选方法**。
3. **$J^TJ$ 病态/奇异**：$J$ 列相关时正规方程无解或解巨大。用 $QR$ 分解解最小二乘（比正规方程稳定），或直接上 LM。
4. **正规方程 vs QR**：$(J^TJ)^{-1}J^Tr$ 用正规方程会平方条件数（$\kappa(J^TJ)=\kappa(J)^2$）；用 $QR$（`np.linalg.lstsq`）只吃 $\kappa(J)$。**工程上解线性最小二乘一律用 QR/SVD，不用正规方程**（除非 $n$ 巨大且病态不严重）。
5. **步长可能过大**：GN 步在远离解时可能把 $\theta$ 甩出合理域（如 $\theta_2<0$ 导致指数爆炸）——又是 LM 的活。

#### 8. 对比辨析：Newton vs GN vs 最速下降（非线性最小二乘）

| 方法 | 搜索方向 | Hessian 使用 | 每步成本 | 残差小时 | 残差大时 |
|---|---|---|---|---|---|
| 优化 Newton | $-(\nabla^2f)^{-1}J^Tr$ | 完整（$J^TJ+S$） | 高（$S$ 难算） | 二阶 | 二阶（但 $S$ 求不出） |
| **Gauss-Newton** | $-({J^TJ})^{-1}J^Tr$ | $J^TJ$（近似） | 低（只需 $J$） | **逼近二阶** | 线性/发散 |
| 最速下降 | $-J^Tr$ | 无 | 最低 | 线性（$\kappa$ 决定） | 线性但极慢 |

> **辨析要点**：GN 的位置是"Newton 与最速下降之间"：它用 $J^TJ$ 白拿了"半份二阶信息"（正定性、方向校正），代价是残差大时失效。**LM（9.4.3）在 GN 与最速下降之间再加一个 $\lambda$ 旋钮**——三种方法从此统一。

#### 9. 伪证辨析栏 ⭐

**伪证 1（看似相等其实不等）**：*"GN 的收敛阶就是二阶。"*

- **不等在哪**：定理 9.20 的 $\|e_{k+1}\|\le c(\|e_k\|^2+\|r^*\|\|e_k\|)$——二阶的前提是 $\|r^*\|=0$（零残差）。一般问题（$\|r^*\|>0$）GN 只是线性，比率 $\sim c\|r^*\|$。
- **正确命题**：**零残差 → 二阶；小残差 → 线性（比率随残差恶化）**。用实测 $\frac{\|e_{k+1}\|}{\|e_k\|^2}$ 是否趋于常数来判定（9.1.3 的收敛阶估计法）。

**伪证 2（看似能推其实缺条件）**：*"$J$ 列满秩 + 初值近 ⇒ GN 收敛。"*

- **缺的条件**：还要求**残差足够小**（或模型近线性）。$J$ 满秩只保证"方向可解"，不保证"方向正确"——方向由 $J^TJ$ 近似决定，$S$ 大时方向就是错的。
- **反例**：实验 B（$\sigma=2.0$）：$J$ 满秩、初值 $(1,1)$ 离解不远，GN 照样爆走。

**伪证 3（看似对其实错）**：*"GN 比 Newton 快，因为它不用算 $S$。"*

- **错在哪**："每步便宜" ≠ "收敛快"。GN 每步 $O(mn)$ 是便宜，但残差大时可能要多跑几十步甚至不收敛；Newton 每步贵但步数少。**总成本 = 每步成本 × 步数**，不能只看一边。

#### 10. 深度透析（考研 / 科研拔高）

**(a) 零残差问题的二阶收敛（证明骨架）**：$r(\theta^*)=0$ 时，Taylor 展开 $r(\theta^*)=r_k+J_k(\theta^*-\theta_k)+O(\|e_k\|^2)$，即 $r_k=J_ke_k+O(\|e_k\|^2)$。代入 $e_{k+1}=e_k-(J_k^TJ_k)^{-1}J_k^Tr_k$：

$$e_{k+1}=(J^TJ)^{-1}J^T\big[J_ke_k-r_k\big]=(J^TJ)^{-1}J^T\cdot O(\|e_k\|^2)=O(\|e_k\|^2)$$

（$J$ 列满秩 ⇒ $(J^TJ)^{-1}J^T$ 有界。）**与定理 9.6 的证明一字不差地同构**——GN 的零残差情形就是 Newton 的二阶性。

**(b) $S$ 项不可算怎么办**：实际中 $\nabla^2r_i$ 常常没有解析式。三条路：① 指望残差小（赌 $S\approx0$）；② 有限差分二阶导（贵且噪声敏感）；③ **信赖域/LM 兜底**——不显式算 $S$，用 $\lambda$ 吸收它的影响。**工程默认走 ③**。

**(c) 与拟 Newton 的结合**：可以只存 $S$ 的近似（如用 BFGS 近似整个 Hessian 再减 $J^TJ$），得到**增广 GN**（augmented GN）——残差大时的进阶方案。

**(d) GN 的统计意义**：GN 迭代的收敛点 $\theta_{\mathrm{ls}}$ 是高斯噪声下的 MLE（9.4.1 深度透析 (b)）；$(J^TJ)^{-1}$ 给出参数协方差 $\sigma^2(J^TJ)^{-1}$——**GN 的副产品是参数不确定性**。

#### 11. 本节自测

**基础**：$y=\theta e^{-t}$，数据 $(0,2.1),(1,0.72),(2,0.28)$。$\theta_0=2$，写 $r$、$J$，算 GN 步 $\Delta$。（$r=(0.1,-0.0158,0.0093)$，$J=(-1,-0.3679,-0.1353)$，$J^TJ=1.1537$，$J^Tr=(-1)(0.1)+(-0.3679)(-0.0158)+(-0.1353)(0.0093)=-0.0955$，$\Delta=+0.0828$，$\theta_1=2.0828$——与正规方程闭式解 $\frac{2.1\cdot1+0.72\cdot0.3679+0.28\cdot0.1353}{1.1537}=2.0830$ 一致。**注意梯度为负时 GN 步为正：$\theta$ 要向增大方向修正**。）

**拔高**：解释：为什么 GN 在"零残差问题"里等价于 Newton？写出两者在 $\theta^*$ 邻域的方向差 $\Delta_{GN}-\Delta_N$ 的表达式，并说明它为何在 $\|r^*\|\to0$ 时趋于 0。（提示：$\Delta_N=-(J^TJ+S)^{-1}J^Tr$，$\Delta_{GN}=-(J^TJ)^{-1}J^Tr$；用 $S\approx0$ 或矩阵逆的展开。）

### 9.4.3 LM 阻尼、实际/预测下降与参数辨识实验

> **一句话本质**：LM 在 GN 步（快但脆）与梯度下降步（稳但慢）之间用 $\lambda$ 插值——解 $(J^TJ\textcolor{green}{+\lambda I})\Delta=-J^Tr$；$\lambda$ 小 → 接近 GN（高速挡），$\lambda$ 大 → 接近最速下降（低速挡）；换挡依据是**实际下降/预测下降**的比率 $\rho$。LM 把 9.3.2 的 Hessian 修正、9.2.3 的信赖域、9.4.2 的 GN 全部缝在一起，是工程参数辨识的事实标准。

#### 1. 生活类比

- **自动挡的 GN**：路况好（$\rho\approx1$：模型预测和实际走的一致）→ 挂高速挡（$\lambda$ 减小，GN 大步）；路况差（$\rho$ 小：实际没按预测的降）→ 挂低速挡（$\lambda$ 增大，保守小步）。**换挡不看油门，看"实际路况与地图的吻合度"。**
- **方向盘修正的力度**：$\lambda$ 是"对地图不信任的程度"——$\lambda=0$ 全信 GN 地图；$\lambda$ 无穷大 = 完全不信地图、只看脚下（最速下降）。**好的司机永远带着一点不信任（$\lambda>0$ 的下限）。**

#### 2. 几何直观

$(J^TJ+\lambda I)\Delta=-J^Tr$ 与信赖域子问题 $(B+\lambda I)s=-g$（9.2.3 深度透析 (b)）**完全同构**：

- $\lambda$ 的角色 = Hessian 修正（9.3.2 的 $\mu$）：保证 $J^TJ+\lambda I$ 正定 → 方向必下降；
- $\lambda$ 的角色 = 信赖域半径的对偶：$\|\Delta(\lambda)\|$ 随 $\lambda$ **单调递减**——$\lambda$ 大 → 步长小（圈小）、方向偏最速下降；$\lambda$ 小 → 步长大（圈大）、方向偏 GN；
- $\rho$ 的角色 = 信赖域的增益比：模型准（$\rho$ 高）→ 放大圈（减 $\lambda$）；模型崩（$\rho$ 低）→ 缩圈（增 $\lambda$）。

**一张图看懂 LM 的全貌**：GN 步 = 无阻尼直线冲；最速下降 = 之字形爬；LM = 沿"插值轨道"走，$\lambda$ 自动调坡度。

![大噪声下 GN 爆走失稳，LM 靠 λ 阻尼稳健收敛；右图 λ 随 ρ 自适应升降](figures/ch9_lm_robust.png)

#### 3. 底层逻辑

**为什么必须阻尼？** GN 步 $\Delta_{GN}$ 有两个死穴：① $J^TJ$ 奇异/病态时解不出来（$J$ 列相关）；② 步长可能巨大（残差大时方向已错，步长还按满格走）。$\lambda I$ 一箭双雕：**保证正定可解 + 缩短步长**。而且 $\lambda$ 的调节完全自动：不需要先验知识，只看 $\rho$。

**为什么用 $\rho$ 而不是直接试步长？** $\rho$ 是"模型健康度"的定量体检：实际下降 $\text{ared}=\|r_k\|^2-\|r_{k+1}\|^2$ 与模型预测下降 $\text{pred}=\|r_k\|^2-\|r_k+J_k\Delta\|^2$ 的比。$\rho\approx1$ → 线性化模型 $\|r_k+J\Delta\|^2$ 是真的 → 放心大步（GN 可信）；$\rho\le0$ → 实际在上升 → 模型完全崩了 → 加大阻尼缩步。**LM = GN + 自动刹车，刹车依据是 $\rho$。**

#### 4. 定义与推导

**定义 9.15（LM 步）** 给定 $\lambda_k\ge0$：

$$\textcolor{blue}{(J_k^TJ_k+\lambda_k I)\Delta_k=-J_k^Tr_k},\qquad \theta_{k+1}=\theta_k+\Delta_k$$

**模型与预测下降**：线性化模型 $m(\Delta)=\frac12\|r_k+J_k\Delta\|^2$，预测下降

$$\text{pred}_k=m(0)-m(\Delta_k)=\frac12\|r_k\|^2-\frac12\|r_k+J_k\Delta_k\|^2\ge0$$

（$\Delta_k$ 是 $m$ 的无约束极小点，故 $m(\Delta_k)\le m(0)$。）实际下降 $\text{ared}_k=\frac12\|r_k\|^2-\frac12\|r_{k+1}\|^2$。

**增益比**：

$$\textcolor{orange}{\rho_k=\frac{\text{ared}_k}{\text{pred}_k}=\frac{\|r_k\|^2-\|r_{k+1}\|^2}{\|r_k\|^2-\|r_k+J_k\Delta_k\|^2}}$$

**λ 自适应策略（Nielsen 常用版）**：

```
若 ρ > 0.75:  λ ← λ/3        （模型可信：减阻尼，放大步）
若 ρ < 0.25:  λ ← λ×3，拒绝步 （模型崩了：加阻尼，重解）
否则:         接受步，λ 不变
```

**推导（$\lambda$ 的两面性，三行）**：

1. **$\lambda=0$**：LM 退化为 GN；
2. **$\lambda\to\infty$**：$(J^TJ+\lambda I)^{-1}J^Tr\approx\frac1\lambda J^Tr$，$\Delta\approx-\frac1\lambda J^Tr$——**LM 退化为最速下降（步长 $\frac1\lambda$）**；
3. **中间 $\lambda$**：方向在 GN 与负梯度之间连续插值，步长随 $\lambda$ 单调递减。

$$\|\Delta(\lambda)\|\ \text{随 }\lambda\text{ 单调递减}:\quad \frac{d}{d\lambda}\|\Delta(\lambda)\|^2=-2\Delta^T(J^TJ+\lambda I)^{-1}\Delta\le0$$

（$J^TJ+\lambda I$ 正定 ⇒ 最后一项 $\le0$。**证明步长单调性的标准动作**。）

**与信赖域的对偶（连接 9.2.3）**：对每个 $\lambda\ge0$ 存在唯一信赖域半径 $\Delta_\mathrm{TR}=\|\Delta(\lambda)\|$，使 LM 步恰好是该半径下的信赖域解；反过来，给定 $\Delta$ 可解出唯一的 $\lambda$。**LM 的 $\lambda$ 与信赖域的 $\Delta$ 是同一枚硬币的两面。**

#### 5. 算法三步走：LM 参数辨识

**① 痛点**：GN 快但脆（病态/大步/大残差三宗罪）；最速下降稳但慢。要一个"自动切换"的档位。

**② 直觉**：$\lambda$ 管档位，$\rho$ 管换挡；$J^TJ+\lambda I$ 保正定，$\|\Delta(\lambda)\|$ 随 $\lambda$ 缩步。

**③ 公式 + 手搓步骤**：

```
输入：r(θ), J(θ), θ0, λ0（如 1e-2）, 最大迭代 N
输出：参数估计
1  对 k = 0, 1, ..., N-1:
2      r_k, J_k ← 当前 θ
3      若 ‖J_k^T r_k‖ < tol: 停止
4      尝试: 解 (J^T J + λ I) Δ = -J^T r
5      算 ρ = (‖r‖²-‖r_new‖²) / (‖r‖²-‖r+JΔ‖²)
6      若 ρ > 0.75: λ ← λ/3, 接受 Δ
        若 ρ < 0.25: λ ← λ×3, 拒绝，重解
        否则: 接受
7      θ ← θ + Δ
```

**手算演示**（延续 9.4.1/9.4.2 的单参数例，一步 LM）：$\theta_0=1$，$r=(0.1,0.2,-0.2)$，$J=(-1,-4,-9)$，$J^TJ=98$，$J^Tr=0.9$，取 $\lambda=2$：

$$\Delta=-\frac{0.9}{98+2}=-0.0090,\qquad \theta_1=0.9910$$

预测下降：$\text{pred}=\frac12(0.1^2+0.2^2+0.2^2)-\frac12\|r+J\Delta\|^2$。$r+J\Delta=(0.1+0.009,0.2+0.036,-0.2+0.081)=(0.109,0.236,-0.119)$，$\|r+J\Delta\|^2=0.0119+0.0557+0.0142=0.0818$，$\|r\|^2=0.09$，$\text{pred}=\frac12(0.09-0.0818)=0.0041$。实际下降：$\theta_1=0.9910$ 的残差 $r_1=(1.1-0.9910,4.2-3.964,8.8-8.919)=(-0.109?)$ 等等：$r_i=y_i-\theta x_i^2$：$r_1=(1.1-0.9910\cdot1,\ 4.2-0.9910\cdot4,\ 8.8-0.9910\cdot9)=(0.109,\ 0.236,\ -0.119)$，$\|r_1\|^2=0.0818$。$\text{ared}=\frac12(0.09-0.0818)=0.0041$。$\rho=\frac{0.0041}{0.0041}=1.0>0.75$ → **接受并减 $\lambda$**（模型极准）。**本例模型关于 $\theta$ 线性，线性化模型是精确的，$\rho\equiv1$——LM 自动确认"GN 模式可以全开"。**

#### 6. Python 复现与误差可视化（参数辨识实验）

完整脚本：`code/ch9/ch9_8_gn_lm.py`，完整实现 LM（含 $\lambda$ 上下限与 $\rho$ 判据）：

```python
import numpy as np

t = np.arange(5, dtype=float)
model = lambda th, tt: th[0]*np.exp(-th[1]*tt)
rng = np.random.default_rng(0)
theta_true = np.array([3.0, 1.5])
# 与 ch9_8_gn_lm.py 完全相同的噪声样本流程：先产生实验 A 的小噪声数据
# （推进 rng 状态），再产生实验 B 的大噪声数据——必须共用同一个 rng，
# 否则噪声样本不同，数值与正文引用的实验 B 结果不一致
_yA = model(theta_true, t) + rng.normal(0, 0.05, t.size)   # 实验 A 数据（仅用于推进随机状态）
y = model(theta_true, t) + rng.normal(0, 2.0, t.size)      # 实验 B 数据（大噪声）

def rfun(th): return y - model(th, t)
def jfun(th):
    J = np.empty((t.size, 2))
    J[:,0] = -np.exp(-th[1]*t); J[:,1] = th[0]*t*np.exp(-th[1]*t)
    return J

th, lam = np.array([1.0, 1.0]), 1e-2
for k in range(50):
    r, J = rfun(th), jfun(th)
    if np.linalg.norm(J.T@r) < 1e-10: break
    for _ in range(40):                       # λ 内循环：调到 ρ 可接受为止
        d = np.linalg.solve(J.T@J + lam*np.eye(2), -J.T@r)
        rn = rfun(th + d)
        pred = -(J.T@r)@d - 0.5*d@(J.T@J)@d   # 模型预测下降
        if pred <= 0: lam = min(lam*5, 1e8); continue
        rho = ((r@r - rn@rn) / pred)
        if rho > 0.75: lam = max(lam/3, 1e-10); th = th + d; break
        elif rho < 0.25: lam = min(lam*3, 1e8)
        else: th = th + d; break
print(f"LM 恢复参数 θ = {th.round(4)}（真值 (3,1.5)；噪声极限下只能到 {np.linalg.norm(th-theta_true):.3f}）")
```

**实验设计（读图的三个层次）**：

1. **实验 A（小噪声 $\sigma=0.05$）**：GN 与 LM 都 8-9 步到达噪声极限 $8.9\times10^{-3}$——小残差下 GN 足够好，LM 不比它差；
2. **实验 B（大噪声 $\sigma=2.0$）**：GN 参数范数爆到 $\sim116$（**发散**），LM 稳健收敛到 $\|\theta-\theta^*\|\approx1.45$（噪声极限）——**同一数据，GN 死、LM 活**；
3. **$\lambda$ 演化图**：大噪声下 $\lambda$ 在 $10^{-2}\sim10^0$ 之间频繁换挡——**每当 $\rho$ 报警就升挡缩步，转好就降挡提速**，这是 LM 的"心电图"。

> **实验结论（本章收官）**：参数辨识的正确姿势——先看数据噪声量级（决定期望精度 = 噪声极限），再用 LM（自动在 GN 与梯度下降间换挡）跑收敛，最后用 $\|J^T r\|$ 与 $\|r\|$ 双重停机。**理论（9.4.1）→ 手算（9.4.2）→ 代码（本节）→ 误差可视化（图）→ 工程限制（噪声极限）五环闭环。**

#### 7. 易错坑点

1. **$\lambda$ 的上下限必须有**：$\lambda\to0$ 时接近 GN，$J^TJ$ 病态会爆；$\lambda\to\infty$ 时退化为龟速。实践取 $\lambda\in[10^{-10},10^8]$ 并加保护。
2. **$\rho$ 的分母要检查**：`pred` 可能 $\le0$（模型预测上升，数值错误）——先判 `pred>0` 且有限，否则直接加阻尼重解（代码里的 `continue` 分支）。
3. **拒绝步不更新 $\theta$**：$\rho<0.25$ 时**保持 $\theta$ 不动**、只增大 $\lambda$ 重解——别把坏步加进去。
4. **停止准则用 $\|J^Tr\|$（梯度范数）**：它是"参数空间梯度"，比 $\|r\|$（残差范数）更直接；$\|r\|$ 小可能是噪声极限而非参数好。
5. **$\lambda_0$ 的初值**：常用 $10^{-2}\sim1$；太小一开始就吃 GN 的亏，太大起步太慢。**与参数尺度有关**——可先跑一步看 $\rho$ 再调。
6. **噪声极限 ≠ 收敛失败**：$\|\theta-\theta^*\|$ 停在不为零的常数是数据决定的（实验 A/B 的 8.9e-3、1.45），**不是算法 bug**。读结果时先估算"这个噪声下能恢复多准"。

#### 8. 对比辨析：全章优化算法一张总表

| 算法 | 方向 | 二阶信息 | 步长 | 可靠性 | 每步成本 | 章节 |
|---|---|---|---|---|---|---|
| 最速下降 | $-g$ | 无 | 线搜索 | 稳但慢 | $O(n)$ | 9.2.2 |
| 阻尼 Newton | $-H^{-1}g$ | $H$（完整） | 回溯/Wolfe | 需 $H$ 正定/修正 | $O(n^3)$ | 9.3.2 |
| BFGS | $-B_k^{-1}g$ | $B_k$（近似） | Wolfe | 强（正定保持） | $O(n^2)$ | 9.3.3 |
| Gauss-Newton | $-(J^TJ)^{-1}J^Tr$ | $J^TJ$（近似） | 无 | 残差小才行 | $O(mn)$ | 9.4.2 |
| **LM** | $-(J^TJ+\lambda I)^{-1}J^Tr$ | $J^TJ+\lambda I$ | $\rho$ 驱动 $\lambda$ | **最强（自动换挡）** | $O(mn)$ | 9.4.3 |

> **辨析要点**：LM 的 $\lambda$ 是"正则化 + 步长 + 信赖域半径"三位一体——它同时完成 Hessian 修正（9.3.2 的 $\mu$）、步长控制（9.2.3 的线搜索/信赖域）与方向插值（GN ↔ 最速下降）。**学完整章再看 LM，会发现它是所有前序思想的最终汇合点。**

#### 9. 伪证辨析栏 ⭐

**伪证 1（看似对其实错）**：*"$\lambda$ 越大越安全，所以设个大 $\lambda$ 最保险。"*

- **反例**：$\lambda=10^6$ 时 $(J^TJ+\lambda I)^{-1}J^Tr\approx\frac1\lambda J^Tr$——LM 变成步长 $10^{-6}$ 的最速下降，收敛慢到天荒地老。**"安全"的代价是"永远到不了"。**
- **正确命题**：$\lambda$ 要**动态**调：准（$\rho$ 高）就降挡提速，不准（$\rho$ 低）才升挡缩步。

**伪证 2（看似能推其实缺条件）**：*"$\rho_k>0.75$ 说明这一步接近最优。"*

- **缺的条件**：$\rho$ 只度量"模型 $m(\Delta)$ 与实际下降的一致性"，**不度量"这一步走了多远/多对"**。$\rho\approx1$ 只能说"线性化模型可信"，可能这一步本来就很短。
- **正确命题**：$\rho$ 是**模型健康度**指标，用于调 $\lambda$（信赖域半径）；步长质量另看 $\|\Delta\|$ 与梯度。

**伪证 3（看似相等其实不等）**：*"LM 解出的 $\theta$ 就是全局最优参数。"*

- **不等在哪**：LM 是**局部**方法（同 Newton 族）——收敛到 $\theta_0$ 所在吸引域里的局部极小。非凸拟合（如多峰模型）需要多起点/全局策略。
- **正确命题**：LM 收敛到"初值附近的驻点"；参数辨识前先用粗网格/多次随机初值扫描，确认全局性。

**伪证 4（看似能推其实缺条件）**：*"GN 发散时把 $\lambda$ 调大就一定收敛。"*

- **缺的条件**：$\lambda$ 大 → 步小 → 接近梯度下降，但**梯度下降本身也可能在噪声极限附近徘徊**（$\|g\|$ 不为零的数值停滞）。$\lambda$ 不是万能药，还要配停止准则（$\|J^Tr\|$、$\|\Delta\|$）与初值质量。

#### 10. 深度透析（考研 / 科研拔高）

**(a) $\lambda$ 与信赖域半径的严格对偶**：LM 步 $\Delta(\lambda)$ 满足 $\|\Delta(\lambda)\|\to0\ (\lambda\to\infty)$、$\|\Delta(0)\|$ 最大，且 $\|\Delta(\lambda)\|$ 严格递减。因此对任意 $\Delta>0$ 存在唯一 $\lambda$ 使 $\|\Delta(\lambda)\|=\Delta$——**LM 是"恰好落在半径为 $\Delta$ 的信赖域边界上的解"**。这解释了为什么 LM 能继承信赖域的全局收敛理论（9.2.3 的 $\rho$ 判据 + Cauchy 点保底）。

**(b) Marquardt 与 Nielsen 策略**：原始 Marquardt 用 $\lambda$ 的乘性因子（$\lambda/10$ 或 $\lambda\times10$）；Nielsen 改进为 $\lambda\leftarrow\lambda\cdot\max(\frac13,1-(2\rho-1)^3)$——**更平滑的换挡**，避免 $\rho$ 在阈值附近抖动引起 $\lambda$ 振荡。实现细节影响收敛速度，但思想不变：$\rho$ 驱动。

**(c) 与阻尼 Newton 的统一**：把 LM 的 $J^TJ$ 换成任意 Hessian 近似 $B$，得到阻尼 Newton 的通用形式 $(B+\mu I)\Delta=-g$（9.3.2）。**LM 是"带最小二乘结构的阻尼 Newton"**；反过来，阻尼 Newton 是"没有结构信息的 LM"。两者共享同一套 $\rho$ 自适应——**这就是为什么全章算法能在一张总表里收尾**。

**(d) 现代工程实现**：SciPy `scipy.optimize.least_squares(method='lm')`、MATLAB `lsqnonlin`、ceres-solver（SLAM/机器人）都实现了 LM 变体。读源码时找三个关键词：**$\lambda$ 更新策略、$\rho$ 判据、$\|J^Tr\|$ 停机**——理解本节，任何 LM 源码都是"换皮"。

```
② 优化（9.2-9.3）   min f  ⇔  求 ∇f(x)=0 的根（梯度方程）
                   → 最优性条件（梯度=0 + H 正定）
                   → 方向与步长分工（负梯度 / Armijo·Wolfe·信赖域）
                   → 曲率：Newton（H）/ 拟 Newton（B≈H 由割线条件增量更新）
③ 最小二乘（9.4）   min ‖r(θ)‖²，Hessian = J^TJ + S
                   → GN：丢 S（残差小时对）
                   → LM：丢不掉就用 λ 兜底（信赖域 + Hessian 修正 + 步长控制）
```

### 9.6.2 十二小节"一句话本质"总表（本教材创新点 4）

| 节 | 一句话本质 |
|---|---|
| 9.1.1 | 二分法只问符号不问导数：每步区间减半、误差减半，用绝对可靠换 1 bit/步。 |
| 9.1.2 | 不动点迭代的判决书只有两行：压缩条件（$|g'|<1$）管"会不会收敛"，导数消失阶数管"收敛几阶"。 |
| 9.1.3 | Newton 每点线性化（切线/Jacobian），残差误差平方（二阶），快得离谱但初值必须近。 |
| 9.2.1 | 梯度为零是嫌疑名单，Hessian 正定才是盖章——必要条件筛人，充分条件认人。 |
| 9.2.2 | 方向管性质、步长管幅度；"最速下降"是瞬间最优的骗局，条件数大的山谷里它之字形爬行。 |
| 9.2.3 | Armijo 防"白走"、Wolfe 防"抠门"、信赖域先画圈再行动——步长策略是全局收敛的安全阀。 |
| 9.3.1 | 优化 Newton 就是对梯度方程求根（$f\leftrightarrow g$，$f'\leftrightarrow H$），唯一新要求是方向必下降。 |
| 9.3.2 | 阻尼刹步长、$H+\mu I$ 扳方向，两帖药合起来让 Newton"局部二阶 + 全局可执行"。 |
| 9.3.3 | BFGS 用走过的 $(s,y)$ 增量拼曲率：对称 + 割线 + 最小变化三条要求锁定唯一公式。 |
| 9.4.1 | 拟合 = 最小化残差平方和；梯度 $J^Tr$、Hessian $J^TJ+S$——$J^TJ$ 是廉价二阶信息。 |
| 9.4.2 | GN 扔掉 $S$ 用 $J^TJ$ 冒充 Hessian：残差小才合理，残差大必翻车。 |
| 9.4.3 | LM 用 $\lambda$ 在 GN 与梯度下降之间自动换挡，$\rho$ 是换挡依据——全章思想的汇合点。 |

### 9.6.3 贯穿全章的三条暗线

1. **线性化-重复**：求根（切线）→ 优化（二次模型）→ 最小二乘（局部正规方程）——同一个元方法；
2. **信息-速度-可靠性三角**：二分（最少信息、最可靠、最慢）→ Newton（最多信息、最快、最脆）→ BFGS/LM（中等信息、强可靠、快）——**没有免费午餐，只有合适的代价**；
3. **修正-阻尼-正则化是同一个动作**：$H+\mu I$、$\lambda I$、信赖域 $\Delta$、$L_2$ 正则都是"给坏条件加保护"，只是名字不同。

## 9.7 综合自测（考研 / 科研向，带答案）

**题 1（概念辨析）**：说明"$f(a)f(b)<0$ 保证至少一个根"与"$|g'(x^*)|<1$ 保证迭代收敛"两句话各自**缺什么条件**才变成完整命题。

（答案：第一句缺"唯一性"——完整版需加单调性；第二句缺"初值在收敛邻域内"与"压缩条件一致成立"——完整版见定理 9.2/9.3。）

**题 2（收敛阶判定）**：某迭代序列误差 $e_k$ 满足 $|e_{k+1}|\le C|e_k|^{1.7}$。它是几阶收敛？若实测 $\frac{|e_{k+1}|}{|e_k|^{1.7}}$ 不趋于常数而 $\frac{|e_{k+1}|}{|e_k|}\to0.2$，结论如何？

（答案：定义中的"阶"是**极限意义**：$\lim|e_{k+1}|/|e_k|^p=C>0$。前者只是说明存在 $C$ 使不等式成立，不能断言 1.7 阶；实测线性（比率 0.2）说明主导项是一阶——**不等式的指数 ≠ 收敛阶**，收敛阶由极限决定。）

**题 3（Newton 与不动点）**：证明 $g(x)=x-\frac{f(x)}{f'(x)}$ 满足 $g'(x^*)=0$ 当且仅当 $f(x^*)=0$（且 $f'(x^*)\ne0$），并解释为何这立即推出 Newton 二阶收敛。

（答案：$g'(x)=\frac{f(x)f''(x)}{f'(x)^2}$，在根处 $f(x^*)=0$ 故 $g'(x^*)=0$；由定理 9.4（$p=2$），$g$ 的导数在不动点处消失一阶 ⇒ 二阶收敛。**Newton = 精心构造 $g$ 使 $g'(x^*)=0$ 的不动点迭代**。）

**题 4（最速下降）**：$A=\text{diag}(1,100)$，$f=\frac12x^TAx$。最速下降（精确线搜索）的渐进收敛比率是多少？从 $x_0=(1,1)$ 出发前两步的几何特征是什么？

（答案：$\frac{\kappa-1}{\kappa+1}=\frac{99}{101}\approx0.98$——每步几乎不缩；前两步沿 $(1,100)$ 方向大跳、再折返，相邻梯度正交，形成拉长的之字形。**这是"最速下降"名不副实的最直观案例**。）

**题 5（Wolfe 与 Zoutendijk）**：简述为什么"Armijo 单独使用"不足以证明全局收敛，Wolfe 曲率条件补上了什么。

（答案：Armijo 允许 $\alpha\to0$，步长序列可能坍缩，$\sum\|g_k\|^2$ 无从控制；曲率条件给出步长下界（定理 9.14 证明第 1-2 步：$\|s_k\|\ge\frac{(1-c_2)\delta}{L}\|g_k\|$），把"每步下降量"与"梯度范数"绑定，才能推出 $\sum\|g_k\|^2<\infty$。）

**题 6（BFGS 正定性）**：$B_k$ 正定、$y^Ts>0$。证明 $B_{k+1}$ 正定，并说明曲率条件为何是 Wolfe 线搜索的必然结果。

（答案：拆 $z^TB_{k+1}z=(I)+(II)$，$(I)\ge0$（Cauchy-Schwarz）、$(II)\ge0$；$z^Ty\ne0$ 时 $(II)>0$，$z^Ty=0$ 时 $z$ 不与 $s$ 平行故 $(I)>0$。曲率条件 $\nabla f_{k+1}^Td_k\ge c_2\nabla f_k^Td_k$ 移项即得 $y^Ts>0$。见定理 9.18/9.19。）

**题 7（GN 与 LM）**：写出 $\nabla^2f$、$J^TJ$、$S$ 的关系，说明：① 零残差时 GN 为何二阶；② 大残差时 LM 为何比 GN 稳。

（答案：$\nabla^2f=J^TJ+\sum r_i\nabla^2r_i$。① 零残差 $\|r^*\|=0$ ⇒ $S\approx0$，GN≈Newton（定理 9.20 第一括号）；② 大残差 $S$ 不可忽略，GN 方向错 + 大步；LM 的 $\lambda$ 既保证 $J^TJ+\lambda I$ 正定（方向可解必下降）、又缩短步长（$\|\Delta(\lambda)\|$ 随 $\lambda$ 递减），$\rho$ 自动调节——**换挡机制吸收了 $S$ 造成的模型失准**。）

**题 8（综合设计）**：数据 $(t_i,y_i)$ 来自 $y=\theta_1e^{-\theta_2t}$，噪声 $\sigma=0.5$。设计完整参数辨识流程（方法选择、初值策略、停止准则、结果评判标准）。

（答案要点：① 方法选 LM（$\lambda_0=10^{-2}$，$\rho$ 判据，$\lambda\in[10^{-10},10^8]$）；② 初值多起点（如 $\theta_1\in[0.5,5]$、$\theta_2\in[0.1,3]$ 网格扫描，取 $\|r\|$ 最小的起点）；③ 停止：$\|J^Tr\|<\varepsilon$ 且 $\|\Delta\|$ 小，或达到 $\lambda$ 上限仍无进展；④ 评判：先估噪声极限 $\sim\sigma\|(J^TJ)^{-1}J^T\|$ 量级，把最终 $\|\theta-\theta^*\|$ 与之对比——落在噪声极限附近即"该数据下已尽力"，远大于才怀疑算法/模型问题。）
