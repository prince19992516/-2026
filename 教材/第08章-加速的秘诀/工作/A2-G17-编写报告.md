## 实验与习题证据
- **环境**：Python 3.12.10（课程虚拟环境），numpy / matplotlib / scipy；CPU；随机种子 2026。
- **运行方式**：`jupyter nbconvert --to notebook --execute --inplace A2-G17-实验.ipynb`（全量执行，输出与图已嵌入）。
- **结果与参考值**：
  - 8.1：30 个未见测试矩阵均值（tol=1e-8）：无预条件 118.7 / Jacobi 58.9 / 学习 deflation r=16 32.6 / oracle 33.9 次迭代；matvec 数降 41%；单次墙钟约 6.3–9.0ms → 4.2–5.9ms（min-of-3 基准，随负载波动）；训练成本单次测量 0.97–38.8s（负载敏感），盈亏平衡 $`N^*\approx 5\times10^2`$–$`1.3\times10^4`$ 次。
  - 8.2：POD r=2 训练/测试误差 ~1e-15；自编码器训练 3e-2、未见测试 0.5。
  - 8.3：一步 RMSE——AR(3) 3e-15 / 线性场 4e-4 / MLP 1.8e-2 / 持久性 5e-2；自由滚动——AR(3) 3e-12 / 线性场 8.6e-3 / MLP 0.31 / 持久性 1.31；泄漏低估约 17 倍。
  - 8.4：开环最大误差 2.04；闭环最大 0.237、最终 0.184。
- **容差依据**：确定性指标（迭代数、RMSE、重构误差）由种子固定、可复跑；墙钟时间按区间如实报告（负载敏感）。
- **尚未核验项**：参考资料部分条目未逐条对照原文（已标"未核验"）；全部内容由 AI 辅助生成、尚未经人工逐项核验（待 B/C 与本组人工复核）。
