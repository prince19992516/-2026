# 第08章-加速的秘诀：模板与协作入口

主题：**学习型预条件子与降阶模型**。核心概念：**学习型预条件子、自编码器降阶、时间预测**。

**先复制，再填写。** 文件名最前面的“模板”表示留给所有小组重复使用的原件。按[模板命名与复制步骤](../../教程/02-Notebook教材写作.md#模板复制与命名)从本章 `模板/` 复制到 `工作/`，再改成本组文件，例如 `A1-G4-正文.md`、`B2组-验证报告.md`。不直接把模板改成作业，也不覆盖另一组副本。

## 文件放在哪里

```text
本章/
├── README.md              ← 章节说明、分组与模板入口
├── 模板/                  ← 供各组复制的原件
│   ├── 模板-A组-正文.md
│   ├── 模板-A组-实验.ipynb
│   ├── ……其余A/B/C模板
│   └── 图片/              ← 模板配套导入图或绘制说明
└── 工作/                  ← 本组副本与最终整合稿放这里
    ├── .gitkeep           ← 空目录占位，无需打开或填写
    └── 图片/              ← 本章工作稿使用的图片
        └── .gitkeep
```

进入[模板](模板/)选取本组角色的文件，**复制到[工作](工作/)后再改名和填写**；例如 `工作/A1-G4-正文.md`、`工作/B2组-验证报告.md`。已有本组文件时继续编辑它，不重复复制覆盖。当前已收录的正文见本页“当前正文稿”，已有本组稿请继续编辑，不要用模板覆盖。`.gitkeep` 是让GitHub保留空文件夹用的，不是作业，也不是程序；只在空目录保留，非空目录的占位应删除。
