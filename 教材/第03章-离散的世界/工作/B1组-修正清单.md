```python
N=5; r=0.4
x=np.linspace(0,1,N+1)
A,b=assemble_1d(N,r,('neumann',1.0),('dirichlet',1.0))
print(A@x[1:-1]-(x[1:-1]+b))
# [-0.16, 0, 约1.11e-16, 0]
```
