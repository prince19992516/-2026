## 为什么需要这份文件

3.1 由三人分段写成（§1–§2 初值问题与 Euler、§3 经典 RK4、§4 数值实验），再合并成一节。
分段写作时最容易走样的是三处：步长用什么字母、误差用哪个下标、试探点与常数是否撞名。
本文件把记号固定下来。**凡与此表冲突的写法，以本表为准**；正文中尚存的冲突列在"同名不同义"一节，并给出待执行的改法。

## 硬规则

1. **3.1 节内时间步长一律记 $h$，不出现以 $k$ 表示步长的写法。** 本节的 $k$ 只有一种用法：Runge–Kutta 的各级斜率 $k_i$（$i=1,2,3,4$）。
2. **同一节内一个符号只表示一件事。** 若不得不用同一个字母承担两个角色，必须在首次出现处加限定词，并登记到"同名不同义"表。
3. 下标约定：$n$ 表示时间节点、$i$ 表示级（Runge–Kutta 的级或求和指标）、$j$ 表示求和的次级指标、$m$ 表示迭代次数。

## 自变量、节点与步长

| 符号       | 含义                                                                | 首次出现 |
| -------- | ----------------------------------------------------------------- | ---- |
| $t$      | 自变量（时间），连续                                                        | §1.1 |
| $t_0$    | 初始时刻                                                              | §1.1 |
| $T$      | 终端时刻，$t\in[t_0,T]$                                                | §2.1 |
| $t_n$    | 第 $n$ 个时间节点，$t_n=t_0+nh$                                          | §2.1 |
| $h$      | **时间步长**，$h=(T-t_0)/M$                                            | §2.1 |
| $M$      | 区间等分数（总步数），$M=O(h^{-1})$；$n=0,1,\dots,M-1$                        | §2.1 |
| $n$      | 时间节点指标                                                            | §2.1 |
| $I$      | 解的定义区间；定理 1 中取 $I=[t_0-\delta,\ t_0+\delta]$                      | §1.1 |
| $\delta$ | 定理 1 保证的存在区间半长，$\delta=\min\{a,\ b/M\}$                           | §1.3 |
| $a,\ b$  | 矩形 $R$ 的半宽与半高：$\lvert t-t_0\rvert\le a$，$\lvert y-y_0\rvert\le b$ | §1.3 |

## 解、近似与迭代

| 符号               | 含义                                                          |
| ---------------- | ----------------------------------------------------------- |
| $y(t)$           | 初值问题的精确解（经典解）                                               |
| $y_0$            | 初值，$y(t_0)=y_0$                                             |
| $y_n$            | 数值近似，$y_n\approx y(t_n)$                                    |
| $y^{(m)}$        | Picard 迭代序列的第 $m$ 次近似，$m=0,1,2,\dots$                       |
| $\tilde y_{n+1}$ | Heun 格式的预测值，$\tilde y_{n+1}=y_n+hf(t_n,y_n)$                |
| $u,\ v$          | Lipschitz 条件中的两个函数值（哑元）；定理 1 的唯一性证明中另记 $u=\lvert y-z\rvert$ |
| $z$              | 唯一性证明与定理 2 中与 $y$ 比较的另一个解（对应初值 $z_0$）                       |

## 右端函数与导数

| 符号                         | 含义                                                     |
| -------------------------- | ------------------------------------------------------ |
| $f(t,y)$                   | 右端函数；初值问题 $y'=f(t,y)$                                  |
| $D$                        | $f$ 的定义域（开区域）                                          |
| $F$                        | $t_n$ 处的斜率，$F=f(t_n,y_n)$（Taylor 展开用）                  |
| $f_t,\ f_y$                | $f$ 对 $t$、对 $y$ 的一阶偏导                                  |
| $f_{tt},\ f_{ty},\ f_{yy}$ | 二阶偏导                                                   |
| $L$                        | Lipschitz 常数                                           |
| $K$                        | 整体延拓的增长常数，$\lvert f(t,y)\rvert\le K(1+\lvert y\rvert)$ |
| $\xi,\ \xi_n$              | 中值定理中的中间点（$\xi\in(0,1)$ 或 $\xi_n\in(t_n,t_{n+1})$）     |
| $g(s)$                     | 命题 1 证明中的辅助函数 $g(s)=f(t,v+s(u-v))$                     |

## 格式与系数

| 符号                | 含义                                                  |
| ----------------- | --------------------------------------------------- |
| $\Phi(t,y,h)$     | 单步法的增量函数，$y_{n+1}=y_n+h\Phi$                        |
| $s$               | Runge–Kutta 的级数（经典 RK4 取 $s=4$）；积分与求导中的哑变量也记 $s$    |
| $k_i$             | Runge–Kutta 第 $i$ 级斜率；经典 RK4 为 $k_1,k_2,k_3,k_4$    |
| $c_i$             | 节点系数（第 $i$ 级取样时刻 $t_n+c_ih$）                        |
| $a_{ij}$          | 级间耦合系数（第 $i$ 级借用第 $j$ 级的斜率）                         |
| $j$               | 求和的次级指标（$\sum_{j<i}$、$\sum_{i>j}$）                  |
| $b_i$             | 组合权重；经典 RK4 为 $\tfrac16,\tfrac13,\tfrac13,\tfrac16$ |
| $M_1,\ M_2,\ E_1$ | §3.3 算例中的三个试探点：试探中点、修正中点、终点试探点                      |
| $\bar k$          | 一步的加权平均斜率，$\bar k=\frac16(k_1+2k_2+2k_3+k_4)$       |

## 误差与阶

| 符号                  | 含义                                                             |
| ------------------- | -------------------------------------------------------------- |
| $\tau,\ \tau_{n+1}$ | **局部截断误差**（LTE）：单步推进引入的误差                                      |
| $E_n$               | **全局误差**，$E_n=y(t_n)-y_n$                                      |
| $M_2$               | $\max\lvert y''\rvert$（§4.1 式 (16) 中的误差界常数）                    |
| $p$                 | 理论收敛阶（Euler 为 $1$，经典 RK4 为 $4$）                                |
| $p_{\mathrm{obs}}$  | 观测收敛阶，$p_{\mathrm{obs}}=\log_2\dfrac{E(h)}{E(h/2)}$            |
| $C$                 | 误差常数，$E(h)\approx Ch^{p}$                                      |
| $\mathrm{e}$        | 自然对数的底（如 $\mathrm{e}^{-t}$、$\mathrm{e}^{L\lvert t-t_0\rvert}$） |
| $O(h^{p})$          | 阶记号（$h\to0$）                                                   |

## 稳定性

| 符号                         | 含义                                                        |
| -------------------------- | --------------------------------------------------------- |
| $\lambda$                  | 线性测试方程 $y'=\lambda y$ 的系数，$\lambda\in\mathbb{C}$          |
| $\operatorname{Re}\lambda$ | $\lambda$ 的实部                                             |
| $z$                        | $z=h\lambda$（稳定性的无量纲参数，与上文"另一个解 $z$"不是同一对象）               |
| $R(z)$                     | 放大因子（稳定函数）；$y_{n+1}=R(z)y_n$，稳定条件 $\lvert R(z)\rvert\le1$ |

> 绝对稳定区域在正文中只以文字出现（"满足 $\lvert R(z)\rvert\le1$ 的 $z$ 的集合"），**未给专用符号**；本表不擅自加记号。
