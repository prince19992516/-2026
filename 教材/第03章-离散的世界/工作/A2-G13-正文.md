# 第03章 离散的世界

## 3.1 ODE初值问题：Euler与RK4（2学时）

**本节目标：** 能实现单步推进并通过步长加密比较精度。

### 概念讲解

设某一理想化系统的状态随着时间逐渐衰减。已知初始状态以及描述变化快慢的微分方程，怎样计算半个时间单位之后的状态？最直观的方法，是根据当前的变化率预测下一时刻的数值。然而，变化率本身可能随状态改变，单凭一个时刻的斜率未必能够准确描述整个时间步内的变化。

由此产生了一条自然的求解思路：**先用初值条件确定问题，再把连续时间划分为离散节点；接着用Euler方法近似一步内的变化，进一步用Runge–Kutta方法提高积分精度；最后通过误差与稳定性判断计算结果是否可靠。** 本节便按照这一顺序展开。

#### 1. 初值问题：由初始状态确定演化轨迹

一阶常微分方程的**初值问题**（initial value problem，IVP）一般写为

**公式（3.1.1）**

```math
\left\{\begin{aligned}
y'(t)=f(t,y(t)), & t\in[t_0,T],\\
y(t_0)=y_0.
\end{aligned}\right.
```

其中，$t$为自变量（在演化问题中通常表示时间），$y(t)$为待求状态，$f(t,y)$为给定的右端函数；$t_0$与$y_0$分别表示初始时刻和初始值，$T$为终止时刻。由$y'(t)=f(t,y(t))$可知，右端函数描述的是状态在时刻$t$的瞬时变化率。

初值条件并非附加在求解之后的修正，而是确定具体演化轨迹的必要信息。对于给定的$f$，不同的初始值通常对应不同的解。若$f$在所考虑区域连续且对$y$满足适当的局部Lipschitz条件，可得到局部解存在唯一性的结论；要保证解在整个$[t_0,T]$上存在，还需相应的延拓条件。

即使方程的解存在且唯一，也不意味着总能把它写成便于计算的解析表达式。数值方法因此转向一个更可操作的目标：**不直接求出整条曲线，而是逐个求出曲线在指定时刻的近似值。**

#### 2. 时间离散：把求函数变成逐步求数值

为了数值求解，将区间$[t_0,T]$划分为$N$个时间步。若采用均匀网格，则

**公式（3.1.2）**

```math
t_n=t_0+nh,\qquad h=\frac{T-t_0}{N}>0,
\qquad n=0,1,\ldots,N.
```

记$y_n$为精确解$y(t_n)$的数值近似，并以初值$y_0$开始计算。所谓**单步方法**，就是利用当前的数值状态及本步内必要的函数评估，构造下一节点的近似值$y_{n+1}$。

需要区分：$y(t_n)$是微分方程真实解在节点处的取值，而$y_n$是计算获得的近似值。随着时间步不断推进，两者之间可能产生并积累误差。步长$h$的选取会同时影响计算精度、稳定性和计算量。

现在的问题就具体化为：**已知$t_n$和$y_n$，怎样得到$y_{n+1}$？** Euler方法从最简单的斜率近似出发，给出了两种具有代表性的回答。

#### 3. 向前Euler：利用当前斜率预测下一步

最直接的思想是：假设一个时间步内的变化率近似等于起点处的变化率。由此得到**向前Euler方法**（forward Euler），也称显式Euler方法：

**公式（3.1.3）**

```math
\left\{
\begin{aligned}
t_{n+1}&=t_n+h,\\
y_{n+1}&=y_n+h f(t_n,y_n).
\end{aligned}
\right.
```

它相当于从当前点$(t_n,y_n)$出发，沿斜率为$f(t_n,y_n)$的切线前进一个步长。由于右端只含已经知道的$t_n$和$y_n$，无需额外求解方程，故称为**显式方法**。

向前Euler每步通常只需一次右端函数求值，计算简单；但它用起点斜率近似整个时间步内的变化率，当斜率变化明显或步长较大时，误差可能显著增加。

如果认为终点处的变化率比起点斜率更能反映该步结束时的状态，便得到另一种Euler方法。不过，此时终点状态尚未求得，计算形式也随之发生变化。

#### 4. 向后Euler：利用下一时刻的斜率

另一种选择是在一个时间步内采用终点处的变化率，得到**向后Euler方法**（backward Euler），也称隐式Euler方法：

**公式（3.1.4）**

```math
\left\{
\begin{aligned}
t_{n+1}&=t_n+h,\\
y_{n+1}&=y_n+h f(t_{n+1},y_{n+1}).
\end{aligned}
\right.
```

与向前Euler不同，右端出现了尚未求得的$y_{n+1}$，因此不能一般地直接代入计算。每一步需要求解关于$y_{n+1}$的代数方程；对非线性方程，可采用Newton迭代等方法。

两种Euler方法都具有一阶全局精度，但它们的稳定性并不相同。向后Euler通常适合处理具有较快衰减模态的问题，不过每步求解代数方程也会增加计算成本。因此，**隐式并不意味着阶数更高，也不意味着对所有问题都更准确或更省时**。

从这里可以看出，向前和向后Euler虽选用了不同位置的斜率，却都只依赖一步中的一次斜率近似。**若希望进一步提高精度，就需要在同一个时间步内获取更多关于斜率变化的信息。** 这正是Runge–Kutta方法的出发点。

#### 5. 从一阶到四阶：Runge–Kutta方法的思想

向前Euler只使用一个阶段的斜率，也可视为最简单的一阶Runge–Kutta方法。如果在一个时间步中计算多个适当位置的斜率，并按一定权重组合，便可能获得更高的精度。

例如，一种典型的**二阶Runge–Kutta方法**先用起点斜率预测终点，再将起点与预测终点的斜率取平均：

**公式（3.1.5）**

```math
\left\{
\begin{aligned}
k_1&=f(t_n,y_n),\\
k_2&=f(t_n+h,y_n+hk_1),\\
y_{n+1}&=y_n+\frac h2(k_1+k_2).
\end{aligned}
\right.
```

这一公式仅用于说明从一阶到高阶的思路，本节不将其列为单独的主要方法。进一步地，**经典四阶Runge–Kutta方法**（RK4）在一个时间步内计算四个阶段斜率，再作加权组合；在通常的光滑性与收敛条件下，可达到四阶全局精度。

需要注意，方法的阶数并非仅由斜率计算次数决定。阶段取值位置、预测状态和组合权重必须共同满足相应的精度条件。

不过，采用更多阶段得到的高阶公式，并不能单凭“阶数更高”就判断其在所有情形下更可靠。为了比较不同方法，还必须明确**误差是如何度量的，以及数值误差会怎样随时间步传播**。

#### 6. 三个容易混淆的概念：局部误差、全局误差与稳定性

**局部截断误差**描述从精确起点出发，按数值公式推进一步后与精确解的差值；**全局误差**描述实际逐步推进至$t_n$后，数值解$y_n$与精确值$y(t_n)$的差值。本节采用局部差值不除以步长$h$的约定。

在解足够光滑、误差传播可控等通常条件下，向前Euler与向后Euler的一步局部差值均为$O(h^2)$、固定有限区间的全局误差均为$O(h)$；经典RK4相应为$O(h^5)$和$O(h^4)$。这说明局部误差阶与全局误差阶不能混为一谈。

**稳定性**则考察数值方法对扰动或衰减模态的传播特性。对于线性测试方程$y'=\lambda y$，若一步更新写为$y_{n+1}=R(h\lambda)y_n$，那么当$\mathrm{Re}(\lambda)<0$时，$|R(h\lambda)|<1$是该模态数值解严格衰减的条件。高阶方法未必具有更大的稳定区域；反过来，数值稳定也不能直接保证计算结果已足够准确。

因此，比较向前Euler、向后Euler和RK4时，至少应同时考察**全局精度、稳定性条件与每步计算开销**。为了使这些概念具体化，下面选取一个既有明确物理直观、又能求得精确解的衰减模型。

#### 7. 一个具有解析解的例子：无量纲衰减

考虑一个理想化的一阶衰减过程，设$y(t)$表示归一化后的状态量，变化率与当前状态成正比、方向相反：

**公式（3.1.6）**

```math
\left\{\begin{aligned}
y'(t)=-y(t),\\
y(0)=1.
\end{aligned}\right.
```

这个方程的解析解为$y(t)=e^{-t}$。因此，状态随时间连续衰减，且任意时刻的精确值都可以计算。它既可用于解释Euler方法“用斜率推进”的含义，也便于比较不同数值方法的误差。

例如，取步长$h=0.5$，向前Euler根据初始斜率$y'(0)=-1$预测下一步；向后Euler则使用下一时刻的未知斜率。两者得到的结果并不相同。下面将从积分关系出发推导公式，并与解析解及RK4的单步结果进行核对。

### 关键推导

推导任务：手写Euler推导与RK4四个阶段，对有解析解的线性ODE手算一步。

下面从初值问题的积分表达式出发，依次推导向前Euler、向后Euler与经典RK4的计算公式，并利用上一部分的线性衰减模型检验一次单步计算。所讨论的误差阶数均以精确解具有足够光滑性、数值计算在固定有限区间内且误差传播可控为前提。

#### 1. 从积分关系推导向前Euler

**已知条件：** 设$y'(t)=f(t,y(t))$，并已知时刻$t_n$的状态$y(t_n)$。根据微积分基本定理，

**公式（3.1.7）**

```math
y(t_{n+1})=y(t_n)+
\int_{t_n}^{t_{n+1}}f(t,y(t))\,\mathrm{d}t,
\qquad t_{n+1}=t_n+h.
```

若用被积函数在左端点的值近似整个时间步内的变化率，则

**公式（3.1.8）**

```math
\int_{t_n}^{t_{n+1}}f(t,y(t))\,\mathrm{d}t
\approx h f(t_n,y(t_n)).
```

用数值近似$y_n$代替$y(t_n)$，得到

**公式（3.1.9）**

```math
y_{n+1}=y_n+h f(t_n,y_n).
```

这就是向前Euler更新公式。其推导也可以从Taylor展开理解：若精确解具有连续的二阶导数，则存在$\xi_n\in(t_n,t_n+h)$，使

**公式（3.1.10）**

```math
y(t_n+h)
=y(t_n)+h y'(t_n)+\frac{h^2}{2}y''(\xi_n).
```

利用$y'(t_n)=f(t_n,y(t_n))$，可知从**精确起点**使用向前Euler推进一步时，舍去项为$O(h^2)$。在适当的误差传播条件下，固定有限区间内累计的全局误差通常为$O(h)$，因此向前Euler是一阶方法。

上述推导依赖精确解的光滑性。若问题缺少所需的正则性，或步长过大导致误差传播不受控制，便不能直接套用这一全局误差结论。

#### 2. 从右端点求积推导向后Euler

仍从精确积分关系出发。如果采用右端点的变化率近似积分，则

**公式（3.1.11）**

```math
\int_{t_n}^{t_{n+1}}f(t,y(t))\,\mathrm{d}t
\approx h f(t_{n+1},y(t_{n+1})).
```

以$y_n$和$y_{n+1}$分别替换精确起点与终点值，得到

**公式（3.1.12）**

```math
y_{n+1}=y_n+h f(t_{n+1},y_{n+1}).
```

由于未知的$y_{n+1}$出现在右端，应先定义

**公式（3.1.13）**

```math
F(u)=u-y_n-h f(t_{n+1},u),
```

再求解$F(u)=0$，把所求得的根作为$y_{n+1}$。当$f$关于$y$非线性且可微时，可使用Newton迭代：

**公式（3.1.14）**

```math
u^{(m+1)}
=u^{(m)}-
\frac{F(u^{(m)})}
{1-h\,f_y(t_{n+1},u^{(m)})}.
```

这里$f_y$表示$f$对第二个变量的偏导数。若处理向量方程组，应求解相应的雅可比线性方程组。迭代是否收敛、代数方程是否存在合适的根，须与时间离散方法本身的稳定性分开考察。

向后Euler亦具有$O(h^2)$的一步局部差值，并在通常条件下具有$O(h)$的全局误差。由此可见，两种Euler方法的精度阶数相同，而显式与隐式的计算机制不同。

#### 3. 从一阶、二阶方法过渡到经典RK4

将向前Euler写成$k_1=f(t_n,y_n)$、$y_{n+1}=y_n+hk_1$，可以看出它用一个斜率代表整个时间步内的变化。典型二阶Runge–Kutta方法则使用起点及预测终点的两个斜率，形成更准确的加权近似。

经典RK4进一步选取四个阶段。第一个阶段采用当前点斜率；第二、三个阶段先后预测中点状态；第四个阶段根据第三个斜率预测终点状态。它们可以统一写为

**公式（3.1.15）**

```math
\left\{
\begin{aligned}
k_1&=f(t_n,y_n),\\
k_2&=f\left(t_n+\frac h2,\;y_n+\frac h2k_1\right),\\
k_3&=f\left(t_n+\frac h2,\;y_n+\frac h2k_2\right),\\
k_4&=f(t_n+h,\;y_n+hk_3).
\end{aligned}
\right.
```

其中，$k_2$和$k_3$虽然在同一时刻$t_n+h/2$计算，却使用不同的预测状态。这一设计使四次函数求值能够提供不同的斜率信息。

将四个阶段按$1:2:2:1$加权，得到经典RK4更新公式：

**公式（3.1.16）**

```math
y_{n+1}=y_n+\frac h6(k_1+2k_2+2k_3+k_4).
```

这里$k_1$对应起点，$k_2$与$k_3$对应两次不同预测的中点，$k_4$对应预测终点。四个阶段及其权重共同满足四阶Runge–Kutta的阶条件；在足够光滑的情形下，一步局部差值为$O(h^5)$，全局误差通常为$O(h^4)$。这并不是说任意四个斜率经过加权都能达到四阶，完整的四阶性质仍以相应阶条件为依据。

#### 4. 线性衰减方程的单步手算

**已知条件：** 取前述初值问题

**公式（3.1.17）**

```math
\left\{\begin{aligned}
y'(t)=-y(t),\\
y(0)=1.
\end{aligned}\right.
```

步长$h=0.5$。由分离变量可得解析解$y(t)=e^{-t}$，于是

**公式（3.1.18）**

```math
y(0.5)=e^{-0.5}\approx0.606530659713.
```

先用向前Euler计算：

**公式（3.1.19）**

```math
y_1^{\mathrm{FE}}=y_0+h(-y_0)
=1-0.5=0.5.
```

再用向后Euler计算：

**公式（3.1.20）**

```math
y_1^{\mathrm{BE}}=1-0.5y_1^{\mathrm{BE}}
\quad\Longrightarrow\quad
y_1^{\mathrm{BE}}=\frac23\approx0.666666667.
```

对于RK4，四个阶段分别为

**公式（3.1.21）**

```math
\left\{
\begin{aligned}
k_1&=-1,\\
k_2&=-\left(1+\frac{0.5}{2}k_1\right)=-0.75,\\
k_3&=-\left(1+\frac{0.5}{2}k_2\right)=-0.8125,\\
k_4&=-\left(1+0.5k_3\right)=-0.59375.
\end{aligned}
\right.
```

代入加权更新式，得到

**公式（3.1.22）**

```math
\begin{aligned}
y_1^{\mathrm{RK4}}
&=1+\frac{0.5}{6}
\left[-1+2(-0.75)+2(-0.8125)-0.59375\right]\\
&\approx\boxed{0.606770833333}.
\end{aligned}
```

比较可见，本例中向前Euler低估真实值，向后Euler高估真实值，RK4的第一步更接近解析解。这只是**特定方程和特定步长**下的计算结果，不能推广为三种方法在所有问题上的固定精度排序。

#### 5. 用放大因子说明稳定性与精度的区别

为了分析数值方法对衰减模态的处理，考虑线性测试方程

**公式（3.1.23）**

```math
y'=\lambda y,\qquad \mathrm{Re}(\lambda)<0,
```

并记$z=h\lambda$。若一步推进可以写成$y_{n+1}=R(z)y_n$，则$R(z)$称为该方法的**稳定函数**。

依次将测试方程代入向前Euler、向后Euler和经典RK4更新公式，可分别得到三种方法的稳定函数：

**公式（3.1.24）**

```math
\left\{
\begin{aligned}
R_{\mathrm{FE}}(z)&=1+z,\\
R_{\mathrm{BE}}(z)&=\frac{1}{1-z},\\
R_{\mathrm{RK4}}(z)&=
1+z+\frac{z^2}{2}+\frac{z^3}{6}+\frac{z^4}{24}.
\end{aligned}
\right.
```

例如，向前Euler满足$y_{n+1}=(1+z)y_n$；向后Euler满足$(1-z)y_{n+1}=y_n$。RK4的稳定多项式则来自四个阶段对线性函数$f(t,y)=\lambda y$的依次代入。

对于前面的衰减模型$\lambda=-1$，即$z=-h$，严格衰减条件为$|R(-h)|<1$。向前Euler要求$0<h<2$；向后Euler对所有$h>0$均满足$0<R(-h)<1$；经典RK4在负实轴上的稳定范围虽比向前Euler宽，却依然有限。

因此，**高阶精度不代表任意步长都稳定，数值衰减也不代表误差一定足够小**。实际计算时，应同时考虑步长、误差目标和函数求值成本。

#### 6. 推导结论与适用范围

以上推导得到的核心结论是：向前Euler与向后Euler均为全局一阶方法，经典RK4为全局四阶方法；向后Euler一般需要解隐式代数方程，而RK4每步通常需要四次右端函数求值。方法的精度阶数、绝对稳定性与计算代价是三个不同方面，不能相互替代。

关于Euler与Runge–Kutta方法的标准阶数及稳定性分析，可参考R. L. Burden、J. D. Faires和A. M. Burden的《Numerical Analysis》（第10版，第5章）以及T. Sauer的《Numerical Analysis》（第3版，第6章）。上述结论要求适当的光滑性和误差传播条件；对非光滑解、强刚性问题或隐式方程迭代未收敛的情况，应进一步分析，不能直接以一般阶数结论代替实际检验。

## 3.2 PDE有限差分：热传导与CFL条件（2学时）

**本节目标：** 能把方程、初边值条件和显式时间步长限制一起离散。

### 概念讲解

#### 3.2.1 一维热方程与初边值条件

##### 1. 概念讲解

考虑一根长度为 $L$ 的均匀导热杆，温度记为 $u(x,t)$。在热物性为常数、无内热源的条件下，温度满足一维热方程

**公式（3.2.1）**

```math
\frac{\partial u}{\partial t}=\kappa\,\frac{\partial^2 u}{\partial x^2},
\qquad 0<x<L,\quad t>0,
```

其中 $\kappa>0$ 为热扩散系数，单位为 $\mathrm{m^2/s}$。$\kappa$ 越大，温度趋于均匀的速度越快。方程 (3.2.1) 是抛物型方程，描述的是热传导这类耗散过程：温度分布随时间的演化不是任意的，而是朝着空间上更加均匀的方向发展；初值中的高频空间起伏会被较快地抹平，低频成分则衰减较慢。这一耗散特征将在 3.2.2 节的稳定性分析中以离散形式再次出现。

##### 2. 为什么需要初边值条件

方程 (3.2.1) 本身只描述了杆内部每一点处温度如何随时间和空间变化，它并不包含杆两端发生了什么、也不包含初始时刻温度分布是什么。从数学上看，方程 (3.2.1) 对时间是一阶的，因此需要给出一个初始时刻的状态才能确定未来；对空间是二阶的，因此需要在区间的两个端点各给出一个条件才能确定空间分布。缺少任何一类条件，问题的解都不唯一，或者根本不存在。下面分别说明本节采用的边界条件和初值条件。

##### 3. 边界条件

本节采用零 Dirichlet 边界条件

**公式（3.2.2）**

```math
u(0,t)=u(L,t)=0,\qquad t>0.
```

它的物理含义是：杆的两端始终与温度为 $0^\circ\mathrm{C}$ 的恒温环境保持理想接触，端点温度被外部环境“钳制”在零度，不随时间改变。数学上，条件 (3.2.2) 直接指定了未知函数在边界上的取值，因此称为第一类边界条件或 Dirichlet 条件。需要注意，条件 (3.2.2) 只规定了端点温度，并没有规定端点处的热流；热量仍然可以通过端点流入或流出杆内，只是端点温度本身被固定住了。这与第二类边界条件（Neumann 条件，指定端点热流）和第三类边界条件（Robin 条件，指定端点温度与环境温度之间的换热关系）不同。本节选择零 Dirichlet 条件，是因为它形式最简单、边界离散最直接，适合作为第一个数值格式的教学起点。

##### 4. 初值条件

初值条件为

**公式（3.2.3）**

```math
u(x,0)=u_0(x),\qquad 0\le x\le L,
```

其中 $u_0$ 是给定的光滑函数。它的作用是给出 $t=0$ 时刻杆内每一点的温度分布，作为时间推进的起点。仅有边界条件 (3.2.2) 而不给出 (3.2.3)，可以构造出无穷多个满足方程和边界条件的解；反过来，仅有初值而不给出边界条件，端点处的温度可以任意变化，杆内的解也无法唯一确定。三类条件——方程 (3.2.1)、边界条件 (3.2.2)、初值条件 (3.2.3)——合在一起，才构成一个适定的初边值问题。

##### 5. 相容性条件

初值 $u_0$ 不能任意选取，它必须与边界条件在角点 $(x,t)=(0,0)$ 和 $(L,0)$ 处相容。具体地说，由边界条件 (3.2.2) 在 $t\to 0^+$ 时的极限可知，端点温度应为零；而由初值条件 (3.2.3) 在 $x=0$ 和 $x=L$ 处取值可知，初始端点温度应为 $u_0(0)$ 和 $u_0(L)$。二者必须一致，即要求

**公式（3.2.4）**

```math
u_0(0)=u_0(L)=0.
```

如果这个条件不满足，例如取 $u_0(x)=1+\sin(\pi x)$，则 $u_0(0)=u_0(1)=1$，而边界条件要求端点在 $t>0$ 时恒为零。此时在角点附近，初值和边界条件互相矛盾，精确解在 $t=0$ 处不连续，数值格式在第一步就会在端点附近产生剧烈振荡，这种振荡与 3.2.2 节将要讨论的稳定性问题是两回事，不能混为一谈。因此，本节要求 $u_0$ 是光滑函数并且满足相容性条件 (3.2.4)。相容性条件只涉及端点值，不要求 $u_0$ 在端点处的导数也满足额外条件；后者只有在更高阶的相容性分析中才会出现，本节不涉及。

方程 (3.2.1)—(3.2.3) 连同相容性要求 (3.2.4) 构成本节的标准模型问题。

##### 6. 具体例子

为便于后续数值实验，下面给出一个完整的初边值问题。取杆长 $L=1\,\mathrm{m}$，热扩散系数 $\kappa=0.1\,\mathrm{m^2/s}$，求解区域为 $0<x<1$、$t>0$。控制方程为

**公式（3.2.5）**

```math
\frac{\partial u}{\partial t}
=
0.1\,\frac{\partial^2 u}{\partial x^2},
\qquad 0<x<1,\quad t>0.
```

边界条件取零 Dirichlet 型：

**公式（3.2.6）**

```math
u(0,t)=u(1,t)=0,\qquad t>0,
```

即杆两端温度始终固定为零度。初值条件取

**公式（3.2.7）**

```math
u(x,0)=\sin(\pi x),\qquad 0\le x\le 1.
```

这个初值在两端取零：$u_0(0)=\sin 0=0$，$u_0(1)=\sin\pi=0$，与边界条件 (3.2.6) 相容，满足 (3.2.4)。它在杆中点 $x=1/2$ 处达到最大值 $1$，向两端光滑地降到零，物理上对应“中间温度最高、两端被固定为零度”的初始温度分布。将 (3.2.7) 代入方程可以验证，初边值问题 (3.2.5)—(3.2.7) 的解析解为

**公式（3.2.8）**

```math
u(x,t)=\sin(\pi x)\,e^{-0.1\pi^2 t}.
```

从 (3.2.8) 可以看出：空间形状始终保持为 $\sin(\pi x)$ 不变，温度分布不会在空间上产生新的振荡；整体振幅按指数因子 $e^{-0.1\pi^2 t}$ 单调衰减，最终趋于零。这个完整的初边值问题将在 3.2.3 节的数值实验中作为独立基线使用：它的方程、边界条件、初值条件和解析解都已明确给出，不依赖任何离散格式，因此可以同时用来检查数值解的误差大小，并区分“数值解有界但不够精确”和“数值解本身已经失去有界性”这两种不同情形。

在进入离散之前，读者只需熟悉二阶偏导数和 Taylor 展开的基本含义，并理解 Dirichlet 边界条件如何指定端点温度、初值条件如何提供时间推进的起点，以及二者在角点处必须满足相容性。下一小节将用中心差分离散二阶空间导数、用前向 Euler 推进时间，并借助 Taylor 展开检查格式的相容性；零 Dirichlet 边界将直接给出网格端点的取值，相容性条件则保证初始时间层的离散数据与边界数据不矛盾。有限差分的基本思想——把连续函数限制在网格点上，将微分方程转化为有限维递推——是下一小节建立显式格式的出发点。本节不预设 von Neumann 稳定性分析，稳定性限制将在 3.2.2 中结合具体格式逐步说明。

### 关键推导

#### 3.2.2 空间差分与显式时间推进

##### 1. 关键推导

在 $[0,L]$ 上取均匀空间网格 $x_j=j\Delta x$，$j=0,1,\dots,J$，其中 $\Delta x=L/J$；在时间方向取均匀步长 $\Delta t$，$t_n=n\Delta t$。记 $U_j^n$ 为精确解 $u(x_j,t_n)$ 的数值近似。假设热扩散系数 $\kappa>0$ 为常数，网格均匀，边界条件按 (3.2.2) 精确给定：$U_0^n=U_J^n=0$ 对所有 $n\ge 0$ 成立。下面从空间和时间两个方向分别离散方程 (3.2.1)，再组装成可计算的递推格式，并用 Taylor 展开检验其相容性。

先处理空间二阶导数。将精确解在 $(x_j,t_n)$ 处关于 $x$ 作 Taylor 展开。对 $x_{j+1}=x_j+\Delta x$，

```math
\begin{aligned}
u(x_{j+1},t_n)
&=u(x_j,t_n)+\Delta x\,u_x(x_j,t_n)
+\frac{\Delta x^2}{2}u_{xx}(x_j,t_n)\\
&\quad+\frac{\Delta x^3}{6}u_{xxx}(x_j,t_n)
+\frac{\Delta x^4}{24}u_{xxxx}(x_j,t_n)
+\mathcal{O}(\Delta x^5),
\end{aligned}
```

对 $x_{j-1}=x_j-\Delta x$，

```math
\begin{aligned}
u(x_{j-1},t_n)
&=u(x_j,t_n)-\Delta x\,u_x(x_j,t_n)
+\frac{\Delta x^2}{2}u_{xx}(x_j,t_n)\\
&\quad-\frac{\Delta x^3}{6}u_{xxx}(x_j,t_n)
+\frac{\Delta x^4}{24}u_{xxxx}(x_j,t_n)
+\mathcal{O}(\Delta x^5).
\end{aligned}
```

两式相加，一阶和三次项相消，得

```math
\begin{aligned}
u(x_{j+1},t_n)+u(x_{j-1},t_n)
&=2u(x_j,t_n)+\Delta x^2\,u_{xx}(x_j,t_n)\\
&\quad+\frac{\Delta x^4}{12}u_{xxxx}(x_j,t_n)
+\mathcal{O}(\Delta x^6).
\end{aligned}
```

移项并除以 $\Delta x^2$，得到中心差分公式

**公式（3.2.9）**

```math
\begin{aligned}
u_{xx}(x_j,t_n)
&=\frac{u(x_{j+1},t_n)-2u(x_j,t_n)+u(x_{j-1},t_n)}{\Delta x^2}\\
&\quad-\frac{\Delta x^2}{12}u_{xxxx}(x_j,t_n)
+\mathcal{O}(\Delta x^4).
\end{aligned}
```

等式右端第一项就是二阶空间导数的中心差分近似，误差主项为 $-\frac{\Delta x^2}{12}u_{xxxx}$，因此该近似具有二阶精度。

再处理时间一阶导数。将精确解在 $(x_j,t_n)$ 处关于 $t$ 作 Taylor 展开：

```math
u(x_j,t_{n+1})
=
u(x_j,t_n)
+\Delta t\,u_t(x_j,t_n)
+\frac{\Delta t^2}{2}u_{tt}(x_j,t_n)
+\mathcal{O}(\Delta t^3).
```

移项并除以 $\Delta t$，得

**公式（3.2.10）**

```math
u_t(x_j,t_n)
=
\frac{u(x_j,t_{n+1})-u(x_j,t_n)}{\Delta t}
-\frac{\Delta t}{2}u_{tt}(x_j,t_n)
+\mathcal{O}(\Delta t^2).
```

等式右端第一项就是时间一阶导数的前向差分近似，误差主项为 $-\frac{\Delta t}{2}u_{tt}$，因此该近似具有一阶精度。

有了空间和时间两方面的离散，就可以组装格式。在网格点 $(x_j,t_n)$ 处，精确解满足 $u_t=\kappa u_{xx}$。用 (3.2.10) 的左端替换 $u_t$，用 (3.2.9) 的右端第一项替换 $u_{xx}$，并丢弃截断误差，得到差分方程

**公式（3.2.11）**

```math
\frac{U_j^{n+1}-U_j^n}{\Delta t}
=
\kappa\,
\frac{U_{j+1}^n-2U_j^n+U_{j-1}^n}{\Delta x^2},
\qquad j=1,\dots,J-1.
```

这里 $U_j^n$ 已是数值近似，不再带有 Taylor 余项；边界条件直接赋值为 $U_0^n=U_J^n=0$。将 (3.2.11) 两端乘以 $\Delta t$，并把 $U_j^n$ 移到右端，整理得

```math
U_j^{n+1}
=
U_j^n
+
\frac{\kappa\Delta t}{\Delta x^2}
\left(U_{j+1}^n-2U_j^n+U_{j-1}^n\right).
```

记无量纲参数

**公式（3.2.12）**

```math
r=\frac{\kappa\Delta t}{\Delta x^2},
```

则格式可写为

**公式（3.2.13）**

```math
U_j^{n+1}
=
U_j^n
+
r\left(U_{j+1}^n-2U_j^n+U_{j-1}^n\right),
\qquad j=1,\dots,J-1.
```

格式 (3.2.11)—(3.2.13) 称为 FTCS 格式（Forward-Time, Centred-Space）。它之所以是**显式**的，是因为每一个 $U_j^{n+1}$ 都只依赖于上一时间层 $t_n$ 的已知值 $U_{j-1}^n,U_j^n,U_{j+1}^n$，不需要求解线性代数方程组，可以直接逐点递推。参数 $r$ 的物理含义是：在一个时间步内，热扩散的特征长度 $\sqrt{\kappa\Delta t}$ 相对于网格间距 $\Delta x$ 的平方比，即 $r=(\sqrt{\kappa\Delta t}/\Delta x)^2$。$r$ 越大，一个时间步内扩散效应跨越的网格范围越宽；但 $r$ 不能任意大，这正是下面稳定性分析的主题。

在讨论稳定性之前，先用 Taylor 展开检验格式的相容性。将精确解代入差分格式 (3.2.11)，定义局部截断误差

**公式（3.2.14）**

```math
\tau_j^n
=
\frac{u(x_j,t_{n+1})-u(x_j,t_n)}{\Delta t}
-
\kappa\,
\frac{u(x_{j+1},t_n)-2u(x_j,t_n)+u(x_{j-1},t_n)}{\Delta x^2}.
```

由时间展开 (3.2.10)，

```math
\begin{aligned}
\frac{u(x_j,t_{n+1})-u(x_j,t_n)}{\Delta t}
&=u_t(x_j,t_n)+\frac{\Delta t}{2}u_{tt}(x_j,t_n)\\
&\quad+\frac{\Delta t^2}{6}u_{ttt}(x_j,t_n)
+\mathcal{O}(\Delta t^3);
\end{aligned}
```

由空间展开 (3.2.9)，

```math
\begin{aligned}
\frac{u(x_{j+1},t_n)-2u(x_j,t_n)+u(x_{j-1},t_n)}{\Delta x^2}
&=u_{xx}(x_j,t_n)\\
&\quad+\frac{\Delta x^2}{12}u_{xxxx}(x_j,t_n)
+\mathcal{O}(\Delta x^4).
\end{aligned}
```

将这两式代入 (3.2.14)：

```math
\begin{aligned}
\tau_j^n
&=
\left[
u_t
+\frac{\Delta t}{2}u_{tt}
+\frac{\Delta t^2}{6}u_{ttt}
+\mathcal{O}(\Delta t^3)
\right]
-
\kappa
\left[
u_{xx}
+\frac{\Delta x^2}{12}u_{xxxx}
+\mathcal{O}(\Delta x^4)
\right] \\
&=
\left(u_t-\kappa u_{xx}\right)
+\frac{\Delta t}{2}u_{tt}
-\frac{\kappa\Delta x^2}{12}u_{xxxx}
+\frac{\Delta t^2}{6}u_{ttt}
+\mathcal{O}(\Delta t^3+\Delta x^4).
\end{aligned}
```

由于精确解满足 $u_t=\kappa u_{xx}$，第一项为零。再利用 $u_{tt}=\partial_t(\kappa u_{xx})=\kappa u_{xxt}=\kappa\partial_{xx}(u_t)=\kappa^2 u_{xxxx}$，可把 $\frac{\Delta t}{2}u_{tt}$ 写成 $\frac{\kappa^2\Delta t}{2}u_{xxxx}$。于是

**公式（3.2.15）**

```math
\tau_j^n
=
\left(\frac{\kappa^2\Delta t}{2}-\frac{\kappa\Delta x^2}{12}\right)u_{xxxx}(x_j,t_n)
+\mathcal{O}(\Delta t^2+\Delta x^4).
```

因此当 $\Delta t,\Delta x\to 0$ 时 $\tau_j^n\to 0$，FTCS 格式与方程 (3.2.1) 相容，且在时间方向一阶、空间方向二阶。但相容性本身只说明“格式逼近方程”，并不保证数值解有界。一个相容格式如果不稳定，舍入误差或初值中的高频分量可能在若干时间步内被放大到淹没真解的程度；下面对此作定量分析。

##### 2. 稳定性定理

由于方程 (3.2.1) 线性、常系数，边界条件齐次，误差 $e_j^n=U_j^n-u(x_j,t_n)$ 满足与 (3.2.13) 相同的齐次递推：

**公式（3.2.16）**

```math
e_j^{n+1}
=
e_j^n
+
r\left(e_{j+1}^n-2e_j^n+e_{j-1}^n\right),
\qquad j=1,\dots,J-1,
```

边界处 $e_0^n=e_J^n=0$。将误差按离散 Fourier 模态展开，$e_j^n=\sum_k G(k)^n e^{ikx_j}$，其中 $k$ 取遍与网格相容的波数。由于递推是线性的，各模态独立演化，只需考察单个模态 $e_j^n=G^n e^{ikj\Delta x}$。代入 (3.2.16)：

```math
G^{n+1}e^{ikj\Delta x}
=
G^n e^{ikj\Delta x}
+
r\left(G^n e^{ik(j+1)\Delta x}-2G^n e^{ikj\Delta x}+G^n e^{ik(j-1)\Delta x}\right).
```

两端除以 $G^n e^{ikj\Delta x}$（非零），得到放大因子

```math
\begin{aligned}
G(k)
&=1+r\left(e^{ik\Delta x}-2+e^{-ik\Delta x}\right)\\
&=1+r\left(2\cos(k\Delta x)-2\right)\\
&=1-2r\left(1-\cos(k\Delta x)\right).
\end{aligned}
```

利用恒等式 $1-\cos\theta=2\sin^2(\theta/2)$，化为

**公式（3.2.17）**

```math
G(k)
=
1-4r\sin^2\!\left(\frac{k\Delta x}{2}\right).
```

格式 (3.2.13) 稳定的充要条件是对所有波数 $k$ 都有 $|G(k)|\le 1$。令 $s=\sin^2(k\Delta x/2)$，则 $s\in[0,1]$，且 $G=1-4rs$。要求 $-1\le 1-4rs\le 1$ 对所有 $s\in[0,1]$ 成立。右半不等式 $1-4rs\le 1$ 即 $-4rs\le 0$，因 $r>0$、$s\ge 0$ 自动成立。左半不等式 $1-4rs\ge -1$ 即 $4rs\le 2$，即 $r\le 1/(2s)$。该式对一切 $s\in[0,1]$ 成立的最坏情形是 $s=1$，于是得到

**公式（3.2.18）**

```math
r\le\frac12.
```

反之，若 $r>1/2$，取 $k\Delta x=\pi$（即 $s=1$），则 $G=1-4r<-1$，$|G|>1$，对应模态逐步被放大。因此 $r\le 1/2$ 是 FTCS 格式稳定的充分必要条件。下面把这一结论连同收敛性估计写成定理。

**定理 3.2.1（FTCS 格式的稳定性与收敛性）** 设 $\kappa>0$ 为常数，空间网格均匀，$r=\kappa\Delta t/\Delta x^2$，边界条件为零 Dirichlet 条件 $U_0^n=U_J^n=0$。

(i) **稳定性。** 若

**公式（3.2.19）**

```math
0\le r\le \frac12,
```

则对任意初始数据 $\{U_j^0\}$，FTCS 格式 (3.2.13) 满足离散最大值原理

**公式（3.2.20）**

```math
\max_{1\le j\le J-1}\left|U_j^{n+1}\right|
\le
\max_{1\le j\le J-1}\left|U_j^n\right|,
\qquad n=0,1,2,\dots
```

从而数值解在最大范数下不增长。

(ii) **收敛性。** 若精确解 $u\in C^4([0,T]\times[0,L])$ 且初始层取精确值 $U_j^0=u(x_j,0)$，则存在仅依赖于 $\kappa$、$T$ 和 $u$ 的四阶导数上界的常数 $C$，使得

**公式（3.2.21）**

```math
\max_{1\le j\le J-1}\left|u(x_j,t_n)-U_j^n\right|
\le
C\,t_n\left(\Delta t+\Delta x^2\right),
\qquad 0\le t_n\le T.
```

**证明**

(i) 将 (3.2.13) 改写为

```math
U_j^{n+1}
=
(1-2r)U_j^n
+
rU_{j+1}^n
+
rU_{j-1}^n.
```

当 $0\le r\le 1/2$ 时，三个系数 $1-2r$、$r$、$r$ 均非负，且

```math
(1-2r)+r+r=1.
```

于是

```math
\begin{aligned}
\left|U_j^{n+1}\right|
&\le
(1-2r)\left|U_j^n\right|
+
r\left|U_{j+1}^n\right|
+
r\left|U_{j-1}^n\right| \\
&\le
(1-2r+r+r)\max_{1\le i\le J-1}\left|U_i^n\right|
=
\max_{1\le i\le J-1}\left|U_i^n\right|.
\end{aligned}
```

对 $j=1,\dots,J-1$ 取最大值即得 (3.2.20)。边界点 $U_0^{n+1}=U_J^{n+1}=0$ 不影响最大值。

(ii) 令误差 $e_j^n=u(x_j,t_n)-U_j^n$。由截断误差的定义 (3.2.14)，精确解满足

```math
u(x_j,t_{n+1})
=
u(x_j,t_n)
+
r\left(u(x_{j+1},t_n)-2u(x_j,t_n)+u(x_{j-1},t_n)\right)
+
\Delta t\,\tau_j^n.
```

减去数值格式 (3.2.13)，得到误差递推

**公式（3.2.22）**

```math
e_j^{n+1}
=
(1-2r)e_j^n
+
re_{j+1}^n
+
re_{j-1}^n
+
\Delta t\,\tau_j^n.
```

边界处 $e_0^n=e_J^n=0$ 对所有 $n$ 成立；初始层 $e_j^0=0$，因为 $U_j^0=u(x_j,0)$。

对 (3.2.22) 取绝对值，利用 $0\le r\le 1/2$ 时系数非负且和为 1：

```math
\left|e_j^{n+1}\right|
\le
(1-2r)\left|e_j^n\right|
+
r\left|e_{j+1}^n\right|
+
r\left|e_{j-1}^n\right|
+
\Delta t\left|\tau_j^n\right|.
```

记 $E^n=\max_{1\le j\le J-1}|e_j^n|$，$T^n=\max_{1\le j\le J-1}|\tau_j^n|$。对 $j$ 取最大值：

```math
E^{n+1}
\le
E^n
+
\Delta t\,T^n.
```

从 $n=0$ 递推到 $n=N$：

```math
E^N
\le
E^0
+
\Delta t\sum_{n=0}^{N-1}T^n
\le
\Delta t\sum_{n=0}^{N-1}\max_{0\le m\le N-1}T^m
=
t_N\max_{0\le m\le N-1}T^m,
```

其中 $t_N=N\Delta t$，且用了 $E^0=0$。由截断误差表达式 (3.2.15)，在 $u\in C^4$ 的假设下，$|u_{xxxx}|$ 和 $|u_{ttt}|$ 在 $[0,T]\times[0,L]$ 上有界，设其上界分别为 $M_4$ 和 $M_3$。则

```math
\begin{aligned}
T^n
&\le\left(\frac{\kappa^2\Delta t}{2}+\frac{\kappa\Delta x^2}{12}\right)M_4
+\frac{\Delta t^2}{6}M_3\\
&\quad+C_1(\Delta t^3+\Delta x^4)\\
&\le C_2(\Delta t+\Delta x^2),
\end{aligned}
```

其中 $C_2$ 只依赖于 $\kappa$、$M_3$、$M_4$ 和 $T$ 的上界（当 $\Delta t\le T$ 时 $\Delta t^2\le T\Delta t$，$\Delta x^4\le L^2\Delta x^2$）。于是

```math
E^N
\le
t_N\,C_2(\Delta t+\Delta x^2)
=
C\,t_N(\Delta t+\Delta x^2),
```

取 $C=C_2$ 即得 (3.2.21)。证毕。

上述稳定性与收敛性结论与 Schedensack 讲义中的 Proposition 2.4 一致；该讲义取 $\kappa=1$、以 $\lambda=\Delta t/\Delta x^2$ 记时间步参数，并给出 $0\le\lambda\le 1/2$ 时的最大值原理与 $\mathcal{O}(\Delta t+\Delta x^2)$ 误差估计。对一般 $\kappa>0$，只需将 $\lambda$ 替换为 $r=\kappa\Delta t/\Delta x^2$，证明过程完全平行。Smith 的经典教材也以定理形式陈述了同一稳定性条件：对 $\kappa=1$ 的归一化方程，显式格式稳定的充要条件是 $\beta=\Delta t/\Delta x^2\le 1/2$。

最后考察条件不满足时的情形。当 $r>1/2$ 时，放大因子 (3.2.17) 在 $k\Delta x=\pi$ 处满足 $|G|=|1-4r|>1$。这个模态在空间上逐点变号，是网格所能分辨的最高频分量。即使初值 $u_0$ 完全光滑、不包含这一分量，浮点运算的舍入误差在每一步都会引入全频段扰动，其中 $k\Delta x=\pi$ 的分量每步被乘以 $|1-4r|>1$，从而指数增长，最终表现为数值解的振荡爆炸。因此 $r\le 1/2$ 不是精度建议，而是 FTCS 格式保持有界性的必要条件。还需强调，定理 3.2.1 的证明使用了常数 $\kappa$、均匀网格和零 Dirichlet 边界；对于变系数、非均匀网格或 Neumann 边界，稳定性条件需要重新分析，不能把 $r\le 1/2$ 直接搬用。

## 3.3 有限元：弱形式与 Galerkin 方法（2 学时）

> **本节目标**：能从一维边值问题写出弱形式，理解 Galerkin 有限元离散的基本思想，并能够装配一维线性单元系统。

#### 导览：如果“每一点都不对”，答案怎么还能对？

##### 历史现场：20 世纪 50 年代，一架飞机的机翼

20 世纪 50 年代，
工程师开始尝试把复杂的飞机结构拆成许多简单的小块来计算。

原因很现实：
真实机翼由蒙皮、梁、肋、开孔等组成，想直接写出一个漂亮的解析解通常并不现实。但与此同时，数字计算机却越来越擅长一件事情：求解大量代数方程。

于是，一个大胆的想法出现了：

> **能不能把一个复杂的连续结构切成许多简单的小块，先算每一个小块，再把它们重新“拼”起来？**

今天，我们不必分析一整架飞机。先把问题缩小到只有一条线，考虑下面的一维边值问题：

**公式（3.3.1）**

```math
\left\{
\begin{aligned}
-u''(x)&=1, 0<x<1,\\
u(0)&=u(1)=0.
\end{aligned}
\right.
```

现在，只把区间 $[0,1]$ 切成两个单元，并规定近似解只能是一条折线。

![两个线性单元连接成的折线近似解](<图片/3.3.1折线.png>)

也就是说，本来要寻找的是一个完整的未知函数 $u(x)$，现在暂时只剩下一个真正未知的数字——中间节点的高度 $U_1$，事情似乎一下简单了很多。可是，一个麻烦也随之出现。

##### 30 秒思考：这条折线真的有资格当“解”吗？

在每个线性单元的内部，$u_h$ 都是一条直线，因此$u_h''(x)=0.$可是，原方程要求$-u''(x)=1.$而且在中间节点处，$u_h'$ 还会突然改变。换句话说，经典意义下的二阶导数在这个节点处并不存在。如果我们的判定标准是“把近似解代回微分方程，要求每一个点都严格成立”，那么这条折线显然不合格。现在，请先作出自己的判断。

**A．直接判定失败：** 连二阶导数都不存在，有限元从一开始就失败了。

**B．暂时接受近似：** 虽然不满足方程，但只要网格足够细，就可以使用。

**C．改变检验方式：** 不再要求近似解逐点满足原方程，而是采用另一种数学条件确定近似解。

先记下你的选择。接下来，一个更奇怪的现象会让这个问题变得更加有趣。

##### 反直觉结果：只有两个单元，节点值却可能准确

这个问题的精确解其实是$u(x)=\frac{x(1-x)}{2}.$因此，中点处的精确解为$u\left(\frac12\right)=\frac18.$后面的有限元推导将表明：即使只使用两个线性单元，中间节点的有限元近似值也可以得到$U_1=\frac18.$也就是说，在这个特殊的例子中，一条在每个单元内部都满足 $u_h''(x)=0$ 的折线，竟然能够准确给出中间节点的函数值。

这听起来有些不可思议。但它并不是因为折线偷偷满足了原来的微分方程，也不是因为我们忽略了二阶导数的问题。真正发生的事情是：

> **有限元改变了近似解满足微分方程的方式，而不是改变了原来的微分方程。**

强形式关心的是：每一个点上，方程是否成立？有限元接下来要做的，是把逐点检验转换为更适合分片函数的整体积分检验。

##### 核心悬念：有限元到底在满足什么？

原方程包含二阶导数，而我们希望使用简单的分片线性函数。既然这种函数通常不能逐点满足原方程，为什么仍然可以用来构造有效的近似解？

本节将围绕三个问题展开：

1. **改变判定标准：** 如果不要求近似解逐点满足微分方程，那么有限元究竟要求什么成立？
2. **降低导数要求：** 为什么引入检验函数并进行分部积分，就能让只具有一阶导数的分片线性函数参与计算？
3. **拼成整体系统：** 一个个小单元上的局部计算，最后为什么能够组成整体线性方程组 $KU=F$？

带着这些问题，我们从强形式出发，逐步建立弱形式，并推导 Galerkin 有限元离散方法。

### 概念讲解：从连续问题到有限元近似

导览中的两单元折线揭示了一个重要问题：有限元希望用连续分片线性函数近似微分方程的解，而原方程却包含二阶导数。这样的近似函数在单元交界处通常有折角，为什么仍然可以用于求解？

为说明这一点，考虑一般的一维 Poisson 边值问题：


```math
\left\{
\begin{aligned}
-u''(x)&=f(x),0<x<1,\\
u(0)&=u(1)=0.
\end{aligned}
\right.
```
其中，$f(x)$ 是给定的源项函数，$u(x)$ 是待求函数；$u(0)=u(1)=0$ 表示两端函数值已知且均为零，称为**齐次 Dirichlet 边界条件**。

像这样直接用微分方程和边界条件描述问题，称为问题的**强形式**（strong form）。若要求方程在区间内部逐点按经典意义成立，未知函数 $u$ 需要具有相应的二阶导数。

但是，连续分片线性函数 $u_h$ 在每个单元内都是一次函数，其二阶导数为零；在相邻单元交界处，一阶导数又可能发生跳跃，因此 $u_h$ 一般不具有在整个区间内逐点存在的经典二阶导数。于是，若直接把 $u_h$ 代入强形式，通常无法逐点满足原方程。

这并不意味着 $u_h$ 不能用来近似精确解，而是说明需要改变对方程的处理方式。具体做法是：选取满足端点零值条件的**检验函数** $v(x)$，将微分方程两边乘以 $v(x)$ 并在区间上积分，再通过分部积分，将 $u$ 的二阶导数转化为只含一阶导数的积分表达式。所得积分关系称为问题的**弱形式**（weak form）。

弱形式并不是随意放宽方程，而是在适当条件下与强形式相一致的另一种表述。它降低了对函数光滑性的要求，为随后采用连续分片线性函数进行 Galerkin 有限元离散奠定了基础。

#### 1. 为什么需要弱形式？

前文已经说明，连续分片线性函数一般不能按照含二阶导数的强形式逐点满足原方程。关键不是放弃原方程，而是寻找一种由原方程推导得到、同时适合分片线性函数的数学表述。下面先建立只涉及一阶导数的积分关系，再讨论如何据此构造有限元近似。

#### 2. 从强形式到弱形式

考虑前述一维 Poisson 边值问题

**公式（3.3.2）**

```math
\left\{
\begin{aligned}
-u''(x)&=f(x), 0<x<1,\\
u(0)&=u(1)=0.
\end{aligned}
\right.
```

为说明弱形式的来源，暂时假定精确解 $u$ 足够光滑。取任意一个足够光滑、且满足 $v(0)=v(1)=0$ 的函数 $v(x)$，称其为**检验函数**（test function）。由于待求解的端点值已经给定，检验函数可以理解为不改变这些端点值的扰动，因此在两端取零。这里的“任意”十分重要：接下来推导的积分关系必须对每一个符合要求的检验函数成立。

将方程 $-u''(x)=f(x)$ 两边乘以 $v(x)$，并在整个区间上积分，得到

**公式（3.3.3）**

```math
-\int_0^1 u''(x)v(x)\,\mathrm{d}x
=\int_0^1 f(x)v(x)\,\mathrm{d}x.
```

对左端进行分部积分，便有

**公式（3.3.4）**

```math
\int_0^1 u'(x)v'(x)\,\mathrm{d}x
-\bigl[u'(x)v(x)\bigr]_0^1
=\int_0^1 f(x)v(x)\,\mathrm{d}x.
```

由于 $v(0)=v(1)=0$，边界项满足

**公式（3.3.5）**

```math
\bigl[u'(x)v(x)\bigr]_0^1
=u'(1)v(1)-u'(0)v(0)=0.
```

因此得到

**公式（3.3.6）**

```math
\int_0^1 u'(x)v'(x)\,\mathrm{d}x
=\int_0^1 f(x)v(x)\,\mathrm{d}x.
```

这就是该边值问题的**弱形式**所依据的积分关系：寻找满足原边界条件的函数 $u$，使上式对所有允许的检验函数 $v$ 成立。需要注意，边界项之所以消失，是因为*检验函数*在端点取零，并不是因为 $u(0)=u(1)=0$ 就能推出 $u'(0)=u'(1)=0$。

与强形式相比，上式仅含 $u$ 的一阶导数。连续分片线性函数在各单元内具有分段常数的一阶导数，即使在单元交界处发生斜率跳跃，仍然可以计算上述积分。因此，弱形式为采用分片线性函数进行有限元近似提供了依据。

至于允许选取哪些试探函数和检验函数，以及如何把弱形式转化为有限个代数方程，将在后面继续讨论。

#### 3. 试探空间与检验空间

上文通过积分分部得到了只含一阶导数的积分关系。要将这一关系作为完整的数学问题，还需要说明：未知函数 $u$ 和检验函数 $v$ 分别允许从哪些函数中选取？

对于本节的齐次 Dirichlet 边界条件，取函数空间

**公式（3.3.7）**

```math
V=H_0^1(0,1)
 =\bigl\{w\in H^1(0,1):w(0)=w(1)=0\bigr\}.
```

其中，$H^1(0,1)$ 表示函数本身及其一阶**弱导数**均平方可积的函数空间；$H_0^1(0,1)$ 则进一步要求函数在两个端点取零。在一维区间上，端点值可以按照函数的连续代表来理解。这里还假定已知源项 $f$ 平方可积，以保证下面的积分有意义。

因此，该边值问题的**弱形式**可表述为：求 $u\in V$，使得对任意 $v\in V$，均有

**公式（3.3.8）**

```math
\int_0^1 u'(x)v'(x)\,\mathrm{d}x
=\int_0^1 f(x)v(x)\,\mathrm{d}x.
```

这里，未知函数 $u$ 所属的空间称为**试探空间**，检验函数 $v$ 所属的空间称为**检验空间**。在当前齐次 Dirichlet 问题中，两者取同一个空间 $V$，但作用不同：$u$ 是需要确定的函数，$v$ 用来检验积分关系是否成立。

需要强调，弱形式并没有取消对函数的要求，而是以一阶弱导数的可积性代替了对经典二阶导数的要求。例如，满足端点零值条件的连续分片线性函数属于 $V$：它在单元内部的一阶导数为常数，节点处即使发生斜率跳跃，也不影响相应积分的计算。

#### 4. 从无限维弱问题到有限维近似

至此，我们已经给出了弱问题的完整表述，但还没有得到可以直接求解的有限个代数方程。原因在于：$V$ 是一个**无限维函数空间**，未知量仍然是函数 $u$，而且积分关系必须对 $V$ 中所有检验函数成立。

有限元方法的下一步，是先将区间划分为若干小单元，再从 $V$ 中选取由连续分片线性函数构成的**有限维子空间** $V_h\subset V$。我们将用 $u_h\in V_h$ 近似 $u$，并相应地从 $V_h$ 中选择检验函数。这样，未知函数就可以用有限个系数表示，积分关系也将转化为有限个代数方程。需要注意，离散后只要求积分关系对 $V_h$ 中的检验函数成立，因此得到的是原弱问题的近似，而不是原问题在所有检验函数下的精确解。

这一过程可以概括为

**公式（3.3.9）**

```math
\underbrace{\text{在 }V\text{ 中求 }u}_{\text{无限维弱问题}}
\quad\longrightarrow\quad
\underbrace{\text{在 }V_h\subset V\text{ 中求 }u_h}_{\text{有限维近似问题}}.
```

至于如何建立网格、构造 $V_h$，以及如何把有限维问题写成线性方程组，将在下面依次说明。

#### 5. 建立网格

上一小节提出，要用一个有限维空间近似原来的无限维空间。为了构造这样的空间，首先将求解区间 $[0,1]$ 划分为 $N$ 个小区间，取节点

**公式（3.3.10）**

```math
0=x_0<x_1<\cdots<x_N=1.
```

其中，$x_i$ 称为**节点**（node），相邻两个节点之间的区间

**公式（3.3.11）**

```math
K_e=[x_{e-1},x_e],\qquad e=1,2,\ldots,N
```

称为一个**单元**（element）。这些单元共同构成区间 $[0,1]$ 上的**网格**（mesh）。有限元方法中的“元”，指的就是这样的单元。

记第 $e$ 个单元的长度为 $h_e$，并定义网格尺寸 $h$：

**公式（3.3.12）**

```math
h_e=x_e-x_{e-1},\qquad
h=\max_{1\le e\le N}h_e.
```

网格不要求各单元等长；当所有单元等长时，$h_e=h=1/N$。一般来说，$h$ 越小，表示网格划分越细。

建立网格只是完成了区间的划分。接下来还需要规定：在每个单元上，用什么样的函数近似未知解？

#### 6. 连续分片线性有限元空间

为使近似函数既易于计算，又能够用于前面建立的弱形式，我们在每个单元上选取次数不超过一次的多项式，并要求它们在相邻节点处连续，同时满足两端的齐次 Dirichlet 边界条件。由此定义**连续分片线性有限元空间**

**公式（3.3.13）**

```math
V_h=\left\{v_h\in C^0([0,1])\;\middle|\;
\begin{aligned}
&v_h|_{K_e}\in P_1(K_e),\quad e=1,2,\ldots,N,\\
&v_h(0)=v_h(1)=0
\end{aligned}
\right\}.
```

这里，$C^0([0,1])$ 表示在整个区间上连续的函数，$P_1(K_e)$ 表示单元 $K_e$ 上次数不超过 $1$ 的多项式构成的空间，$v_h|_{K_e}$ 表示函数 $v_h$ 在该单元上的限制。下标 $h$ 表示这一空间依赖于所选网格。

因此，$V_h$ 中的函数在每个单元上是一条直线段，整体上则是一条连续折线。虽然它们在单元交界处可能存在折角，但其一阶弱导数在各单元内部为常数，因而平方可积。又因为这些函数在两端取零，所以它们属于前面定义的空间 $V=H_0^1(0,1)$，即

**公式（3.3.14）**

```math
V_h\subset V.
```

更重要的是，连续分片线性函数由各节点处的函数值唯一确定。由于两端节点值已经固定为零，只剩下 $N-1$ 个内部节点值可以独立选取。因此，$V_h$ 是一个维数为 $N-1$ 的有限维空间。

至此，我们在原来的无限维空间 $V$ 中构造了一个可由有限个节点值描述的近似子空间 $V_h$。下一步将构造这个空间的基函数，并由此把近似函数写成有限个未知系数的线性组合。

#### 7. 帽函数与有限元近似解的表示

上一小节构造了连续分片线性有限元空间 $V_h$，并说明其中的函数由 $N-1$ 个内部节点值唯一确定。为了将求解未知函数的问题转化为确定有限个系数的问题，需要为 $V_h$ 选取一组便于计算的基函数。

对每个内部节点 $x_i$（$i=1,2,\ldots,N-1$），定义函数 $\phi_i\in V_h$，使它在网格节点上满足

**公式（3.3.15）**

```math
\phi_i(x_j)=
\left\{\begin{aligned}
1,&j=i,\\
0,&j\ne i,
\end{aligned}\right.
\qquad j=0,1,\ldots,N.
```

由于 $\phi_i$ 在每个单元上都是次数不超过一次的多项式，以上节点取值条件唯一确定了它。利用相邻节点之间的线性插值，可得

**公式（3.3.16）**

```math
\phi_i(x)=
\left\{\begin{aligned}
\dfrac{x-x_{i-1}}{x_i-x_{i-1}},
    &x_{i-1}\le x\le x_i,\\[6pt]
\dfrac{x_{i+1}-x}{x_{i+1}-x_i},
    &x_i\le x\le x_{i+1},\\[6pt]
0,&\text{其他位置}.
\end{aligned}\right.
```

函数 $\phi_i$ 在节点 $x_i$ 处取值为 $1$，向左右相邻节点线性下降至 $0$，在其他位置为 $0$。由于图形形似帽子，这类基函数称为**帽函数**（hat function）。它只在相邻的两个单元 $K_i$ 和 $K_{i+1}$ 上可能非零，这一性质称为**局部支撑**。

下图给出一维网格上帽函数的形状，可以看到每个基函数只在相邻两个单元上非零：

![一维网格上的分片线性帽函数](<图片/图 3.3-1.png>)

从图中可以看出，帽函数在对应节点处取值为 $1$，在相邻节点处降为 $0$，其余位置恒为零。这正是它具有局部支撑的原因。
需要注意，图中两端的灰色半帽函数用于示意一般节点形函数。在本节的齐次 Dirichlet 问题中，边界节点值已经固定为零，因此 $V_h$ 的基函数只取内部节点对应的 $\phi_1,\ldots,\phi_{N-1}$。

帽函数的节点取值性质使任意 $u_h\in V_h$ 都可以唯一表示为

**公式（3.3.17）**

```math
u_h(x)=\sum_{j=1}^{N-1}U_j\phi_j(x).
```

事实上，令 $U_j=u_h(x_j)$，则上式右端与 $u_h$ 在全部节点上的取值相同；又因为二者在每个单元上都是一次多项式，所以它们在整个区间上相同。

反过来，令 $x=x_i$，利用 $\phi_j(x_i)=1$（当 $j=i$）和 $\phi_j(x_i)=0$（当 $j\ne i$），得到

**公式（3.3.18）**

```math
u_h(x_i)=\sum_{j=1}^{N-1}U_j\phi_j(x_i)=U_i,
\qquad i=1,\ldots,N-1.
```

因此，$U_i$ 就是有限元近似解在节点 $x_i$ 处的函数值。结合前面的唯一性结论，$\phi_1,\ldots,\phi_{N-1}$ 构成了 $V_h$ 的一组基。

回到导览中的两单元网格，它只有一个内部节点 $x_1=1/2$，因而 $u_h(x)=U_1\phi_1(x)$。这里的 $U_1$ 正是折线中点尚待确定的高度。一般情况下，有限元节点值 $U_i$ 是未知量，不能预先认为它等于精确解的节点值 $u(x_i)$。

#### 8. Galerkin 方法：建立有限维弱问题

通过帽函数展开，近似函数 $u_h$ 已经由 $N-1$ 个未知系数 $U_1,\ldots,U_{N-1}$ 表示。但是，仅有这一表示还不能确定这些系数。接下来需要利用前面建立的弱形式，给出确定它们的方程。

原弱问题要求：求 $u\in V$，使积分关系对任意 $v\in V$ 成立。有限元方法将试探函数和检验函数都限制在子空间 $V_h\subset V$ 中，得到以下 **Galerkin 有限元问题**：求 $u_h\in V_h$，使得

**公式（3.3.19）**

```math
\int_0^1u_h'(x)v_h'(x)\,\mathrm{d}x
=\int_0^1f(x)v_h(x)\,\mathrm{d}x,
\qquad\forall v_h\in V_h.
```

这里，$u_h$ 所在的试探空间和 $v_h$ 所在的检验空间均为 $V_h$，这就是本节所采用的 **Galerkin 方法**。与原弱问题相比，离散后只要求积分关系对 $V_h$ 中的全部检验函数成立，而不要求对整个 $V$ 中的全部函数成立。

虽然上式包含“任意检验函数”，但 $V_h$ 已经是有限维空间。由于帽函数 $\phi_1,\ldots,\phi_{N-1}$ 构成它的一组基，且积分关系对检验函数是线性的，只需依次取 $v_h=\phi_i$（$i=1,\ldots,N-1$），即可得到 $N-1$ 个方程，用来确定 $N-1$ 个节点未知量。

至此，我们不仅用有限个系数表示了有限元近似解，还得到了确定这些系数的有限个方程。下一部分将把积分方程整理成线性方程组，并介绍逐单元计算与整体装配。

### 关键推导：让结论有依据

#### 1. 从 Galerkin 方程得到线性方程组

上一部分已经说明，$\phi_1,\ldots,\phi_{N-1}$ 构成有限元空间 $V_h$ 的一组基。由于 Galerkin 积分关系对检验函数是线性的，只需依次取 $v_h=\phi_i$（$i=1,\ldots,N-1$）。于是有限维弱形式可写为

**公式（3.3.20）**

```math
\int_0^1 u_h'(x)\phi_i'(x)\,\mathrm{d}x
=\int_0^1 f(x)\phi_i(x)\,\mathrm{d}x,
\qquad i=1,\ldots,N-1.
```

由上一小节的帽函数展开式，有限元近似解为

**公式（3.3.21）**

```math
u_h(x)=\sum_{j=1}^{N-1}U_j\phi_j(x).
```

在每个单元内部求导，得到

**公式（3.3.22）**

```math
u_h'(x)=\sum_{j=1}^{N-1}U_j\phi_j'(x).
```

这里的导数可按分段导数理解：虽然帽函数在个别节点处可能没有经典导数，但这不影响上述积分的计算。

将展开式代入 Galerkin 积分关系，并交换有限求和与积分的顺序，得

**公式（3.3.23）**

```math
\sum_{j=1}^{N-1}U_j
\int_0^1\phi_j'(x)\phi_i'(x)\,\mathrm{d}x
=\int_0^1 f(x)\phi_i(x)\,\mathrm{d}x,
\qquad i=1,\ldots,N-1.
```

定义**刚度矩阵**（stiffness matrix）$K$ 和**载荷向量**（load vector）$F$ 的分量为

**公式（3.3.24）**

```math
\begin{aligned}
K_{ij}&=\int_0^1\phi_j'(x)\phi_i'(x)\,\mathrm{d}x,\\
F_i&=\int_0^1 f(x)\phi_i(x)\,\mathrm{d}x,
\qquad i,j=1,\ldots,N-1.
\end{aligned}
```

这样，上面的积分方程就成为

**公式（3.3.25）**

```math
\sum_{j=1}^{N-1}K_{ij}U_j=F_i,
\qquad i=1,\ldots,N-1.
```

将各个方程组合起来，便得到线性方程组

**公式（3.3.26）**

```math
KU=F,
\qquad
U=\begin{bmatrix}U_1&U_2&\cdots&U_{N-1}\end{bmatrix}^{\mathsf T}.
```

其中，$K\in\mathbb{R}^{(N-1)\times(N-1)}$，$F\in\mathbb{R}^{N-1}$，$U$ 是由内部节点未知值组成的向量。求得 $U$ 后，便可由帽函数展开式重构近似解 $u_h$。

需要注意：这里的 $K$ 和 $F$ *只对应内部节点自由度*，因为两端节点值已由齐次 Dirichlet 边界条件给定。后面介绍逐单元装配时，为了统一处理每个单元的两个端点，将先形成包含全部节点的装配矩阵和向量，再处理边界自由度；两种矩阵应使用不同记号。

#### 2. 从整体积分到逐单元计算

虽然刚度矩阵和载荷向量已经有了明确的积分表达式，但如何实际计算这些积分，还需要结合网格和帽函数的局部结构。

前面把区间 $[0,1]$ 划分为 $N$ 个单元 $K_e=[x_{e-1},x_e]$。由于整个区间上的积分等于各单元积分之和，因此

**公式（3.3.27）**

```math
\begin{aligned}
K_{ij}
&=\sum_{e=1}^{N}\int_{K_e}\phi_j'(x)\phi_i'(x)\,\mathrm{d}x,\\
F_i
&=\sum_{e=1}^{N}\int_{K_e}f(x)\phi_i(x)\,\mathrm{d}x.
\end{aligned}
```

这表明，整体矩阵和向量的各个分量，都可以由单元上的积分贡献累加得到。

进一步，帽函数 $\phi_i$ 只在节点 $x_i$ 左右的两个相邻单元上可能非零。因此，当 $|i-j|>1$ 时，$\phi_i'$ 和 $\phi_j'$ 不会在同一个单元内部同时非零，从而有

**公式（3.3.28）**

```math
K_{ij}=0,\qquad |i-j|>1.
```

也就是说，对本节的一维连续分片线性有限元，刚度矩阵 $K$ 只有主对角线及其相邻两条对角线上可能出现非零元素，即它是一个**三对角稀疏矩阵**。

在每个单元内部，最多只有与该单元两个端点对应的节点形函数非零。因此，可以先计算这个单元产生的小矩阵和小向量，再按照局部节点与全局节点的对应关系，将各单元贡献累加到整体矩阵和向量的相应位置。这一过程称为**装配**（assembly）。

为了清楚展示单元计算与装配过程，后文将首先使用包含全部节点的全局量 $K^{\mathrm{all}}$、$F^{\mathrm{all}}$。对本节的齐次 Dirichlet 边界条件，消去边界自由度后，其内部节点子系统恰好对应前面得到的 $KU=F$。下面先计算一个线性单元的局部刚度矩阵。

#### 3. 推导线性单元的局部刚度矩阵

上一小节已经说明，整体刚度矩阵中的积分可以分解为各单元上的积分。为了计算这些单元贡献，考虑第 $e$ 个单元

**公式（3.3.29）**

```math
K_e=[x_{e-1},x_e],\qquad
h_e=x_e-x_{e-1}>0,\qquad e=1,2,\ldots,N.
```

在 $K_e$ 上，线性函数由两个端点值唯一确定。为此，定义两个**局部形函数**：

**公式（3.3.30）**

```math
N_1(x)=\frac{x_e-x}{h_e},\qquad
N_2(x)=\frac{x-x_{e-1}}{h_e},\qquad x\in K_e.
```

其中，$N_1$ 在左端点取 $1$、右端点取 $0$；$N_2$ 则恰好相反。它们分别对应左、右端点的节点值。设 $U_i=u_h(x_i)$，则有限元近似函数在该单元上的表达式为

**公式（3.3.31）**

```math
u_h(x)=U_{e-1}N_1(x)+U_eN_2(x),\qquad x\in K_e.
```

这里省略了局部形函数对单元编号 $e$ 的依赖；对于内部节点，它们正是前面全局帽函数在该单元上的限制。局部计算同时保留单元两端的节点，但全局有限元空间 $V_h$ 的独立未知量只对应内部节点。对于本节的齐次 Dirichlet 问题，边界节点值已知，即 $U_0=U_N=0$。

对两个局部形函数求导，得到

**公式（3.3.32）**

```math
\bigl(N_1\bigr)'(x)=-\frac{1}{h_e},\qquad
\bigl(N_2\bigr)'(x)=\frac{1}{h_e}.
```

与整体刚度矩阵的定义相对应，第 $e$ 个单元的**局部刚度矩阵**定义为

**公式（3.3.33）**

```math
K^{(e)}=
\begin{bmatrix}
\displaystyle\int_{K_e}\bigl((N_1)'\bigr)^2\,\mathrm{d}x &
\displaystyle\int_{K_e}(N_1)'(N_2)'\,\mathrm{d}x\\[10pt]
\displaystyle\int_{K_e}(N_2)'(N_1)'\,\mathrm{d}x &
\displaystyle\int_{K_e}\bigl((N_2)'\bigr)^2\,\mathrm{d}x
\end{bmatrix}.
```

由于形函数的导数在单元内均为常数，例如

**公式（3.3.34）**

```math
\begin{aligned}
\int_{K_e}\bigl((N_1)'\bigr)^2\,\mathrm{d}x
&=\frac{1}{h_e^2}(x_e-x_{e-1})=\frac{1}{h_e},\\
\int_{K_e}(N_1)'(N_2)'\,\mathrm{d}x
&=-\frac{1}{h_e^2}(x_e-x_{e-1})=-\frac{1}{h_e}.
\end{aligned}
```

其余两项同理，于是得到

**公式（3.3.35）**

```math
K^{(e)}=\frac{1}{h_e}
\begin{bmatrix}1&-1\\-1&1\end{bmatrix}.
```

这个结果表明，对当前的一维 Poisson 问题，线性单元的局部刚度矩阵只由单元长度 $h_e$ 决定。它描述的是该单元对整体矩阵的贡献，而不是一个需要单独求解的方程组。

#### 4. 计算局部载荷向量

除了刚度矩阵，还需要计算源项 $f(x)$ 对各节点的贡献。与整体载荷向量的定义对应，第 $e$ 个单元的**局部载荷向量**为

**公式（3.3.36）**

```math
F^{(e)}=
\begin{bmatrix}F_1^{(e)}\\F_2^{(e)}\end{bmatrix}
=
\begin{bmatrix}
\displaystyle\int_{K_e}f(x)N_1(x)\,\mathrm{d}x\\[8pt]
\displaystyle\int_{K_e}f(x)N_2(x)\,\mathrm{d}x
\end{bmatrix}.
```

它的两个分量分别表示该单元对左、右端点载荷的贡献。若源项在单元上为常数 $f(x)=c$，由于两个局部形函数在单元上的积分均为 $h_e/2$，便有

**公式（3.3.37）**

```math
F^{(e)}=\frac{ch_e}{2}\begin{bmatrix}1\\1\end{bmatrix}.
```

例如，导览中的模型取 $f(x)=1$，因此每个单元的局部载荷向量为 $\frac{h_e}{2}[1,1]^{\mathsf T}$。对于一般的 $f(x)$，若积分可以解析计算，就直接求积分；否则可采用 Gauss 求积等数值积分方法。

至此，每个单元都产生了一对局部计算结果：刚度矩阵 $K^{(e)}$ 与载荷向量 $F^{(e)}$。下一步需要将它们组合成描述整个区间的矩阵和向量。

#### 5. 从局部到整体：装配

所谓**装配**（assembly），就是根据局部节点与全局节点的对应关系，将各单元的贡献累加到整体矩阵和载荷向量中。为了与前面只包含内部自由度的 $K$、$F$ 区分，这里将尚未处理边界条件、包含全部节点的装配结果记为 $K^{\mathrm{all}}$ 和 $F^{\mathrm{all}}$。

回到导览中的两单元网格，取

**公式（3.3.38）**

```math
x_0=0,\qquad
x_1=\frac12,\qquad
x_2=1.
```

两个单元分别为 $K_1=[x_0,x_1]$ 和 $K_2=[x_1,x_2]$，长度均为 $h_1=h_2=1/2$。根据上一小节的结果，两个局部刚度矩阵相同：

**公式（3.3.39）**

```math
K^{(1)}=K^{(2)}=
2\begin{bmatrix}1&-1\\-1&1\end{bmatrix}
=\begin{bmatrix}2&-2\\-2&2\end{bmatrix}.
```

第一个单元的局部节点对应全局节点 $(0,1)$，因此对全部节点组成的矩阵，其贡献位于第 $0,1$ 行及第 $0,1$ 列：

**公式（3.3.40）**

```math
\begin{bmatrix}
2&-2&0\\-2&2&0\\0&0&0
\end{bmatrix}.
```

第二个单元对应全局节点 $(1,2)$，其贡献位于第 $1,2$ 行及第 $1,2$ 列：

**公式（3.3.41）**

```math
\begin{bmatrix}
0&0&0\\0&2&-2\\0&-2&2
\end{bmatrix}.
```

将这两部分逐项相加，得到**未经边界条件处理的完整装配矩阵**

**公式（3.3.42）**

```math
K^{\mathrm{all}}=
\begin{bmatrix}
2&-2&0\\-2&4&-2\\0&-2&2
\end{bmatrix}.
```

下面的示意图直观地展示了两个单元的局部刚度矩阵如何按共享节点累加装配成整体刚度矩阵：

![两单元一维有限元的局部刚度矩阵到整体刚度矩阵的装配示意](<图片/图 3.3-2.png>)

如上图所示，中间节点 $x_1$ 同时属于左右两个单元，因此两个单元对该节点的刚度贡献相加，使完整装配矩阵对应的对角元素成为 $2+2=4$。这正体现了*共享节点处累加贡献*的装配规则。

载荷向量也按照相同的节点对应关系装配。若继续取导览中的 $f(x)=1$，由于两个单元长度均为 $1/2$，其局部载荷向量都是

**公式（3.3.43）**

```math
F^{(1)}=F^{(2)}=\begin{bmatrix}1/4\\1/4\end{bmatrix}.
```

因此，完整装配载荷向量为

**公式（3.3.44）**

```math
F^{\mathrm{all}}=
\begin{bmatrix}1/4\\1/4\\0\end{bmatrix}
+
\begin{bmatrix}0\\1/4\\1/4\end{bmatrix}
=\begin{bmatrix}1/4\\1/2\\1/4\end{bmatrix}.
```

应当注意，$K^{\mathrm{all}}$ 与 $F^{\mathrm{all}}$ 只是包含全部节点的装配结果，不能直接当作前文内部自由度方程 $KU=F$ 中的 $K$ 和 $F$。本节的齐次 Dirichlet 边界条件已给定 $U_0=U_2=0$，所以真正需要求解的只有内部节点值 $U_1$。如何从完整装配结果得到最终的求解系统，将在下一小节说明。

#### 6. 边界条件怎样进入最终计算？

上一小节通过逐单元装配，得到了包含全部节点的刚度矩阵 $K^{\mathrm{all}}$ 和载荷向量 $F^{\mathrm{all}}$。但这还不是可以直接求解的线性系统，因为本节的**齐次 Dirichlet 边界条件**已经规定

**公式（3.3.45）**

```math
u(0)=u(1)=0,\qquad U_0=U_N=0.
```

也就是说，两端节点值是已知的，真正需要确定的只有内部节点值。更重要的是，前面建立的弱形式仅要求积分关系对端点为零的检验函数成立，因此不能直接要求完整装配矩阵的每一行都满足 $K^{\mathrm{all}}U^{\mathrm{all}}=F^{\mathrm{all}}$。

将内部节点集合记为 $I=\{1,\ldots,N-1\}$，边界节点集合记为 $B=\{0,N\}$。为了书写方便，按内部节点和边界节点的顺序排列相应的矩阵与向量：

**公式（3.3.46）**

```math
K^{\mathrm{all}}=
\begin{bmatrix}
K_{II}^{\mathrm{all}}&K_{IB}^{\mathrm{all}}\\
K_{BI}^{\mathrm{all}}&K_{BB}^{\mathrm{all}}
\end{bmatrix},\qquad
F^{\mathrm{all}}=
\begin{bmatrix}F_I^{\mathrm{all}}\\F_B^{\mathrm{all}}\end{bmatrix},\qquad
U^{\mathrm{all}}=
\begin{bmatrix}U_I\\U_B\end{bmatrix}.
```

这里，$U_I$ 是内部节点未知值组成的向量，$U_B$ 是已知的边界节点值向量。由于检验函数在两端为零，有限元弱形式所对应的是**内部节点方程**

**公式（3.3.47）**

```math
K_{II}^{\mathrm{all}}U_I+K_{IB}^{\mathrm{all}}U_B
=F_I^{\mathrm{all}}.
```

将已知的边界节点值移到右端，得到真正需要求解的系统：

**公式（3.3.48）**

```math
K_{II}^{\mathrm{all}}U_I
=F_I^{\mathrm{all}}-K_{IB}^{\mathrm{all}}U_B.
```

对于本节的齐次 Dirichlet 边界条件，$U_B=0$，因此上式简化为

**公式（3.3.49）**

```math
K_{II}^{\mathrm{all}}U_I=F_I^{\mathrm{all}}.
```

这恰好是前面由内部节点帽函数直接推导的 $KU=F$，其中 $K=K_{II}^{\mathrm{all}}$、$F=F_I^{\mathrm{all}}$、$U=U_I$。

现在完成导览中的两单元计算。上一小节已经得到

**公式（3.3.50）**

```math
K^{\mathrm{all}}=
\begin{bmatrix}
2&-2&0\\
-2&4&-2\\
0&-2&2
\end{bmatrix},\qquad
F^{\mathrm{all}}=
\begin{bmatrix}
\frac14\\
\frac12\\
\frac14
\end{bmatrix}.
```

因为只有中间节点 $x_1=1/2$ 是内部节点，所以只需取矩阵的中间一行，并代入 $U_0=U_2=0$：

**公式（3.3.51）**

```math
-2U_0+4U_1-2U_2=\frac12
\quad\Longrightarrow\quad
4U_1=\frac12
\quad\Longrightarrow\quad
U_1=\frac18.
```

于是有限元近似解为 $u_h(x)=\frac18\phi_1(x)$。这个中点值与导览中精确解 $u(x)=x(1-x)/2$ 在 $x=1/2$ 处的取值一致，但两单元折线在单元内部仍不是精确解。

由此可见，施加 Dirichlet 边界条件不是求解结束后才将两端节点值“补成零”，而是在确定未知自由度和建立最终求解系统时就必须考虑。完整装配矩阵的边界节点行并不需要与 $F_B^{\mathrm{all}}$ 逐项相等；这些位置由给定的边界条件约束。
