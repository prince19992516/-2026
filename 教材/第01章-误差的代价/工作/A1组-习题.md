## 题1：对应1.1 浮点数与舍入误差

- **完整题面：** 准确输入为十进制有理数 $1/5$。假想二进制格式采用规格化表示、有效精度 $p=4$、舍入到最近值；实际实验比较 IEEE binary32 和 binary64（最近舍入）。
- **推导或概念小问：** 手算 $1/5$ 的二进制展开、$p=4$ 的舍入值、绝对与相对误差；说明 $0.625$ 为何能被有限二进制精确表示，而 $0.2$ 不能。
- **代码或结果分析小问：** 分别把 `numpy.float32("0.2")` 和 `numpy.float64("0.2")` 构造为相应浮点数，提交实际存储值、对准确 $1/5$ 的有符号误差、绝对误差、相对误差。可用 Python 标准库、NumPy 和 `Decimal.from_float`；参考必须用准确的 `Decimal("0.2")` 或有理数 $1/5$，不得把浮点值的格式化输出作为参考。
- **陷阱辨析小问：** 辨析以下说法：“屏幕都显示0.2，所以两个值都准确；binary64机器精度约为 $10^{-16}$，因此任何数值计算的绝对误差都不超过 $10^{-16}$。”
提交格式（按测试输入扩展行数）：

### 存储与误差

| 类型 | 实际存储值 | 有符号误差 | 绝对误差 | 相对误差 |
| --- | --- | --- | --- | --- |
|  |  |  |  |  |


- 结果核对： 手算值和误差应精确；实测值与 IEEE 舍入一致，误差报告至少6位有效数字；清楚区分显示、单步相对舍入界与最终算法误差。
- 难度、预计课后用时与来源： 基础，约25分钟；本章§1.1及[正文参考资料](#ch01-ref-goldberg)中的 Goldberg、Python 浮点文献。

## 题2：等价公式与差分步长（对应1.2）

- **完整题面：** 计算 $d(x)=\sqrt{x+1}-\sqrt{x}$：binary32 取准确整数 $x=2^{24}$，binary64 取 $x=2^{53}$。另以 $D_h=[e^{1+h}-e]/h$ 近似 $e$，步长集合为 $\{10^{-1},10^{-4},10^{-8},10^{-12},10^{-16}\}$。所有低精度运算在所标精度内完成；高精度参考使用准确 $x$ 和实际存储的 $h$。
- **推导或概念小问：** 有理化 $d(x)$；说明为何直接式可能为零而有理化式仍为正。求 $D_h-e$ 的首个非零截断项；仅在舍入项可由 $Bu/h$ 表述的模型下，推导平衡步长量级并说明 $B$ 依赖运算路径。
- **代码或结果分析小问：** binary32只取 $x=2^{24}$，binary64只取 $x=2^{53}$；分别比较直接式和 $1/(\sqrt{x+1}+\sqrt{x})$，列参考值及绝对误差。对所列五个 $h$ 提交 $D_h$、绝对误差、`fl(1+h)==1` 的真值，并指出**本集合**最优步长。可用 Python 标准库、NumPy 和至少80位十进制参考；表或误差—步长图均可。
- **陷阱辨析小问：** 辨析以下说法：“步长越小越准；代数等价保证浮点实现同样可靠。”指出各自的失败输入及原因。
提交格式（按测试输入扩展行数）：

### 差额

| 类型与 $x$ | 参考值 | 直接值 | 直接绝对误差 | 有理化值 | 有理化绝对误差 |
| --- | --- | --- | --- | --- | --- |
|  |  |  |  |  |  |

### 差分

| 类型 | 实际 $h$ | $D_h$ | 绝对误差 | $\mathrm{fl}(1+h)=1$？ |
| --- | --- | --- | --- | --- |
|  |  |  |  |  |


- 结果核对： 有理化恒等式、$D_h-e=eh/2+O(h^2)$ 和平衡量级正确；失败区间、误差指标、独立参考与运行环境可复核。不同数学库引起的末位或实测最优点差异，若有数据支持，可接受。
- 难度、预计课后用时与来源： 中等，约40分钟；本章§1.2及[正文参考资料](#ch01-ref-higham)中的 Higham 文献。

## 题3：对应1.3 条件数与稳定性

- **完整题面：** 实验A对 $F(x)=\ln x$ 从 $x=1.0001$ 作正向相对扰动 $\eta$，观察准确输出的相对变化。实测：$\eta=10^{-8}$ 时输出变化 $1.000049994\times10^{-4}$，$\eta=10^{-6}$ 时变化 $1.000049499\times10^{-2}$。实验B以 $I_n=e^{-1}\int_0^1 t^ne^t\,dt$ 为准确目标，分别用 $I_n=1-nI_{n-1}$、初值 $\widehat I_0=0.6321$ 正向递推，以及 $I_{n-1}=(1-I_n)/n$、终值 $\widehat I_9=0.0684$ 反向递推（binary64）。数据如下：

  | $n$ | 准确参考 | 正向值 | 反向值 |
  |---:|---:|---:|---:|
  | 0 | 0.63212056 | 0.63210000 | 0.63212062 |
  | 8 | 0.10093197 | -0.72800000 | 0.10351111 |
  | 9 | 0.09161229 | 7.55200000 | 0.06840000 |

- **推导或概念小问：** 求 $F$ 的相对条件数与两种递推的初始误差传播因子；依表判断实验A的主要现象和实验B的主要现象，并解释反向终值为何仍不准确。
- **代码或结果分析小问：** 用正项级数 $I_n=e^{-1}\sum_{k=0}^{\infty}1/[k!(n+k+1)]$（至少100项且核验尾项，推导见正文选读“怎样保证参考值可靠”）或高精度数值积分，独立复核 $I_0,I_8,I_9$；报告两条递推各自的绝对误差。区分初值误差与新增舍入误差。
- **陷阱辨析小问：** 辨析以下说法：“反向在 $n=0$ 很准，故原问题良态；对数问题病态，故对数算法必定错误。”说明条件数、输入模型及算法稳定性分别回答什么。
提交格式（按测试输入扩展行数）：

### 积分递推

| $n$ | 独立参考 | 正向值 | 正向绝对误差 | 反向值 | 反向绝对误差 |
| --- | --- | --- | --- | --- | --- |
|  |  |  |  |  |  |

另注明参考精度与尾项界。


- 结果核对： $\kappa_F(x)=1/|\ln x|$，忽略新增舍入时，正向初值误差的大小按 $n!$ 放大；从末端 $N$ 反向递推到 $n$，末值误差的大小乘以 $n!/N!$，本题 $N=9$；对 $n=0,8,9$ 分别给出正向值与反向值的绝对误差，共六个误差值。说明积分定义与任意初值递推问题有不同条件性。
- 难度、预计课后用时与来源： 中等，约40分钟；本章§1.3及[正文参考资料](#ch01-ref-higham)中的 Higham 文献。

## 题4：对应1.4 AI关联——训练中的数值问题

- **完整题面：** 待辨析的实现建议：“Softmax先直接算 $e^{z_i}$，除以指数之和即可。只要训练损失下降、程序没有NaN，就说明数值实现稳定。”测试 logits $A=(0,1,2)$、$B=(1000,1001,1002)$、$C=(-1000,-999,-998)$；另取 $T=(0,-1000)$，真实类别为第2类。比较 binary32 和 binary64。**不要求运行完整训练**。
- **推导或概念小问：** 人工写出减最大值的 Softmax、指数和的对数（log-sum-exp）和交叉熵；对有限 logits 证明 $1\le\sum_i e^{z_i-m}\le n$，解释 $T$ 的低概率类可能下溢而交叉熵仍可计算。
- **代码或结果分析小问：** 对 $A,B,C$，在两种精度下运行直接版与平移版；提交“输出全有限”、$E_\infty=\max_i|\hat p_i-p_i^{ref}|$、$E_\Sigma=|\sum_i\hat p_i-1|$。在 $T$ 上比较先求概率再取负对数与稳定对数路径。参考概率至少80位并以更高精度复查。
- **陷阱辨析小问：** 逐条辨析建议；选出概率输出全部有限、但先求概率的损失路径仍失败的输入，解释原因；判断损失下降能否证明数值实现正确，还应检查哪些量，并结合本题测试说明。
提交格式（按测试输入扩展行数）：

### 概率

| 输入组 | 类型 | 实现 | 全有限？ | $E_\infty$ | $E_\Sigma$ |
| --- | --- | --- | --- | --- | --- |
|  |  |  |  |  |  |

### $T$ 的损失

| 类型 | 尾概率 | 概率路径损失 | 对数路径损失 |
| --- | --- | --- | --- |
|  |  |  |  |


- 结果核对： 两种精度中直接版 $B,C$ 出现非有限输出；平移版 $A,B,C$ 有限，且本题三维测试的 $E_\infty<10^{-6}$（binary32）、$E_\infty<10^{-14}$（binary64）。须报告每组 $E_\Sigma$ 实测值。$T$ 的概率路径损失为非有限，而对数路径约1000。报告环境、代码和全部输入；阈值不推广到任意维数或极小尾部概率，不能以归一化替代尾概率的相对误差检查。
- 难度、预计课后用时与来源： 中等，约45分钟；本章§1.4及[正文参考资料](#ch01-ref-softmaxpaper)中的 Blanchard、Higham、Higham 文献。
