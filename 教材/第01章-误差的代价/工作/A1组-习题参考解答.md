## 题1：对应1.1 浮点数与舍入误差

小问索引：(a)推导；(b)实现、参考与结果；(c)辨析。

- 条件与符号： 准确 $x=1/5$，存储值 $\hat x$；有符号误差为 $\hat x-x$，绝对误差为 $|\hat x-x|$，相对误差为 $|\hat x-x|/|x|$。假想 $p=4$ 的首位二进制数字计入有效位数。
- 手动推导或概念解释（以下为AI辅助整理，待组员逐步核验）： $1/5=(0.0011001100\ldots)_2=(1.1001100\ldots)_2 2^{-3}$；保留四位后的邻数为0.1875与0.203125，中点为0.1953125。准确值0.2严格超过中点，故最近舍入为 $(1.101)_2 2^{-3}=13/64=0.203125$。绝对误差 $1/320=0.003125$，相对误差 $1/64=0.015625$。$0.625=5/8=(0.101)_2$ 可有限表示；$1/5$ 因分母含因子5，二进制展开不终止。
- 实现位置与独立参考： Notebook §题1，代码单元 `exercise-1`。用 `Decimal("0.2")` 表示准确值，`Decimal.from_float(float(value))` 揭示存储值；二者不同路径。最近舍入选择与准确值距离最小的机器数，中点时选择有效数最低位为零者；文献来源为 Goldberg。
- 实际输出、误差和容差理由：两种格式的准确存储值分别为：
  - float32：`0.20000000298023223876953125`。
  - float64：`0.200000000000000011102230246251565404236316680908203125`。

  | 类型 | 有符号误差 | 绝对误差 | 相对误差 |
  |---|---:|---:|---:|
  | binary32 | $+2.98023223877\times10^{-9}$ | $2.98023223877\times10^{-9}$ | $1.49011611938\times10^{-8}$ |
  | binary64 | $+1.11022302463\times10^{-17}$ | $1.11022302463\times10^{-17}$ | $5.55111512313\times10^{-17}$ |

  两者格式化到小数1位均显示0.2。两项误差为正，故绝对误差恰与有符号误差的大小相同。存储值由IEEE舍入确定；有限位打印的误差至少保留6位有效数字。
- 陷阱的正确解释及适用范围： 显示精度不等于存储值准确性。机器单位舍入误差只在特定单步浮点模型下控制相对舍入误差，并非任意算法最终绝对误差的上界；抵消、累积、条件性、范围问题都可能主导。binary64中 $10^{16}+1$ 舍为 $10^{16}$，相对于准确整数之和的绝对误差为1。

## 题2：等价公式与差分步长（对应1.2）

小问索引：(a)推导；(b)实现、参考与结果；(c)辨析。

- 条件与符号： binary32取准确整数 $x=2^{24}$，binary64取 $x=2^{53}$；差分参考使用实际存储的 $h$。$d(x)>0$；导数准确值为 $e$。
- 手动推导或概念解释（以下为AI辅助整理，待组员逐步核验）： $d(x)=1/(\sqrt{x+1}+\sqrt{x})$。对有效精度为 $p$ 的格式，$x=2^p$ 右侧的相邻数是 $x+2$。准确的 $x+1$ 恰在中点，按最近舍入、遇中点取偶数的规则选择最低有效位为0的 $x$，故 `fl(x+1)==x`，直接版返回0，而实数值仍为正。泰勒展开得 $D_h=e+(e/2)h+O(h^2)$。在 $A,B>0$ 的模型 $E(h)=Ah+Bu/h$ 下，$E\prime(h)=A-Bu/h^2=0$ 给出 $h_*=\sqrt{Bu/A}$；$E\prime\prime(h)=2Bu/h^3>0$，所以这是模型最小点。平衡量级为 $\sqrt u$；系数取决于实现，不能拿它当精确实测极小点。
- 实现位置与独立参考： Notebook §题2，代码单元 `exercise-2`。准确整数输入经100位 `Decimal.sqrt` 得有理化参考，120位复查；导数参考为100位 `Decimal(1).exp()`，120位复查。数值误差以实际存储的浮点值计算。
- 实际输出、误差和容差理由：

  | 类型、$x$ | 参考 $d(x)$ | 直接值 | 有理化值 | 有理化绝对误差 |
  |---|---:|---:|---:|---:|
  | binary32，$2^{24}$ | $1.220703106810\times10^{-4}$ | 0 | $1.220703125\times10^{-4}$ | $1.819\times10^{-12}$ |
  | binary64，$2^{53}$ | $5.268356063862\times10^{-9}$ | 0 | $5.26835606386\times10^{-9}$ | $3.208\times10^{-25}$ |

  | 类型 | $h$ | $D_h$ | 绝对误差 | `fl(1+h)==1` |
  |---|---:|---:|---:|---|
  | binary32 | $10^{-1}$ | 2.85884141922 | $1.405596\times10^{-1}$ | 否 |
  | binary32 | $10^{-4}$ | 2.71797180176 | $3.100267\times10^{-4}$ | 否 |
  | binary32 | $10^{-8},10^{-12},10^{-16}$ | 0 | $2.718282$ | 是 |
  | binary64 | $10^{-1}$ | 2.85884195487 | $1.405601\times10^{-1}$ | 否 |
  | binary64 | $10^{-4}$ | 2.71841774708 | $1.359186\times10^{-4}$ | 否 |
  | binary64 | $10^{-8}$ | 2.71828182186 | $6.602751\times10^{-9}$ | 否 |
  | binary64 | $10^{-12}$ | 2.71871414270 | $4.323142\times10^{-4}$ | 否 |
  | binary64 | $10^{-16}$ | 0 | $2.718282$ | 是 |

  binary32合并列出的三个失败步长分别运行，结果均为0。在所列五个步长内，binary32最优为 $10^{-4}$，binary64最优为 $10^{-8}$。不同数学库可能改变末位或实测集合内的最优点；可接受可复现且解释明确的差异，不能接受未说明环境或以另一低精度公式代替参考。
- 陷阱的正确解释及适用范围： 缩小步长会减少截断误差，但分子抵消与输入舍入会令总误差回升，最终可得到0。实数等价不保证浮点路径同样可靠；有理化也不自动解决所有极端尺度的范围问题。

## 题3：对应1.3 条件数与稳定性

小问索引：(a)推导；(b)实现、参考与结果；(c)辨析。

- 条件与符号： 实验A的扰动作用于准确输入；实验B真实目标由积分定义，递推仅是两种实现。$\delta_n$ 表示相应近似与真实 $I_n$ 的差。
- 手动推导或概念解释（以下为AI辅助整理，待组员逐步核验）： 对 $F(x)=\ln x$，$\kappa_F(x)=|xF'(x)/F(x)|=1/|\ln x|$，在1.0001约为10000.4999917。积分分部积分给出 $I_0=1-e^{-1}$、$I_n=1-nI_{n-1}$。忽略新增舍入时，正向 $\delta_n=(-n)(-(n-1))\cdots(-1)\delta_0=(-1)^n n!\delta_0$；反向 $\delta_{n-1}=-\delta_n/n$，从末端 $N$ 到 $n$ 有 $\delta_n=(-1)^{N-n}(n!/N!)\delta_N$（$0\le n\le N$）。大小因子来自 $|\delta_n|=|\delta_N|/[N(N-1)\cdots(n+1)]=(n!/N!)|\delta_N|$（$n<N$）：向前反复乘整数，向后反复除整数，$n=N$ 时因子为1。本题 $N=9$，末值误差传到 $n=0,8,9$ 时的大小因子依次为 $1/9!$、$1/9$、1；反向终值本身仍是给定粗近似。
- 实现位置与独立参考： Notebook §题3，代码单元 `exercise-3`。实验A用100位十进制对数；(b)的参考值精度核验：实验B用正项级数 $I_n=e^{-1}\sum_{k\ge0}1/[k!(n+k+1)]$ 前160项，不调用被检查的递推生成参考。令 $a_k=1/[k!(n+k+1)]$，$k\ge160$ 时有 $a_{k+1}/a_k=(n+k+1)/[(k+1)(n+k+2)]<1/161$，故 $0<R_{160}<e^{-1}/[160!(n+161)]\cdot1/(1-1/161)$。对 $n=0,8,9$，尾项界均小于 $4.88\times10^{-288}$。另以120位重算，报告位数不变；提高运算精度不能替代尾项界。
- 实际输出、误差和容差理由： 实验A在 $\eta=10^{-8}$ 与 $10^{-6}$ 时输出相对变化约为 $1.000049994\times10^{-4}$ 与 $1.000049499\times10^{-2}$，分别与一阶预测吻合。实验B：

  | $n$ | 参考 | 正向绝对误差 | 反向绝对误差 |
  |---:|---:|---:|---:|
  | 0 | 0.6321205588 | $2.05588\times10^{-5}$ | $6.39669\times10^{-8}$ |
  | 8 | 0.1009319674 | $8.28932\times10^{-1}$ | $2.57914\times10^{-3}$ |
  | 9 | 0.0916122930 | $7.46039$ | $2.32123\times10^{-2}$ |

  前向在 $n=8$ 得到 -0.728，已违背正积分；在 $n=9$ 得到7.552。该结论主要展示前向初值误差的放大；反向低阶值较准，不能推出反向整张表都准。不同实现的新增舍入可影响最后几位，但前向 $n!$ 与从 $N$ 到 $n$ 的反向 $n!/N!$ 的误差大小因子不变。
- 陷阱的正确解释及适用范围： 某个输出准确，不证明原问题对所有输入扰动良态；对数在近1处相对病态，也不意味着任一对数实现必然错误。若把 $I_0$ 改成任意输入并把递推当成另一个数学问题，其条件数需另作分析；不能与原积分问题混同。

## 题4：对应1.4 AI关联——训练中的数值问题

小问索引：(a)推导；(b)实现、参考与结果；(c)辨析。

- 条件与符号： 题面建议为**教学构造，非真实AI引语**。$p_i$ 是准确Softmax概率，$\hat p_i$ 是浮点计算值；$E_\infty=\max_i|\hat p_i-p_i|$，$E_\Sigma=|\sum_i\hat p_i-1|$。$T$ 的真实类别为第2类。
- 手动推导或概念解释（以下为AI辅助整理，待组员逐步核验）： 令 $m=\max_i z_i$。则 $p_i=e^{z_i-m}/\sum_j e^{z_j-m}$，$\mathrm{LSE}(z)=m+\log\sum_j e^{z_j-m}$，$\ell_y=\log\sum_j e^{z_j-m}-(z_y-m)$。因 $z_i-m\le0$ 且至少一个为0，每项指数在 $(0,1]$，至少一个为1，故 $1\le\sum_j e^{z_j-m}\le n$。$T=(0,-1000)$ 中第2类准确概率约 $5.0759589\times10^{-435}$，两种精度均存为0；但 $\ell_2=1000+\log(1+e^{-1000})\approx1000$ 可由对数式算出。
- 实现位置与独立参考： Notebook §题4，代码单元 `exercise-4`，本Notebook中对应的函数定义。参考概率由100位十进制运算建立，并以120位复查。程序对两种精度同时运行直接指数版和平移版。

  演示中，`np.errstate` 仅用于暂时忽略预期的上溢、下溢、除零和无效运算告警；程序仍检查输出是否有限，忽略告警不改变计算结果。

  平移及对数损失的推导已在本题上方给出，Blanchard、Higham、Higham文献作为研究出处保留。
- 实际输出、误差和容差理由： $A,B,C$ 的准确概率相同，约 $(0.09003057317,0.24472847105,0.66524095577)$。先看B、C的有限性，再看A的误差；避免范围失效不等于每个误差指标都下降。两种实现的指标分别列出；归一化偏差用高精度累加实际存储概率计算。直接版在B、C上为NaN，不能作有限误差比较。

  | 输入 | 类型 | 实现 | 全有限 | $E_\infty$ | $E_\Sigma$ |
  |---|---|---|---|---:|---:|
  | A | binary32 | 直接版 | 是 | $1.96554608\times10^{-8}$ | $7.45058060\times10^{-9}$ |
  | A | binary32 | 平移版 | 是 | $1.23430\times10^{-8}$ | $2.23517\times10^{-8}$ |
  | A | binary64 | 直接版 | 是 | $1.08467934\times10^{-17}$ | $0$ |
  | A | binary64 | 平移版 | 是 | $1.04544\times10^{-16}$ | $1.11022\times10^{-16}$ |
  | B | binary32 | 直接版 | 否 | NaN | NaN |
  | B | binary32 | 平移版 | 是 | $1.23430\times10^{-8}$ | $2.23517\times10^{-8}$ |
  | B | binary64 | 直接版 | 否 | NaN | NaN |
  | B | binary64 | 平移版 | 是 | $1.04544\times10^{-16}$ | $1.11022\times10^{-16}$ |
  | C | binary32 | 直接版 | 否 | NaN | NaN |
  | C | binary32 | 平移版 | 是 | $1.23430\times10^{-8}$ | $2.23517\times10^{-8}$ |
  | C | binary64 | 直接版 | 否 | NaN | NaN |

- 陷阱的正确解释及适用范围： 未出现NaN仍可能出现无穷值；例如 `np.isnan(np.inf)` 和 `np.isfinite(np.inf)` 都为False。本题T的概率为(1,0)，先取负对数得到的正无穷没有NaN，却不是有限值。即使输出全有限，也不能据此判断准确；应分别检查有限性，将概率、损失等量与独立参考比较。损失下降也不说明概率、梯度或参数更新都准确。应以独立参考、分量误差、极端输入和不同精度复算检查。本题只运行函数级CPU实验，**未运行完整模型训练**，不能证明收敛。
