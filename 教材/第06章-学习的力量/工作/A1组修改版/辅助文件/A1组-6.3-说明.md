- Python 统一要求 **3.12.x**；本批实测 3.12.15，PyTorch 2.14.1+cpu（B1 组以 2.6.0+cpu 运行成功，故 2.14.1 非必需），NumPy 2.5.4。

## 3. 为什么 `辅助文件/` 里有 `.txt` 和 `.pt`

- `A1组-6.3-requirements.txt`：复现 Python 3.12.x 环境所需，按交付要求不放根目录；用 UTF-8 重写注释以对应 B2 `CH06-G09-B008`。
- `A1组-6.3-模型检查点.pt`：这是随稿保存的模型权重存档（模型权重，不是代码）。它服务于 `A1组-实验-6.3.ipynb` 的长任务断点恢复：把 `Config.resume` 设为 `True` 即可跳过训练、直接加载该权重评估，因此本交付物内有可直接调用它的代码；保留它同时也是 `bestEpoch=848` 处最优权重的证据。

## 4. 证据边界

本轮**未重训**主实验与消融：所有误差指标仍是随稿批次的保存值。改动集中在数值出处的统一、优化器超参显式化（取值与默认相同，不影响已保存输出）、消融表增补记忆基线列、结论强度降级。`数据/A1组-6.3-消融结果.csv` 的 `memoMean`/`memoMedian`/`ratioToMemo` 三列由 notebook 的 `memorization_baseline()` 按每组自己的数据流复算（该函数只做最近邻检索，不涉及训练），七行比值与正文表 6.3-14 逐项一致；主实验 `N_test=200` 的复算值 0.152286 与 npz 的 `eL2_memo` 均值 1.523e-1 相同，可据此判断复算脚本与原始流程一致。仍未闭环的是：B1 复测、948/848 轨迹在干净环境的逐位复现（机理未定，不归因于 eps）。文献卷期页码已按出版方记录核对。
