## 题1：6.1 PINN原理与实现

1. 由于$(ax+b)''=0$，仿射偏移不会改变内部残差。只施加$u(0)=0$时$b=0$，而$a$仍自由，解不唯一。两个端点一起使用才可排除该自由度。
2. 边界权重为零后，损失无法区分同一二阶导数对应的仿射偏移。网络没有理由一定产生$3x+2$这一特定偏移，也可能偶然给出较小的端点误差；缺少约束是结构性缺陷，不能用某一次偶然结果反驳。该变式为课后扩展，基础实验保留解析反例而不预填未运行数据。
3. 设$u=x(1-x)N$，乘积法则给出$u'=(1-2x)N+x(1-x)N'$，$u''=-2N+2(1-2x)N'+x(1-x)N''$。必须对完整$u$求导，不能遗漏前因子产生的项。两个零端点则由前因子精确保证。
4. 增加配置点可扩充方程检查位置，但固定预算下的网络误差不保证单调下降。配置点分布、初始化及优化是否充分都可能改变结果。应固定评价网格，对每档点数保留多个种子和全部误差；本包基线为64点，16/32点属于学习者扩展。

## 题2：6.2 正问题与反问题

1. 正问题给定$k$求$u$；反问题由方程、边界及观测恢复$k,u$。直接求导可验证$u=\sin(\pi x)/k$。把真值固定在残差中只训练网络，是正问题，不是系数反演。
2. 令$s_j=\sin(\pi x_j)$、$a=1/k$。对$\sum(as_j-y_j)^2$求导得$2\sum s_j(as_j-y_j)=0$，故$\hat a=\sum s_jy_j/\sum s_j^2$。独立零均值同方差噪声下，$\hat a-a_*=\sum s_j\varepsilon_j/\sum s_j^2$，方差为$\sigma^2/\sum s_j^2$。端点$s_j=0$，没有参数信息。正系数估计还要求$\hat a>0$。
3. $\partial_kL_f=-2N_f^{-1}\sum r_{\theta,k}(x_i)u_\theta''(x_i)$。softplus的导数为$dk/d\rho=1/(1+e^{-\rho})$，故$\partial_\rho L=(\partial_kL_f)/(1+e^{-\rho})$。这里网络与$\rho$为独立变量，数据及边界项对$\rho$的直接偏导为零。正性只限制搜索域，所有正$k$仍与端点观测相容。
4. 全部六次主反演和三次边界诊断见Notebook的结构化输出与分析。较弱边界权重10时，含噪边界误差约0.0084；提高至1000后约0.00023，且未放宽检查线。较低的观测RMSE并不能补偿精确边界被破坏。三个启动条件共用一个噪声实现，不能据此给出参数置信区间。
5. 源项为$c\pi^2\sin(\pi x)$时，状态为$(c/k)\sin(\pi x)$。$(c,k)=(1,1.5)$与$(2,3)$产生同一状态。需要独立已知源项幅值或系数，或增加能区分二者的其他物理测量；重复测量相同状态不能打破比值歧义。

$B=b_\theta(a)\in\mathbb R^{N\times p},\quad T=t_\phi(y)\in\mathbb R^{Q\times p},\quad \hat U=B\,T^\top\in\mathbb R^{N\times Q}.$

关键依据：$b_k$ 是**输入函数相关**的系数（branch 把整个 $f$ 压成的特征），$t_k$ 是**位置相关**的基（trunk 在查询点读出的基函数值），内积即 $f$ 在位置 $y$ 处的解。算子 UAT（Chen & Chen 1995；Lu 等 2021）只保证**逼近误差**任意小，**不**保证优化误差与泛化误差。


- **实现位置与独立参考：** 写在本章 Notebook 同号小节（6.3 方法实现与运行 / 误差图表与比较两个代码单元）；独立参考解为二阶中心差分 $O(h^2)$（本 1D 问题可信、可复算）。参考代码：
```python
import numpy as np, torch, torch.nn as nn, matplotlib.pyplot as plt
torch.manual_seed(0); np.random.seed(0)
# --- FD 求解 -u''=f, u(0)=u(1)=0 ---
def fd_solve(M, f):
    h = 1/(M+1)
    A = (2*torch.diag(torch.ones(M))
         - torch.diag(torch.ones(M-1),1) - torch.diag(torch.ones(M-1),-1))/h**2
    return torch.linalg.solve(A, f.T).T            # [n,M]
# --- 一族右端项：先抽系数，再在任意网格求值（保证 branch 输入与标签是同一个 f）---
K = 8; k = torch.arange(1,K+1).float(); dec = k**-1.5
def gen(n): return torch.randn(n,K)*dec, torch.randn(n,K)*dec
def eval_f(a,b,x):
    X=x[None,:]; KK=k[:,None]
    return (a[:,:,None]*torch.cos(2*np.pi*KK*X)[None]
            + b[:,:,None]*torch.sin(2*np.pi*KK*X)[None]).sum(1)
x_c = torch.linspace(1/257,256/257,256)           # 标签网格
x_f = torch.linspace(1/513,512/513,512)           # 参考真值网格
xs  = torch.linspace(0,1,31)                      # 传感器点
ar,br = gen(500); at,bt = gen(100)                # 训练/测试用不同函数
U_tr = fd_solve(256, eval_f(ar,br,x_c))
U_te = fd_solve(512, eval_f(at,bt,x_f))           # 全新函数上的真值
fs_tr = eval_f(ar,br,xs); fs_te = eval_f(at,bt,xs)
# --- DeepONet：branch 读采样值，trunk 读坐标，内积出解 ---
p = 16
branch = nn.Sequential(nn.Linear(31,64), nn.Tanh(), nn.Linear(64,p))
trunk  = nn.Sequential(nn.Linear(1,64), nn.Tanh(), nn.Linear(64,p))
opt = torch.optim.Adam(list(branch.parameters())+list(trunk.parameters()), lr=1e-3)
xq = x_c[:,None]
for ep in range(8000):
    opt.zero_grad()
    pred = branch(fs_tr) @ trunk(xq).T             # [500,256]
    loss = (pred-U_tr).norm()/U_tr.norm()          # 相对 L2
    loss.backward(); opt.step()
# --- 在全新函数上测试 ---
with torch.no_grad():
    pred_te = branch(fs_te) @ trunk(x_f[:,None]).T
err = (pred_te-U_te).norm(dim=1)/U_te.norm(dim=1)
print("test relL2 均值=%.3e 中位=%.3e" % (err.mean(), err.median()))
plt.plot(x_f, U_te[0], "k-", label="truth (FD512)")
plt.plot(x_f, pred_te[0], "r--", label="DeepONet")
plt.xlabel("x"); plt.ylabel("u(x)"); plt.legend()
```
- **实际输出、误差和容差理由：** 本题给定参数（500/100、M=256/512、8000 步）**未在本机运行**。参考行为：训练 relL2 应降到 $\lesssim0.1$，未见函数测试 relL2 中位数约 $0.05\sim0.3$。容差理由：本最小模型容量小（p=16）、步数有限，误差不应像 FD 那样到 $10^{-3}$；若测试 relL2 与训练都 $<10^{-3}$，说明发生数据泄漏，判错。（量级参照：同方法在 800/200、M=256/1024、p=32 配置下实测未见函数 relL2 中位约 0.12、FD 离散误差约 7e-4。）

- **陷阱的正确解释及适用范围：** 同一 $f_1$ 拆点测得的 $2\times10^{-3}$ 度量的是 "该解在不同网格点上的插值 / 记忆误差"，不是算子泛化 —— 训练点与测试点共享同一个 $f_1$，网络只需背下这一条曲线。换全新 $f_2$ 后误差会从 $10^{-3}$ 量级显著升到 $10^{-1}$ 量级。适用范围：凡把 "函数" 误当 "网格点" 做随机划分都会泄漏；正确规则是**按函数整体划分，训练与测试绝不共享任何一个** $f$。

### 6.4-1 参考解答

源任务是原系数范围和给定源函数分布上的解算子学习，目标任务是新系数范围内同类映射。网络在源数据上得到 $\theta_0$，随后由目标数据更新为 $\theta^*$；$k$ 是描述PDE的已知输入，不是网络权重。直接使用保留 $\theta_0$；全量微调更新全部或大部分参数；参数高效微调只更新少量部分或新增模块；从头训练以随机参数为起点。使用旧权重只描述初始化，迁移收益须通过独立目标问题及可比的随机初始化对照判断。

### 6.4-2 参考解答

二阶求导给出 $\widehat u''=-\sum_{m=1}^3m^2b_m\sin(m\pi x)$，因此 $r=\sum_m(km^2b_m-c_m)\sin(m\pi x)$。精确匹配要求 $b_m=c_m/(km^2)$。令 $d_m=km^2b_m-c_m$，则误差为 $e=\sum_m d_m\sin(m\pi x)/(km^2\pi^2)$。由 $\int_0^1\sin(m\pi x)\sin(n\pi x)\,\mathrm dx=\delta_{mn}/2$，有

$$\|e\|_{L^2}^2=\frac12\sum_{m=1}^3\frac{d_m^2}{k^2m^4\pi^4}
\leq\frac{1}{k^2\pi^4}\frac12\sum_{m=1}^3d_m^2
=\frac{1}{k^2\pi^4}\|r\|_{L^2}^2.$$

两端条件由每个正弦基自动满足，不依赖学习；极小端点误差只反映浮点实现与这一结构一致。该推导不适用于随意删除边界后的解族，也不是一般PDE的无条件误差界。
