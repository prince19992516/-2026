## 运行方式

在提交包根目录执行：

```powershell
python -m pip install -r 辅助文件/A1组-6.1-requirements.txt
jupyter-nbconvert --to notebook --execute --inplace --ExecutePreprocessor.timeout=1800 --ExecutePreprocessor.kernel_name=python312 A1组-实验-6.1.ipynb
```

> 本机实际执行使用 `python312`（Python 3.12.10）内核；Notebook 的 `metadata.kernelspec.name` 已按规范设为 `python3`。若当前环境的 `python3` 就是 Python 3.12.10，可把命令中的 `python312` 改为 `python3`。

Notebook 的图片路径为：

```python
FIG_DIR = Path("图片")
```
