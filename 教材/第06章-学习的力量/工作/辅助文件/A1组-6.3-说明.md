# A1组-6.3 运行说明

6.2 的运行说明另见 `A1组-6.2-说明.md`；本文件只说明 6.3 最终 Python 版的运行、数据与命名口径。

## 环境

- 操作系统：Windows 11；CPU（8 逻辑核，训练设 4 线程）。
- Python 3.12.15（Anaconda）；PyTorch 2.14.1+cpu；NumPy 2.5.4；Matplotlib 3.11.2。
- 实验入口：`A1组-实验-6.3.ipynb`，共 21 个单元、14 个代码单元。
- 随机种子：数据生成与训练均为 2024；训练/验证/测试索引固定。

## 运行口径

- 训练/验证/测试函数数 1000/200/200；传感器 $m=32$、输出网格 $M=64$、潜在维 $p=32$。
- Adam，学习率 $10^{-3}$，batch 32；最多 1000 epoch，早停耐心 100。
- 实际运行 948 epoch，最优第 848 epoch，验证相对 $L^2$ 为 4.176e-3；测试均值 4.144e-3、中位数 3.857e-3、P95 7.131e-3、H1 均值 9.257e-2。
- 记忆基线 1.523e-1（约 37 倍）；OOD 幅值 ×1.8 的均值 8.813e-3，频率 $K=8$ 的均值 1.194e-1；网络推理 0.343 ms，谱求解器 0.036 ms，二阶差分 0.049 ms。
- 消融 7 组；$m$ 与 $p$ 的影响在优化噪声内，$N_{\rm train}=100/300/1000$ 对应 1.072e-1/4.889e-2/1.827e-2。

## 时间与检查点

- 正式长任务：948 epoch，总墙钟 807.83 s；其中约 750 s 为系统挂起。无干扰运行约 64.5 s；Notebook 复跑主训练 83.19 s、7 组消融约 174 s，指标与正式记录一致。
- 检查点：`辅助文件/A1组-6.3-模型检查点.pt`，90,087 bytes，对应 948 epoch。二进制权重无法转成文本，保留用于复现评估。
- 正式运行日志：`辅助文件/A1组-6.3-实验日志.md`，保留主实验、消融、成本和图的控制台记录。
