# 6.1—6.4 习题参考解答

## 题1：6.1 PINN原理与实现

1. 由于$(ax+b)''=0$，仿射偏移不会改变内部残差。只施加$u(0)=0$时$b=0$，而$a$仍自由，解不唯一。两个端点一起使用才可排除该自由度。
2. 边界权重为零后，损失无法区分同一二阶导数对应的仿射偏移。网络没有理由一定产生$3x+2$这一特定偏移，也可能偶然给出较小的端点误差；缺少约束是结构性缺陷，不能用某一次偶然结果反驳。该变式为课后扩展，基础实验保留解析反例而不预填未运行数据。
3. 设$u=x(1-x)N$，乘积法则给出$u'=(1-2x)N+x(1-x)N'$，$u''=-2N+2(1-2x)N'+x(1-x)N''$。必须对完整$u$求导，不能遗漏前因子产生的项。两个零端点则由前因子精确保证。
4. 增加配置点可扩充方程检查位置，但固定预算下的网络误差不保证单调下降。配置点分布、初始化及优化是否充分都可能改变结果。应固定评价网格，对每档点数保留多个种子和全部误差；本包基线为64点，16/32点属于学习者扩展。

5. 对完整候选函数求二阶导数。原候选内部残差为零，加入$0.1x^2$后$-v^{\prime\prime}-f=-0.2$。自检应在扰动后报告非零残差，不能用始终为零的表达式替代候选函数。

## 题2：6.2 正问题与反问题

1. 正问题给定$k$求$u$；反问题由方程、边界及观测恢复$k,u$。直接求导可验证$u=\sin(\pi x)/k$。把真值固定在残差中只训练网络，是正问题，不是系数反演。
2. 令$s_j=\sin(\pi x_j)$、$a=1/k$。对$\sum(as_j-y_j)^2$求导得$2\sum s_j(as_j-y_j)=0$，故$\hat a=\sum s_jy_j/\sum s_j^2$。独立零均值同方差噪声下，$\hat a-a_*=\sum s_j\varepsilon_j/\sum s_j^2$，方差为$\sigma^2/\sum s_j^2$。端点$s_j=0$，没有参数信息。正系数估计还要求$\hat a>0$。
3. $\partial_kL_f=-2N_f^{-1}\sum r_{\theta,k}(x_i)u_\theta''(x_i)$。softplus的导数为$dk/d\rho=1/(1+e^{-\rho})$，故$\partial_\rho L=(\partial_kL_f)/(1+e^{-\rho})$。这里网络与$\rho$为独立变量，数据及边界项对$\rho$的直接偏导为零。正性只限制搜索域，所有正$k$仍与端点观测相容。
4. 主反演和三次弱边界诊断见修订Notebook。弱边界误差范围0.008425—0.008476，强边界对应0.000222—0.000231。应分开比较观测RMSE、系数、解、边界和残差，三种启动的共同噪声不能用作噪声置信区间。
5. 源项为$c\pi^2\sin(\pi x)$时，状态为$(c/k)\sin(\pi x)$。$(c,k)=(1,1.5)$与$(2,3)$产生同一状态。需要独立已知源项幅值或系数，或增加能区分二者的其他物理测量；重复测量相同状态不能打破比值歧义。

6. 高斯均值为 $s_j/k$，均值导数为 $-s_j/k^2$，所以 $I(k)=\sum_j s_j^2/(\sigma^2k^4)$。正则无偏估计器方差下界为 $I(k)^{-1}$，标准差下界约0.008825；相对尺度约0.5883%。幅值LS的方差 $\sigma^2/6.5$ 是精确值，倒数LS系数的一阶近似不是精确方差，PINN也不由该下界保证无偏或达到下界。固定噪声6102的系数偏差约为一阶尺度2.92倍。新增独立噪声重复的分位数是经验描述，不是三种初始化得到的参数置信区间。

## 题3：6.3 DeepONet 与 FNO

1. $G$ 的输入是右端项函数 $f$，输出是解函数 $u=G(f)$。$y$ 只是求值位置：$G(f)$ 已经是一个函数，$G(f)(y)$ 才取到该函数在 $y$ 处的值，所以 $y$ 不属于算子的输入。算子 UAT 只保证**逼近误差**可任意小；不保证优化误差（能否训到最优）与泛化误差（未见函数上是否准确），也不保证少量神经元即可逼近。
2. $B=b_\theta(a)\in\mathbb{R}^{N\times p}$，$T=t_\phi(y)\in\mathbb{R}^{Q\times p}$，$\hat U=B T^\top\in\mathbb{R}^{N\times Q}$。$b_k$ 是把整个 $f$ 压成的、与输入函数相关的系数；$t_k$ 是 trunk 在位置 $y$ 读出的基函数值。8 个谐波中每个 $k$ 给出 $\cos 2\pi kx$ 与 $\sin 2\pi kx$ 两个线性无关方向，共 16 个，且在 $(0,1)$ 上两两正交，解族是 16 维线性子空间。$p=32>16$，基的张成空间已覆盖解族，表示误差为零；实际误差来自 branch 回归与 15000 步优化，不是基不够用。
3. 实测（seed=0、CPU）：训练全局 $9.36\times10^{-2}$；训练逐函数均值 $1.33\times10^{-1}$、中位 $1.01\times10^{-1}$、最大 $8.96\times10^{-1}$；测试均值 $1.60\times10^{-1}$、中位 $1.19\times10^{-1}$、最大 $1.20$（200 个中 1 个超过 1，P90 为 $2.72\times10^{-1}$）；FD 粗网格对细网格均值 $7.42\times10^{-4}$、中位 $6.96\times10^{-4}$、最大 $2.71\times10^{-3}$。半 MSE 与相对 $L^2$ 的梯度只差一个正常数因子，Adam 对梯度尺度不敏感，两者更新方向几乎相同，因此训练可用半 MSE、评价用相对 $L^2$；但报告时必须说明各自口径，不能把全局比值填进逐函数列。
4. 离线：组装并分解两组矩阵约 $0.14$–$0.15$ s，数据生成约 $3.8$–$3.9\times10^{-2}$ s（每函数约 $0.039$ ms），训练 15000 步约 $71$–$73$ s。在线：DeepONet 推理 200 个函数（1024 点）约 $2.0$–$2.5$ ms，约 $0.0098$–$0.0127$ ms/函数；FD1024 现场组装+分解+求解约 $136$–$151$ ms，已分解一次求解约 $0.10$ ms。所以"快数个量级"只在"每次重新组装并分解"的口径下成立（约四个数量级，$1.1\times10^{4}$–$1.5\times10^{4}$ 倍）；相对已分解一次求解只快 $8$–$10$ 倍，在一个数量级以内，不是数量级差距。
5. 训练点与测试点共享同一个 $f_1$，网络只需背下这一条曲线，$2\times10^{-3}$ 度量的是该曲线的插值/记忆误差，不是算子泛化。换全新 $f_2$ 后误差会升到 $10^{-1}$ 量级（本节测试均值 $1.60\times10^{-1}$）。正确规则是按函数整体划分：训练用 $\{f_1,\dots,f_{800}\}$，测试用全新的 $\{f_{801},\dots,f_{1000}\}$，任何测试函数都不得在训练中出现。

## 题4：6.4 科学基础模型

以下解答对应[本组习题](习题-修订版.md)。数值讨论使用配套实验保存的运行结果。

### 6.4-1 参考解答

源任务是原系数范围和给定源函数分布上的解算子学习，目标任务是新系数范围内同类映射。网络在源数据上得到 $\theta_0$，随后由目标数据更新为 $\theta^*$；$k$ 是描述PDE的已知输入，不是网络权重。直接使用保留 $\theta_0$；全量微调更新全部或大部分参数；参数高效微调只更新少量部分或新增模块；从头训练以随机参数为起点。使用旧权重只描述初始化，迁移收益须通过独立目标问题及可比的随机初始化对照判断。

### 6.4-2 参考解答

由于 $\widehat u=U_0\sum_m b_m\sin(m\pi x)$ 且 $U_0=\pi^{-2}$，二阶求导中的 $\pi^2$ 与 $U_0$ 抵消。于是 $\widehat u''=-\sum_{m=1}^3m^2b_m\sin(m\pi x)$，因此 $r=\sum_m(km^2b_m-c_m)\sin(m\pi x)$。精确匹配要求 $b_m=c_m/(km^2)$。令 $d_m=km^2b_m-c_m$，则误差为 $e=\sum_m d_m\sin(m\pi x)/(km^2\pi^2)$。由 $\int_0^1\sin(m\pi x)\sin(n\pi x)\,\mathrm dx=\delta_{mn}/2$，有

$$\|e\|_{L^2}^2=\frac12\sum_{m=1}^3\frac{d_m^2}{k^2m^4\pi^4}
\leq\frac{1}{k^2\pi^4}\frac12\sum_{m=1}^3d_m^2
=\frac{1}{k^2\pi^4}\|r\|_{L^2}^2.$$

两端条件由每个正弦基自动满足，不依赖学习；极小端点误差只反映浮点实现与这一结构一致。该推导不适用于随意删除边界后的解族，也不是一般PDE的无条件误差界。

### 6.4-3 参考解答

每个源函数及参数组合完整归属一个数据组。目标范围内生成未参与适配的新源函数作为分布内测试；另在目标训练范围之外预留参数区间形成外推测试。新边界必须显式说明变化，并使模型能够接收相应条件；本模型正弦输出恒为零边界，未经结构修改不能声称覆盖非零边界。同一曲线的网格点拆分会让模型已接触该问题，检验的是已见问题上的补点，而非新的输入函数。分布内外需要相对于目标适配数据定义，不能永远只相对于源任务定义。

### 6.4-5 参考解答

未被表示的精确解部分为 $\sum_{m=4}^{M}c_m\sin(m\pi x)/[k(m\pi)^2]$。由正交性，任意前三项预测都满足

$$\|\widehat u-u\|_{L^2(0,1)}^2\geq\frac{1}{2k^2\pi^4}\sum_{m=4}^{M}\frac{c_m^2}{m^4}.$$

当预测恰好等于精确解的前三个模态时可以取等；只保留第四模态即退化为正文例6.4-2。下界来自表示空间的限制，不能仅通过增加微调步数消除。可以扩充基函数或改变模型结构。这是解析结论。正文实际训练与测试仍采用三个模态，精确解包含在原表示空间中；那里的外推误差不能解释成缺少第四模态所造成的误差地板。

### 6.4-6 参考解答
