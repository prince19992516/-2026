### 核心判断

A1 与 A2 都完整覆盖 4.1 至 4.4，没有遗留的正文空白占位，均可视为正文阶段稿。但两版都存在结构性失衡：

- A2 在 4.4 过度展开“PCA-LoRA-可微求解器”的统一框架。

整合时应以 A2 的教学顺序为主线，只嵌入 A1 中最能支撑核心结论的证明、反例和误差分析。

### 三项最重要的发现

1. **内容完整度：均通过章节级检查。**  
   两版都覆盖 LU / Cholesky、CG / 预条件、特征值 / SVD、可微求解器 / PCA / LoRA，并包含实验、易错点与总结。

2. **教学可读性：A2 明显更适合作为主干。**  
   A2 用定义、例子、结果表逐层推进，段落标题更稳定；A1 的证明价值高，但 4.1 与 4.3 的证明堆叠过密，而 4.2、4.4 又明显偏短。

3. **数学严谨性：A1 更强，但并非“全部正确”。**  
   主要需修正幂迭代的复数相位与特征向量基条件；A2 需修正矩阵扰动界、PCA 计分公式，以及 LoRA 与数据主方向之间的过度断言。

## 5. 定理与关键推导核验

**判定口径：**

- **正确：** 结论与主证明思路成立；
- **有条件：** 结论在明确假设下成立，但正文的适用范围或措辞需收紧；
- **证明不完整：** 结论可以保留，但当前证明不足以独立闭环；
- **有错误：** 若照现文讲授会误导读者，整合前必须修改。

## 6. 整合前必须修正的六个问题

### 6.1 A2 的系数矩阵扰动界缺分母

若 `A` 可逆、`A+delta A` 仍可逆，令

```text
epsilon = kappa(A) * ‖delta A‖ / ‖A‖
```

在 `epsilon<1` 时可用：

```text
‖delta x‖ / ‖x‖ <= epsilon / (1-epsilon)
```

更紧的形式使用

```text
delta = ‖A^-1 delta A‖ < 1
```

分母写为 `1-delta`。A2 当前省略分母，不能无条件成立。

### 6.2 A2 的 PCA 矩阵方向和计分不一致

A2 取 `X in R^(d x n)` 后写 `X=U Sigma V^T`，且 `U` 的列是主方向；此时计分应写成 `U_r^T X`。文中 `V_r^T X` 一般既不是同一维度的计分，也不是对应 `U` 的主成分。

整合时建议统一为“样本×特征”矩阵：

```text
X_c in R^(n x d)
X_c = U Sigma V^T
```

- 主方向为 `V` 的列；
- 计分为 `X_c V_r`；
- 重构为 `X_c V_r V_r^T`。

### 6.3 LoRA 与 PCA 主方向的关系需要降格

在线性层、平方损失和岭回归模型下，最优增量可写成

```text
Delta W* = sum_i [g_i / (lambda_i + gamma)] v_i^T
```

其中 `v_i` 是数据协方差的主方向。这说明行空间可被主方向描述，但不能推出“LoRA 的最优秩 `r` 近似恰好在这些主方向上”。秩 `r` 的最优左右奇异子空间还取决于 `g_i` 的大小，标准 LoRA 也不是对 `Delta W*` 做一次 SVD 截断。

**建议保留的表述：**

LoRA 的核心事实是：它把可训练更新 `Delta W` 限制为秩不超过 `r` 的矩阵，参数量由 `kd` 降为 `r(k+d)`。Eckart-Young 可以解释为什么低秩重构有用，但不能保证任务效果，也不自动把 PCA 主方向变成 LoRA 的最优参数化方向。

### 6.4 幂迭代必须收紧条件

教材主线建议只使用“实矩阵、主特征值简单且严格占优、初值主特征投影非零”的版本。若矩阵有复特征值，归一化向量会保留相位，不能写成一概趋向正负 `v_1`；若特征向量不正交，Rayleigh 商的展开也不能直接写成 `c_i^2` 的实平方和。

### 6.5 追赶法与 Cholesky 的“稳定”措辞要收紧

对角占优能保证追赶法无零主元和乘数有界，是重要的稳定性依据；但“误差不会被放大”不等于对任意问题成立，前向误差仍与条件数有关。

同理，Cholesky 对 SPD 矩阵无需主元，不代表病态矩阵的误差就小。

### 6.6 统一 PCA 的 `1/n` 与 `1/(n-1)` 约定

A1 使用样本协方差 `1/(n-1)`，A2 多处使用 `1/n`。二者只差常数缩放，不改变主方向，但必须全章统一并在首次出现时说明。

建议样本协方差写 `1/(n-1)`。若把

```text
C = XX^T / n
```

称为二阶原点矩或 scatter matrix，则必须明确写出。
