# 脚本目录：做什么、什么时候用、怎么用

“脚本”就是可以执行的程序文件。**本目录只保留`构建教材.py`：把已写好的章节整理成HTML网页教材。** 日常写作不需要到这个目录里操作。

| 文件 | 做什么 | 什么时候用 |
| --- | --- | --- |
| 构建教材.py | 按教材/_toc.yml的章节顺序，把正文、Notebook代码及已保存输出排版成网页 | 想查看整本教材，或交给老师汇总时 |
| README.md | 当前这份文字说明 | 不清楚操作时阅读，不用运行 |

## 先安装，再使用

从没安装软件的电脑先完整阅读[环境安装教程](../教程/01-环境安装与运行.md)。按教程亲手创建.venv、安装库并登记内核以后，在JupyterLab亲自运行Notebook，核对输出，按Ctrl+S保存。生成程序使用保存下来的内容，不执行Notebook代码，也不判断公式或AI回答是否正确。

## 推荐操作：让课程助手替你运行

1. 打开课程根目录，就是同时看得见`course.cmd`、`course.py`、`教材`和`脚本`的那一层。
2. 在文件资源管理器地址栏输入`powershell`，按回车。若原来的终端正在运行Jupyter，保持它打开，另开这个窗口即可。
3. 输入下面这一条，按回车并等待：

```powershell
.\course.cmd build
```

4. 看到“构建完成”后，再输入：

```powershell
.\course.cmd preview
```

5. 打开浏览器，在地址栏输入[http://127.0.0.1:8000](http://127.0.0.1:8000)，即可查看整本教材。预览时终端持续运行是正常的，看完后按Ctrl+C停止。

Windows也可双击根目录`course.cmd`，输入`2`生成教材，完成后输入`3`预览；输入`0`退出菜单。macOS/Linux在课程根目录分别运行`python3.12 course.py build`、`python3.12 course.py preview`。

## 如果想直接运行这个Python文件

这与助手的build做的是同一件事，两种方式选一种即可。**仍然在课程根目录的终端输入，不能放进Notebook代码单元，也不用先cd到脚本目录。**

Windows：

```powershell
.\.venv\Scripts\python.exe 脚本/构建教材.py
```

macOS/Linux：

```bash
.venv/bin/python 脚本/构建教材.py
```

前半段指定本课程安装好的Python，后半段指定要运行的程序。运行结束会回到终端提示符，然后再用preview查看网页。不要把这两条不同系统的命令一起输入。

## 结果放在哪里

生成文件在`教材/_build/html/`，首页是index.html。源文件仍在各章目录，不会被生成程序覆盖。之后修改教材，需要重新运行并保存涉及的Notebook，再重新生成网页。

`教材/_ext/local_images.py`是配套的图片路径兼容程序，由构建过程调用，保证中文图片名能正常显示；不需要单独运行。

没有图表或结果时，先确认相应Notebook运行后已经保存；只写了代码但没运行，网页不会凭空产生输出。需要更多说明，阅读[生成与查看教材](../教程/05-生成与查看教材.md)。
